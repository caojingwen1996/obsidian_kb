### 如果今天这是一笔现金，我会买它吗

- 回答：不会；只在特定条件下重新评估。
- 我的判断：国药现代的央企平台、原料药 + 制剂一体化和分红能力仍有底，但当前最重要的变量不是估值便宜，而是盈利是否还在下修。H1 预告确认原料药板块毛利率从 32.04% 降到 17.32%，这个幅度足以压低估值中枢。

## 4. 商业模式与竞争格局

### 4.1 事实

- 收入来源：医药中间体与原料药、化学制剂、动物疫苗、大健康等。
- 客户与定价权：制剂端受国家和省级带量采购、医保控费和终端渠道影响；原料药 / 中间体端直接服务国内终端客户，国际市场面向境外医药企业与贸易商，价格受全球产能、贸易保护和客户需求影响。
- 成本结构：制造业属性明显，原料药 / 中间体毛利率对价格高度敏感；制剂端需要研发、销售和合规体系。
- 资本强度：拥有多剂型生产线，推进 MES、LIMS、ERP 等系统建设；2026Q1 固定资产约 50.57 亿元。
- 竞争者：化学仿制药和抗生素产业链企业，包括普洛药业、华海药业及其他仿制药 / 原料药公司。
- 监管约束：GMP、药品注册、仿制药一致性评价、集采、医保和环保安全监管。

- 位置间交叉与去重说明：原料药和制剂存在产业链一体化协同，但估值时不能把同一抗感染产品链条重复计入。

- 弱关联 / 待验证位置：大健康和动物疫苗暂不构成核心估值驱动。

### 4.2 我的判断

- 我的判断：公司具备央企平台、国药集团协同、原料药 + 制剂一体化和多治疗领域产品组合优势，但这些优势当前只能提高生存质量，不能抵消原料药价格坍缩。
- 我的判断：商业模式最脆弱环节是“集采向上游传导 + 原料药产能过剩 + 海外保护主义”三者同时压价格，导致以价换量失去利润弹性。
- 证伪条件：H2 原料药 / 中间体毛利率企稳回升、制剂毛利率不再下滑、扣非净利恢复同比增长。

### 11.9 风险传导链

- 信息源头：2026Q1 报告与 2026H1 业绩预告。
- 核心变量：抗生素类医药中间体及原料药价格与毛利率。
- 传导机制：海外保护主义 + 国内产能过剩 + 集采向上游传导 → 公司以价换量 → 毛利率从 32% 附近降至 15%-17% → 归母和扣非利润大幅下降 → 估值锚从低 PB 修复转为盈利下修。
- 影响对象：国药现代利润表、PB-ROE 估值、交易情绪。
- 市场行为变化：年初以来下跌，低位反弹但未形成强趋势。
- 风险方向：风险重新增强。
- 验证指标：H1 正式报、H2 毛利率、原料药价格、股价是否跌破 7.67 元。
- 失效条件：价格压力缓和、半年报利空钝化、扣非利润环比改善。

### 11.10 风险方向结论

- 风险方向结论：风险重新增强。
- 判断依据：2025 年已有收入利润下滑，2026Q1/H1 预告进一步大幅恶化，且原因直指核心板块毛利率坍缩。
- 反证：公司仍盈利、低 PB、央企平台和分红仍有防御价值。
- 未获取到：融资融券、资金分档、行业价格序列。
- 置信度：中高。

### 11.12 最终动作与约束

- 主动作：wait / observe。
- 新增现金：不买，等待 7.5-8.0 元或 H2 经营改善证据。
- 已有持仓：review；高成本仓在反弹接近 9.6 元且无业绩修复时考虑 reduce。
- 承接条件：H1 正式报不低于预告中枢、H2 毛利率改善、成交放大站稳 9.6 元。
- 退出条件：跌破 7.67 元、H2 指引继续下修、原料药毛利率低于 17% 且无改善。
- 下一复核节点：2026 半年报。
- 我的判断：方向不能转化为买点，因为估值便宜被盈利下修抵消，三要素没有共振。

## 12. 最终结论

- 估值结论：合理偏高。不是绝对高估，但相对当前盈利下修风险，现价没有足够安全边际。
- 操作结论：观望 / 规避新增。
- 综合估值区间：6.8-9.6 元。
- 相对现价空间：上行约 +7.6%，下行至下沿约 -23.8%。
- 如果今天这是一笔现金，我会买它吗：不会。
- 我的判断：国药现代的低 PB 和央企背景值得跟踪，但 2026H1 预告确认主业风险正在重新增强。当前更像“等待利润坑确认是否到底”的标的，而不是“便宜就买”的标的。
- 结论失效条件：H1 正式报和 H2 经营数据显示毛利率企稳，扣非利润环比改善，股价在利空后不跌并放量站稳 9.6 元。
