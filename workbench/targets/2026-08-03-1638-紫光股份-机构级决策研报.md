## 4. 商业模式与竞争格局

### 4.1 事实

- 收入来源：新华三为核心，覆盖网络设备、服务器、存储、云与智能平台、安全、终端和 IT 分销供应链。
- 客户与定价权：政企、运营商、金融、互联网和行业客户；网络设备份额强，服务器和硬件放量阶段定价权弱于收入弹性。
- 成本结构：硬件、芯片、存储、供应链和渠道成本占比较高；2025 年毛利率代理 14.59%，2026Q1 约 12.88%。
- 资本强度：固定资本开支不高，但营运资金占用重；2026Q1 存货 453.06 亿元、应收账款 146.22 亿元。
- 竞争者：华为、浪潮信息、中兴通讯、锐捷网络、联想、星网锐捷等。
- 监管约束：A股信息披露、国资与产业安全约束、定增审核和融资成本约束。

### 4.2 我的判断

### 4.4 企业价值类型与主估值锚

- 企业价值主类型：成长企业。
- 分类依据：利润增长依赖新华三权益提升、算力网络 / 服务器需求和经营效率改善；资产结构和现金流尚不足以按稳定盈利企业处理。
- 分部类型映射：ICT 基础设施为已验证基本盘；IT 分销为低毛利基本盘；AI 服务器 / 算力网络为商业化成长业务；光互联 / 超节点为前沿期权业务但证据不足。
- 主估值锚：2026—2027 年未来利润 × 届时合理 PE 后折现。
- 必做交叉验证：可比公司 PE / PB、新华三权益价值、自由现金流质量、反向估值。
- 价值创造链：渠道 / 产品矩阵 → 收入增长 → 利润率稳定 → 现金回款 → 少数股权收购增厚归母 → 摊薄后 EPS 增长。
- 核心价值驱动及可持续时间：算力网络与服务器景气至少到 2026—2027 年，但需要每季验证。
- 市场目前可能低估的因素：新华三权益提升后的归母利润增厚和数据中心网络份额。
- 市场目前可能高估的因素：把服务器低毛利收入、光互联 / 超节点叙事和定增进度线性外推。
- 价值创造链证伪条件：毛利率继续下行、经营现金流不改善、应收 / 存货继续快于收入、定增高摊薄低增厚。

- 三表扫描对估值状态的约束：不能升级为买入；更接近普通高估 / 安全边际不足，而不是严重泡沫。

## 12. 最终结论

- 企业价值主类型：成长企业。
- 分部类型映射：ICT 基础设施为已验证基本盘；AI 服务器 / 算力网络为商业化成长业务；光互联 / 超节点为前沿期权但证据不足。
- 主估值锚：2026—2027 年未来利润 × 届时合理 PE 后折现，并用现金流、分部价值和反向估值交叉验证。
- 价值创造链及可持续时间：新华三产品和渠道承接算力网络需求，利润修复后通过少数股权收购转化为归母增厚；至少按 2026—2027 年季度验证。
- 估值结论：合理偏高 / 普通高估，主要问题是安全边际不足。
- 操作结论：新增现金 wait / observe，不追高；已有持仓 review，成本高且仓位重时降低单日波动暴露。
- 公允价值区间：30—40 元；中枢约 35 元。
- 相对现价空间：以 36.43 元计，下沿 -17.7%，上沿 +9.8%。
- 如果今天这是一笔现金，我会买它吗：不会；等半年报和更好的价格。
- 我的判断：紫光股份是有方向资格和核心资产的公司，但 36 元上方已经把 H1 预告和算力网络乐观预期计入较多。没有正式现金流和毛利率验证前，新增现金不该用追高方式表达。
- 宏观价格环境及净影响：中等暴露；经营层看成本和周转，金融层看海外长债、日元和 A 股两融高位，净影响是压低估值容错率。
- 结论失效条件：2026H1 正式报告显示扣非接近上沿、毛利率企稳、经营现金流显著收窄或转正，且定增条款证明 EPS 增厚大于摊薄。
- 改变通胀结论的条件：芯片 / 存储 / 汇率成本稳定并通过毛利率体现，或海外利率 / 日元风险显著缓和。
- 估值锚失效后的退出条件：未来利润锚失效；若 H1 / Q3 利润不能延续、毛利率继续下行、经营现金流持续为负且股价反弹仍无长期资金承接，应从 review 降为 reduce / avoid 复核。
