# 冰冰小美-风险体系

## 主题说明

风险体系不在三要素里，但它在三要素之前。**先认识风险，再判断方向，再看流动性，最后通过情绪位置来执行。**


---


| 层次                      | 名称          | 回答的问题            |
| ----------------------- | ----------- | ---------------- |
| 相对稳定的定义 RiskDef         | **风险定义与机制** | 这是什么风险，如何形成和传导？  |
| 某一时点的切片 `risk_snapshot` | **风险状态快照**  | 此刻风险处于什么状态？      |
| 多个切片的连续观察               | **风险演化轨迹**  | 风险怎样从此前状态变成当前状态？ |

### 风险快照核心变量影响证据记录

config_variable
= 全局变量配置库
= 一个可持续观察、可被多个 Risk 复用的“核心变量定义”。

`risk_snapshot_variable_evidence`
一行代表：某份风险快照中，一个核心变量当前发生了什么、发生了怎样的变化、这种变化对风险产生什么方向和强度的作用，以及形成该判断的解释和证据。

|字段|字段类型|属性性质|含义|生成方式|
|---|---|---|---|---|
|`id`|UUID|描述性|记录ID|系统生成|
|`risk_snapshot_id`|UUID / FK|描述性|所属风险快照|关联 `risk_snapshot.id`|
|`risk_source_id`|VARCHAR / FK|描述性|该变量来源的风险源|引用风险源配置|
|`variable_id`|VARCHAR / FK|描述性|核心变量|引用变量配置|
|`observed_state`|ENUM / VARCHAR|分析性|核心变量当前状态|根据该变量下的观测指标综合判断|
|`change_direction`|ENUM|**分析性 / 跨快照派生**|相比上一快照的变化方向|上升 / 下降 / 稳定|
|`change_magnitude`|ENUM / DECIMAL|**分析性 / 跨快照派生**|相比上一快照的变化幅度|小 / 中 / 大，或标准化数值|
|`change_momentum`|ENUM|**分析性 / 跨快照派生**|变量变化速度|加速 / 稳定 / 减速|
|`risk_effect`|ENUM|分析性|当前变量状态及变化对风险的作用方向|`AGGRAVATE / NEUTRAL / MITIGATE`|
|`effect_strength`|ENUM|分析性|对风险作用强度|弱 / 中 / 强|
|`interpretation`|TEXT|分析性|对“变量状态/变化 → 风险变化”的解释|LLM / 规则 / 人工生成|
|`confidence`|DECIMAL(3,2)|元数据|本条分析可信度|根据指标完整度、一致性等计算|
|`analysis_method`|ENUM|元数据|分析方式|`RULE / LLM / HUMAN / HYBRID`|
|`observed_at`|DATETIME|描述性|本次变量状态对应时间|取本轮观测时间|
|`created_at`|DATETIME|元数据|记录生成时间|系统生成|

对长期配置，《波动风险》明确说长期看好仍可以调整仓位；对突然变化，






**三要素：用三要素辨别主导力量和条件变化**

《体系的三要素的联动》明确写出“竞争格局的比较优势＞流动性辩证分析＞情绪位置的变化”，并分别用情绪转弱、流动性变化解释两次风险提示，同时判断长期竞争格局是否变坏。这支持的理解是：短期情绪可能恶化，资金条件也可能恶化，但长期产业优势未必同步变化；需要辨别哪一种力量主导行情及其持续性。[[sources/manual/体系及案例分析/一、核心体系/5、仓位管理与交易策略/117_情绪体系认知篇第一期：体系的三要素的联动#正文|《体系的三要素的联动》]]

《风险转弱的节点》进一步从宏观、中观、微观、交易变化讨论改善，并列举情绪冰点转折、指数信心转折、库存周期转向、长周期变化等窗口，最后提出三要素同步有利的买入要求。这里既有不同尺度的风险转折，也有具体交易条件，不能全部压成一个统一买点。[[sources/articles/2026-05-21-冰冰小美：风险转弱的节点#正文|《风险转弱的节点》]]


**个人风控：资金安排、心理承受和交易模式，决定同一种风险对你的伤害。*
    
  《交易心理分析的重要性》把仓位过重、生活收入压力、急于靠股市改变处境，与心理失衡联系起来；还明确区分短期和长期容错率：低估值可能改善长期参与条件，同时短期交易依然困难。由此不能把“长期看好”直接等同于“当前仓位适合自己”。[[sources/articles/2025-07-26-冰冰小美：交易心理分析的重要性#原文内容|《交易心理分析的重要性》]]

《模式的失效》强调，同一市场中的短线套利和长期投资需要不同的风险审视；过去赚钱的模式会因资金、情绪和驱动因素变化而失效。《科普交易工具风控》又指出，普通人的工具条件有限，理解工具缺陷与交易中的不利处境，本身就是风控的一部分。[[sources/manual/体系及案例分析/一、核心体系/5、仓位管理与交易策略/120_情绪体系认知篇第四期：模式的失效#正文|《模式的失效》]]、[[sources/manual/体系及案例分析/三、实战操作/1、套利机会与风险提示/249_科普交易工具风控#正文|《科普交易工具风控》]]
