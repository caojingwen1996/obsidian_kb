# 冰冰小美-风险传导路径总结

## 风险的定义与观察框架

### 风险的定义

**投资风险，是在不确定的变化中，由于资产价值受损、定价缺乏支撑、资金约束或行为失误，使投资者遭受损失的可能性。**



### 风险的观察角度

风险来源变化 → 具体如何传导 → 哪些主体受影响。
风险驱动因素 → 风险路径 → 市场风险维度 → 资产表现





| 观察层次           | 回答的问题              | 需要记录的内容                                       |
| -------------- | ------------------ | --------------------------------------------- |
| **风险来源**       | 发生了额什么？什么变化可能带来损害？ | 宏观变量与事件、产业供需与制度变化、企业经营事件、资金与交易结构变化；注明起因、方向和时间 |
| **风险形成与传导路径**  | 这些变化影响了哪一方面？       | 基本面、估值、流动性、情绪中适用的机制及其作用顺序；保留跨机制反馈             |
| **风险暴露（影响对象）** | 谁会受影响，程度多大？        | 公司、股票、股东、基金或持仓账户；暴露规模、集中度、杠杆、期限及缓冲条件          |

**监测证据**

| **监测证据**      | 这条损害路径是否成立，是否正在变化？  | 事件落地、指标与市场反馈、当前和比较窗口、支持证据、反证及证据缺口          | 据证据评估可能后果；区分已经发生的损害与尚待验证的情景 |
| ------------- | ------------------- | ------------------------------------------ | --------------------------- |
| **损失后果与可恢复性** | 可能损失什么，能否恢复，能否等到恢复？ | 资产价值与价格支撑、可能损失程度和持续时间、恢复条件，以及投资者的资金与行为承受能力 | 将恢复所需条件和失效条件纳入后续跟踪，更新风险判断   |

同一来源可以通过多类机制影响不同主体，不要求凑齐四类风险。观察框架不是固定的事件发生顺序；持续监测所得证据，也可能推翻原先认定的来源、机制或暴露。


#### 风险等级

风险等级 = 异常程度 + 变化速度 + 持续性 + 影响范围

| 维度   | 能说明什么             | 需要注意什么            |
| ---- | ----------------- | ----------------- |
| 异常程度 | 当前偏离正常状态有多大       | 异常不一定有害，要说明如何造成损害 |
| 变化速度 | 风险是否快速恶化、应对时间是否缩短 | 快速缓和也是变化快，必须结合方向  |
| 持续性  | 不利条件是否会长期存在       | 长期轻微风险不一定高于短期致命冲击 |
| 影响范围 | 风险波及哪些主体、市场或环节    | 范围小也可能对特定主体造成严重损失 |

## **风险来源**


风险源与传导机制 → 提取关键变量 → 配置观测指标 → 记录风险快照。

| 概念        | 回答什么            | 债务风险示例              |
| --------- | --------------- | ------------------- |
| **关键变量**  | 什么因素决定风险大小与持续性？ | 再融资能力               |
| **观测指标**  | 用什么证据观察这个变量？    | 续贷获批比例、新发行债券利率、融资期限 |
| **指标观测值** | 某个时点具体是什么情况？    | 本期续贷获批比例为多少、较上期如何变化 |
|           |                 |                     |

**如何提取关键变量？**
- 它变化时，是否会明显改变风险判断？
- 它是否决定某个传导环节能否成立？
- 它是否决定风险何时加剧、转弱或解除？
