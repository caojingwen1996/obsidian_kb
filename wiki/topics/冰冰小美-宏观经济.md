# 冰冰小美-宏观经济

## 主题说明


##  基本概念

宏观经济的组成部分：实体经济 → 财政 → 货币金融 → 对外部门

| 领域       | 描述：当前发生什么               | 解释：背后机制是什么              | 政策：怎么办                   | 对应政策体系               |
| -------- | ----------------------- | ----------------------- | ------------------------ | -------------------- |
| **实体经济** | GDP、就业、消费、投资、通胀         | 增长机制、经济周期、供需机制、就业机制     | 稳增长、促消费、扩投资、稳就业、产业扶持     | **经济增长政策、就业政策、产业政策** |
| **财政**   | 财政收入、财政支出、赤字率、政府债务      | 财政乘数、赤字形成、债务可持续性        | 增减税、扩大/压缩支出、补贴、发债        | **财政政策、政府债务管理**      |
| **货币金融** | 利率、M1/M2、流动性、信用、杠杆、资产价格 | 利率传导、货币创造、信用扩张与收缩、金融加速器 | 加降息、降准、公开市场操作、QE/QT、信贷调控 | **货币政策、宏观审慎政策、信用政策** |
| **对外部门** | 汇率、进出口、经常账户、资本流动、外汇储备   | 汇率形成、国际收支、利差与资本流动机制     | 外汇干预、汇率管理、资本流动管理、贸易措施    | **汇率政策、国际收支政策、贸易政策** |


**财政政策周期：**

政府财政政策从扩张到收缩，再到下一轮扩张的循环。
主要观察：赤字率 + 发债规模 + 利息支出

| 阶段        | 财政特征   | 常见动作          | 经济影响         |
| --------- | ------ | ------------- | ------------ |
| 财政扩张  | 赤字扩大   | 减税、增加政府支出、发债  | 拉动需求、刺激经济    |
| 财政加速  | 赤字继续扩大 | 大规模基建、补贴、转移支付 | 经济和通胀可能进一步上升 |
| 财政收缩  | 赤字缩小   | 减少支出、增税、控制债务  | 需求降温、经济增速承压  |
| 财政再平衡 | 债务压力缓和 | 恢复财政空间        | 为下一轮扩张做准备    |


**货币政策周期：**

宽松 → 紧缩 → 再宽松

央行可以使用：加息/降息 QE/QT  YCC 前瞻指引 流动性工具
其中 利率周期属于货币政策周期里最重要的表现形式之一：
**加息周期 → 高利率平台 → 降息周期 → 低利率平台 → 下一轮加息。**
