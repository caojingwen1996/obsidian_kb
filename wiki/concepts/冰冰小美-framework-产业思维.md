# 产业思维

## 一句话定义

纵向看产业演化，负责发现方向和建立候选池


## 概念要解决的问题


如何利用产业思维寻找企业？

|层级|解决的问题|
|---|---|
|产业判断|这个产业值不值得长期跟踪？|
|阶段判断|当前处于启动、主升、泡沫、出清还是二次成长？|
|个股筛选|产业确定以后，应该选哪家公司？|
- **国家战略、全球竞争、产业阶段、市场阶段、资金、产业扩张** → 属于产业判断
- **需求、供给、技术、第二曲线** → 属于产业景气判断
- **龙头、财务验证、风险、最终决策** → 才真正进入选股

## 具体的分析
### 一、产业研究

#### 产业战略地位

战略方向：国家和时代为什么需要这个产业

此问题在[[冰冰小美-macro-国运||国运]]话题下讨论

国家战略方向 + 产业发展趋势 + 企业自身价值兑现

国家需要+产业扩张+企业订单、利润、竞争力持续兑现

#### 产业空间有多大？

**产业结构**

识别产业推进被什么卡住，例如资金、技术、资源、牌照、标准、场景、成本、库存、定价权或组织能力。约束条件决定产业的推进速度，也决定哪个环节最可能获得资本、政策或订单支持。

分析这个企业在产业链的地位。比如是否产业的核心材料，设备，有没有技术含量，技术壁垒，与谁合作，订单来自哪里，

研究产业链、上下游、核心环节、价值分配、关键约束。

**产业天花板：这个产业最终能做多大**

### 二、行业研究


#### **行业景气周期**

回答当前这一轮行业当前经营状态如何？时间跨度为数月—3年

衰退期（Contraction）  
→ 谷底（Trough）  
→ 复苏期（Recovery）  
→ 扩张期（Expansion）  
→ 繁荣/峰值（Boom / Peak）  
→ 收缩期（Contraction）

行业与宏观经济周期的关系:

**顺周期**：与宏观经济周期走势相同，包括：
工程机械、钢铁、有色、化工、航运、券商、可选消费

**逆周期**：经济越差，部分需求反而增强，包括：
债务重组、破产清算、部分折扣零售、职业培训、部分黄金相关业务

**弱周期/防御性**: 经济好坏对需求影响较小
医药、公用事业、必选消费、电信



需求决定当期增长，供给决定景气强度，库存和价格验证供需状态，资本开支决定未来供给。

| 子周期         | 核心问题                                       | 主要指标                 |
| ----------- | ------------------------------------------ | -------------------- |
| **供需周期**    | 供给和需求谁增长得更快？                               | 产量、销量、产能利用率、价格       |
| **库存周期**    | 当前在补库存还是去库存？                               | 库存、库销比、库存同比          |
| **资本开支周期**  | 企业是在扩产还是收缩投资？<br>当前资本开支形成的新产能，将如何改变未来供需关系？ | Capex、在建工程、设备订单、新增产能 |
| **利润周期**    | 产业景气目前停留在订单端、收入端、利润端，还是已经进入现金流兑现阶段。        | 毛利率、净利率、ROE、利润增速     |
| **价格周期**    | 产品价格处于上涨还是下跌阶段？                            | ASP、商品价格、价差          |
| **信用/融资周期** | 企业融资环境松还是紧？                                | 利率、信用利差、贷款、发债        |

 **各个周期的观测指标**

| 维度    | 监测指标         | 指标含义             | 利好方向 |
| ----- | ------------ | ---------------- | ---- |
| 需求    | 新增产能增速       | 观察供给扩张速度及未来过剩风险  |      |
