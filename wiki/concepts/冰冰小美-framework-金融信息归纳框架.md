# 冰冰小美-framework-信息归纳框架

## 一句话定义

归纳，是从海量信息中筛选出能够改变市场行为的信息，并通过持续跟踪这些信息，判断风险正在增加还是减弱，从而决定哪些方向应该回避、哪些方向可以逐渐参与。

## 核心内涵

### 归纳什么？

> “归纳内容的核心要点是在于这种信息会引发市场行为变化，特别是其相关风险评估。”



分类维度:  
按来源：市场数据（股价、汇率）、机构数据（财报、监管报告）、用户数据（交易记录、信用评分）。  
按功能：风险类（波动率、违约率）、交易类（订单流、流动性）、分析类（行业趋势、政策解读）  
  

关注：引发市场行为变化的信息 + 风险变化。

|建档级别|信息源类型|建档条件与用途|
|---|---|---|
|**核心源：长期建档**|央行、财政及统计部门、重要政策发布机构、监管机构与交易所|持续提供货币、财政、制度和经济运行的一手材料，是长期判断的依据|
|**专题源：按研究需要建档**|公司公告与投资者关系栏目、行业协会、产业统计机构、相关主管部门|与正在跟踪的产业、企业或风险直接相关，能提供连续数据或执行证据|
|**观察源：试用建档**|研究机构、专业媒体、专家和分析者|能持续提供独特线索，引用可追溯，观点可以事后验证；需要记录立场、利益关系和纠错情况|
|**线索源：通常不独立建档**|聚合平台、转载号、匿名爆料、偶然看到的文章|仅记录具体线索及原始出处；持续提供独特且可验证的信息后，再升级为观察源|
### 怎么归纳？

信息归纳表

| 层级       | 归纳内容                | 核心问题                                            | 冰冰小美文中的案例                                                  |
| -------- | ------------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| 第一层：事件节点 | 记录发生了什么             | 事件=**发生了什么重要事情？**<br><br>节点=现实从状态A切换到了状态B的那个节点。 | 房地产出现恒大等信用事件；美元信用问题升温；化工品涨价；外资风险上升                         |
| 第二层：影响   | 判断事件改变了哪些金融或产业变量    | **这件事改变了什么？**<br>流动性？通胀？信用？                     | 房地产信用事件导致融资环境恶化；美元信用问题带来输入性通胀预期；化工涨价改变产品价格预期；美股风险影响外资流动性   |
| 第三层：市场行为 | 判断机构、散户、外资、游资等会如何行动 | **这个信息有没有能力改变人的行为？**                            | 房地产风险上升后，资金持续回避地产板块；化工长期下跌后散户集中度降低、筹码出现断层；重大政策出现后短期形成羊群效应  |
| 第四层：金融反应 | 判断风险方向和风险程度         | **风险正在增加、减弱，还是维持高位？**                           | 房地产信用危机扩散 → 风险增加；政策持续托底、信用环境改善 → 风险减弱；量化、减持、流动性恶化 → 波动风险增加 |
| 第五层：长期跟踪 | 把单一事件放入时间线持续观察      | **后续有没有新的证据确认或推翻原判断？**                          | 光伏技术突破→产业扩张→产能过剩                                           |
