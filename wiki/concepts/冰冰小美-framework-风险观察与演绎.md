## 概念要解决的问题

如何观察风险变化
## 核心内涵

风险会随着时间和事件演化，判断风险要先定位时间节点，再追踪事件变化，最后识别真正决定风险持续性的核心变量。

1.[[2025-09-20-冰冰小美：风险变化如何观察|观察风险]] 不是印证和应对，只需要实事求是。
2.观察风险的两个维度：
- 一是时间，时间的变化，风险也会变化。
- 二是观察变化，变化意味着，一个一个不同的事件发生，因此，有必要把，这一段时间的各种宏观，中观，微观，按照时间顺序记录下来，以便于理解事件在特定时间内的连续性与相关联系紧密程度。（通过信息的归纳进行观察）


## 观察风险变化的方法论

```
                 新信息持续进入
                       ↓
                 【信息归纳】
                       ↓
                  判断相关性
                 ↙           ↘
         与当前风险无关      与当前风险有关
               ↓                 ↓
          信息库继续积累      风险演绎时间轴
                                  ↓
                         风险来源有没有变化
                                  ↓
                         核心变量有没有变化
                                  ↓
                         风险增加/维持/减弱
```


风险观察以已经完成的[[冰冰小美-framework-信息的金融处理|信息处理结果]]作为输入。

输入： 
- 已识别的核心问题 
- 结构化事件及时间轴
- 共同现象 
- 核心变量 
- 信息归纳结果 
风险观察不再负责信息获取、事件提取、信息分类、时间窗口建立、事件聚合和共同变量提炼。

风险观察只回答两个问题：
1. 当前这些信息反映的是什么风险？ 
2. 已经识别出的风险，后续是在增加、维持还是减弱？


### 第一层：风险识别：是什么风险？为什么？

建立“风险模型”。

解决的问题：

> 当前已经归纳出的信息，反映的是什么风险？风险从哪里产生？什么变量决定它后续如何演化？

**第一层输出：Risk Model**

风险识别完成后形成一个稳定的风险观察基准：

```
Risk Model
│
├─ Risk Type
│   风险类型
│
├─ Risk Manifestation
│   风险表现
│
├─ Risk Source
│   风险来源
│
├─ Risk Key Variable
│   风险关键变量
│
└─ Risk Transmission Path
    风险传导关系
```

这个 Risk Model 是后续风险演绎观察的基准。


**Step 1：识别风险表现**

先识别当前已经出现的异常或不利表现。

回答：

> 风险具体表现在哪里？

例如：

- 流动性明显收紧
- 信用环境恶化
- 市场波动率快速上升
- 融资可得性下降
- 资产价格出现持续异常波动
- 某产业经营环境明显恶化

风险表现是已经观察到的结果。

这一阶段只描述风险表现，不解释风险来源。

**Step 2：确定风险类型**

风险类型用于给当前问题建立风险观察对象。


- 定风险类型：这属于什么风险？（风险类型的定义参考：[[冰冰小美-indacator-风险类型]]）

**Step 3：识别风险来源**

回答：

> 是什么因素正在推动这个风险形成或扩大？

风险来源指风险形成的驱动力。(风险来源定义参考[[wiki/topics/冰冰小美-风险来源与传导路径]]：)

找风险来源：由什么变量驱动？
- 找核心变量：哪个变量最能够决定风险继续演化还是结束？
- 
**Step 4：确定风险关键变量**

回答：

> 哪个变量最能够决定风险继续强化、维持还是减弱？

这里的“风险关键变量”与信息处理阶段得到的“共同变量”含义不同。

```
信息处理的 Core Variable
=
大量信息共同收敛到什么变量

风险关键变量
=
什么变量最能决定风险下一步如何演化
```

风险关键变量应满足：

- 与风险来源存在直接关系；
- 能够反映风险程度变化；
- 后续可以持续观察；
- 其变化能够改变风险状态判断。

输出：

```
Risk Key Variable
```

**Step 5：建立风险传导关系**

在风险类型、风险来源和风险关键变量明确以后，建立风险自身的传导结构。

推荐结构：

```
风险来源
    ↓
风险关键变量
    ↓
市场 / 主体行为变化
    ↓
风险表现
```

例如：

```
融资条件收紧
        ↓
信用可得性下降
        ↓
企业融资行为收缩
        ↓
违约压力增加
```

该链条描述：

> 风险是如何从来源逐步传导到现实表现的。

这一阶段形成：

```
Risk Transmission Path
```


### 第二层：风险演绎观察：风险接下来怎么变化？

建立“风险监控”

解决的问题是：

> 已经识别出来的风险，随着时间和新事件落地，风险程度究竟怎么变化。**是在增加、维持，还是减弱。

风险演绎是风险从形成、发展到强化或缓和的动态过程。从这个节点开始建立“风险演绎时间轴”。

输入：风险识别后的Risk Model 
输出：风险演绎时间轴（过程）+风险状态判断（当前结果）

**Step 1：建立风险观察基准**

以第一层形成的 `Risk Model` 作为 T0。

基准包括：

```
风险类型
风险来源
风险关键变量
风险传导关系
当前风险表现
```

从这一时点开始，只观察能够改变 Risk Model 的新增证据。

关注范围收缩为：

```
影响风险来源的变化
+
影响风险关键变量的变化
+
风险应对力量的变化
+
风险表现的变化
```



**Step 2：观察风险演绎力量**

**风险演绎过程中，其实同时存在两种力量**：
- 风险来源→ 推动风险扩大
- 风险应对→ 推动风险缓和
持续观察“风险来源”和“风险应对”两股力量的变化，再判断风险的方向和持续时间。

2.1 观察风险来源 主要观察 推动风险形成和扩大的力量发生了什么变化？
2.2 观察风险应对 针对当前风险，是否出现了能够缓解风险的治理力量？
2.3 比较两股力量 当前推动风险扩大和推动风险缓和的力量，哪一方占优势？

2.4 输出风险状态：风险方向（增加、维持还是减弱）



风险维持期容易误判，把反复事件放到较长窗口里，看核心变量整体有没有改变。

**Step3: 判断风险持续性**

当前推动风险演绎的力量有没有持续基础？
看风险来源是否具有持续性？是一次性冲击，还是能够持续存在？
看风险应对是否具有持续性？风险缓解力量能够持续发挥作用吗？
看风险关键变量是否形成趋势
输出 （短期 中期 长期）

**Step4 动态更新Risk Model**

每轮观察完成后，需要判断原 Risk Model 是否仍然有效。

 原风险继续 → 更新风险状态 继续跟踪
  风险减弱/消失 →结束当前风险观察
  风险性质改变 → 原 Risk Model 失效 重新执行风险识别
