# 冰冰小美-concept-竞争格局的比较优势

## 1. 一句话定义

投资是基于[[冰冰小美-macro-国运|国运]]红利的分配史。先确定一个国家、行业、企业在竞争关系中的位置，寻找能够承接国家发展方向，并真正把国家比较优势转化为产品、利润、就业和社会贡献的企业。

比较优势 = 在明确竞争对象和自身定位以后，比较双方的国情、资源、能力、制度、产业和发展方向，找到一方相对另一方最难被替代、最具有影响力的优势。

## 3. 概念要解决的问题

**竞争格局回答：**

我拥有什么？—— 国情 

我准备往哪里走、我要争什么位置？—— 战略方向

跟谁比？——竞争对象

比什么？——战略定位

**比较优势回答：**

相对强在哪里？——比较优势

优势未来扩大还是缩小？——趋势（国运）

为实现长期目标，国家重点推动什么？—— 国策

## 竞争格局


竞争格局=竞争主体+竞争目标+竞争位置。

**1.竞争格局怎么形成的？**

竞争是事物发展的必然规律。

国情 + 国家能力
↓
确定战略定位
↓
**战略定位发生重合**
↓
各参与者之间形成的相对位置和力量结构
↓
形成竞争格局

战略定位发生重合形成竞争格局

案例： [[sources/articles/2026-05-14-冰冰小美：中美建设性战略稳定关系|中美从互补关系变成竞争关系]]   

**2.战略定位为什么会发生变化？**

原有发展模式遇到约束（国情） ：原有的经济增长模式让增长空间会越来越受约束，发展阶段变化推动 战略位置变化。

比较优势自身发生变化（国家能力/优势）：优势增多推动战略升级

外部环境变化（竞争对手）：战略定位是相对关系。其他国家发生变化会互相影响关系变化

技术革命推动国家重新确定战略定位（技术革命）：技术革命会重新定义“什么位置最重要”

案例：[[2024-05-27-冰冰小美：竞争格局的比较优势|我国的战略定位为什么发生变化？以及给国际环境带来什么影响？]]

	 
3.**怎么观察竞争格局的变化**

回顾历史、立足现在、展望未来。旧关系被打破就是发生了变化。

变化监测表：
- 战略定位
- 国策和政策方向改变 （自上而下）
- 资源配置：（自下而上）钱、人、产能、能源正在流向哪里？
- 影响力（“谁影响谁”）发生变化：
	- 依赖关系变化，谁对谁的依赖正在下降/上升？
	- 谁的定价权、技术权、资源权在增强？
- 结果验证：市占率、盈利、出口、订单有没有确认？


## 比较优势



定位 = 找到事物在整个系统中的真实位置；
立场 = 从这个位置出发形成的利益和行为方向；
比较优势 = 各种位置和力量相互竞争以后，谁更占优势。

跟谁比？参与者有谁
比较的维度什么？
优势是什么？
优势未来在扩大还是缩小？

怎么判断国家的比较优势？


**怎么判断产业的比较优势？**

| 维度             | 核心问题          | 重点观察                    |
| -------------- | ------------- | ----------------------- |
| 1. 成本优势        | 谁能更便宜地生产？     | 人工、能源、原材料、融资、物流、规模成本    |
| 2. 技术优势        | 谁能做得更好、更先进？   | 核心技术、专利、研发、产品性能、迭代速度    |
| 3. 产业链优势       | 谁的产业生态更完整？    | 上下游完整度、本地配套、供应链响应、国产化率  |
| 4. 规模与效率优势     | 谁能又快又多地生产？    | 产能、良率、自动化、工程化、单位成本      |
| 5. 市场优势        | 谁更容易把产业做大？    | 内需、渗透率、应用场景、客户基础、出口市场   |
| 6. 资源与要素优势     | 谁掌握关键投入品？     | 矿产、能源、人才、数据、电力、资本       |
| **7. 影响力/控制力** | 谁能够影响产业其他参与者？ | 市占率、定价权、标准、关键环节控制、不可替代性 |
|                |               |                         |


%%竞争格局的比较优势，是一种影响力。创新与变革，引领世界改变。


比较优势回答最根本的交易问题——"你挣什么钱？

```
你挣什么钱？
  │
  ├── 方向：挣的是哪个赛道的钱？（比较优势回答）
  │     效率端（科技/AI/新质生产力）？还是公平端（制造/资源/化债）？
  │
  ├── 稳固度：这个钱有多安全？（安全回答）
  │     产业链会不会被卡脖子？护城河够不够宽？仓位安不安全？
  │
  └── 外部条件：国际环境在帮你还是害你？（国际博弈回答）
        关税在加还是减？制裁在收紧还是放松？外资在进还是出？
```


根据经济学常识，钱要么印导致财富增长，要么货物贬值本币升值带来的购买力增强。
比较优势的两个方向拆清楚了：

```
效率端（印导致财富增长）：
  钱印出来 → 流入科技创新 → 新产业成长 → 财富增长
  → 美股逻辑 → "左手新质效率"
  → 对应：科技/AI/半导体/新能源

公平端（购买力增强）：
  产能过剩 → 价格下降 → 本币购买力提升 → 生活成本降低
  → A股逻辑 → "左手油矿公平"
  → 对应：制造业/资源/基建/化债
```

「公平与效率不可兼得。」 比较优势的判断，本质上就是判断当前政策在效率端还是公平端，资本应该往哪边流。
