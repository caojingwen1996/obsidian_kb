# 冰冰小美-concept-竞争格局的比较优势

## 1. 一句话定义

投资是基于[[冰冰小美-macro-国运|国运]]红利的分配史。先确定一个国家、行业、企业在竞争关系中的位置，寻找能够承接国家发展方向，并真正把国家比较优势转化为产品、利润、就业和社会贡献的企业。

比较优势 = 在明确竞争对象和自身定位以后，比较双方的国情、资源、能力、制度、产业和发展方向，找到一方相对另一方最难被替代、最具有影响力的优势。

## 3. 概念要解决的问题

**竞争格局回答：**

我拥有什么？—— 国情 

我准备往哪里走、我要争什么位置？—— 战略方向

跟谁比？——竞争对象

比什么？——战略定位

**比较优势回答：**

相对强在哪里？——比较优势

优势未来扩大还是缩小？——趋势（国运）

为实现长期目标，国家重点推动什么？—— 国策

## 竞争格局是什么


竞争格局=竞争主体+竞争目标+竞争位置。

**1.竞争格局怎么形成的？**

竞争是事物发展的必然规律。

国情 + 国家能力
↓
确定战略定位
↓
**战略定位发生重合**
↓
各参与者之间形成的相对位置和力量结构
↓
形成竞争格局

战略定位发生重合形成竞争格局

案例： [[sources/articles/2026-05-14-冰冰小美：中美建设性战略稳定关系|中美从互补关系变成竞争关系]]   

**2.战略定位为什么会发生变化？**

原有发展模式遇到约束（国情） ：原有的经济增长模式让增长空间会越来越受约束，发展阶段变化推动 战略位置变化。

比较优势自身发生变化（国家能力/优势）：优势增多推动战略升级

外部环境变化（竞争对手）：战略定位是相对关系。其他国家发生变化会互相影响关系变化

技术革命推动国家重新确定战略定位（技术革命）：技术革命会重新定义“什么位置最重要”

案例：[[2024-05-27-冰冰小美：竞争格局的比较优势|我国的战略定位为什么发生变化？以及给国际环境带来什么影响？]]

	 



## 比较优势是什么


定位 = 找到事物在整个系统中的真实位置；
立场 = 从这个位置出发形成的利益和行为方向；
比较优势 = 各种位置和力量相互竞争以后，谁更占优势。

### 3层 × 5问模型

|五问|功能|属于什么|
|---|---|---|
|**① 跟谁比？参与者有谁？**|确定竞争主体、参照系|竞争格局识别|
|**② 比什么？**|确定比较维度和竞争要素|比较框架|
|**③ 优势是什么？**|找出相对领先项及来源|**比较优势判断核心**|
|**④ 优势怎么变？**|判断优势扩大、稳定、缩小、逆转|**动态比较优势核心**|
|**⑤ 什么情况下优势会消失？**|找优势失效条件、替代风险、反转信号|**比较优势风险核心**|

| 3层级        | 跟谁比                   | 比较维度 | 谁有什么优势       | 优势怎么变 | 什么情况下消失         |
| ---------- | --------------------- | ---- | ------------ | ----- | --------------- |
| **国家层**    | 中国 vs 其他国家            |      | 国家产业比较优势     | 强化/弱化 | 成本上升、技术落后、产业迁移等 |
| **产业/行业层** | 环节 vs 环节、企业群体 vs 企业群体 |      | 产业链位置/行业结构优势 | 改善/恶化 | 扩产、技术替代、需求下降等   |
| **企业层**    | A vs B vs C           |      | 企业比较优势       | 扩大/缩小 | 技术追赶、客户流失、成本反转等 |

各层比较维度：


1.竞争格局比较优势：国家层


| 维度   | 核心问题            | 重点观察                                               |
| ---- | --------------- | -------------------------------------------------- |
| 国策高度 | 国策产业 = 比较优势最强方向 | 政治局会议、中央经济工作会议、政府工作报告 、五年规划纲要、国民经济和社会发展计划、预算、法律、决议 |
| 政策定调 | 政策开始落地          | 实施方案、实施细则、管理办法、申报指南、补贴办法、技术标准、考核办法。                |
| 资源配置 |                 | 财政 / 信贷 / 产业资本 / 政府采购                              |


得出：国家比较优势，即中国在全球产业分工中的什么产业凭什么承接？

2.竞争格局比较优势：产业行业层

| 维度         | 核心问题            | 重点观察                    |
| ---------- | --------------- | ----------------------- |
| **产业链位置**  | 向上游移动 = 比较优势在升级 | 是上游核心还是下游组装？            |
| **产业资本动向** |                 |                         |
| 影响力/控制力    | 谁能够影响产业其他参与者？   | 市占率、定价权、标准、关键环节控制、不可替代性 |


4.竞争格局比较优势：企业层

| 维度          | 核心问题            | 重点观察                 |
| ----------- | --------------- | -------------------- |
| **技术壁垒**    | 向上游移动 = 比较优势在升级 | 是上游核心还是下游组装？         |
| **准入门槛**    |                 | 垄断、定价权               |
| **企业/估值**   | 谁能够影响产业其他参与者？   | 毛利率、经营情况、合理估值、偏贵也可以买 |
| 商业空间 / 成长空间 | 这门生意还能做多大？      | 市场规模、渗透率、需求增长、行业天花板  |
