# 冰冰小美-macro-basic-货币

## 一句话定义

货币承担交换媒介、计价单位和价值储藏等职能；理解货币条件，需要分别观察其价格、数量、流动与所处周期。

## 概念要解决的问题

什么是货币？什么是资产定价？二者之前的关系是什么？
什么是资产负债表？加息 扩表 缩表什么意思？为什么买股票需要盯着这些概念？


文章脉络：
钱是怎么产生的？又是怎么消失的？不同地方的钱能互相使用吗？不用的钱怎么让其产生价值？

## 核心内涵


### 经济资源

**经济资源** = 有价值、可利用、可配置的稀缺资源。
- **有用**：能满足消费、生产、投资等需要
- **稀缺**：数量有限，不能无限免费取得
- **可配置**：可以决定怎么使用，比如消费、生产、出租、投资、出售

**经济主体拥有和控制的经济资源 = 资产**  

**资产 = 货币性资产 + 非货币性资产**  

**净资产 = 资产 - 负债

货币供给 → 货币价格 → 货币流动 → 资产配置 → 经济活动

## 货币

**资金 funds**=被拿来使用、配置、融资或投资的货币性资源。

**货币 money** =钱，通用购买力载体


货币的价格：跨时间、跨空间（币种）研究 钱的定价。利率加息降息直接影响货币的价格.
货币的数量：研究 钱的数量，的钱的产生.央行商业银行资产负债表的变化直接影响货币的数量.
货币的流动：研究钱往哪里流，流速快慢，流过去之后，变成了什么？



### 货币的价格

1.**汇率**：相较于其他货币  curency

	≈ 两个国家之间“利率、通胀、增长、信用、资金流”的相对结果

汇率影响因素

| 分类        | 影响因素    | 典型变化       | 对本币的常见影响 | 核心逻辑              |
| --------- | ------- | ---------- | -------- | ----------------- |
| **政策因素**  | 央行利率    | 加息         | 升值压力 ↑   | 本币资产收益率提高 → 吸引资金  |
|           | 货币政策    | 收紧流动性      | 升值压力 ↑   | 货币供给趋紧、利率通常上升     |
|           | 货币政策    | 降息 / 宽松    | 贬值压力 ↑   | 本币资产收益吸引力下降       |
|           | 外汇干预    | 央行买入本币     | 升值压力 ↑   | 直接增加本币需求          |
|           | 资本管制    | 限制资本流出     | 减轻贬值压力   | 减少本币抛售            |
| **经济基本面** | 经济增长    | 增长强于其他国家   | 升值压力 ↑   | 投资回报预期改善 → 资本流入   |
|           | 通胀      | 通胀长期偏高     | 贬值压力 ↑   | 本币实际购买力下降         |
|           | 贸易差额    | 出口 > 进口    | 升值压力 ↑   | 海外购买本国产品 → 本币需求增加 |
|           | 经常账户    | 顺差扩大       | 升值压力 ↑   | 持续形成外汇流入          |
|           | 财政状况    | 赤字/债务风险恶化  | 贬值压力 ↑   | 市场对本币资产要求更高风险补偿   |
| **资金流动**  | 利差      | 本国利率相对更高   | 升值压力 ↑   | 国际资金追求更高收益        |
|           | 证券投资    | 外资买入股票、债券  | 升值压力 ↑   | 先兑换成本币            |
|           | 直接投资    | FDI流入增加    | 升值压力 ↑   | 增加长期本币需求          |
|           | 资本外流    | 居民/机构买海外资产 | 贬值压力 ↑   | 卖出本币、买入外币         |
| **市场定价**  | 风险偏好    | 全球避险升温     | 取决于币种    | 美元、瑞郎等避险货币可能受益    |
|           | 汇率预期    | 市场预期本币升值   | 升值压力 ↑   | 资金提前买入本币          |
|           | 政治/信用风险 | 风险上升       | 贬值压力 ↑   | 资本要求更高风险补偿或撤离     |
|           | 市场流动性   | 流动性恶化      | 波动率 ↑    | 短期供需失衡被放大         |

政策调控

2.**利率**：跨时间使用资金的价格 

	= 今天的钱 和 未来的钱 之间的交换关系（折现率）
    ≈ 时间补偿+通胀补偿+风险补偿+资金供需

利率影响因素：

| 分类        | 影响因素    | 典型变化      | 对利率的常见影响 | 核心逻辑                    |
| --------- | ------- | --------- | -------- | ----------------------- |
| **政策因素**  | 央行政策利率  | 加息        | 利率 ↑     | 央行直接提高短期资金价格            |
|           | 央行政策利率  | 降息        | 利率 ↓     | 降低金融体系基础融资成本            |
|           | 公开市场操作  | 回收流动性     | 利率 ↑     | 市场资金减少 → 资金更紧           |
|           | 公开市场操作  | 投放流动性     | 利率 ↓     | 市场资金增加 → 资金更宽松          |
|           | QE / 扩表 | 央行购买债券    | 中长期利率 ↓  | 增加债券需求 → 债券价格上涨 → 收益率下降 |
|           | QT / 缩表 | 减少债券持有    | 中长期利率 ↑  | 市场需要吸收更多债券供给            |
|           | 财政政策    | 财政赤字扩大    | 利率 ↑ 压力  | 政府融资需求增加                |
|           | 政府发债    | 发债规模增加    | 利率 ↑ 压力  | 债券供给增加，需要更高收益率吸引资金      |
| **经济基本面** | 经济增长    | 增长加快      | 利率 ↑ 压力  | 企业投资、居民融资需求增加           |
|           | 经济增长    | 增长放缓      | 利率 ↓ 压力  | 融资需求减弱，同时降息预期可能上升       |
|           | **通胀**  | **通胀上升**  | **利率 ↑** | **出借资金需要更高通胀补偿**        |
|           | 通胀预期    | 未来通胀预期上升  | 长期利率 ↑   | 投资者要求更高名义回报             |
|           | 企业投资    | 资本开支增加    | 利率 ↑ 压力  | 企业融资需求增加                |
|           | 居民消费/住房 | 借贷需求增加    | 利率 ↑ 压力  | 信贷需求增加                  |
| **资金供需**  | 居民储蓄    | 储蓄增加      | 利率 ↓ 压力  | 可贷资金供给增加                |
|           | 银行流动性   | 流动性充裕     | 短期利率 ↓   | 银行之间资金供给增加              |
|           | 信贷需求    | 企业、居民借钱增加 | 利率 ↑     | 对资金需求增加                 |
|           | 海外资本流入  | 资金流入债券市场  | 利率 ↓ 压力  | 可投资资金增加、债券需求增加          |
|           | 资本流出    | 资金撤离      | 利率 ↑ 压力  | 资金供给减少                  |
| **金融定价**  | 信用风险    | 违约风险上升    | 信用利率 ↑   | 投资者要求更高风险补偿             |
|           | 期限风险    | 借款期限变长    | 长期利率通常 ↑ | 不确定性增加，需要期限补偿           |
|           | 期限溢价    | 期限溢价上升    | 长债收益率 ↑  | 投资者要求更多长期持有补偿           |
|           | 流动性风险   | 市场流动性恶化   | 利率/利差 ↑  | 投资者要求流动性补偿              |
|           | 风险偏好    | 避险情绪增强    | 国债利率可能 ↓ | 资金买入安全资产 → 债券价格上涨       |
|           | 信用利差    | 风险溢价扩大    | 企业融资利率 ↑ | 基准利率之外的风险补偿增加           |

### 货币的数量

**基础货币,** 央行直接造出来的钱,包括 现金(流通中的库存),(商业银行存在央行的)准备金

**广义货币**, 整个经济里可以用于支付、交易和储蓄的钱,不包括准备金.


#### 货币数量变化的机制链条: 

货币供给:钱从无到有地进入存量,有货币创造,货币派生
货币回收:

**货币创造** = 央行投放基础货币.

央行有货币发行权,可以直接创造新的货币,通过记账的方式直接增加商业银行在央行的准备金.
具体常见的途径有:

|分类|途径|具体操作|商业银行准备金变化|央行资产端变化|典型工具/场景|
|---|---|---|--:|---|---|
|买资产|买入国债等证券|央行从银行或市场买入证券|↑|国债等资产 ↑|QE、公开市场买入|
|买资产|买入外汇|央行用本币购买银行持有的外汇|↑|外汇资产 ↑|外汇占款|

#### 信用可得性

货币数量决定系统里有多少钱，信用条件决定这些钱愿不愿意流到你手里。

为什么货币可得性与信用与关?


现代货币体系，本身就是建立在多层信用关系之上的。新创造出来的存款货币 = 背后对应着借款人未来偿还贷款的承诺。

信用 = 现在先获得资源，未来再履行偿付义务。
信用把“未来的收入和偿付能力”转换成“今天的购买力”。

银行相信借款人 → 才愿意放贷  
社会相信银行 → 银行存款才能被当成钱使用

**信用可得性观测指标表**

> 想融资的人，能不能真正拿到钱？

| 观测对象   | 指标            | 指标含义         | 指标上升通常意味着 | 传导判断  |
| ------ | ------------- | ------------ | --------- | ----- |
| 银行贷款标准 | 银行贷款标准收紧比例    | 银行审批是否变严格    | 融资门槛提高    | 可得性下降 |
| 授信额度   | 企业/居民授信额度     | 银行愿意提供多少融资额度 | 可获得资金增加   | 可得性改善 |
| 贷款审批率  | 贷款申请通过率       | 申请融资后实际获批比例  | 更容易获得贷款   | 可得性改善 |
| 抵押要求   | LTV、抵押率、担保要求  | 获取贷款需要提供多少担保 | 融资要求提高    | 可得性下降 |
| 信用利差   | 企业债收益率－无风险利率  | 市场对信用风险要求的补偿 | 风险融资难度提高  | 可得性趋弱 |
