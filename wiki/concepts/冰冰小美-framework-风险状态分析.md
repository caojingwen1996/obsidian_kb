# 风险状态分析的方法论

## 一句话定义

**风险状态分析分成两部分：当前状态回答“现在是什么样”，状态变化回答“与基准相比发生了什么变化”。**

概念本质 = 核对关键变量与传导事实 + 判断当前损害压力及缓冲能力 + 形成可被新证据修正的状态结论。^[inferred]

本页是基于冰冰小美原文形成的方法归纳。它细化 [[wiki/concepts/冰冰小美-framework-风险观察|风险观察]] 的“本轮状态判断”：风险识别提供观察对象和传导假设，一次分析可以形成当前状态快照；有可比时点证据后，再形成状态变化判断，连续记录用于分析风险演绎。这里的分级、流程和模板是整理者提出的工作口径，并非作者发布过的完整标准，也不是已经验证的预测模型。

## 概念来源

- **来源明确提出**：[[sources/articles/2025-09-20-冰冰小美：风险变化如何观察|《风险变化如何观察》]] 要求按时间记录宏观、中观、微观事件，理解联系，并辨别风险大小、类型和持续性；同时观察风险来源与应对的落地情况。
- **来源明确提出**：[[sources/articles/2026-05-21-冰冰小美：风险转弱的节点|《风险转弱的节点》]] 区分基本面、情绪、流动性和估值四类风险，并从宏观、中观、微观和交易变化讨论转弱节点。正文日期为 2024-05-09，文件名中的日期不是实际发布时间。
- **来源明确提出**：[[sources/articles/2025-01-25-冰冰小美：行情不等于风险|《行情不等于风险》]] 强调行情向好时也可能积累风险；[[sources/articles/2026-03-23-冰冰小美：风险对冲|《风险对冲》]] 强调对冲可能只是推迟问题，未必解决风险源头。
- **来源间接支持**：[[sources/articles/2025-10-19-冰冰小美：波动风险|《波动风险》]]、[[sources/articles/2026-05-10-冰冰小美：历史危机的经验与警示|《历史危机的经验与警示》]] 和 [[sources/articles/2026-06-08-冰冰小美：风险提前到来与流动性危机|《风险提前到来与流动性危机》]] 为观察事件聚集、杠杆、现金流、流动性反馈、扩散及应对滞后提供案例。
- **整理者归纳**：将维度组织为当前状态与状态变化两部分；建立时点基准、条件分级、证据表、转弱确认及重识别规则。两部分分别记录证据可信度。下文标注为工作口径的部分均属于综合推导。
- **待验证**：不同对象与风险类型的分级阈值、确认窗口、指标有效性和预测能力。原文中的历史数字、政策描述及因果解释未在本轮独立核验，本页仅提炼分析方法。

## 概念要解决的问题

1. 哪个对象面临哪一项具体风险？哪些维度可能受损？
2. 当前证据说明风险只是潜在积累，还是已传导并形成损害？
3. 风险有多严重，影响局部还是正在扩散，现有缓冲能否承受？
4. 与上一观察时点相比，风险增加、维持还是减弱？
5. 当前状态可能持续到什么条件改变？哪些事实会推翻判断？

分析适用于市场、经济体、金融系统，也可用于行业或企业的具体风险；每次必须固定对象与范围，不能把全球风险判断直接套到单个对象。具体标的的状态记录进入 Workbench，本页只保存可复用方法。

## 核心内涵

### 一、先分清“风险是什么”和“风险处于什么状态”

[[wiki/concepts/冰冰小美-indacator-风险源与传导路径|风险源]] 回答起因，[[wiki/concepts/冰冰小美-indacator-风险类型|风险维度]] 回答哪里受损，状态回答当下达到什么程度。三者不能混为一个标签。

例如“利率与货币条件变化”是来源线索，“流动性风险”是受损维度；“当前程度高、影响多个市场”属于当前状态，“比上次增强、由单一市场扩展到多个市场”属于状态变化。具体是否成立，必须检查对象的暴露和传导证据。^[inferred]

以下按当前状态与状态变化分开记录，避免压成一个无法解释的分数。该结构为整理者工作口径。^[inferred]

#### 第一部分：当前状态——一个时点的风险快照

回答“截至现在，风险是什么样”。一次完整分析即可形成，不要求先有另一份快照。^[inferred]

| 项目 | 回答的问题 | 建议记录方式 |
|---|---|---|
| 当前程度 | 损害压力与承受能力相比有多严重？ | 低／中／高／极高；或证据不足暂不分级 |
| 当前传导阶段 | 风险已走到哪一环？ | 积累、触发、传导、损害释放、修复；可并存并注明不同环节 |
| 当前影响范围 | 哪些对象和维度受到影响？ | 局部／多个关联对象／系统范围，并列出实际对象 |
| 当前持续性判断 | 根据现在的条件，风险可能持续多久？ | 明确短中长期的实际窗口、持续条件与转折条件；这是条件性展望，不是已发生事实 |
| 当前判断的证据可信度 | 对本次快照的依据有多充分？ | 较充分／有限／不足，并列关键缺口与反证 |

#### 第二部分：状态变化——相对基准的比较结果

回答“与哪个时点相比，哪些方面变了，为什么”。至少需要两个可比较时点的证据，但不要求此前已经做过一次完整分析；首次分析也可使用可靠的历史基准。^[inferred]

| 项目 | 回答的问题 | 建议记录方式 |
|---|---|---|
| 变化方向 | 风险总体增加、维持还是减弱？ | 增加／维持／减弱／方向待定；依据主导变量和传导条件判断，减弱后转强注明重新增强 |
| 程度变化 | 风险程度是否改变？ | 基准程度 → 当前程度；同档位内也可增强或减弱，不用等级未变代替方向维持 |
| 阶段迁移 | 风险由哪个环节走到哪个环节？ | 基准阶段 → 当前阶段；可注明阶段未变、局部迁移或暂不可比 |
| 范围变化 | 受影响对象或维度是否改变？ | 扩大／收缩／不变／转移／待定，列明新增与退出的对象或维度 |
| 持续性判断变化 | 对持续时间和条件的判断有何修订？ | 延长／缩短／不变／待定，并说明持续基础或终止条件如何改变 |
| 变化判断的证据可信度 | 两个时点是否可比，变化依据是否充分？ | 较充分／有限／不足；记录基准来源、口径差异、新证据和相反解释 |

证据可信度描述判断质量，不是风险本身的程度；两部分各自填写，当前状态有把握也不意味着变化方向有把握。变化原因及关键变量的前后值作为第二部分的依据保留。^[inferred]

没有可比基准时，完整记录第一部分，第二部分统一标记“未评估：本次建立初始基准”，不填“维持”。有基准但证据冲突时，才将无法确定的变化项标为“待定”。两次比较只能说明这段区间的变化，不能直接推断为持续趋势。^[inferred]

阶段不必按固定顺序发展，突发冲击可能跳过可观测的积累期。风险释放描述损害正在兑现，不能据此认定风险已出清；修复也不自动意味着剩余风险较低。^[inferred]

### 二、固定观察对象、时点与基准

依据 [[sources/articles/2025-09-20-冰冰小美：风险变化如何观察|《风险变化如何观察》]] 对时间顺序的强调，每次判断至少固定以下内容：

- **对象与风险命题**：谁因什么变化，可能遭受什么损害；说明其资金、债务、业务或持仓暴露。
- **信息截止时点**：本轮允许使用的信息最晚到何时。
- **观察窗口**：研究未来一个事件窗口、一轮融资过程还是较长的经营周期；写明实际日期或条件。
- **比较基准（状态变化部分需要）**：首次识别时点 T0、上一轮时点或可靠历史时点，保留当时结论（如有）、关键变量、证据及口径。

首次观察可以完成当前状态快照；没有可比数据时，变化部分写“未评估：本次建立初始基准”。比较前核对风险对象、传导机制、指标与分级口径、时间窗口是否一致；存在差异应解释或暂不比较。持续性比较还需区分终止时间预期改变与日历自然推进，不能因剩余天数减少就认定风险持续性缩短。回看历史只能使用当时已知资料，不能用后来发生的事件替当时判断补证。以上操作要求为方法归纳。^[inferred]

#### 对象、既定暴露与受损容易度

“对象在既定暴露下有多容易受损”，指的是：**面对已经明确的风险冲击，这个对象的自身结构，会不会让它很容易出现损失或功能障碍？** 以下解释及例子是本方法的操作性归纳，不是原文直接给出的定义或案例。^[inferred]

**对象**是本次分析中可能受到损害的主体或系统。例如，经济衰退风险的对象可以是某个经济体，流动性风险的对象可以是某个市场或金融机构，融资风险的对象可以是某家公司。必须先选定对象与分析范围，才能判断其脆弱性；同一冲击对不同对象的影响可能不同。^[inferred]

**既定暴露**是已经明确的“对象通过什么渠道与风险发生关联、涉及多少、何时受到影响”。“既定”表示先把本轮分析的暴露条件明确下来，不表示暴露永远不变；无法核实的部分仍需标为待验证。以公司利率风险为例：^[inferred]

| 暴露要素 | 要明确的内容 | 利率风险示例 |
|---|---|---|
| 渠道 | 通过什么业务、资金、债务或持仓受到影响？ | 浮动利率债务随利率调整而改变融资成本 |
| 规模 | 涉及多少金额、占比和集中度？ | 会重新定价的债务金额及其占总债务的比例 |
| 时间 | 何时、在多长时间内受到影响？ | 立即重定价，还是到下一重定价日或续借时才受影响 |

**受损容易度**描述脆弱性：在相同或明确的冲击条件下，是否容易突破对象的关键约束。它不是已发生损失的大小，也不等于有数据支持的精确受损概率。判断时检查：^[inferred]

| 判断角度 | 核心问题 | 观察重点 |
|---|---|---|
| 敏感性 | 风险变量变化一定幅度，会造成多大影响？ | 利润、现金流、资产价值或功能对冲击的反应程度 |
| 依赖性与集中度 | 是否过度依赖某一种资金、客户、供应商或交易方向？ | 单一渠道依赖、业务集中、共同风险敞口 |
| 结构缺陷 | 什么结构会放大损害？ | 高杠杆、期限错配、刚性支出及其他难以调整的约束 |
| 距关键约束的距离 | 离亏损、融资中断、无法支付或功能失常还有多远？ | 将冲击造成的影响与明确的约束边界比较，并注明假设 |

例如，假设两家公司各有1亿元浮动利率债务，均在年初重定价，利率增加1个百分点，全年新增利息均为100万元。在其他经营条件不变、无对冲且新增利息全额计入当期费用的简化假设下：^[inferred]

- A公司原年度税前利润为120万元，新增利息后剩20万元，接近亏损边界。
- B公司原年度税前利润为2,000万元，新增利息后剩1,900万元，距亏损边界较远。

两者在这个例子中的债务暴露和利率冲击相同，但A的盈利结构更脆弱。这只比较盈利受损的敏感性，不直接推导偿付风险或整体风险等级；可用现金、可靠融资、对冲安排和外部支持是否能实际减轻冲击，应继续在“缓冲”维度核验。^[inferred]

**暴露看“通过什么渠道、涉及多少、何时受影响”；脆弱性看“冲击有多容易击穿自身约束”；损害兑现看“实际上已经损失多少”；缓冲看“有什么实际能力承受或化解冲击”。** 同一指标可以帮助解释多个环节，但不能重复计量。^[inferred]

### 三、风险状态分析的四个定性变量维度

风险状态分析要把**压力、脆弱性、传导与缓冲一起看**。四者是组织判断的定性变量维度，每个维度由具体变量、观察指标和证据支撑。[[sources/articles/2026-03-20-冰冰小美：宏观分析的框架|《宏观分析的框架》]] 提供观察线索，但线索出现不等于损害成立。以下四维结构为本方法的整理口径，不是作者原文直接提出的分类。^[inferred]

**压力对应风险推动力量，即推动风险形成和扩大的关键变量所产生的压力。** 风险来源说明变量产生压力的背景与机制，关键变量将推动力量落实为可以持续观察的对象。^[inferred]

各维度分别记录具体变量、作用机制、当前水平、持续基础及观察指标；有可比基准时再补充前后值和变化判断。变量用于解释机制，指标用于观测变量，证据用于支持或反驳判断。现实表现与损害兑现是验证四个维度及最终状态的依据，不再单列为一个定性变量维度；同一事实可支持多个环节，但不能被重复计为独立证据。^[inferred]

| 定性变量维度 | 必须追问 | 记录重点 |
|---|---|---|
| 压力 | 推动风险形成和扩大的关键变量是什么，当前作用有多强？ | 来源背景、推动变量、不利作用方向、当前水平、持续基础；可描述为弱／中／强／待判断，并附依据 |
| 脆弱性 | 对象在既定暴露下有多容易受损？ | 先明确暴露渠道、金额、占比和时间，再看融资依赖、杠杆、期限错配、集中度等易损结构；可描述为低／中／高／待判断 |
| 传导 | 压力能否抵达对象，哪些条件成立，已传到哪一环？ | 触发条件、传导路径、反馈放大、实际约束与损害兑现；可描述为未成立／部分成立／已贯通／受阻／待验证，并注明具体环节 |
| 缓冲 | 对象能否吸收冲击、阻断传导或修复损害？ | 可用资源、替代渠道、应对措施、实际覆盖与效果、持续性；可描述为充足／有限／不足／待验证，政策宣布不等于缓冲有效 |

暴露说明对象与风险的关联规模，脆弱性说明受到冲击后有多容易受损，损害兑现说明实际结果。缓冲着重记录可用资源及干预效果；与脆弱性使用同一指标时，要说明各自作用，避免重复计量。四维描述不能机械相加或平均，具体口径仍需按风险对象校准。^[inferred]

每条证据保留来源、事件发生时间、首次可得时间和数据所属期；同一事件的转载只算一个证据来源。事实、作者解释、分析假设分开写；事实成立也不自动证明某条因果链成立。^[inferred]

[[sources/articles/2026-03-23-冰冰小美：风险对冲|《风险对冲》]] 中的保证金压力和资产抛售、[[sources/articles/2026-07-02-冰冰小美：这是什么风险|《这是什么风险》]] 中的赎回与踩踏，提示关注反馈放大；[[sources/articles/2026-06-08-冰冰小美：风险提前到来与流动性危机|《风险提前到来与流动性危机》]] 则明确提到改善需要时间、仍有尾端效应。使用时应验证具体机制，不能直接沿用历史案例的结论。

### 四、判断当前程度：压力、脆弱性、传导与缓冲一起看

当前程度综合考察四个定性变量维度：**压力有多强、对象有多脆弱、传导条件是否具备、缓冲是否有效**。同时用已发生损害和在观察窗口内有证据支持的潜在损害验证判断。尚未下跌或尚未违约，不足以判定低风险。^[inferred]

以下为定性分级建议，原文没有给出统一四档标准。应用前应针对对象定义“关键约束”“重大损害”和有效缓冲的判据；无法定义或证据缺失时保留不确定性，不强行打分。^[inferred]

| 程度 | 条件性判断依据 | 需要防止的误判 |
|---|---|---|
| 低 | 有正面证据显示来源压力较弱、对象暴露有限或关键传导被有效阻断，缓冲足以应对已识别压力 | 仅因没有坏消息、价格上涨或关键数据缺失而判低 |
| 中 | 来源与暴露已有依据，关键约束尚未被击穿；缓冲仍在，但其效果或持续性需要验证 | 把尚未兑现误认为不会兑现 |
| 高 | 关键约束正被逼近或突破，重大潜在损害有机制与证据支持；或已有明显损害且缓冲不足 | 必须等到全面暴跌或正式违约才承认风险高 |
| 极高 | 核心功能、偿付或融资连续性出现严重受阻，并有反馈失控或风险快速扩散证据，应对尚未有效阻断 | 将单一资产大跌直接称为系统性危机 |
| 暂不分级 | 核心变量缺失、关键证据相互冲突或传导条件无法核实 | 把未知塞入中档，或把不确定性当安全 |

“高”不等于发生概率已达到某个百分比。记录重大损害的可能条件和后果即可，缺少模型与数据时不生成精确概率。系统性也不是单纯的程度档位：必须另有跨主体、跨市场关联或共同融资约束的证据。^[inferred]

### 五、状态变化方向：比较四个定性变量维度的变化

本节在完成当前状态快照且具备可比基准后执行。除总体方向外，同步比较程度、阶段、范围；各项变化按前述第二部分记录。^[inferred]

[[sources/articles/2025-09-20-冰冰小美：风险变化如何观察|《风险变化如何观察》]] 同时讨论事件加剧风险和落地缓和风险；[[sources/articles/2025-06-15-冰冰小美：当风险突然降临的时候|《当风险突然降临的时候》]] 比较外部冲击、不同经济体条件和政策应对。由此可把方向判断落实为以下规则。^[inferred]

| 方向 | 相对上一可比时点的判据 |
|---|---|
| 增加 | 压力增强、对象脆弱性上升、传导更顺畅或缓冲失效，使原损害路径更易成立或损害范围扩大；同时检查暴露是否扩大 |
| 维持 | 关键变量有持续观测，压力、脆弱性、传导与缓冲综合作用未实质改变；短期扰动不足以改变判断 |
| 减弱 | 压力减弱、对象脆弱性降低、关键传导受阻或缓冲增强，使损害路径弱化；需注明证据确认到哪一环以及现实约束是否改善 |
| 方向待定 | 已有可比基准，但当前数据滞后，或不同证据相互冲突且尚无法确定主导机制；无可比基准时，变化部分整体标记未评估 |

两股力量同时增强时，不按新闻条数相减，而检查哪一方改变了主导变量、是否作用于同一对象、何时生效、效果能维持多久。只宣布政策但效果未出现，可写“缓解力量形成，效果待验证”；若可靠的领先证据已改变传导条件，可以提前更新方向，同时注明现实结果尚待确认。^[inferred]

因此，允许出现“**高程度、正在减弱**”或“**低程度、正在增加**”。程度是当前水平，方向是相对变化；没有新增信息只能说明本轮信息不足，不能单独证明风险维持。^[inferred]

### 六、持续性判断分析

持续性在第一部分表示“根据当前证据，风险可能持续到何时或什么条件改变”；在第二部分表示“与基准相比，这个判断是否改变”。前者可以在首次快照中给出，后者需要比较依据。转弱确认也属于第二部分，仅在存在减弱证据时执行。^[inferred]

持续性依据来源是否可重复、对象能否承受、应对能否持续和关键变量是否形成趋势，不能仅由一次市场反应推断。[[sources/articles/2025-09-20-冰冰小美：风险变化如何观察|《风险变化如何观察》]] 支持把事件放回连续时间轴；[[sources/articles/2026-06-08-冰冰小美：风险提前到来与流动性危机|《风险提前到来与流动性危机》]] 提醒留意应对时滞与尾端影响。

短期、中期、长期应按对象的实际机制定义，例如事件落地前后、下一融资到期窗口、经营或投资周期；不统一规定为若干交易日。短期缓解与中期风险仍高可以并存，应分别给出依据。^[inferred]

确认转弱时逐项检查：^[inferred]

1. **改善来自哪里**：风险来源消退、暴露降低、传导受阻，还是仅由临时资金承接？
2. **改善是否作用到关键环节**：价格反弹之外，融资、现金流、杠杆或其他主导变量有没有变化？
3. **改善能否延续**：是否依赖即将到期的支持，或尚未兑现的政策承诺？
4. **风险是否转移**：当前对象缓解的同时，是否转移到别的主体、期限或维度？
5. **还有什么会使其重新增强**：列出可观测条件及下一次核验节点。

风险减弱通常仍需跟踪。只有在既定范围和窗口内，风险来源消退、关键传导被持续阻断或原风险假设被证伪，且没有未处理的重要残余暴露时，才可考虑结束本轮专项观察；保留重新开启条件。风险性质或主导机制改变时，应重新识别，而不是只改一个等级。上述退出规则为整理者提出。^[inferred]

### 七、按固定顺序形成结论

建议每轮按以下顺序执行；首次完成后保留原记录，以新增快照承接后续变化。^[inferred]

```text
固定对象、风险命题、时点和窗口
            ↓
分析四个定性变量维度：压力、脆弱性、传导、缓冲
用观测证据与现实表现验证各维度判断
            ↓
第一部分：形成当前状态快照
程度、阶段、范围、持续性判断与本次证据可信度
            ↓
检查是否存在可比基准
无基准：第二部分标记未评估，本次作为初始基准
有基准：分析第二部分的状态变化
方向、程度变化、阶段迁移、范围变化与持续性判断变化
            ↓
分别检查两部分的证据可信度、反证和缺口
            ↓
记录本轮结论、下一核验节点与重识别条件
```

同一对象同时面临多项风险时，先分别分析，再检查共同驱动、放大关系和主导风险。一个风险转弱不能抵消另一个风险增加；汇总时应写明哪个约束决定总体判断，不把异质风险的标签机械平均。^[inferred]

### 八、用相同表面现象检验方法是否分得清

以下是依据原文机制构造的示例，不是对历史行情的重新定级，也不是当前市场判断。^[inferred]

| 表面现象与补充证据 | 可以作出的状态判断 | 下一步核验 |
|---|---|---|
| 市场上涨，但已有证据显示融资高度集中、关键融资约束趋紧，缓冲不足 | 风险可能增加；若重大损害路径已具备条件，当前程度可高，即使损害尚未兑现 | 融资可得性、杠杆退出约束与实际承接 |
| 支持政策已宣布、市场反弹，但资金尚未到达受影响对象，原约束未变 | 原程度不能仅因反弹下调；缓解力量形成，效果待验证。关键变量仍稳定则方向维持，数据缺失则方向待定 | 实际投放、对象覆盖及约束是否缓解 |
| 融资恢复、强制出售减少，但损失与高杠杆尚未充分处理 | 可以是高程度、方向减弱；阶段进入修复，仍需观察残余暴露 | 支持持续性、偿付缺口与再次抛售条件 |

这些区分对应 [[sources/articles/2025-01-25-冰冰小美：行情不等于风险|《行情不等于风险》]]、[[sources/articles/2025-10-19-冰冰小美：波动风险|《波动风险》]] 和 [[sources/articles/2026-03-23-冰冰小美：风险对冲|《风险对冲》]] 的核心提醒。

## 判断标准 / 使用检查表

以下检查表与记录模板为整理者归纳，用于让判断可复核，不代表已完成阈值校准。^[inferred]

| 检查项 | 要判断的问题 | 通过标准 | 不通过时的含义 |
|---|---|---|---|
| 对象与暴露 | 谁会受到什么损害？ | 对象、来源、暴露、损害清楚 | 先补风险识别，不能评整个“市场好坏” |
| 时点与窗口 | 结论对应何时和多久？ | 当前快照有截止时间与数据期；变化判断另有明确、可比的基准 | 结论可能混用不同时间的信息 |
| 传导依据 | 风险如何抵达对象？ | 区分已成立、待验证和受阻的环节 | 只识别到风险线索，尚未支持完整判断 |
| 当前状态与状态变化 | 有没有把转弱等同低风险，或把首次快照填成维持？ | 分两部分记录；无基准时变化未评估，有基准时逐项比较 | 时点判断与变化判断混淆 |
| 应对效果 | 缓冲是否真正有效？ | 区分宣布、执行、效果和持续性 | 只能记录缓解预期 |
| 范围与持续性 | 是否夸大为系统性或永久性？ | 有关联证据及明确持续、终止条件 | 缩小结论范围，保留待验证 |
| 反证与未知 | 什么会推翻结论？ | 列反证、冲突证据、缺口和下一核验点 | 结论不可证伪或证据不足 |
| 可追溯性 | 能否复核当时为何这样判断？ | 原文或数据来源、时间、判断理由及前次记录保留 | 无法复盘，暂不做趋势比较 |

### 单轮风险记录模板：当前状态与状态变化

两部分共用风险对象、风险命题和证据来源；各自保留判断依据与可信度。第二部分缺少基准，不影响第一部分独立保存。^[inferred]

#### 第一部分：当前状态快照

| 字段 | 填写内容 |
|---|---|
| 对象与风险命题 | 谁因什么变化，可能遭受什么损害；其具体暴露是什么 |
| 信息时点与窗口 | 信息截止时间；数据所属期；本轮关注的实际日期或条件窗口 |
| 压力 | 推动风险形成和扩大的关键变量；作用机制、当前水平与持续基础 |
| 脆弱性 | 既定暴露下的易损程度；融资依赖、杠杆、期限错配、集中度等依据 |
| 传导 | 条件是否成立、路径是否畅通、实际传到哪个环节及反馈放大情况 |
| 缓冲 | 可用资源、应对措施、实际效果及可持续性 |
| 观测证据与现实表现 | 对四个维度逐项附指标、数据时点和来源；记录真实约束、损害兑现、反证与缺口 |
| 程度／阶段／范围 | 分别填写；说明分级条件、传导到哪一环、哪些对象受影响 |
| 当前持续性判断 | 实际时间窗口、持续条件与终止条件；注明条件性展望 |
| 当前判断可信度与反证 | 较充分／有限／不足；最关键证据、相反解释及缺口 |
| 下一核验 | 下次事件或数据节点；无历史基准时，本次快照作为初始基准 |

#### 第二部分：状态变化记录

| 字段 | 填写内容 |
|---|---|
| 比较条件 | 可比较／无基准未评估／口径不一致暂不可比；后两种情况不强填变化结论 |
| 基准与本次时点 | 两个时点及快照或证据来源；风险对象、机制、指标、分级与窗口是否可比 |
| 变化方向 | 增加／维持／减弱／待定；说明主导依据 |
| 程度变化 | 基准程度 → 当前程度；有无同档位内变化 |
| 阶段迁移 | 基准阶段 → 当前阶段；注明未变或不同环节的迁移 |
| 范围变化 | 扩大／收缩／不变／转移／待定；具体对象与维度 |
| 持续性判断变化 | 基准判断 → 当前判断；说明持续基础或终止条件的变化 |
| 变化原因与证据 | 压力、脆弱性、传导与缓冲分别发生什么变化，暴露是否改变；保留前后值、新增证据及现实表现验证 |
| 变化判断可信度与反证 | 较充分／有限／不足；可比性、冲突证据与缺口 |
| 下一核验与处理 | 核验变化能否延续；继续观察／待补证／重新识别／具备结束条件 |

两部分结论分别写成：

> **当前状态：**截至〔时间〕，针对〔对象〕的〔具体风险〕，当前程度为〔等级或暂不分级〕，处于〔阶段〕，影响〔范围〕。在〔窗口〕内，持续性取决于〔条件〕。依据为〔关键变量、传导事实与缓冲〕；本次判断可信度为〔判断及理由〕，主要反证或缺口是〔内容〕。

> **状态变化：**相对〔基准时点〕，风险〔方向〕，程度〔前 → 后〕，阶段〔前 → 后〕，范围〔变化〕，持续性判断〔变化〕。主要原因是〔主导变量或传导条件变化〕；变化判断可信度为〔判断及理由〕，下次在〔节点〕核验。

没有可比基准时，第二段替换为：“**状态变化：未评估。本次建立初始基准。**”

风险状态结论为后续决策提供依据；具体买卖仍需结合估值、收益空间、资金期限与承受力另行判断。[[sources/articles/2026-05-21-冰冰小美：风险转弱的节点|《风险转弱的节点》]] 对体系三要素的讨论说明，风险缓解只是判断有利窗口的一部分；原文中的“买入不败”不能在本方法中转换为无损失保证。
