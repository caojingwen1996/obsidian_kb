# 冰冰小美-concept-情绪位置的变化

## 1. 一句话定义

**在A股，交易决策的本质就是情绪位置判断。情绪是基于整个市场贪婪与恐惧的程度理解，根据程度不同，分为不同阶段，选择是高位博弈还是低位博弈，选择是题材权重趋势模式还是连板妖股报团模式，和相应的情绪套利理解。**

```
 情绪交易体系 = 判断情绪位置 = 决定交易行为
```

## 核心内涵

### 在体系三要素的位置

情绪在三要素中的位置：最表层，也是落地层

冰美定义了三要素的不等式：竞争格局的比较优势 > 流动性辩证分析 > 情绪位置的变化。

情绪排在第三位——但这不是说它不重要。恰恰相反：竞争格局告诉你方向对不对，流动性告诉你钱够不够，但它们最终都要在情绪层落地。 你赚的每一分钱，都是在某个情绪位置上买入、在另一个情绪位置上卖出的结果。


**情绪的特殊性**：

  竞争格局和流动性的变化是慢的（周/月级别）
  情绪位置的变化是快的（日/小时级别）
  → 情绪是每天都要重新判断的东西
  → 这就是冰美说"每天的情绪状态都不一样，所以无法预测"的原因


### 情绪周期

```
霍华德的情绪周期

贪婪或恐惧增强  
→ 投资者放弃怀疑  
→ 从众与相互强化  
→ 嫉妒推动追赶  
→ 自负阻止纠错  
→ 最终妥协  
→ 价格严重偏离价值。

```

情绪周期并不等于情绪变化本身。情绪的变化，更多的是要理解贪婪与恐惧的程度，

冰冰小美将情绪周期分为大周期和中周期，每次情绪的大周期的到来，往往都是出现[[冰冰小美-concept-风险的定义|风险]]：要么是指数的风险，要么是估值的风险，要么是流动性的风险。

### 情绪位置的变化

情绪位置变化不是“跌到冰点就买”，而是先找到[[冰冰小美-concept-亏钱效应|亏钱效应]]的来源，再观察它是否停止制造风险，随后验证新方向能否带动指数、流动性和挣钱效应共同转强。

**1.从冰点开始**

情绪变化通常是冰点开始，冰点最容易判断。
整个市场没有人挣钱，也就是通常说的2/8行情，随着注册制后，变成1/9行情，甚至1/19行情。
**当市场已经没有正常情绪波动，情绪进入近似“封死”的状态，才可以理解为冰点。**

冰点的形态：
- A杀，涨40%跌40%
- 趋势坏透跌40%以上
- 核心股全部跌停
- 指数持续下跌
- 题材全面退潮
- 恐慌情绪蔓延
- 核按钮满天飞


**2.冰点转折**


当冰点后，情绪开始从无法波动转向向上修复，就进入冰点转折。

转折的表现可能包括：

有转势板，带动指数企稳，流动性增强。
情绪螺旋上升。


但转折只能说明冰点开始松动，还不能直接等同于转势。一冰修复失败后的再次恐慌，迎来二冰。

**3.真正的转势**
真正的冰点转势必须得到指数确认

新方向转强
→ 带动指数企稳
→ 市场信心增强
→ 流动性向新方向集中
→ 挣钱效应扩散
→ 情绪位置由冰点转向修复

同时，新方向最好具备实体经济支撑和竞争格局比较优势
