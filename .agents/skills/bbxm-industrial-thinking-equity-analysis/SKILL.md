# 个股产业思维筛选

## 1. 定位

本技能把冰冰小美的产业思维落到单家上市公司，回答四个递进问题：

1. 公司所在产业是否值得长期跟踪；
2. 产业当前处于什么长期阶段和经营周期；
3. 公司是否位于约束、价值量和利润池真正流向的环节；
4. 产业逻辑是否已经转化为订单、收入、利润、现金流和合理预期。

产业思维负责发现方向、建立候选池和判断公司受益质量，不单独决定短线买卖点。若用户需要DCF、公允价值、目标价或交易溢价，完成本报告后转入 `个股估值计算`；若用户需要竞争格局、流动性、情绪位置和买卖时点，转入或联合使用 `bbxm-three-factor-analysis`。

## 2. 权威框架

每次执行前完整读取：

`wiki/concepts/冰冰小美-framework-产业思维.md`

该页面是本技能关于产业思维定义、层级、阶段、变量、权重和边界的唯一权威来源。不得使用历史对话摘要、旧报告或本技能中的记忆替代当前页面。

读取后形成当次框架快照，至少提取：

- 页面更新时间；
- 产业判断、阶段判断、个股筛选的层级关系；
- 产业研究、行业研究、公司研究、投资价值的当前结构；
- 产业投资生命周期的阶段名称和判断信号；
- 行业景气周期及需求、供给、库存、价格、资本开支、利润、信用等变量；
- 公司竞争地位、壁垒、份额、盈利、业绩兑现和第二曲线要求；
- 当前指标权重及其适用边界；
- 页面明确列出的误区、风险和反证要求。

若页面无法读取、为空或乱码，停止正式分析，说明框架未加载，不得凭印象生成报告。

## 4. 输入契约

先识别并在报告中写明：

- 公司名称、证券代码、市场；
- 分析日期和数据截止时间；
- 用户核心问题；
- 用户是新增现金、已有持仓，还是仅做研究；
- 公司主营业务和目标产业口径；
- 是否存在多业务分部或跨产业经营；
- 用户提供的材料、观点和假设。

名称或证券代码有歧义时先核验身份。产业归属有多种口径时，按收入、利润、订单、资产和战略投入拆分，不用概念标签直接归类。

## 5. 证据规则

### 5.1 来源优先级

1. 交易所、监管机构、政府部门、官方统计、公司公告和定期报告；
2. 行业协会、权威数据库、正式招投标和可复核产业数据；
3. 公司业绩说明会、投资者关系记录和同行正式披露；
4. 可信媒体和专业机构研究；
5. 市场传闻只作为待验证线索，不进入核心结论。

A 股财务数据优先使用本地结构化数据和公司法定披露交叉验证；当前价格、估值、行业数据和政策状态必须核验到报告截止日。所有关键证据写明发布日期或数据日期。

### 5.2 数据新鲜度

- 研究开始前建立关键数据清单，逐项记录指标、发布频率、理论最新期和首选来源；
- 区分数据所属期、发布日期和访问时间，不用抓取时间代替数据所属期；
- 证据快照只作为检索入口，每次生成或重新生成报告时重新核验月度、季度和高频数据是否已有更新；
- 月度指标原则上使用报告截止日已经公开的最新月份，季度指标使用最新已披露季度，行情使用最新交易日，高频产业数据使用截止日可取得的最新一期；
- 旧数据用于历史比较时必须明确标为历史口径，不得写成“最新观察”；
- 最新来源无法访问或口径不可比时写“证据不足”，不得静默沿用旧值。

### 5.3 事实边界

- 区分事实、公司表述、外部观点和本次推断；
- 产品能力不等于订单，订单不等于收入，收入不等于利润，利润不等于现金流；
- 集团任务不等于上市公司受益；合作、送样、认证和框架协议不等于批量商业化；
- TAM、渗透率、市场份额和业务占比没有可靠口径时写“未获取到”，不得自行补数；
- 目标公司自身披露不能作为唯一产业验证，至少寻找一个上游、下游、同行或官方旁证；
- 最新数据缺失时降低置信度，不用旧数据伪装当前状态。

### 5.4 证据等级

| 等级 | 定义 | 用途 |
|---|---|---|
| A | 官方文件、监管披露、法定财报、正式统计 | 核心结论 |
| B | 行业协会、招投标、权威数据库、同行正式披露 | 关键旁证 |
| C | 可信媒体、机构观点、产业访谈 | 补充解释 |
| D | 传闻、未核实社交信息 | 仅列待验证 |

## 6. 三个时间尺度

必须把以下三个尺度分开，避免把短期景气误写成长周期拐点：

| 尺度 | 核心问题 | 典型跨度 |
|---|---|---|
| 产业投资生命周期 | 产业处于关注启动、资本扩张、过热调整还是二次成长 | 约十年 |
| 行业经营周期 | 需求、供给、库存、价格、资本开支和利润处于什么位置 | 数月到三年 |
| 公司兑现与市场定价 | 订单、收入、利润、现金流和估值预期是否匹配 | 最新季度到三年 |

若三个尺度结论不一致，明确写出“阶段错位”，不要强行合并成一个景气标签。

## 7. 标准流程

### 步骤 0：建立数据清单

在分析前按报告截止日列出关键指标及其发布频率、理论最新期和首选来源。至少覆盖当前价格与估值、行业需求与供给、库存、价格与价差、资本开支、信用融资、技术渗透、外部约束、公司最新财报。先确认最新可得期，再开始写结论。

### 步骤 1：建立公司业务地图

按分部收入、利润、订单、资产和资本开支识别公司真实业务。区分已验证基本盘、产业成长业务、前沿期权业务、弱相关或仅概念关联业务。

### 步骤 2：先做产业判断

回答国家和时代为什么需要这个产业，长期空间来自哪里，产业链如何分层，当前第一约束是什么，价值量、定价权和利润池位于哪里，以及产业处于当前框架定义的哪个长期阶段。产业方向不成立时仍可继续分析公司，但结论不得写成长期产业趋势受益。

### 步骤 3：判断行业经营周期

逐项检查需求、供给、库存、价格、成本、资本开支、融资、技术渗透和外部约束，判断行业处于衰退、谷底、复苏、扩张、繁荣或收缩中的哪一段。

使用同行财报和上下游数据进行旁证，至少回答：

- 需求增长是否快于供给；
- 库存和价格是否支持景气判断；
- 当前资本开支会不会转化为未来过剩；
- 利润改善停留在订单、收入、利润还是现金流；
- 行业的核心矛盾和最近边际变化是什么。

### 步骤 4：映射公司在产业链的位置

先完成“第一且唯一判断”，回答公司是否是所研究行业的第一且唯一：

- 明确行业 / 产品、地域、客户场景、比较对象和数据截止期；多业务公司按业务分别判断，不把细分产品的地位扩展为全公司或整个行业的地位。
- **第一**：选取与行业竞争优势相关且可比较的指标（如市场份额、销量、收入或技术性能），列出公司与主要同行的同口径证据，说明排名及持续性；不能仅凭市值、股价或“龙头”称号判定。
- **唯一**：明确独有的产品、技术、牌照、资源或供给能力，核验其他供应商与替代路线；“唯一上市公司”“国内少数”或公司宣传不等于行业唯一，未找到竞争者也不等于不存在竞争者。
- 分别输出“第一：是 / 否 / 证据不足”和“唯一：是 / 否 / 证据不足”，再给出“第一且唯一：是 / 否 / 证据不足”。两项均有证据支持才写“是”；任一项被反证则写“否”；其余情况写“证据不足（待验证）”。保留来源 / 日期、反证、置信度和下一验证点，至少使用一项公司自述以外的旁证。
- 将结果用于解释公司筛选资格，不将其单独等同于投资价值或买入条件，也不因不满足“第一且唯一”而自动终止后续研究。

判断公司是否直接解决第一约束，是否位于高价值量或利润池环节，是否具备真实份额、客户、订单或认证，是否具有技术、成本、品牌、渠道、牌照、标准、规模或组织壁垒，能否在价格战、产能过剩或周期下行中保持现金流和份额，以及资本、政策和订单是否真正流向公司。

### 步骤 5：验证公司兑现

建立以下传导链：

```text
产业方向
→ 需求或约束变化
→ 公司订单与份额
→ 收入
→ 毛利率与利润
→ 经营现金流与资本回报
```

逐层标记“已验证 / 部分验证 / 未验证 / 被反证”。产业逻辑不能跨过中间环节直接跳到估值结论。

### 步骤 6：分析第二增长曲线

第二曲线必须同时检查新需求、新技术或新商业模式、商业化里程碑、独立收入或订单、所需资本开支、融资和稀释。只具备技术储备或合作关系时，将其视为期权，不并入已验证基本盘。

### 步骤 7：判断市场预期与赔率

比较当前估值、历史区间、可比公司和市场隐含预期，判断市场在定价基本盘、产业景气还是远期第二曲线，检查隐含增长是否被订单、利润和现金流验证，并识别产业阶段、公司兑现阶段和市场定价阶段的错位。

本技能只做估值观察和预期审计，不单独搭建 DCF 或给目标价。用户要求精确公允价值时转入 `个股估值计算`。

### 步骤 8：形成结论

分别给出：

- 产业跟踪资格：通过 / 有条件通过 / 不通过 / 证据不足；
- 第一且唯一判断：是 / 否 / 证据不足（分别列明第一、唯一及适用口径）；
- 公司筛选资格：通过 / 有条件通过 / 不通过 / 证据不足；
- 当前投资资格：有利 / 部分有利 / 不利 / 证据不足；
- 候选池动作：纳入 / 保留 / 降级 / 剔除；
- 下一验证点、反证和失效条件。

概念页中的指标权重用于分配研究注意力和解释重要性。除非当前权威页面同时提供完整评分尺度与阈值，否则不得把权重机械换算成伪精确总分。

### 步骤 9：审计数据源

报告完成后、生成 HTML 前，逐项审计所有用于当前状态判断的关键数据。审计表必须记录指标、发布频率、报告使用期、截止日最新可得期、发布日期或获取日期、来源和审计结果。

审计结果只允许：

- `通过`：报告使用期等于截止日最新可得期；
- `证据不足`：已检查但无法取得可靠最新值，正文已同步降低置信度；
- `不适用`：该指标不用于本报告当前状态判断。

若发现存在比报告使用期更新的可得数据，先标记 `滞后`，更新证据、正文结论和来源后重新审计。审计表中仍有 `滞后` 时禁止生成 HTML 和交付报告。

若不在 llmwiki 项目中，直接在对话中按模板交付，不擅自创建知识库目录。

## 9. 质量检查

交付前逐项检查：

- 已重新读取当前产业思维概念页；
- Markdown与HTML目录严格对应框架页四个一级模块和17个二级节点，没有额外标题层级；
- 先判断产业，再判断公司，没有从股价倒推产业逻辑；
- 长期生命周期、行业经营周期、公司兑现和市场定价已分开；
- 已识别第一约束、利润池和公司真实产业链位置；
- 公司研究首节已分别核验第一、唯一及综合结论，注明比较口径、同行 / 替代路线、来源日期和证据缺口；
