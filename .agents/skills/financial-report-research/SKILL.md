# 财报研究 Skill

## 定位

本技能用于把财报、招股书、业绩预告、业绩说明会和重要附注转化为可复核的财报研究报告。它偏审计与证券研究风格，核心不是复述财务报表，而是回答：

- 收入、利润和现金流质量是否真实改善；
- 资产负债表、债务、资本开支和股本稀释是否带来压力；
- 会计口径、分部口径或合并范围变化是否影响同比判断；
- 财报证据是否强化、削弱或证伪原投资逻辑；
- 下一次需要跟踪哪些可证伪指标。

保持审慎、双向验证和证据可追溯。不要只寻找支持既有观点的证据。

## 路由边界

使用本技能：

- 分析某家公司最新年报、季报、中报或招股书；
- 判断收入质量、利润质量、现金流质量、债务和融资压力；
- 检查关联交易、商誉、资本开支、客户集中度、合同负债、应收账款、存货、股权激励或解禁稀释；
- 对比两家公司或多个报告期的财报；
- 从财报判断原投资逻辑是否强化、持平、弱化或证伪；
- 建立财报发布后的监控清单。

使用相邻技能：

- 完整个股投资决策、目标价、DCF、公允价值、安全边际、是否值得买：优先使用 `bbxm-equity-research`，本技能提供财报章节和证据底稿。
- 资金流、交易方画像、融资融券、龙虎榜、ETF 资金和资金动作：使用 `fund-flow-analysis`。
- 持仓每日监控和新公告映射原研报假设：使用 `portfolio-daily-monitoring`。
- 只查询单个结构化数据字段或行情明细：优先使用已可用的本地数据工具或 `strategy-backtest-expert:westock-data`。

## 开始前确认

尽量确认：

1. 公司名称、证券代码、上市地和币种；
2. 报告期和报告类型：年报 / 中报 / 季报 / 招股书 / 预告 / 业绩会；
3. 用户的研究目标：快速体检、标准财报研究、深度审计式研究、持仓逻辑复核或公司对比；
4. 是否有用户提供的财报文件、公告链接、原投资逻辑、持仓成本、仓位和重点疑问；
5. 当前项目落盘规则。处于 `llmwiki` 时，具体标的财报研究进入 `workbench/targets/`，不进入正式 `wiki/`。

标的身份有歧义时先核对身份，不要把同名公司、母子公司、A/H/美股不同主体或不同会计准则数据混用。

## 本地数据优先规则

### A 股优先使用 `tushare-data`

研究沪深北 A 股时，先检查当前会话是否已热加载本地 `tushare-data` MCP。若未热加载，可通过本项目的本地 stdio server 尝试调用：

```text
tools/tushare-data/scripts/mcp_server.py
```

本地工具用于快速建立结构化事实底稿，但不替代法定披露。MCP 调用失败、无权限、返回空行、字段缺失或对象不适用时，记录失败原因，再回退交易所、巨潮资讯、公司公告、AKShare 或公开页面；不得把“工具没返回”写成“事实不存在”。

| 数据需求 | 优先本地工具 | 用途 | 边界 |
|---|---|---|---|
| 证券身份、简称、行业、上市状态 | `get_stock_basic` | 身份核验 | 不能替代财报中的业务分部 |
| 日线价格、成交额、量价窗口 | `get_stock_daily` | 财报发布前后价格反应 | Tushare 日线通常为不复权收盘数据 |
| PE、PB、PS、股息率、市值、换手率 | `get_stock_valuation` | 估值位置和市场反应 | 需说明日期、单位和字段口径 |
| 利润表、资产负债表、现金流核心科目 | `get_financial_statements` | 三大表结构化初稿 | 关键结论仍需年报、季报和附注复核 |
| 分红历史 | `get_dividend_history` | 股东回报和现金分配旁证 | 分红不是资金流入证据 |
| 资金分档 / 大单代理 | `get_stock_moneyflow` | 财报后交易承接旁证 | 只能说明订单规模方向，不能识别账户身份 |
| 融资融券 | `get_margin_detail` | 杠杆资金和财报后风险偏好 | 不可与订单流机械相加 |
| 指数成分和权重 | `get_index_constituents` | 指数或 ETF 背景 | 不能确认 ETF 申购者身份 |

### 法定披露复核

无论本地数据是否返回，关键财报判断必须回到更高优先级来源复核：

1. 交易所、监管机构、公司正式申报文件；
2. 财报正文、附注、审计报告、招股书和合同原文；
3. 公司公告、业绩说明会和投资者关系材料；
4. 官方结构化数据或 XBRL；
5. 权威数据库和主流财经媒体；
6. 行业研究、券商研报、博客、论坛和聚合信息。

低层级来源只能用于发现线索，关键结论应回到高层级来源验证。

## 研究模式

### 快速体检

适合财报刚发布后的初步判断。重点回答：

- 财报整体偏正面、中性还是负面；
- 收入、利润、现金流和资产负债表最重要的三处变化；
- 原投资逻辑是强化、持平、弱化还是证伪；
- 下一阶段最该盯的 3-5 个指标。

### 标准财报研究

适合形成完整财报分析。覆盖：

- 会计边界和可比口径；
- 三张报表和关键事实表；
- 分部业务、收入质量、利润质量、现金流质量；
- 债务、融资、担保、关联交易、股本稀释；
- 竞争性假设、核心因果链、风险评级和监控清单。

### 深度审计式研究

适合 IPO、并购重组、强周期、资本开支密集、债务压力大或会计争议多的公司。额外检查：

- 原始附注逐项核对；
- 会计政策和估计变更；
- 客户合同约束力与收入确认；
- 内部转移定价与分部利润真实性；
- 资本开支回报模型；
- 多情景压力测试；
- 关键结论置信度评级。

## 研究原则

### 先确定会计边界

分析前确认：

- 合并范围包含哪些主体；
- 是否发生并购、分拆、共同控制合并或新业务首次并表；
- 会计政策、会计估计和收入确认口径是否变化；
- 历史数据是否追溯调整；
- 分部口径是否变化；
- 同比、环比和历史序列是否仍可比。

输出时明确说明：当前财务数据包含哪些业务，以及这会如何影响同比和分部判断。

### 以问题组织研究

不要按报表科目流水账复述。先提出关键问题，再找证据：

- 收入增长来自价格、销量、并购、会计重分类还是真实需求；
- 利润改善来自毛利率、费用率、税率、非经常性收益还是会计调整；
- 净利润和经营现金流是否匹配；
- 资本开支是否能形成合理回报；
- 债务增加是否对应经营扩张，还是用于填补现金缺口；
- 关联交易是否存在利益冲突；
- 股权激励、可转债、解禁和再融资会造成多大稀释；
- 当前估值是否已经反映这些财报风险。

### 区分四类结论

重要结论标注类型：

- **事实**：来自财报、附注、公告或官方数据；
- **会计解释**：对报表科目、准则和政策的解释；
- **我的判断**：基于事实形成的经营和投资判断；
- **待验证假设**：证据不足，需要后续跟踪。

### 建立竞争性假设

重要问题至少建立正反两个解释，并比较哪个更符合证据。

示例：

```text
假设 A：资本开支扩张会拖累自由现金流。
假设 B：资本开支正在形成未来产能和规模优势。
验证：收入兑现速度、产能利用率、折旧压力、订单质量、经营现金流。
```

## 标准流程

### Step 1：确定研究问题和时间窗口

明确报告期、研究目标、财报发布时间、市场关注点、财报前后价格反应和需要回答的投资问题。

### Step 2：建立来源矩阵

至少列出：

| 数据项目 | 目标来源 | 实际来源 | 数据时间 | 状态 | 口径 / 缺口 |
|---|---|---|---|---|---|
| 本地 Tushare 调用清单（A 股适用） | `tushare-data` |  |  | 已获取 / 未获取到 / 不适用 / 口径冲突 |  |
| 财报原文与附注 | 交易所 / 巨潮 / 公司公告 |  |  |  |  |
| 三大财务报表 | 本地工具起底 + 法定披露复核 |  |  |  |  |
| 分部收入与利润 | 财报附注 / 管理层讨论 |  |  |  |  |
| 行情、估值、市值 | 本地工具 / 行情平台 |  |  |  |  |
| 债务、担保、关联交易 | 财报附注 / 公告 |  |  |  |  |
| 股本、解禁、股权激励 | 财报 / 公告 / 交易所 |  |  |  |  |

状态只能写 `已获取`、`部分获取`、`未获取到`、`不适用`、`口径冲突待解释`。

### Step 3：确认会计边界

输出合并范围、会计政策变化、追溯调整、非经常性项目、分部口径变化及其对同比判断的影响。

### Step 4：建立关键财务事实表

至少覆盖：

| 指标 | 本期 | 上年同期 | 同比 | 环比 | 占收入比例 | 来源 / 口径 |
|---|---:|---:|---:|---:|---:|---|
| 营业收入 |  |  |  |  |  |  |
| 毛利润 / 毛利率 |  |  |  |  |  |  |
| 营业利润 |  |  |  |  |  |  |
| 归母净利润 |  |  |  |  |  |  |
| 经营现金流 |  |  |  |  |  |  |
| 资本开支 |  |  |  |  |  |  |
| 自由现金流 |  |  |  |  |  |  |
| 现金及等价物 |  |  |  |  |  |  |
| 有息债务 |  |  |  |  |  |  |
| 应收账款 |  |  |  |  |  |  |
| 存货 |  |  |  |  |  |  |
| 合同负债 |  |  |  |  |  |  |

数字必须带期间、单位、币种和口径。不得混用不同期间或不同准则的数据。

### Step 5：分析三类质量

收入质量：

- 增长来自价格、销量、并购还是会计口径变化；
- 应收账款增速是否高于收入；
- 合同负债、订单、客户集中度和收入确认是否支持真实交付；
- 是否存在渠道压货、提前确认或一次性项目。

利润质量：

- 毛利率、费用率、税率和分部利润变化；
- 非经常性损益、政府补助、资产处置、减值转回；
- 股权激励、折旧摊销、资本化政策和调整后利润差异。

现金流质量：

- 经营现金流 / 净利润；
- 自由现金流 = 经营现金流 - 资本开支；
- 营运资本占用；
- 资本开支 / 收入、资本开支 / 经营现金流；
- 现金消耗速度和静态现金跑道。静态现金跑道只是压力测试，需说明未计入未来经营现金流、融资和资本开支调整。

### Step 6：分析债务、融资、关联交易和股本

债务与融资：

- 总债务、净债务、短期到期债务、利息支出、担保、租赁负债、再融资需求；
- 净债务 / EBITDA、EBITDA / 利息支出、经营现金流 / 利息支出、一年内到期债务 / 现金。

关联交易与治理：

- 交易对手、关联关系、交易金额、定价依据、审批流程、担保责任和利益冲突；
- 公允性判断必须写清比较口径，不能只写“公允”。

股本与稀释：

- 总股本、流通股、限售股、解禁、股权激励、可转债、回购、潜在稀释率；
- 解禁要区分“解禁”“可交易”“实际出售”和“市场吸收能力”。

### Step 7：建立核心因果链

把重要结论写成传导链：

```text
资本开支增加 → 固定资产增加 → 折旧和维护成本增加 → 若收入兑现慢于预期 → 资产回报率下降 → 自由现金流恶化 → 再融资需求上升
```

```text
应收账款增速高于收入 → 现金回款弱于收入确认 → 经营现金流低于净利润 → 收入质量需要折价 → 估值容错下降
```

### Step 8：情景和估值连接

本技能不强制完整 DCF，但必须把财报风险连接到收入、利润、自由现金流、净债务和估值变量。若用户要求完整公允价值、目标价或买卖动作，转入 `bbxm-equity-research`。

至少列出乐观、中性、悲观三种情景下：

- 收入；
- 毛利率 / 营业利润率；
- 经营现金流；
- 自由现金流；
- 净债务；
- 完全摊薄股本；
- 估值含义。

### Step 9：催化剂和监控清单

输出未来验证表：

| 日期或窗口 | 事件 | 影响变量 | 风险方向 | 需要验证的数据 |
|---|---|---|---|---|
| 下次财报 | 收入与现金流更新 | 收入 / FCF | 双向 | 收入、毛利率、经营现金流、Capex |
| 债务到期 | 再融资 | 利息 / 现金 | 负面 | 新融资成本和债务期限 |
| 项目投产 | 产能释放 | 收入 / 利润率 | 双向 | 利用率、良率、毛利率 |

## 落盘规则

在 `llmwiki` 项目中：

- 财报专项研究属于具体标的工作产物，保存到 `workbench/targets/`；
- frontmatter 使用 `artifact_type: financial_report_research`；
- 默认文件名：`YYYY-MM-DD-HHmm-<标的>-财报研究.md`；
- 若只是更新同一标的既有权威研报中的财报章节，优先更新原 `机构级决策研报.md`，不要另建重复权威研报；
- 更新 `workbench/index.md` 与根 `log.md`；
- 不更新根 `index.md`，不得保存到 `wiki/queries/`。

## 声明

财报研究基于研究截止时间可取得的公开资料和本地结构化数据，不构成证券投资建议。真实投资决策前应重新核验公告、价格、流动性、个人风险承受能力和最新披露。
