# 基本面与价格预期校验

## 来源与取舍

本参考吸收 LSEG `equity-research` 技能的研究骨架：共识预期、历史基本面、价格表现、估值和宏观背景都要连接到投资论点。资金面分析只借用这套方法形成“基本面与价格预期校验”，不复制其 LSEG / IBES 工具依赖，也不把本技能改成完整公司研究。

原始参考：<https://github.com/anthropics/financial-services/blob/main/plugins/partner-built/lseg/skills/equity-research/SKILL.md>

## 融入资金面分析的目的

资金流不能只回答“今天谁买了”。它还要回答：

1. 当前资金是在交易什么预期；
2. 这个预期是否被财报、估值、分红、价格位置和宏观背景支持；
3. 如果共识已经很满，资金继续流入需要什么增量催化；
4. 如果资金流出，流出是基本面证据被削弱、价格预期透支、估值过高、宏观逆风，还是短期交易拥挤释放。

## A 股可用数据映射

| LSEG 技能模块 | 资金面技能中的对应检查 | Tushare MCP 优先数据 | 资金面解释 |
|---|---|---|---|
| 共识预期 | 市场当前在交易的盈利、分红、订单、政策或主题预期 | 暂无一致预期工具；使用公告、研报摘要、公开页面或用户提供资料 | 只作为资金持续性的背景，不得虚构 FY1 / FY2 一致预期 |
| 历史基本面 | 收入、利润、现金流、负债与资本开支是否支持资金叙事 | `get_financial_statements` | 基本面证据支持可提高资金持续性判断；基本面证据背离时降低流入置信度 |
| 价格表现 | YTD、1Y、52 周区间或近 20 日相对位置 | `get_stock_daily` | 判断资金是在低位修复、趋势推进、冲高回落、高位拥挤，还是已经透支预期 |
| 估值与分红 | PE、PB、PS、股息率、市值位置 | `get_stock_valuation`、`get_dividend_history` | 判断资金买入是否有估值容错或红利吸引力，不能直接证明资金身份 |
| 宏观背景 | 利率、汇率、通胀、信用、政策、行业景气 | MCP 暂无宏观工具；使用公开宏观数据或知识库框架 | 判断宏观是资金顺风、逆风还是中性背景 |
| 投资论点 | 资金状态、主导资金、反证、催化与失效条件 | 汇总所有来源 | 资金结论必须落到 `buy / wait / observe / review / reduce / sell` 条件 |

## 执行规则

1. 先完成资金事实采集，再做基本面与价格预期校验；不要让基本面叙事或价格故事替代资金流证据。
2. 能用 `tushare-data` MCP 的基础资料、行情、估值、财报、分红，优先使用 MCP；一致预期和宏观数据当前没有 MCP 覆盖时，写明“未获取到 / 待核验”或引用公开来源。
3. 所有估值和财务指标必须写清时点、单位和会计期。财报滞后时，不能把上一季数据当成当前资金方向。
4. 估值便宜、分红高或基本面改善只能说明资金承接理由增强，不等于确认长期资金正在买入。
5. 价格涨跌要和资金窗口对应：单日资金、近 5 日资金、近 20 日资金分别看对应价格表现。
6. 结论中必须回答“市场可能错在哪里”：是过度乐观、过度悲观、价格已经透支，还是资金数据不足以挑战共识。
7. 不输出完整基本面分析、目标价、DCF、公允价值或独立估值结论；如用户需要这些内容，转向 `bbxm-equity-research`，本技能只保留与资金面有关的校验结论。

## 输出落点

- 在“数据审计”中列出已获取和未获取的共识、财报、估值、价格、宏观资料。
- 在“资金来源全景”中解释基本面证据、价格预期、估值和宏观背景对各类资金持续性的影响。
- 在“价格、广度与筹码交叉验证”中加入估值位置、基本面证据、价格预期和预期差检查。
- 在“支持证据、反证与缺口”中单列基本面证据 / 价格预期 / 估值 / 宏观反证。
- 在“下一验证点与失效条件”中加入财报、预告、公告、政策、宏观、价格位置和估值切换触发项。
