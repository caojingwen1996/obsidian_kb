# 竞争格局比较优势分析

## 1. 定位

围绕单一标的建立“纵向产业演化 + 横向相对选择”框架，依次回答：

1. 标的属于什么产业、产业链环节和投资阶段；
2. 当前是结构性成长、周期上行、周期下行、供给出清还是稳态成熟；
3. 相对其他产业、相邻环节和直接竞争者，优势与短板在哪里；
4. 优势是否已经转化为份额、价格、成本、利润、现金流和资本回报；
5. 优势能否持续，当前市场价格是否已经充分反映。

核心链路：

> 产业定位 -> 产业演化 -> 当前景气 -> 竞争结构 -> 横向比较 -> 财务兑现 -> 持续性 -> 市场定价

不要混淆好行业、好公司和好股票。经营比较优势用于判断公司质量，市场定价用于判断投资吸引力，两者分别输出。

## 4. 输入契约

识别并在报告开头写明：

- `target`：标的名称或证券代码，必填；
- `as_of_date`：分析基准日，默认当前日期；
- `market`：上市市场和主要经营区域；
- `horizon`：默认未来 1-2 年与 3-5 年；
- `peer_set`：用户指定同行；
- `user_thesis`：需要验证的观点；
- `mode`：`fundamental`、`investment` 或 `full`，默认 `full`；
- `depth`：`brief`、`standard` 或 `deep`，默认 `standard`。

名称或代码有歧义时先核验身份。产业归属有多种口径时，按收入、利润、现金流、资产和战略投入拆分，不使用市场标签直接归类。

用户未指定同行时，自动建立三类比较对象：

1. 直接竞争者：同产品、客户、区域或技术路线的 3-6 家公司；
2. 替代与相邻对象：替代技术、相邻环节或争夺同一利润池的 2-4 个对象；
3. 资本配置替代项：仅在投资模式下选择 2-3 个风险收益相近的标的或行业。

说明每个对象纳入理由、口径差异，以及重要但未纳入的对象和原因。

## 5. 证据规则

来源按以下顺序取证：

1. 公司公告、定期报告、招股书和投资者关系材料；
2. 政府部门、统计机构、交易所和行业协会；
3. 竞争对手正式披露；
4. 权威数据库、学术研究和专业机构；
5. 主流财经媒体；
6. 社交媒体和论坛仅作线索，不作关键结论的唯一证据。

当前事实、历史事实和预测值分开标注。同行尽量统一报告期、币种、会计口径、区域和业务范围；无法统一时明确差异。

重要结论标注为：`事实`、`推断`、`判断` 或 `未知`。每项优势必须回答：

- 相对于谁；
- 比较什么指标；
- 在什么区域和业务范围；
- 截至什么时间；
- 优势在扩大、稳定还是收窄；
- 是否已转化为经营和财务结果。

禁止以下替代推理：

- 收入规模大不等于龙头；
- 毛利率高不自动等于成本优势；
- 研发费用高不自动等于技术优势；
- 行业增长快不等于公司一定受益；
- 股价强势不等于基本面优势；
- 没有市场总量分母时不自行计算市占率；
- 数据缺失时不以主观评分补齐，标为“未知”。

## 6. 执行流程

### 步骤 1：界定业务与比较框架

拆分核心收入、利润、现金流和资本占用来源，识别主产业、次产业与战略期权。核验市场标签是否与真实利润来源一致，并建立比较组。

### 步骤 2：建立产业地图与阶段判断

从需求、供给、技术、政策和市场空间构建产业地图。市场空间尽量拆为：

> 客户数量 x 单位需求 x 渗透率 x 更新频率 x 价格

判断产业处于技术验证、需求导入、渗透加速、产能扩张、供需再平衡与出清、龙头集中与稳定回报、衰退或二次成长中的哪一阶段。给出支持证据、切换信号、下一阶段观察指标和反向证据。

景气判断至少由需求、供给、价格、库存、产能利用率、订单、盈利和资本开支中的三个独立指标支持，最终归类为：结构性成长、周期上行、高位扩张、周期下行、供给出清、低位复苏或稳态成熟。

### 步骤 3：分析竞争结构与利润分配

检查市场边界、CR3/CR5/HHI、市占率变化、进入退出、价格战、扩产纪律、客户绑定、产品迭代和并购整合。无法取得可靠集中度时，不填假数字，改用可验证的竞争行为和份额方向。

说明行业利润主要由资源稀缺、成本曲线、技术性能、品牌、渠道、认证、服务、规模、网络、牌照或资本实力中的哪些因素决定，并判断格局在改善、稳定还是恶化。

### 步骤 4：完成五层比较优势

依次分析：

1. 国家或区域：资源、能源、人才、产业链完整度、市场、物流、融资、政策和地缘风险；
2. 产业：长期需求、渗透率、供给约束、资本回报、波动、政策和技术淘汰风险；
3. 产业链环节：利润池、定价权、稀缺性、资本强度、现金转换、客户黏性和替代风险；
4. 企业：规模份额、成本、技术产品、客户渠道、品牌定价、国际化、治理、财务实力、资本效率和战略选择权；
5. 资本市场定价：估值、预期、拥挤度、催化剂和下行保护。该层不计入经营优势。

### 步骤 5：建立同行矩阵

至少比较市占率、收入增长、毛利率、ROIC、自由现金流、单位成本、产品性能、客户渠道、海外能力和资产负债表。每一行同时给出静态水平、近 3-5 年趋势、口径差异、相对位置和证据充分度。

### 步骤 6：验证优势兑现

把叙事映射到可验证链条：

> 市占率 -> 收入 -> ASP 或单位成本 -> 毛利率 -> ROIC -> 自由现金流

将每项优势归类为：`已兑现`、`正在兑现`、`尚未兑现`、`叙事与数据矛盾` 或 `信息不足`。指出链条在哪一环成立、在哪一环受阻。

### 步骤 7：评估持续性

说明优势来源、复制条件和时间、维持投入、技术或政策冲击、客户与区域集中度，以及行业成熟后是否消失。按短期（通常少于 2 年）、中期（2-5 年）或长期（通常超过 5 年）分类，不把区间写成精确预测。

### 步骤 8：评分、定价与监控

经营比较优势采用 1-5 级相对评分：1 显著落后，2 相对落后，3 中性，4 相对领先，5 显著领先。

| 维度 | 权重 |
|---|---:|
| 产业结构性吸引力 | 15% |
| 当前产业阶段与景气窗口 | 10% |
| 产业链环节与利润池位置 | 15% |
| 行业竞争结构 | 15% |
| 企业特有竞争优势 | 25% |
| 财务兑现质量 | 10% |
| 优势持续性 | 10% |

总分为 `Σ（权重 x 评分 / 5）`。80-100 为强结构性比较优势，65-79 为中强，50-64 为优势不明显，35-49 为相对弱势，0-34 为结构性劣势。

缺失维度显示“未知”，同时报告已知维度得分、数据覆盖率和潜在偏差，不把未知按零分处理。评分附高、中、低置信度。

经营评分后单独覆盖市场定价，分析估值分位、同行估值差、盈利预测隐含要求、市场一致预期、催化剂和下行风险。最后列出至少三项反证、乐观/基准/悲观三情景和 8-12 个动态监控指标。
