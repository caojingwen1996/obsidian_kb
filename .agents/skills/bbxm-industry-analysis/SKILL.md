# 产业分析 Skill

## 1. 定位与边界

本 Skill 执行产业思维的前两层，研报范围到行业研究：

1. 第一层产业研究：判断产业战略地位、长期成长空间和产业投资生命周期，输出产业判断、主要变化、关键约束与产业链全表。
2. 第二层行业研究：划分候选行业，验证需求传导、供需景气、竞争格局和核心矛盾，输出行业比较及重点研究／观察／排除清单。

在同一份报告中完成“产业 → 行业”，不能停在交接问题。最终分别说明已处于高景气的行业和低位改善的行业，以及各自的证据、持续条件与反证；没有满足条件的候选时明确说明，不强行选出赢家。

范围在公司研究前结束。企业名称、产品份额和分部数据可作为行业结构与经营验证的证据，必须说明样本覆盖和局限，不能由少数公司推定全行业。单家公司竞争优势、财务模型、公司候选筛选、个股估值、预期差、仓位与买卖建议转入后续流程。

## 3. 触发与分流

以下请求使用本 Skill：

- 分析一个产业是否值得长期跟踪；
- 分析产业战略地位、长期成长空间、TAM、渗透率或应用场景；
- 拆解产业结构、产业链、价值流向、关键约束或产业天花板；
- 判断产业投资生命周期及阶段转换条件；
- 从产业链划分候选行业，比较行业景气、竞争格局、利润分配与研究优先级；
- 生成覆盖产业研究和行业研究的完整报告。

以下请求转入其他流程：

- 单家公司基本面、竞争优势或财务研究；
- 个股估值和投资建议；
- 纯宏观分析或单一数据查询。

若一个请求同时包含多个层级，先明确分层。本 Skill 的产物覆盖产业与行业两层，公司和投资价值层由对应流程另行输出。

- 前两层的衔接、进入公司研究的条件，以及持续跟踪中的证据、反证和重估要求；
- 已核实事实、作者观点、整理者推断、假设与待验证的边界。

### 4.1 生命周期唯一来源

生命周期图和正文必须逐行采用主文件 `#### 产业投资生命周期` 下的详细定义表。

主文件前部框架树只用于识别层级和导航。框架树与详细表名称不一致时：

1. 图表、正文和阶段引用使用详细表原名；
2. 元数据记录名称差异；
3. 不得在 Skill、模板或渲染器中写死另一套名称；
4. 详细表缺失、为空或无法解析时停止生成正式报告。

### 4.2 阶段与证据边界

- 产业投资生命周期判断整体发展阶段；产业链传导进度说明哪个环节受到需求或约束变化影响；行业景气判断具体行业的经营状态。三者不能相互替代。
- 生命周期是原文案例归纳的框架，不要求每个产业按固定时长、固定顺序走完；允许“当前主阶段 + 过渡特征”，证据不足不定位。
- 宁德时代的历史价格和新能源汽车40%渗透率只属于原文案例，不成为其他产业的阈值或收益预期。
- 原始文件中的“原文结构速览”、整理备注及知识页的操作表格，不得冒充作者原文；重复转载不算独立证据。
- 知识库中保留的暂定行业权重未经验证，不用于本技能评分或自动判断。

### 4.3 框架元数据缺失

框架没有版本号时，仍读取全文并按标题和正文解析，将版本写为“未声明”、解析方式写为“根据正文推导”。不得沿用历史版本号。

## 7. 证据计划

按第一层三个模块和第二层各行业研究模块建立证据清单：

```yaml
evidence_plan:
  - module:
    question:
    required_facts:
    required_indicators:
    preferred_sources:
    freshness:
    fallback_sources:
    missing_data_handling:
```

产业战略地位单独按主框架当前顺序建立证据计划：全球环境、中国国情、战略酝酿、国家战略形成、政策落地、产业政策落地、财政资源、金融资源、产业资本、生产要素和国家比较优势。每一层都记录“第一信息源、要观察的事实、与本产业的关系、尚未打通的下一环节”；不得只搜政策标题或用后端行业经营数据倒推前端国家战略。

长期成长空间必须单独规划：

- TAM 的地域、产品或服务边界、时间和名义或实际口径；
- 渗透率的分子、分母和数据时间；
- 应用场景的使用者、付费主体、付费方式和价值兑现路径；
- 产业链子环节、上游投入、客户与付费主体、各环节解决的需求或约束，以及本轮变化和证据日期；
- 新应用、替代、更新、海外需求与旧需求下降的关系，区分新增与需求转移；
- 理论空间到可实现空间的数量、单价、约束和谨慎／基准／乐观情景，避免上下游营业收入重复相加；
- 资金、技术、资源、牌照、标准、场景、成本、库存、定价权和组织能力约束；
- 决定产业天花板的需求、支付、技术成本、资源许可和供给条件。

生命周期必须按详细定义表的每个阶段和关键观察指标规划证据，不得只搜集支持当前阶段的正向材料。

对每个重点候选与观察候选，逐项规划需求、有效供给、库存、价格与成本、资本开支、融资、技术应用、外部约束及盈利现金回收证据；按行业选择主导变量，其他维度说明辅助作用、缺口或不适用原因。竞争证据包括同口径市场份额、进入退出、定价行为、壁垒替代、议价和利润分配。初筛排除项保留业务关系不成立等具体理由，不以缺数据冒充负面结论。

## 8. 证据与数据规则

证据优先级：

1. 国务院、统计部门、部委和监管机构；
2. 行业主管部门和行业协会；
3. 企业正式公告、年报、招股书和交易所文件；
4. 招标、采购、审批、环评和建设信息；
5. 权威研究机构；
6. 主流媒体；
7. 专家观点和二手资料；
8. 市场传闻，仅作为待验证。

每项关键数据记录指标定义、统计范围、时间、单位、名义或实际口径、来源和可比性。发生变化的判断必须说明观察与比较窗口；没有可比数据则仅描述现状，并保留缺口。

必须区分：

- 已核实事实、作者观点、整理者推断、假设和待验证；
- 当前事实、政策目标和第三方预测；
- 理论总市场、当前可服务市场、可扩展市场和已实现需求；
- 用户数、连接数、销量、收入和资本开支；
- 技术可用、试点、商用和规模化；
- 集团任务与具体主体获得订单或收入。

禁止建立以下等式：

- 政策目标 = 当前规模；
- 产业规划 = 已形成有效需求；
- 技术成功 = 商业模式成立；
- 项目试点 = 规模付费；
- 资本开支增长 = 产业价值已经兑现；
- 产业空间大 = 当前估值合理。

数据失败时说明原因并保留缺口，不得用替代数据伪造结论。

## 9. 执行顺序

先按本次 `framework_snapshot.industry_modules.order` 完成产业层，再按 `sector_modules` 完成行业层；不得用宏观热度或产业长期空间跳过行业经营验证。

### 9.1 产业战略地位

严格按本次主框架快照中的顺序回答：

```text
全球环境
→ 中国国情
→ 国家战略（先区分战略酝酿与正式形成）
→ 政策落地
→ 产业政策落地
→ 资源配置（财政／金融／产业资本／生产要素，政府采购归入可核验的财政或采购工具）
→ 国家比较优势
→ 是否属于未来重点发展的产业方向
```

1. **全球环境与中国国情。** 先说明外部竞争、技术、贸易、安全或资源环境发生了什么，再用国家统计局、各部委、海关总署、人民银行等一手资料检查中国的GDP、人口就业、产业结构、能源资源、进出口、社融信贷和财政收支中与本产业直接相关的矛盾。只选真正相关指标，未使用的指标说明不适用，不为填表堆砌宏观数据。全球事实与中国问题分开，不能因海外趋势存在就认定中国必然把该产业列为战略方向。
2. **国家战略形成。** 将“战略酝酿”和“国家战略形成”分开。前者检查中央政治局会议、中央财经委、求是、新华社中的领导讲话、集体学习、新概念首次提出和反复强调；后者从12371、新华社、中国政府网检查党代会报告、中央全会公报及《建议》《决定》、中央经济工作会议等是否正式确立方向。媒体热度、地方表态或一次讲话不能代替国家战略形成。
3. **政策与产业政策落地。** 先核对中国政府网政策文件库及主管部委的国务院文件、部门规章、指导／实施意见、行动方案和管理办法，再核对发改委、工信部、科技部、能源局等主管部门的产业规划、技术路线、准入目录、设备更新和示范项目。写清政策工具、作用对象、执行主体、时间与约束；规划目标不当成已完成项目或现实需求。
4. **资源配置。** 财政从财政部、发改委检查中央预算、专项债、中央预算内投资、超长期特别国债、补贴、税收优惠和政府采购；金融从人民银行、金融监管总局、证监会检查再贷款、专项贷款、信贷指导、资本市场和保险资金政策；产业资本从国资委、国家级产业基金和地方国资检查国企资本开支、基金投资和央企投资计划；生产要素从发改委、自然资源部、能源局和地方政府检查土地、能耗、电价、数据中心指标、矿权、牌照、频谱等。区分“允许／引导”“预算或基金设立”“项目获得资源”“实际支出或采购”，只将可归属到本产业的资源计入已落地证据。
5. **国家比较优势。** 回答中国在全球产业分工中凭什么承接该产业，分别列出已证实的优势、短板和依赖。比较口径必须明确产品、地域、时间和指标；国内市场大、政策支持或单项产能高不能自动等于全球竞争优势。
6. **形成结论。** 以证据链已走到的最高环节和首个断点为核心，给出“未来重点发展方向：是／有条件／否／待验证”、长期跟踪价值、方向、受益者与付费者、主要投入主体、第一约束、国家比较优势、置信度和反证。结论是产业战略地位，不替代第2章空间、第3章生命周期、第5章行业景气，更不直接推出公司利润或投资建议。

关键误读逐项排除：全球趋势不等于中国国情需要，战略酝酿不等于正式战略，正式战略不等于政策落地，政策文件不等于资源已配置，资金或要素倾斜不等于行业盈利，国家比较优势不等于每家公司受益。证据缺失时停在已确认的层级并标记“待验证”，不得跨越断点补结论。

### 9.2 长期成长空间

先建立产业链、应用场景和付费需求，再测算市场空间与渗透率；按模板展示产业边界与 TAM、渗透率、应用场景、产业链全表、约束与价值分配、天花板及新旧需求变化。

产业链全表逐行回答“投入什么、卖什么、卖给谁、谁付钱、解决什么问题、当前发生什么变化”；按产品、客户和约束拆分，不以概念板块或整家公司代替细分环节。可实现空间须给出情景和证据，量化条件不够时使用定性情景，不能补造规模。

代表主体只验证产业链位置和约束，不进入公司财务、竞争优势或估值。

```yaml
investment_lifecycle_visual:

    - order:
      name:
      state: 已经历 / 当前 / 未进入 / 待验证
      time_range:
      current_judgment:
      transition_features:
      key_evidence:
      next_stage_condition:
      main_risk:
      confidence: 高 / 中 / 低
  evidence_nodes:
    - time:
      stage:
      event:
      evidence_type: 已核实事实 / 作者观点 / 整理者推断 / 假设 / 待验证
      impact:
      source:
```

最多一个主阶段标记为“当前”。过渡特征单独记录，不通过标记多个当前阶段表达混合状态；证据不足时可以没有当前阶段，并写“待验证”。其他阶段缺少经历证据时也写“待验证”，不按阶段编号反推历史。

### 9.4 产业维度结论

汇总是否值得长期跟踪、长期空间、当前主阶段与过渡特征、第一约束、下一阶段条件、风险和证据缺口。

### 9.5 行业划分与候选清单

从最终用途反问需要采购什么产品与服务，沿产业链追到材料、设备、制造和配套。用协会资料、产品用途和企业披露交叉核对，记录“卖什么、卖给谁、解决什么问题”；按产品、客户、地域、技术标准和供需定价逻辑划分可比较的行业，不能用整家公司或概念板块代替。

把产业层交接问题落为“产业变化 → 客户采购或要求变化 → 受影响产品 → 证据与日期 → 失效条件”，包括需求增长、供应退出、成本变化、升级和新应用。每个行业保留独立标识，初筛为重点研究／观察／排除，并说明理由；候选资格不等于高景气。

### 9.6 行业景气与经营验证

对未排除候选逐个分析，先确定主导变量及观察／比较窗口，再核验需求、有效供给、库存、价格与成本、资本开支、融资、技术应用、外部约束和盈利现金回收。行业财务样本必须说明覆盖范围，剔除一次性损益、会计变化与低基数等影响。

区分真实终端消耗和渠道补库、计划产能和有效产能、报价和成交价、提价和价差改善；同一笔扩产对设备供应商形成需求、对产品行业增加供给，须分别说明。按知识库给定标签描述行业景气阶段，允许混合证据或待验证，不与产业投资四阶段强行对应。

每个行业同时输出“景气水平（偏低／中性／偏高／待验证）+ 变化方向（改善／持平／转弱／待验证）+ 主导原因 + 持续条件 + 反证 + 置信度”。无可比窗口只描述现状，变化方向写待验证；只有低基数增长、股价上涨或一次提价，不能确认高景气。

对应报告 5.3，只回答“这个行业现在怎样、相对自身过去如何变化”。行业之间的取舍留到 6.1，不在景气标签中暗含研究顺序。

### 9.7 行业竞争格局与核心矛盾

按产品、地域、时间和销量／收入等口径核对 CR3／CR5、进入退出、扩产与价格战、壁垒与替代、上下游议价和利润分配。可靠份额不足时保留缺口；集中度高不能直接等于竞争有利。区分需求受益、收入受益和利润受益，指出利润被哪类参与者取得及其原因，不展开单家公司研究。

逐行业写清“当前最限制盈利的因素、正在发生的变化、影响供需或利润的路径、已经验证的部分、失效条件”。需求增加但供给更快、售价上涨但成本更快、增长利润被客户拿走时，应调整判断并保留分歧。

### 9.8 行业比较与研究优先级

对应报告 6.1，回答“相对哪些候选，为什么先研究这一项；什么证据会改变选择”。5.3 是单行业状态判断，本节是跨行业的研究取舍，不能复制景气表后仅追加优先级标签。以下是落实知识库比较要求的操作规则，不是作者发布的评分模型。

1. **确定比较对象与问题。** 按共同需求、利润传导或待解决的研究问题组织有意义的两两比较或分组比较，给比较编号；不要求穷举所有组合。说明产品、地域、时间窗口、指标和样本边界。跨商业模式可比较需求到利润的兑现链和证据强弱，但不同口径的增速、利润率、价格不直接比大小或拼成统一分数，也不用暂定行业权重。
2. **识别决定性差异。** 综合 5.2—5.5 的真实需求、供给约束、竞争与利润留存、持续性和证据质量，选出改变研究安排的关键差异；引用双方证据与日期，写清哪项占优、哪项不利以及为什么本轮更重视前者。利润留存要给出已验证／部分验证／待验证的判断及依据，不能只填“能否保留利润”等问题。证据更完整只说明结论更可验证，不自动证明行业经营更好。
3. **给出相对选择和逆转条件。** 明确 A 优先于 B、并列研究、分组不排序或暂不能判断，并说明取舍代价、置信度和限制。逆转条件应指向差异如何改变，例如 A 的利润优势消失，或 B 补齐同口径回款证据；不能只重复各行业一般风险。没有决定性证据可并列、保留观察或先补数据，不强行产生赢家；只有一个有效候选时说明无横向对象。
4. **将比较落到研究任务。** 用第二张研究安排表逐项承接全部初筛候选，保留相同标识并引用比较编号；排除、不可比或无比较对象的说明原因。研究任务区分“经营候选深入”（经营证据相对较强）、“关键缺口核验”（重要约束或潜在机会尚缺决定性证据）、“常规跟踪”及排除项“不适用”。最终安排仍写重点研究／观察／排除，注明组内先后、并列或不排序及初筛调整；不同任务不混成一个景气排名。缺数据不能作为行业走弱或排除的证据，优先核验也不等于确认高景气。

“已高景气”和“低位改善”的归类引用 5.3，仅简述其对本次取舍的影响，不再重列景气矩阵。研究优先级不等于预期收益或买入顺序，不给出公司名单、估值或交易建议。

#### 最终结论与后续公司研究的分工

- 4.1 是产业层结论；6.1.1 是行业选择的比较论证；6.1.2 固定命名为“最终结论：行业选择与研究安排”，是本报告最终行业结论的唯一汇总位置。报告开头提供阅读指引；若有摘要，必须与此处安排一致，不能另列一套排名。
- 6.2 固定命名为“后续公司研究清单”，只回答“沿已选行业研究具体公司时，还要验证什么”，不承载最终结论，也不是要求当前报告完成公司筛选。
- 仅承接 6.1.2 已安排“经营候选深入”的方向，保留相同行业标识。行业关键缺口核验仍留在 6.1.2，常规跟踪留在 6.3；不要机械复制全部候选、景气标签或下一行业验证节点。没有公司研究交接项时，明确写“当前无公司研究交接项”，说明应先完成的行业验证，不虚构交接对象。
- 每个交接方向用一行列明具体公司的验证问题、需要的公司级证据、继续研究或暂缓条件。围绕真实产品及收入利润占比、客户认证与量产交付、相对同行的优势、订单与回款归属选择关键问题；共性的财务治理检查合并说明，避免逐行重复。
- 交接项是待办，不是已验证的公司结论；经营数据或样本公司的成功不能替代拟研究公司的业务证明。继续研究不等于确认公司合格或可以买入，后续流程另行完成公司财务、治理与估值研究。

### 9.9 持续跟踪与重新研究

记录判断层级、产业或行业对象、原判断、证据日期、核心变量、下一验证节点、反证和重新研究的触发条件。更新时比较同口径证据，说明哪些判断保留、增强、减弱或仍待验证，以及候选是否升级、降级或退出；股价涨跌不能代替经营验证。频率随变量和披露节奏确定，不固定为统一周期。
