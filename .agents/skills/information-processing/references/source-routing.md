# 信息源路由

本表是对项目框架 Source Routing 待完善项的执行补充，不是已经配置的订阅列表，也不承诺渠道始终可用。每次执行应核对入口与工具的实际可用性。

## 先区分目标、材料与渠道

公司、产业、利率、政策问题是观察对象；晨报、新闻、文章是材料；网站、数据库、接口和账号是渠道。不能因为输入来自晨报，就把“晨报”当成其涉及事件的原始来源。

| 观察对象 | 需要的原始证据 | 来源与路由 |
|---|---|---|
| 利率、货币、流动性、信贷 | 政策决定、执行报告、统计数据；区别政策利率和市场利率 | 对应央行；债务与财政事项找财政部门；美债发行和财政部收益率数据找 Treasury，不把财政部当作所有利率的发布者 |
| 国情与长期发展 | 人口、增长结构、收入、产业结构、长期规划 | 官方统计部门、国家规划及原始长期文件 |
| 国策、政策、规则 | 正式文件、草案、修订、生效和执行记录 | 制定或执行部门原文；先核对发布主体和状态，再看官方解读 |
| 产业、供需、技术 | 行业统计、投入、产能、需求、技术验证及项目进展 | 行业主管部门、行业协会原始统计、项目或技术主体披露；统一口径后比较 |
| 企业或证券标的 | 主体身份、公告、定期报告、经营事件 | 交易所、法定披露平台、公司正式公告；可用已配置数据工具，保存具体出处和所属期 |
| 已发生事件 | 发生、执行、取消、修订等原始记录 | 事件主体、监管或官方发布机构；冲突来源并列，不用转述覆盖原文 |
| 市场反应 | 有时间窗口与口径的价格、成交或其他实际指标 | 交易所及可核验行情来源；仅作观察，不推断参与者身份或风险结论 |
| 舆论与传播 | 原始言论、发布时间、传播与澄清 | 新闻、评论、社交平台仅作线索或传播事件；回到原发布者核验，转载去重 |

金融专题按需读 [金融信息指标页](<../../../../wiki/concepts/冰冰小美-indicator-金融信息（todo).md>)；非金融专题按需读 [非金融信息观测指标表](../../../../wiki/concepts/冰冰小美-indicator-非金融信息观测指标表.md)。指标页是可选项库，是否完成、字段与实际内容以本次读取为准，不把文件名的 todo 当成不存在，也不把已有表当成全量自动扫描配置。

## 各模式如何获取

- **feed**：首先处理用户实际提供的全文或文件；链接材料则读取链接正文。需要核实时沿文中原始出处回查。无法打开正文时，不从标题虚构 Event。
- **monitor**：优先读取用户给定的观察对象、来源、窗口和已有 Event/成功扫描状态。首次无基准时获取约定窗口的材料，标首次记录；不得假设此前事件均未出现。没有预设来源时，先提出围绕对象的路由清单，缺少必要范围则询问，不默认订阅所有指标。
- **target**：确认对象身份后，按核心问题选取表中的相关渠道，先取一手披露，再以其他来源补充遗漏；遇到同名企业或证券跨市场歧义，先确认或明确可核验身份。

原始平台内容确需专门抓取时，可使用项目现有 `cjw-xueqiu-daily-monitor`，范围限定为本次输入；金融数据可使用当前已配置并适用的数据工具。工具或技能不在环境中可用时，使用可核验的公开原文或说明缺口，不假装已经调用。

维护本轮“计划来源、实际查询区间、获取结果、原始出处、失败原因、未覆盖项”的记录。访问失败保留错误；新发布时间落在本轮但事实时间较早的材料属于晚到信息，仍按实际发生时间进入时间轴。
