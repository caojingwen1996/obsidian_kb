# 中证红利股息率信号

当用户要求检查、运行、定时触发或记录“中证红利买入信号 / 中证红利股息率信号”时，使用此 skill。

## 执行方式

在 llmwiki 项目根目录运行内置脚本：

```powershell
python .agents\skills\zzhl-dividend-signal\scripts\check_signal.py
```

脚本会执行以下动作：

1. 获取中证红利 `000922` 指数估值数据，并得到用于规则判断的股息率口径。
   - 当前使用 AKShare `stock_zh_index_value_csindex` 的 `股息率2`。
2. 获取中证红利日收盘价，计算本年度首个交易日至指数估值日期的全年收益率和年内最大回撤，并生成指数成立以来的逐年历史。
3. 通过腾讯行情接口获取中证红利 `sh000922` 的当天涨跌幅；该涨跌幅日期默认等于记录日期。
4. 通过 AKShare `bond_zh_us_rate` 获取 10 年期中国国债收益率。
5. 优先解析理杏仁公开页面获取中证红利近10年股息率分位和80%分位点；若公开页面失败，由 Codex/大模型通过网页查询核对数值后，用脚本参数传入；若参数也未传入，脚本自动回退到中证官方指数推算口径（见下）。
6. 优先读取已应用的每日策略配置，尚无配置时读取本技能 `strategy-v1.json`，按V1连续加权评分计算综合分、子分数、权重贡献和等级。原问题页仅保留旧研究背景，不作为V1参数源。
7. 将每日结果写入 `sources/automations/中证红利信号/中证红利每日信号.xlsx`。
8. 将最近一次结果写入 `sources/automations/中证红利信号/最新信号.md`。
9. 将原始输入、实际数据日期、策略版本、得分贡献和连续确认状态写入 `sources/automations/中证红利信号/评分记录.json`。
10. 将指数成立以来每一年的收益率和年内最大回撤写入 `sources/automations/中证红利信号/中证红利年度表现.json`。

## 数据源优先级

本 skill 的主数据源优先级为：

1. AKShare 免费数据源。
2. 腾讯行情。
3. 理杏仁公开页面或由 Codex/大模型核验后通过参数传入的理杏仁分位数据。
4. 理杏仁不可用时，脚本用中证官方价格指数(000922)与全收益指数(H00922)推算的滚动12个月股息率及其近10年分位。

脚本会在来源说明中写明实际使用的数据源。不要把公开接口未返回字段理解为“没有股息率”；这只表示当前接口、权限或字段口径未取得，需要回退或人工核验。

| 数据 | 优先接口 | 回退接口 | 脚本用途 |
|---|---|---|---|
| 中证红利指数估值数据 | AKShare `stock_zh_index_value_csindex(symbol="000922")` | 无自动回退 | 使用 AKShare `股息率2` 作为绝对股息率和股债利差口径 |
| 中证红利指数日收盘价 | 中证指数官网 `index-perf(000922)` | AKShare `stock_zh_index_daily_tx(symbol="sh000922")`，再回退 `stock_zh_index_daily` | 官网日线从发布日期 `2008-05-26` 起计算逐年收益率和最大回撤；AKShare 只在官网失败时回退 |
| 中证红利当天行情 | 腾讯行情 `http://qt.gtimg.cn/q=sh000922` | 无自动回退 | 获取当天涨跌幅；日期默认等于记录日期，只记录，不修正股息率 |
| 中国10年国债收益率 | AKShare `bond_zh_us_rate(...)` | 无自动回退 | 获取中国10年国债收益率，用于计算股债利差 |
| 理杏仁指数估值分位 | 理杏仁公开页面 `https://www.lixinger.com/equity/index/detail/sh/000922/922/fundamental/valuation/dyr?metrics-type=mcw`（2026-10 起该页面对未登录访问返回 403“此页面已暂时关闭”） | Codex/大模型网页核验后用参数传入；再回退中证官方指数推算口径 | 获取中证红利近10年股息率分位和80%分位点 |
| 历史分位兜底口径 | 中证官方指数推算：AKShare `stock_zh_index_hist_csindex("000922")` × `stock_zh_index_hist_csindex("H00922")` | 无 | 推算滚动12个月股息率 = (TR/PR)(t) ÷ (TR/PR)(t-244) − 1，取当前值在近10年窗口的分位及窗口80%分位值；来源栏注明“中证官方指数推算” |

股息率口径约定：

- 使用 `股息率2` 作为本 skill 的默认数据源口径。
- 不使用 `股息率1` 作为默认口径。`股息率1` 与 `股息率2` 可能在同一天出现明显差异，例如 2026-06-02 中证红利 `股息率1 = 5.04%`，`股息率2 = 4.83%`。
- 未来更换数据源时，应优先寻找与 `股息率2` 对应或更接近指数实际权重的估值口径。
- 每天下午运行时，指数估值日期通常仍是上一个交易日；脚本会保留该估值日期和 `股息率2`，并额外记录当天涨跌幅（腾讯行情）。当天涨跌幅的日期默认等于同一行的记录日期，不单独写入行情日期列；不用当天涨跌幅修正股息率。
- 当前 AKShare 指数估值接口可能只返回最近一段数据，不一定足以直接计算真正的“近10年股息率分位”。若要严格执行历史分位点规则，应接入完整历史股息率数据源后再计算分位。
- 近10年历史分位点优先使用理杏仁分位数据；理杏仁公开页面已关闭且未传入核验参数时，自动使用中证官方指数推算口径（价格指数与全收益指数推算滚动12个月股息率），并在来源栏注明实际口径。该兜底口径与理杏仁市值加权股息率存在小幅方法差异，使用时注意区分。
- 年度收益率按每个自然年首个可用交易日收盘价至末个可用交易日收盘价计算；2008年标记为“成立首年”，当前年度标记为“年内”，其余标记为“完整年度”。
- 年内最大回撤按每个自然年内日收盘价相对此前峰值的最大跌幅计算，不跨年延续峰值。
- 不再调用理杏仁 Open API。公开页面失败时，不要编造数值；应由 Codex/大模型通过网页搜索或浏览器查询到可核验数值后，使用以下参数传入脚本：

```powershell
python .agents\skills\zzhl-dividend-signal\scripts\check_signal.py `
  --llm-lixinger-date "2026-07-03" `
  --llm-lixinger-dividend-yield "4.66" `
  --llm-lixinger-percentile-10y "30.44" `
  --llm-lixinger-percentile-80-value "6.12" `
  --llm-source-note "Codex/大模型网页查询：说明查询页面或检索来源"
```

如果需要人工核对原始指数页面，可从中证指数官网查询中证红利 `000922`：

```text
https://www.csindex.com.cn/
```

## V1 加权评分

不可变V1默认参数源为 [strategy-v1.json](strategy-v1.json)，基础算法版本 `dividend-weighted-v1`。每日脚本优先读取 `tools/a-share-market-dashboard/data/红利信号/strategy-settings.json` 的当前参数；配置尚不存在时使用V1默认值。看板的本地参数保存不会回写每日配置，只有“保存并应用到每日测算”会发布参数。

```text
综合分 = 历史分位得分 × 45% + 绝对股息率得分 × 30% + 股债倍数得分 × 25%
股债倍数 = 股息率2 ÷ 中国10年国债收益率
```

| 子分数 | 近10年历史分位 | 绝对股息率 | 股债倍数 |
|---:|---:|---:|---:|
| 0 | 0% | 3% | 1倍 |
| 40 | 50% | 4% | 2倍 |
| 60 | 70% | 5% | 3倍 |
| 80 | 80% | 6% | 4倍 |
| 100 | 100% | 7% | 5倍 |

两锚点之间线性插值：`s = s1 + (x−x1)/(x2−x1) × (s2−s1)`；低于或高于端点时分别截断至0或100。贡献为 `子分数 × 权重 / 100`，等级使用原始精度，展示一位小数。

| 综合分 | 等级 | 含义 |
|---|---|---|
| <40 | D | 吸引力偏弱 |
| ≥40且<60 | C | 基础配置区间 |
| ≥60且<80 | B | 加大买入区间 |
| ≥80 | A | 重点配置区间 |

Excel原有三项字母列在新记录中表示各项连续得分对应的等级，仅作分项说明；综合等级直接使用加权总分。综合B/A行标黄，不再以达标项数决定。旧行保留原有综合结论和原规则含义，不将其倒改为V1成绩；旧兼容函数仅用于读取旧记录。

### 数据质量与缺失

- 缺项不填零、不重新分配权重。下界为已知贡献之和，上界为下界加缺失项权重，不输出完整综合等级。
- 非有限数、负股息率、非正国债收益率、越界历史分位作为无效输入。无法取得关键源数据时保留原产物并明确报告失败，不制造数据。
- 官方指数推算等替代历史口径标为“参考评分”；数据质量单独显示，不混入估值分数扣分。
- 指数、分位、国债日期不一致或日期缺失时标为“日期未对齐”，不参与连续确认。页面分别显示真实日期。
- 来源切换或评分算法版本切换重新建立连续确认基准。分位序列必须使用一致方法；更换口径不拼接成同一估值历史。

### 连续确认

默认3个交易日，只影响策略调整提示，不改变当日分数或等级。使用既有指数日线实际交易日期作为证据日历，按指数估值日期去重，同日或休市日重跑不增加次数。

初次连续3个有效交易日为同一等级时建立基准；之后同一新等级连续3个有效交易日才提示调整。缺失或无效交易日中断连续序列，周末和节假日不计入交易日；来源/版本切换重建基准。缺少日历或记录时标为“证据不足”。旧历史数据试算和首次参考快照不作为正式V1确认记录。

### 结构化输出与兼容

`评分记录.json` 包含 `schemaVersion`、本次任务的 `strategy`、`latest`、`records` 和 `tradingDates`。每条记录保存 `input`、`dates`、`sourceKey`、`reference`、`kind`、`strategyVersion`、`components`、`score/lower/upper`、`grade/label`、`nextGrade/nextDistance`、`quality`、`eligible` 和原始字段 `raw`；最新条目附 `confirmation`。每条新增结果附 `strategySnapshot`，保留当次参数。历史记录按“估值日期＋策略版本”去重；同日新版本保留旧版本结果。Excel同记录日期的新策略版本亦保留旧行，同版本重跑才替换本版本行。

每日Markdown同步追加评分说明；Excel在原列之后追加策略版本、综合分/等级、上下界、三项得分/贡献、质量和连续确认状态，保留中文表头可见。旧文件缺少这些字段仍可读取。

首次离线重算使用以下命令，生成 `评分记录.json` 与 `V1参考快照.md`，不联网，不覆盖旧 `最新信号.md` 和工作簿，也不把重算时间当作行情日期：

```bash
.work/zzhl-dividend-signal/.venv/bin/python .agents/skills/zzhl-dividend-signal/scripts/check_signal.py --snapshot-from-local
```

正常每日运行命令和现有数据来源保持原流程，读取最新已应用的每日参数；单次任务开始时锁定参数快照，任务中途发布的新参数留待下次运行。参数或算法变更须更新版本，不能无声改变历史成绩。

### 看板参数设置

“策略详情”可编辑三项权重、五个输入锚点与内部得分、等级分界、连续确认天数。分数端点固定0/100，历史分位输入端点固定0%/100%。输入即校验，可保存到当前浏览器当前站点；可撤销未保存修改或恢复V1默认值。更换浏览器或服务端口不共享参数；存储不可用时明确提示仅保留本次会话。

权重各项大于0且合计100%；输入锚点与分数严格递增；分位0～100%、股息率锚点非负、倍数锚点正数；分界满足 `0<C<B<A<100`，确认天数1～20整数。无效值标注字段并禁用保存，不自动纠正。

看板展示“每日记录结果”和“策略详情”参数表单；本地实时测算卡片已移除，编辑参数不再生成当日试算分数、分差或等级变化。每日结果的连续确认按有效评分记录与交易日历判断，不按页面访问次数计数。

“保存本地参数”仅保留浏览器参数。“保存并应用到每日测算”调用本地服务 `POST /api/dividend-strategy`（`strategy` 与 `expectedRevision`），保存后下一次每日任务生效，同时同步浏览器本地参数。当前每日结果及旧历史不立即重算。`GET /api/dividend-strategy` 返回当前配置；修改前读取版本，冲突返回409并保留编辑参数。直接打开HTML或旧服务不支持应用时，提示使用/重启启动面板。

每日配置文件包含 `schemaVersion`、`revision`、`strategy`、`updatedAt`、`history`。首次变更发布 `dividend-weighted-v1-r1`，后续每次参数变化递增revision；相同参数重复应用不生成新版本。配置历史保留各版完整参数和北京时间。写入使用进程/文件锁与原子替换，非法参数或保存失败不覆盖原配置；配置损坏明确报错，不静默退回默认。保存配置不改调度时间、不主动运行每日任务。恢复V1默认值先只改变编辑参数，需再次点击应用按钮才发布到每日任务。

版本改变后连续确认重新建立基准；已记录旧版本的分数、贡献和结论仍可回溯。

### 验证边界

权重45/30/25和各锚点为用户确认的设计初值，尚未经收益回测证明优于旧策略。历史分位、绝对股息率和股债倍数共享股息率信息，权重没有消除相关性。当前输出是估值吸引力评分，不代表上涨概率，不直接规定投入金额、频率或仓位比例。

数学与行为验证使用 [共享样例](tests/scoring-cases.json)、Python `tests/test_scoring.py` 和看板 `dividend-scoring.test.mjs`；截图数据35.83%、4.13%、1.67%为38.0440694611分，显示38.0、D。
