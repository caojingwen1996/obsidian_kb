# 个股估值计算

## 定位

本技能只解决三个问题：

1. 企业在可审计假设下值多少钱；
2. 当前价格隐含了什么增长、利润率、周期位置或成功概率；
3. 现价中有多少是公允价值、可解释估值溢价和交易定价偏离，是否已进入估值泡沫。

它不是全能公司研报。产业方向、财报质量、资金结构和风险状态可以由相邻技能提供；本技能只提取会改变估值模型、公允价值区间、市场价格分解和估值泡沫判断的部分。

## 必读估值框架

执行市场价格分解和估值泡沫判断前，必须读取知识库 [wiki/concepts/冰冰小美-framework-估值判断.md](../../../wiki/concepts/冰冰小美-framework-估值判断.md)。本技能的操作规则必须服从该页的三个价格层次：

```text
市场价格
= 已验证业务及概率加权未来业务的公允价值
+ 未在公允价值模型中重复计入的可解释估值溢价
+ 交易定价偏离
```

其中，交易定价偏离来自流动性、风险偏好、杠杆、拥挤、抱团和情绪一致性；它可以为正，也可以为负。价格高于公允价值中枢只说明存在溢价，不自动等于泡沫。

## 开始前确认

- 公司名称、证券代码、市场和币种；
- 估值基准日、当前价格及价格时间；
- 用户需要完整重估、局部重算还是只更新交易定价偏离；
- `workbench/targets/` 是否已有同一证券代码的权威估值报告；
- 是否已有同一标的最新“产业思维分析”报告；
- 是否发生足以推翻产业或财务基线的重大事项。

证券身份、币种或复权口径不清时先核验，不得在身份未确认时计算每股价值。

## 前置输入：个股产业思维筛选

估值前优先读取同一标的由 `个股产业思维筛选` 生成的最新权威 Markdown 报告。llmwiki 中优先按证券代码检索：

```text
workbench/targets/*<标的>*产业思维分析.md
```

从报告中只提取以下估值前提：

1. 产业趋势和生命周期；
2. 公司产业链位置与利润池来源；
3. 比较优势及持续性；
4. 各业务分部成熟度；
5. 第二增长曲线的兑现阶段和失败概率；
6. 产业约束、反证与失效条件。

不得机械照搬。必须检查报告的数据截止时间，以及此后是否出现重大并购、定增、资产注入、政策变化、技术路线变化、订单或产能变化。只有会改变估值锚的事实需要重新核验。

没有产业思维报告时允许降级运行：

- 完整估值请求：优先先执行 `个股产业思维筛选`；
- 无法执行上游技能或用户只要快速估值：完成最低限度的产业前提核验，在报告中写明缺口，并下调结论置信度；
- 不得为了补缺口在本报告中展开一份完整产业分析。

## 证据与数据

### 来源优先级

1. 交易所、监管机构、公司公告、法定财报和业绩说明材料；
2. 本地结构化金融数据工具；A 股优先 Tushare 数据工具；
3. 公司官网、投资者关系材料和正式演示；
4. 可靠数据库、券商研究和行业协会；
5. 主流财经媒体；
6. 搜索摘要、论坛和社交平台只作为线索。

所有关键输入必须标注日期、单位和口径。未取得的数据写“未获取到”，不得用搜索摘要或市场价格反推成事实。

### A股最低数据集

| 数据 | 用途 |
|---|---|
| 证券身份、总股本和流通股本 | 每股价值与稀释计算 |
| 当前及历史行情、估值指标 | 价格位置、交易定价偏离和历史位置 |
| 3—5年财务及最新报告期 | 盈利正常化、现金流和资产质量 |
| 分部收入、利润、资本投入 | SOTP和利润来源拆解 |
| 分红、回购、增减持、定增和可转债 | 股东价值桥与稀释 |
| 资金流、融资、换手和成交结构 | 交易定价偏离持续性 |
| 连续多期股东人数 | 筹码集中或分散趋势 |
| 大宗交易、龙虎榜和公开持仓变化 | 交易方画像；发生时重点检查 |

股东人数只能使用连续变化，不能用单点下结论；户数下降不等于机构增持，户数上升也不等于必然利空。资金流和交易方画像不能证明基本面改善或恶化。

## 估值流程

### Step 1：读取上游结论并建立估值基线

记录产业思维报告路径、截止时间、可复用结论和待复核事项。随后提取3—5年财务与最新报告期，完成：

- 非经常损益、资产处置、补贴和会计口径调整；
- 周期高点或低点的盈利正常化；
- 资本化研发、租赁、少数股东权益和净债务调整；
- 定增、可转债、股权激励和潜在稀释；
- 自由现金流与利润的差异解释。

### Step 2：判断价值类型与估值锚

| 价值类型 | 主估值锚 | 常用交叉验证 |
|---|---|---|
| 稳定盈利 | DCF、合理PE | EV/EBITDA、股息率 |
| 周期资源 | 正常化盈利、资产价值 | PB、周期中枢、单位资源价值 |
| 重资产 | 重置成本、NAV、正常化ROIC | PB、EV/EBITDA |
| 成长企业 | 收入—利润—现金流路径 | PEG、PS、反向DCF |
| 多业务集团 | SOTP | 整体倍数与控股折价 |
| 前沿科技 | 已验证基本盘＋概率加权期权价值 | 融资稀释、里程碑与反向估值 |

企业存在多类业务时按分部成熟度选择估值方法，不得用一个整体PE掩盖成熟业务和未商业化业务的差异。涉及前沿科技时读取 [references/frontier-tech-valuation.md](references/frontier-tech-valuation.md)。

### Step 3：计算公允价值范围

至少使用一种主方法和一种交叉验证方法；方法不适用时明确说明原因，不机械凑齐DCF、相对估值和SOTP。

公允价值范围必须解释：

- 下限：保守经营和可验证资产对应的价值；
- 中枢：最可能经营路径和合理资本成本对应的价值；
- 上限：合理乐观情景、已审计成长溢价或概率加权新业务价值；
- 高于上限：需要哪些新增订单、利润率、现金流、周期或成功概率才能成立。

不同模型按数据质量和商业模式适用性赋权，不机械平均。必须检查重复计入：竞争优势、成长、概率、时间折现、未来投入和融资稀释不能在多个环节重复加减。

### Step 4：情景、敏感性与反向估值

至少给出悲观、基准、乐观三个情景，并展示真正驱动结果的2—4个变量。反向估值必须计算现价隐含的增长、利润率、资本回报、周期位置或成功概率，并与历史、产业约束、可比公司和上游产业结论比较。

### Step 5：市场价格分解与估值泡沫判断

先完成价格位置与安全边际计算，作为泡沫判断的价格层输入：

```text
相对中枢溢价率 = 当前价格 ÷ 公允价值中枢 - 1
相对上限偏离率 = 当前价格 ÷ 公允价值上限 - 1
中枢潜在回报 = 公允价值中枢 ÷ 当前价格 - 1
保守安全边际 = 1 - 当前价格 ÷ 公允价值下限
相对中枢溢价金额 = 当前价格 - 公允价值中枢
上沿外偏离金额 = max(0, 当前价格 - 公允价值上限)
```

这些指标只说明现价在估值区间中的位置，不直接给出泡沫结论。周期股还必须对比正常化周期中枢，成长股必须对比反向估值隐含的增长年限，前沿业务必须对比成功概率和后续融资稀释。

严格按 `wiki/concepts/冰冰小美-framework-估值判断.md` 分三层计算：

```text
市场价格 = 公允价值 + 可解释估值溢价 + 交易定价偏离

可解释估值溢价
= 已验证、但尚未在增长率、利润率、折现率、估值倍数或概率权重中计入的质量或成长价值

交易定价偏离估算
= 当前价格 - 公允价值中枢 - 可解释估值溢价

交易定价偏离率
= 交易定价偏离估算 ÷ 公允价值中枢
```

公允价值本身是区间，因此不能把中枢残差伪装成精确真值。必须同时报告 `相对中枢溢价率`、`相对上限偏离率` 和 `上沿外偏离金额`。可解释估值溢价无法独立量化时写“未单独量化”，不得为了凑出交易定价偏离而倒推一个无证据数字。

如果企业质量和成长已经体现在增长率、利润率、折现率、估值倍数或成功概率中，不得再次增加“质量溢价”。只有订单、利润、现金流、定价权、ROIC 或产业里程碑已验证，且模型尚未计入时，才允许单列可解释估值溢价。

估值泡沫判断依次执行：

1. 价格层：现价相对公允价值下限、中枢和上限的位置；
2. 反向估值层：现价隐含的增长年限、稳态利润率、ROIC、周期位置或成功概率是否可实现；
3. 经营验证层：订单能否转化为收入、利润和自由现金流，是否扣除后续投入、融资稀释和失败概率；
4. 交易驱动层：价格是否主要依赖流动性、杠杆、拥挤、抱团、风险偏好和情绪一致性；
5. 压力测试层：流动性恢复正常或增长降至正常水平后，基本面价值能否继续支撑现价，市场是否仍认真讨论失败情景。

交易定价偏离必须结合以下证据判断方向和持续性：

- 多窗口资金流与成交结构；
- 融资余额、换手率和拥挤度；
- 连续多期股东人数变化；
- 机构、产业资本、游资、散户等交易方画像；
- 大宗交易、龙虎榜、回购、增减持和解禁；
- 资金、筹码与价格是否同向确认。

完整资金研究优先调用 `fund-flow-analysis`，本技能只读取与交易定价偏离直接相关的结论。资金流入不能抬高内在价值，资金流出也不能直接下调内在价值；它们只改变交易定价偏离、风险折价和偏离持续性的判断。

默认输出以下一个状态，并同时列出支持证据、反证和置信度：

- `折价`：现价低于公允价值下限；
- `公允价值内`：现价位于公允价值区间，且反向估值假设没有明显超出产业与经营约束；
- `估值溢价`：现价包含区间上部或区间外溢价，但额外质量、成长或产业兑现已有可验证证据；
- `普通高估`：现价高于合理区间，隐含假设偏乐观但仍存在可验证实现路径，交易定价偏离开始主导；
- `估值泡沫`：现价明显依赖未兑现的远期增长、流动性、杠杆或一致性情绪，正常化假设难以支撑；
- `严重估值泡沫`：只有多个极端假设同时成立才能支撑现价，并伴随现金流、融资依赖、拥挤或承接脆弱等高风险证据；
- `证据不足`：缺少现价、公允价值、反向估值或经营/交易证据，无法完成分层判断。

状态不能只按单一百分比机械映射。`相对上限偏离率`越高、反向假设越不可实现、经营兑现越弱、流动性与杠杆依赖越强，泡沫等级才越高。

默认报告必须读取并完整执行 [references/valuation-bubble-trigger-scan.md](references/valuation-bubble-trigger-scan.md) 的32项扫描：基本面9项、流动性14项、预期9项。每个观察项都必须单列，不得合并、抽样或跳过；状态只允许 `有利 / 逆转 / 证据不足 / 不适用`。`逆转`必须给出当前证据与时间，`不适用`必须解释原因，没有数据必须写`证据不足`。

32项扫描后必须汇总三类状态数量、击中主估值锚的关键逆转、基本面—流动性—预期之间是否形成传导链，以及 `未见出清触发 / 出清观察 / 出清中 / 证据不足`。逆转项数量只检查扫描完整性，不用于机械打分，也不能替代公允价值和反向估值。

所有标的先按 [references/inflation-transmission.md](references/inflation-transmission.md) 做通胀暴露筛查；高暴露或中等暴露时读取全文并展开分部传导，低暴露时不设置独立通胀章节，证据缺失时写“证据不足”。

### Step 6：形成结论与失效条件

结论必须回答：

- 当前基本面状态是否支持原估值锚；
- 公允价值下限、中枢和上限；
- 当前市场价格分解、交易定价偏离及主要来源；
- 当前属于折价、公允价值内、估值溢价、普通高估、估值泡沫、严重估值泡沫还是证据不足；
- 资金与筹码是否支持交易定价偏离继续维持；
- 哪些事实会触发局部重算或完整重估；
- 当前动作是 `buy / reduce / sell / wait / observe / review` 中哪一种及原因。

## 每日跟踪面板

HTML必须在五章正文前生成唯一一组每日跟踪面板。面板不是独立章节，不进入目录，只读取第1章同名字段。

固定四张卡片，顺序不得改变：

1. `基本面状态`：改善 / 稳定 / 走弱 / 待确认，加一句关键依据；
2. `公允价值范围`：下限—上限、中枢和估值基准日；
3. `交易定价偏离`：现价、相对中枢溢价率、相对上限偏离率、市场价格分解及泡沫状态；
4. `资金与筹码`：资金趋势、股东人数趋势和主要交易方画像；缺失项明确标注。

`每日跟踪时间`必须注明收盘、盘中或重大公告后的具体时点。只有价格变化时更新交易定价偏离，不修改公允价值范围；只有估值输入或核心假设变化达到重估条件时，才重算内在价值。

## 报告结构

使用同目录 [template.md](template.md)。Markdown正文必须且只能包含以下5个编号二级标题，名称和顺序完全一致：

```text
1. 估值摘要
2. 估值基础
3. 估值方法与假设
4. 估值结果与交易溢价
5. 风险与结论
```

允许使用三级标题组织细节，但不得增加第6个编号二级标题。来源清单、数据缺口和声明放在第5章末尾的信息块中，不再单独占目录。

## llmwiki落盘

为兼容既有权威研报、产业反向链接和持仓每日监控，继续使用：

- Markdown：`workbench/targets/YYYY-MM-DD-HHmm-<标的>-机构级决策研报.md`；
- frontmatter：`artifact_type: equity_research`；
- HTML：原自动化分类 `sources/automations/<分类>/`，未分类时使用 `sources/automations/temp/`；
- 同一证券代码已有权威研报时原地更新，不新建第二份权威研报；
- `workbench/targets/`保持扁平；
- 更新 `workbench/index.md` 和根 `log.md`，不更新根 `index.md`。

旧版16章报告保留为历史内容；下一次明确重估时，读取原报告证据并迁移为五章结构，不得只为换模板而无依据改写估值结论。
