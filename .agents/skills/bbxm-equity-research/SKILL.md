# 个股估值计算

## 定位

本技能只解决三个问题：

1. 企业在可审计假设下值多少钱；
2. 当前价格隐含了什么增长、利润率、周期位置或成功概率；
3. 现价中有多少是公允价值、可解释估值溢价和交易定价偏离，是否已进入估值泡沫。

它不是全能公司研报。产业方向、财报质量、资金结构和风险状态可以由相邻技能提供；本技能只提取会改变估值模型、公允价值区间、市场价格分解和估值泡沫判断的部分。

## 必读估值框架

开始估值前，必须读取知识库 [wiki/concepts/冰冰小美-framework-估值判断.md](../../../wiki/concepts/冰冰小美-framework-估值判断.md) 的最新正文，包括“基本面判断”；不得仅凭历史报告或本技能中的摘要执行。先完成六项基本面核验，再计算公允价值、市场价格分解和估值泡沫状态。在报告 `framework_refs` 中记录框架路径，并注明本次读取日期。本技能的操作规则必须服从该页的三个价格层次：

```text
市场价格
= 已验证业务及概率加权未来业务的公允价值
+ 未在公允价值模型中重复计入的可解释估值溢价
+ 交易定价偏离
```

其中，交易定价偏离来自流动性、风险偏好、杠杆、拥挤、抱团和情绪一致性；它可以为正，也可以为负。价格高于公允价值中枢只说明存在溢价，不自动等于泡沫。

## 开始前确认

- 公司名称、证券代码、市场和币种；
- 估值基准日、当前价格及价格时间；
- 用户需要完整重估、局部重算还是只更新交易定价偏离；
- `workbench/targets/` 是否已有同一证券代码的权威估值报告；
- 是否已有同一标的最新“产业思维分析”报告；
- 是否发生足以推翻产业或财务基线的重大事项。

证券身份、币种或复权口径不清时先核验，不得在身份未确认时计算每股价值。

## 前置输入：个股产业思维筛选

估值前优先读取同一标的由 `个股产业思维筛选` 生成的最新权威 Markdown 报告。llmwiki 中优先按证券代码检索：

```text
workbench/targets/*<标的>*产业思维分析.md
```

从报告中只提取以下估值前提：

1. 产业趋势和生命周期；
2. 公司产业链位置与利润池来源；
3. 比较优势及持续性；
4. 各业务分部成熟度；
5. 第二增长曲线的兑现阶段和失败概率；
6. 产业约束、反证与失效条件。

不得机械照搬。必须检查报告的数据截止时间，以及此后是否出现重大并购、定增、资产注入、政策变化、技术路线变化、订单或产能变化。只有会改变估值锚的事实需要重新核验。

没有产业思维报告时允许降级运行：

- 完整估值请求：优先先执行 `个股产业思维筛选`；
- 无法执行上游技能或用户只要快速估值：完成最低限度的产业前提核验，在报告中写明缺口，并下调结论置信度；
- 不得为了补缺口在本报告中展开一份完整产业分析。

## 证据与数据

### 来源优先级

1. 交易所、监管机构、公司公告、法定财报和业绩说明材料；
2. 本地结构化金融数据工具；A 股优先 Tushare 数据工具；
3. 公司官网、投资者关系材料和正式演示；
4. 可靠数据库、券商研究和行业协会；
5. 主流财经媒体；
6. 搜索摘要、论坛和社交平台只作为线索。

所有关键输入必须标注日期、单位和口径。未取得的数据写“未获取到”，不得用搜索摘要或市场价格反推成事实。

### A股最低数据集

| 数据 | 用途 |
|---|---|
| 证券身份、总股本和流通股本 | 每股价值与稀释计算 |
| 当前及历史行情、估值指标 | 价格位置、交易定价偏离和历史位置 |
| 3—5年财务及最新报告期 | 盈利正常化、现金流和资产质量 |
| 分部收入、利润、资本投入 | SOTP和利润来源拆解 |
| 分红、回购、增减持、定增和可转债 | 股东价值桥与稀释 |
| 资金流、融资、换手和成交结构 | 交易定价偏离持续性 |
| 连续多期股东人数 | 筹码集中或分散趋势 |
| 大宗交易、龙虎榜和公开持仓变化 | 交易方画像；发生时重点检查 |

股东人数只能使用连续变化，不能用单点下结论；户数下降不等于机构增持，户数上升也不等于必然利空。资金流和交易方画像不能证明基本面改善或恶化。

## 估值流程

### Step 1：读取上游结论并建立估值基线

记录产业思维报告路径、截止时间、可复用结论和待复核事项。随后提取3—5年财务与最新报告期，完成：

- 非经常损益、资产处置、补贴和会计口径调整；
- 周期高点或低点的盈利正常化；
- 资本化研发、租赁、少数股东权益和净债务调整；
- 定增、可转债、股权激励和潜在稀释；
- 自由现金流与利润的差异解释。

随后按知识库“基本面判断”逐项建立六项证据表，写入报告第2章2.5。已有财报研究可复用，但须复核截止时间、口径与重大变化；没有上游财报报告也不能跳过六项核验。

| 基本面维度 | 必查数据与判断 | 对估值的影响 |
|---|---|---|
| 负债 | 总负债、短期与长期结构、有息负债、利息负担和到期偿付压力；区分经营性负债与融资负债，结合行业和融资用途判断 | 净债务、利息费用、融资成本、再融资与稀释情景 |
| 净现金 | 现金及等价物＋短期投资－有息负债；列明各分项，剔除重复统计，核验受限资金与短期投资的可变现性 | 财务安全垫、股东价值桥、分红回购和未来投入能力 |
| 现金流 | 经营活动现金流及其与利润的连续多期关系，追踪应收、存货、回款与营运资金占用；另列资本开支与自由现金流 | 现金转换率、营运资本和未来自由现金流预测 |
| 开销合理性 | 分别检查销售、管理、研发费用占收入或毛利润的比例、历史稳定性和可比公司差异，注明分母及资本化研发口径 | 可持续费用率、利润率和研发投入假设 |
| 真实利润 | 从归母净利润桥接至扣非归母净利润和正常化可持续利润，说明资产处置、公允价值变动等调整，并与经营现金流交叉核验 | PE盈利基数、周期正常化和DCF盈利现金化路径 |
| 扣除商誉的净资产 | 同口径净资产（股东权益）－商誉；明确合并或归母口径，不能直接用合并商誉扣归母权益 | PB / NAV资产质量交叉验证及减值压力情景 |

**固定顺序与判断权重：** 六项必须始终按 `1.负债 → 2.净现金 → 3.现金流 → 4.开销合理性 → 5.真实利润 → 6.扣除商誉的净资产` 执行和展示，顺序代表判断权重由高到低，不只是排版顺序。基本面分析正文、证据表、摘要中列举六项及HTML展示均不得重排、合并或省略；缺失或不适用项保留原位置并说明原因。

综合判断时先解释高权重项，再用后续指标补充和交叉验证。指标冲突时，必须说明高权重项如何约束最终基本面状态及估值假设，不能用低权重项表现良好或有利项数量多，直接抵消高权重项的实质风险或掩盖其证据缺口。权重是相对优先级；用户未指定百分比，不自行编造数值权重、加权总分或一票否决规则。

每项都要列当前值、比较期值、变化原因、来源与时间、证据缺口，以及受影响的模型参数或“暂不调整”的理由。流量数据使用可比期间，不将半年累计值直接与全年比较；缺失数据写“未获取到 / 待验证”。不适用须解释行业原因及替代核验口径。

**摘要必须明确变化方向：** 基本面卡片六行均写“关键数值＋比较口径＋改善／恶化／持平（或分化、待验证）”，不能只并排列数字、只写增长率或让读者自行判断。流量用同口径同比，存量若仅比较上年末则明确写“较年末”，不得误称同比。融资义务增加写“融资负担较年末恶化”，减少写“融资负担改善”，不据此断言偿债危机；净现金减少或净负债扩大写“严格现金缓冲恶化”，理财/定存另列，不能冒充全部资金流失。现金流同时说明CFO与FCF代理的各自方向；负值缺口缩小是改善但仍为负。扣非利润增长写“同比改善”，减少或亏损扩大写“同比恶化”；合并范围变化不可比时写“同比待验证”并注明原因。费用率分别升降时写“同比分化”，明确哪项改善、哪项费用负担加重，不能将研发减少直接等同效率提升。扣商誉净资产增加只写“账面规模较年末改善”，不推断资产质量改善；近似持平需说明精度或微小变化，不能抹去真实差异。各项方向不代替综合判断，也不改六项权重顺序。

六项是估值输入核验，不是机械打分：净现金为正不能单独证明可长期存活，需结合现金消耗和偿付义务；经营现金流为负须检查经营周期和营运资金原因，不能直接认定利润虚假；扣除商誉的净资产不等于清算价值。上述为执行口径约束，不改写知识库原文。

净现金与净债务必须对账。进入股东价值桥的仅为模型尚未计入且可归属股东的现金或资产，不得在企业价值转股权价值、PE / PB与SOTP中重复加现金、扣债务或扣商誉。

综合状态判断的是本次已披露报告期相对比较期的变化，给出 `改善 / 稳定 / 走弱`，不是预测未来经营。已有半年报和比较数据时必须按六项权重作出方向判断，不得因为缺少9月数据、等待下半年或指标分化而写“待确认”。分化时解释主导因素与反证；“稳定”必须有总体变化不显著的证据，不能代替不敢判断。观察期与比较期写在六项指标对应行和第2章2.5，直写“余额较2025年末；利润、现金流较2025年上半年”，不用“存量比、流量比”等缩写，不放入“综合”一栏。确实缺失可比数据的具体指标保留缺口；若全部关键依据不足则明确“数据不足，无法判断”，不得编造方向。合并范围变化时限定可判断的财务范围，不声称经营同比可比。未来持续性和项目估值缺口另行说明，不改变已确认的当期方向。将影响估值锚的变化写入第6章重估条件；本规则不改变4.5的32项触发扫描状态。

### Step 2：判断价值类型与估值锚

| 价值类型 | 主估值锚 | 常用交叉验证 |
|---|---|---|
| 稳定盈利 | DCF、合理PE | EV/EBITDA、股息率 |
| 周期资源 | 正常化盈利估值（正常化归母利润×周期PE）、资产价值 | PB、周期中枢、单位资源价值 |
| 重资产 | 重置成本、NAV、正常化ROIC | PB、EV/EBITDA |
| 成长企业 | 收入—利润—现金流路径 | PEG、PS、反向DCF |
| 多业务集团 | SOTP | 整体倍数与控股折价 |
| 前沿科技 | 已验证基本盘＋概率加权期权价值 | 融资稀释、里程碑与反向估值 |

企业存在多类业务时按分部成熟度选择估值方法，不得用一个整体PE掩盖成熟业务和未商业化业务的差异。涉及前沿科技时读取 [references/frontier-tech-valuation.md](references/frontier-tech-valuation.md)。

**估值方法命名：** 报告标题、计算结果速览、表格及正文必须使用具体方法名称，与本技能保持一致；不得用“主模型”“主方法”等角色名称代替计算方法。周期归母利润乘PE统一写“正常化盈利估值”，首次出现注明“正常化归母利润×周期PE”；其他方法写清DCF、合理PE、PB、NAV、EV/EBITDA、SOTP或概率加权期权价值等实际方法。多种方法加权后的结果写“综合估值（列明方法与权重）”，不得将综合值误称为其中一种方法的结果。主要方法与交叉验证的角色、权重另列，不改变原计算或证据边界。

**主估值锚与交叉验证：** 在计算结果速览和方法路由中明确列出“主估值锚：具体方法名称”和“交叉验证方法：具体方法名称”。主估值锚写清公式、选择依据、结果及是否决定最终区间；每项交叉验证写清核验对象、结果、要防范的误判及局限。明确交叉验证是仅作约束还是参与加权，参与时列出实际权重；不存在独立价值结果时写明仅作一致性检查，不编造点值或权重。方法共享利润或资产输入时说明相关性，不称为独立证据；出现分歧时说明对最终区间或置信度的影响，不机械平均。

### Step 3：计算公允价值范围

至少使用一种主方法和一种交叉验证方法；方法不适用时明确说明原因，不机械凑齐DCF、相对估值和SOTP。

公允价值范围必须解释：

- 下限：保守经营和可验证资产对应的价值；
- 中枢：最可能经营路径和合理资本成本对应的价值；
- 上限：合理乐观情景、已审计成长溢价或概率加权新业务价值；
- 高于上限：需要哪些新增订单、利润率、现金流、周期或成功概率才能成立。

不同模型按数据质量和商业模式适用性赋权，不机械平均。必须检查重复计入：竞争优势、成长、概率、时间折现、未来投入和融资稀释不能在多个环节重复加减。

### Step 4：情景、敏感性与反向估值

至少给出悲观、基准、乐观三个情景，并展示真正驱动结果的2—4个变量。反向估值必须计算现价隐含的增长、利润率、资本回报、周期位置或成功概率，并与历史、产业约束、可比公司和上游产业结论比较。

同时读取 [references/kelly-position-sizing.md](references/kelly-position-sizing.md)，根据价值下限、上限和有日期的现价计算凯利情景，写入第5章5.1及公允价值卡片。使用部分亏损公式 `f*=p/d−(1−p)/u`，不得把区间位置当作胜率。没有概率证据时展示50%、60%、70%、80%、90%假设敏感性，标明真实概率待验证；输出盈亏幅度、盈亏平衡概率、理论值、仅做多不加杠杆全凯利与半凯利。区间外不强行套公式，按 reference 保留不适用原因。此为条件化仓位测算，不自动替换已有交易结论。

### Step 5：市场价格分解与估值泡沫判断

先完成价格位置与安全边际计算，作为泡沫判断的价格层输入：

```text
相对中枢溢价率 = 当前价格 ÷ 公允价值中枢 - 1
相对上限偏离率 = 当前价格 ÷ 公允价值上限 - 1
中枢潜在回报 = 公允价值中枢 ÷ 当前价格 - 1
保守安全边际 = 1 - 当前价格 ÷ 公允价值下限
相对中枢溢价金额 = 当前价格 - 公允价值中枢
上沿外偏离金额 = max(0, 当前价格 - 公允价值上限)
```

这些指标只说明现价在估值区间中的位置，不直接给出泡沫结论。周期股还必须对比正常化周期中枢，成长股必须对比反向估值隐含的增长年限，前沿业务必须对比成功概率和后续融资稀释。

严格按 `wiki/concepts/冰冰小美-framework-估值判断.md` 分三层计算：

```text
市场价格 = 公允价值 + 可解释估值溢价 + 交易定价偏离

可解释估值溢价
= 已验证、但尚未在增长率、利润率、折现率、估值倍数或概率权重中计入的质量或成长价值

交易定价偏离估算
= 当前价格 - 公允价值中枢 - 可解释估值溢价

交易定价偏离率
= 交易定价偏离估算 ÷ 公允价值中枢
```

公允价值本身是区间，因此不能把中枢残差伪装成精确真值。必须同时报告 `相对中枢溢价率`、`相对上限偏离率` 和 `上沿外偏离金额`。可解释估值溢价无法独立量化时写“未单独量化”，不得为了凑出交易定价偏离而倒推一个无证据数字。

如果企业质量和成长已经体现在增长率、利润率、折现率、估值倍数或成功概率中，不得再次增加“质量溢价”。只有订单、利润、现金流、定价权、ROIC 或产业里程碑已验证，且模型尚未计入时，才允许单列可解释估值溢价。

估值泡沫判断依次执行：

1. 价格层：现价相对公允价值下限、中枢和上限的位置；
2. 反向估值层：现价隐含的增长年限、稳态利润率、ROIC、周期位置或成功概率是否可实现；
3. 经营验证层：订单能否转化为收入、利润和自由现金流，是否扣除后续投入、融资稀释和失败概率；
4. 交易驱动层：价格是否主要依赖流动性、杠杆、拥挤、抱团、风险偏好和情绪一致性；
5. 压力测试层：流动性恢复正常或增长降至正常水平后，基本面价值能否继续支撑现价，市场是否仍认真讨论失败情景。

交易定价偏离必须结合以下证据判断方向和持续性：

- 多窗口资金流与成交结构；
- 融资余额、换手率和拥挤度；
- 连续多期股东人数变化；
- 机构、产业资本、游资、散户等交易方画像；
- 大宗交易、龙虎榜、回购、增减持和解禁；
- 资金、筹码与价格是否同向确认。

完整资金研究优先调用 `fund-flow-analysis`，本技能只读取与交易定价偏离直接相关的结论。资金流入不能抬高内在价值，资金流出也不能直接下调内在价值；它们只改变交易定价偏离、风险折价和偏离持续性的判断。

默认输出以下一个状态，并同时列出支持证据、反证和置信度：

- `折价`：现价低于公允价值下限；
- `公允价值内`：现价位于公允价值区间，且反向估值假设没有明显超出产业与经营约束；
- `估值溢价`：现价包含区间上部或区间外溢价，但额外质量、成长或产业兑现已有可验证证据；
- `普通高估`：现价高于合理区间，隐含假设偏乐观但仍存在可验证实现路径，交易定价偏离开始主导；
- `估值泡沫`：现价明显依赖未兑现的远期增长、流动性、杠杆或一致性情绪，正常化假设难以支撑；
- `严重估值泡沫`：只有多个极端假设同时成立才能支撑现价，并伴随现金流、融资依赖、拥挤或承接脆弱等高风险证据；
- `证据不足`：缺少现价、公允价值、反向估值或经营/交易证据，无法完成分层判断。

状态不能只按单一百分比机械映射。`相对上限偏离率`越高、反向假设越不可实现、经营兑现越弱、流动性与杠杆依赖越强，泡沫等级才越高。

默认报告必须读取并完整执行 [references/valuation-bubble-trigger-scan.md](references/valuation-bubble-trigger-scan.md) 的32项扫描：基本面9项、流动性14项、预期9项。每个观察项都必须单列，不得合并、抽样或跳过；状态只允许 `有利 / 当期恶化，持续性待确认 / 不利信号出现 / 证据不足 / 不适用`。`不利信号出现`必须给出当前证据与时间，`不适用`必须解释原因，没有数据必须写`证据不足`。已有同口径数据确认当期恶化，但触发器要求的持续性或机制尚未验证时，必须写`当期恶化，持续性待确认`，不能仅写`证据不足`，也不自动升级为`不利信号出现`。证据列写清当期与比较期，缺口列写清尚缺的持续性证据和下一验证节点。

32项扫描后必须分别汇总三张表内五类扫描状态数量、击中主估值锚的关键不利信号、基本面—流动性—预期之间是否形成传导链，以及 `未见出清触发 / 出清观察 / 出清中 / 证据不足`。不利信号项数量只检查扫描完整性，不用于机械打分，也不能替代公允价值和反向估值。

所有标的先按 [references/inflation-transmission.md](references/inflation-transmission.md) 做通胀暴露筛查；高暴露或中等暴露时读取全文并展开分部传导，低暴露时不设置独立通胀章节，证据缺失时写“证据不足”。

### Step 6：仓位测算、网格交易与最终结论

第5章独立列出仓位测算与网格交易：5.1承接凯利输入、公式、五档概率敏感性和仓位边界；5.2评估网格适用性并列参数；5.3列执行约束与停止条件。凯利是单资产条件测算，不是网格策略胜率或网格资金预算。第6章保留估值失效条件与最终结论。

网格部分必须区分估值区间与交易区间；不得直接将公允价值上下限当作网格边界。列明区间依据、等差/等比、格数/间距、每格金额或股数、最大仓位、备用现金、费用、交易单位与市场交易限制。未知参数标待确认，不生成可执行价位、订单或回测收益。规则变动须按交易市场核验；仅在参数充分时计算网格，列明向下突破、单边上涨、库存耗尽、估值失效和资金不足时的处理，不能默认无限补仓。未做回测时明确说明，不宣称网格改善收益。

结论必须回答：

- 当前基本面状态是否支持原估值锚；
- 公允价值下限、中枢和上限；
- 当前市场价格分解、交易定价偏离及主要来源；
- 当前属于折价、公允价值内、估值溢价、普通高估、估值泡沫、严重估值泡沫还是证据不足；
- 资金面是否支持交易定价偏离继续维持；
- 哪些事实会触发局部重算或完整重估；
- 当前动作是 `buy / reduce / sell / wait / observe / review` 中哪一种及原因。

## 每日跟踪面板

HTML必须在六章正文前生成唯一一组每日跟踪面板。面板不是独立章节，不进入目录，读取第1章对应字段；“心理面”是展示主标题，读取“公允价值范围”和“凯利测算”字段。

固定四张卡片，顺序不得改变：

1. `基本面状态`：直接逐行显示 `负债：…`、`净现金：…`、`现金流：…`、`开销合理性：…`、`真实利润：…`、`扣除商誉的净资产：…`，顺序代表权重，不得变更。每行填关键数值（含单位与必要口径）和简短判断，不用长段落代替指标；Markdown 表格单元格内用 `<br>` 分行。缺数值写“待验证”，有实际债务不得写“无负债”。六项后的“综合”写1—2句完整结论：先给改善 / 稳定 / 走弱，再说明决定判断的高权重主导因素；有指标分化时交代关键反证为何未改变总体判断。写法示例（仅示意，须按标的证据重写）：“综合：走弱。融资负担加重、净现金缓冲收窄且现金流恶化，利润增长尚不足以抵消财务压力。”不只写状态标签，不把比较期、数据口径、“不外推未来经营”“详见正文”等备注放在此处；这些信息保留在六项对应行或第2章2.5，未来持续性限制放第6章。关键证据不足时写“综合：数据不足，无法判断”，并点明缺失的关键依据；所有内容追溯至第2章2.5；
2. `心理面`：卡片顶部显示主标题“心理面”，下设“公允价值范围”和“凯利测算”子标题；公允价值范围展示下限—上限、中枢和估值基准日，凯利测算沿用原字段内容；
3. `情绪面`：主标题为“情绪面”，副标题为“交易偏离定价”；读取第1章“交易定价偏离”字段，展示现价、相对中枢溢价率、相对上限偏离率、市场价格分解及泡沫状态；
4. `资金面`：资金趋势、股东人数趋势和主要交易方画像；缺失项明确标注。

`每日跟踪时间`必须注明收盘、盘中或重大公告后的具体时点。只有价格变化时更新交易定价偏离，不修改公允价值范围；只有估值输入或核心假设变化达到重估条件时，才重算内在价值。
