# 通胀适用性与公司基本面传导

本参考用于把通胀从单一宏观指标转化为可验证的公司经营和估值变量。所有公司先筛查，只有中高暴露公司展开完整分析，避免让低暴露企业的研报被无关宏观内容占据。

## 1. 适用性筛查

依次检查：

1. 能源、原材料、物流、人工等成本是否足以改变利润率；
2. 产品或服务能否提价，提价相对成本变化是否存在时滞；
3. 客户购买力、资本开支或订单是否对通胀、利率和信用敏感；
4. 负债、账期、库存和营运资金是否放大价格冲击；
5. 海外收入、汇率、合同调价机制或上游客户资本开支是否形成缓冲。

输出只允许：

- `高暴露`：至少一条渠道可能显著改变收入、利润、现金流或估值锚；
- `中等暴露`：存在实质影响，同时有定价权、业务结构或地区分散缓冲；
- `低暴露`：直接与间接影响均不足以改变核心财务和估值结论；
- `证据不足`：成本占比、提价、需求或金融条件证据不足，不能默认低暴露。

## 2. 通胀类型

不得只看 CPI。至少用一组价格证据、一组需求证据和一组利润传导证据交叉判断。

| 类型 | 需求与数量 | 成本与价格 | 典型公司传导 |
|---|---|---|---|
| 通缩或低通胀修复 | 从低位改善 | 温和回升 | 若订单、销量、利润同步改善，可形成顺周期修复 |
| 温和再通胀 | 需求扩张 | 产品价格与成本共同上升 | 有定价权企业收入和利润可能同步改善 |
| 输入性 / 供给冲击型通胀 | 未同步增长或走弱 | 能源、资源、关税、物流或供应中断抬高成本 | 上游可能受益，低定价权下游利润受压 |
| 滞胀或恶性通胀 | 增长疲弱或收缩 | 高成本持续且政策趋紧 | 需求、利润率、融资和估值同时承压 |
| 混合状态 | 地区、分部或阶段方向不一 | 多种冲击并存 | 分部判断后给出净影响，不能用单一总标签覆盖 |
| 证据不足 | 关键数据缺失或互相冲突 | 关键数据缺失或互相冲突 | 降低置信度并列出下一验证点 |

常用证据按适用性选择，不机械凑数：CPI / 核心 CPI、PPI、能源与主要原料、PMI 新订单 / 购进价 / 出厂价、固定资产投资、消费与地产、利率与信用、汇率与运价、公司提价、分部订单、毛利率和现金流。

## 3. 分部传导

对每个实质影响利润或估值的分部填写：

| 分部 | 需求影响 | 成本影响 | 定价权与时滞 | 二阶影响 / 缓冲 | 利润与现金流 | 验证指标 / 失效条件 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

传导顺序：

```text
价格与政策冲击
→ 客户需求和资本开支
→ 产品销量与价格
→ 原料、能源、物流、人工和融资成本
→ 毛利率与经营利润率
→ 库存、应收、营运资金和自由现金流
→ 正常化利润、估值倍数与公允价值区间
```

必须同时列出主要反证。油价上涨既可能抬高制造和运输成本，也可能增加油气、煤炭、金属矿客户的资本开支；最终判断取决于各分部暴露、利润贡献和传导时滞。

## 4. 估值一致性

中高暴露公司把通胀假设压入悲观、基准、乐观情景，至少说明收入、利润率、营运资金、融资成本和估值锚中的适用项。周期制造与资源企业使用正常化需求、价格和利润率，不能永久外推当前高点或低点。

同一冲击已进入收入、利润率、WACC 或估值倍数后，不得再次扣减；上游受益和下游受损若来自同一利润来源，也不得重复计算。

## 5. 报告落点

- 第 1 章：填写 `宏观价格环境`，并让 `基本面状态`反映净影响与置信度；
- 第 4 章：保留适用性、通胀类型和分部传导底稿；
- 第 9 章：分别列入多头、空头论据与失效条件；
- 第 10 章：进入估值情景和正常化假设；
- 第 11 章：经营成本传导与货币条件传导分开扫描；
- 第 12—13 章：进入结论失效条件和监控指标。

经营层通胀关注成本、需求、定价权和现金流；流动性表中的通胀只关注其对利率、信用、美元与估值的金融传导。两者不得用一个“有利 / 不利”标签相互覆盖。
