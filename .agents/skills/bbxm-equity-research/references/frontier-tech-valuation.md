# 尚未盈利前沿科技估值

本参考文件把 `wiki/concepts/冰冰小美-framework-估值判断.md` 中“已跑通基本盘＋融资或期权价值”的概念，转换为 `bbxm-equity-research` 可审计、可复核的估值流程。

它适用于商业航天、创新药、先进芯片、机器人、前沿材料、早期 AI 产品及其他尚未形成可靠利润、但拥有可识别技术项目或未来业务的企业。它不用于给热门叙事统一增加溢价，也不允许用总市场空间直接计算公司价值。

## 一、先按分部判断成熟度

公司整体亏损不代表所有业务都没有价值；公司拥有成熟主业也不代表所有研发项目都能按成功计价。逐项识别：

| 成熟度 | 最低证据 | 主要估值方法 |
|---|---|---|
| 已验证基本盘 | 可追踪收入、毛利、订单、利润或现金流 | DCF、正常化利润、EV/EBITDA、资产价值 |
| 商业化成长业务 | 关键技术、监管和交付节点已通过，已出现可重复收入，但规模和利润率未稳定 | 分阶段 DCF、收入 / 毛利倍数、可比公司 |
| 前沿期权业务 | 技术、认证、客户、量产或盈利仍有决定性节点未完成；仅有试点、意向订单或首批付费订单不自动升级 | 里程碑概率加权 SOTP、融资 / 交易定价 |
| 失败或退出业务 | 商业化路径中止，仅剩设备、专利或其他残值 | 清算价值、残值或零值 |

同一分部只能进入一个成熟度状态；成熟度变化必须由新证据触发。已经纳入基本盘收入和现金流的业务，不再单独增加完整期权价值。

若同一分部同时满足两类的表面描述，优先检查是否已经通过决定商业可行性的技术、监管、稳定交付和复购节点。没有形成可重复收入或关键节点仍未完成时，按前沿期权业务处理；首批付费订单只提高对应客户里程碑的条件概率，不直接把全部未来收入纳入估值中枢。

## 二、统一价值口径

默认先计算企业价值，再桥接到当前股东的每股价值：

```text
当前股东价值
= 已验证基本盘价值
+ Σ（未来业务情景价值 × 情景概率 × 时间折现 × 当前股东保留比例）
+ 非经营性现金
- 有息负债
- 公司自行承担且尚未计入分部价值的未来投入
```

必须说明每个分部使用的是企业价值还是股权价值。不得将项目企业价值、子公司投后股权价值和上市公司市值不经调整直接相加。

### 融资处理

- 使用现有现金投入：从净现金或价值桥中扣除尚未计入预测的现金消耗。
- 外部股权融资：通过当前股东保留比例或未来稀释后股本反映。
- 新增债务融资：进入净债务，并计入利息和偿债压力。
- 战略合作方承担投入：只计入公司实际拥有的经济权益，不把合作方投入全部视为公司资产。

同一笔融资不能既全额扣作未来投入，又通过股权稀释再次扣除。成功情景价值若已经是融资后的投后股权价值，必须按公司持股比例或当前股东保留比例换算。

## 三、建立里程碑证据链

按业务实际选择里程碑，不要求所有行业使用同一套节点：

| 里程碑 | 可接受证据 | 常见反证 |
|---|---|---|
| 技术验证 | 样机、重复测试、正式性能数据、第三方验证 | 只有实验室单次结果或宣传材料 |
| 监管 / 认证 | 临床、适航、行业准入、客户认证进展 | 申请未受理、节点反复延期 |
| 客户验证 | 付费订单、合同负债、复购、联合开发 | 意向书、框架协议、免费试用 |
| 规模制造 | 良率、产能、交付、供应链和单位成本 | 只有规划产能，没有稳定交付 |
| 单位经济性 | 毛利率、贡献利润、回款和获客效率 | 收入增长但毛利、现金流持续恶化 |
| 融资生存 | 现金余额、现金消耗、授信或已完成融资 | 资金缺口早于下一验证节点 |

每个概率判断必须紧邻证据、反证、数据时间和下一验证点。证据不足时，不给出伪精确的单点概率；使用区间，并把该业务限制在上沿或观察项。

## 四、使用情景树而不是单一成功率

至少考虑以下情景中适用的项目；各情景概率合计必须为 100%：

| 情景 | 含义 | 价值基础 |
|---|---|---|
| 失败 / 退出 | 技术或商业化失败 | 残值、可回收现金或零值 |
| 延期 | 路线仍存在，但时间和投入上升 | 延后折现，并增加资金需求 |
| 有限商业化 | 获得局部客户，但规模或利润率有限 | 可验证细分市场和保守倍数 |
| 基准成功 | 达到有证据支持的收入、利润率或订单目标 | 行业可比、分阶段 DCF 或交易定价 |
| 突破成功 | 技术和商业化均超预期 | 只进入上沿，必须列新增证据要求 |

未来业务的成功价值可以采用：风险调整后项目净现值、可比业务 EV/收入或 EV/毛利、EV/产能、EV/用户、订单储备、技术授权交易、独立融资定价或其他行业特定方法。TAM 只用于约束收入上限，不能直接乘市场份额后当作企业价值。

## 五、概率、折现率与失败风险不要重复惩罚

风险必须放在最能解释它的位置：

- 技术、监管、客户和量产失败：主要进入情景概率。
- 时间等待和一般资本成本：进入折现率。
- 公司资金不足：进入现金消耗、融资情景和股东保留比例。
- 永久失败后的残值：进入失败情景价值。

如果技术和商业失败已经通过概率折价，就不要再用异常高折现率重复惩罚同一风险。反之，如果使用风险调整折现率吸收某项风险，必须说明没有再对同一项风险重复下调概率。

## 六、DCF 的角色

完整 DCF 仍然适合已验证基本盘和能够形成可审计收入、利润率、再投资路径的成长业务。以下任一情形出现时，将完整公司 DCF 降为低权重约束：

- 自由现金流预计第五年以后才转正；
- 终值占企业价值超过 70%；
- 稳态利润率、资本开支或商业化年份缺乏外部证据；
- 合并报表亏损主要来自尚未商业化分部，掩盖了成熟基本盘。

五年和 70% 是技能初始治理阈值，不是金融定律。报告必须披露实际数值，并允许基于行业周期、研发周期和历史案例调整，但不能无说明地放宽。

DCF 无法形成可审计预测时写“不适用”，不要为完成模板制造数字。此时仍应：

1. 对已验证基本盘单独估值；
2. 完成未来业务概率加权 SOTP；
3. 使用融资 / 交易或可比定价交叉验证；
4. 完成反向估值，说明现价要求哪些里程碑兑现。

## 七、融资与交易定价的调整

独立第三方融资可以证明市场愿意在特定条款下出价，但不自动等于上市公司普通股价值。至少调整：

- 交易日期与市场环境；
- 投前或投后口径；
- 清算优先权、回购、对赌和其他保护条款；
- 控制权或战略协同溢价；
- 子公司与上市公司之间的实际持股比例；
- 流动性差异；
- 后续资金需求和预计稀释。

关联方交易、缺少条款的媒体报道或公司自行宣布的目标估值，只能作为线索，不能作为中枢的唯一依据。

## 八、实物期权成立条件

前沿业务只有同时具备以下结构，才可以在“融资定价”之外进一步解释为实物期权：

1. 公司拥有排他性技术、许可、资源或进入权；
2. 未来存在可识别的不确定事件和验证时间点；
3. 管理层能够在新信息出现后扩张、延期、缩减或放弃；
4. 下行损失受投入节奏或放弃权限制，上行仍有扩张空间；
5. 期权没有已经完整计入基本盘现金流或其他分部。

只有“大市场＋研发项目”而没有排他权、里程碑或管理选择，不足以形成可计价期权。

## 九、区间输出

| 区间位置 | 必须表达的含义 |
|---|---|
| 下沿 | 净现金、可回收资产和保守基本盘；未经验证期权原则上不计入 |
| 中枢 | 基本盘加已有里程碑支持的概率加权未来业务价值 |
| 上沿 | 下一阶段技术、客户、量产或单位经济性验证成功 |
| 高于上沿 | 多数关键业务成功或突破性商业化，需要新增证据才能成立 |

最终报告必须列出基本盘、各未来业务、净现金 / 净债务、未来投入、股东保留比例和每股价值桥。区间变宽是对不确定性的诚实表达，不使用单一精确目标价掩盖模型脆弱性。

## 十、反向估值与防故事化检查

反向估值至少回答：

- 当前市值扣除基本盘后，为未来业务支付了多少价值；
- 该价值对应哪些项目成功、成功概率和商业化时间；
- 对应的收入、利润率、资本投入和股权稀释是否可实现；
- 当前价格已经把未来几年的哪些里程碑提前定价；
- 哪一个失败、延期或融资节点会首先击穿估值中枢。

完成前逐项检查：

- [ ] 没有用 TAM 直接计算企业价值；
- [ ] 没有把管理层目标、意向订单或热门叙事当作已验证收入；
- [ ] 基本盘与未来业务没有重复计算；
- [ ] 同一风险没有同时通过概率和折现率重复惩罚；
- [ ] 同一笔资金没有同时扣作投入和稀释；
- [ ] 融资估值已经调整交易条款、持股比例和流动性；
- [ ] 中枢只包含已有里程碑支持的未来价值；
- [ ] 上沿和高于上沿分别列明需要新增的证据。
