# 风险评估方法

本页对应[[1.1金融风险通用研究框架 V1.0|金融风险通用研究框架 V1.0]]输出模块4／环节5。原页“风险暴露与影响范围模块（待整理）”备注已归入[[01-研究方法论/框架版本与待办|框架版本与待办]]，暂缓其独立设计；本页只落实当前八字段评估。

| 评估字段 | 执行要求 |
| --- | --- |
| 评估日期 | 风险状态对应的日期 |
| 风险水平 | 低、中、高等，须有明确规则 |
| 变化趋势 | 上升、稳定、下降或不确定 |
| 主要风险来源 | 当前占主导的风险来源 |
| 核心变量状态 | 关键变量的最新变化 |
| 情景分析 | 基准、压力及其他合理情景 |
| 关键证据 | 支持结论的指标与资料 |
| 置信度与局限 | 数据质量、模型假设及不确定性 |

## 等级与趋势的规则

低/中/高可以使用，但须先明确对象、评价标准、期限、规则版本、证据来源和适用条件。阈值/条件应写清适用于何种情境；当前框架没有全球统一阈值，也未要求建立统一总分。缺规则、数据过期或不可比时保持“未判断”。

趋势是上升、稳定、下降或不确定；水平高但改善、水平低但上升可以同时成立。置信度反映证据与假设可靠程度，不与损失概率、等级混同。不把单一CPI、利差或LCR读数直接视为总风险结论。

## 三类陈述和时间

| 类别 | 应记录 | 常见错误 |
|---|---|---|
| 观测事实 | 数据定义、值、单位、统计期、可获知时间、来源版本 | 用未来才披露信息替代当时证据 |
| 分析判断 | 从多项证据到结论的条件、主导源与变量状态、反证 | 把代理值直接等同变量/因果 |
| 预测情景 | 基准、压力及其他合理假设，方向、路径、条件、时滞和不确定性 | 把情景值写成真实读数或确定未来 |

按[[02-风险基础知识库/风险监测指标/数据与指标口径规范|数据与指标口径规范]]保留时点；原始观察放[[99-研究模板/监测快照模板|监测快照模板]]，判断放[[99-研究模板/综合评估模板|综合评估模板]]，保存见[[04-风险评估与案例/动态评估层导航|动态评估层导航]]。

## 情景与损失边界

用[[02-风险基础知识库/风险驱动因素/风险驱动因素索引|风险驱动因素索引]]的条件路径和[[02-风险基础知识库/传导机制/传导机制索引|传导机制索引]]选情景，考虑共同因素、反向反馈、抵消和替代解释。若已有可靠条件可算损失，必须注明基准和方法；V1.0不要求独立敞口量化、影响范围模块或跨主体损失模型。

市值重估、信用违约与迫售折价不能重复相加；系统性或集中度标签不另加一笔同样损失。既有[[04-风险评估与案例/人民币教学情景算例|人民币教学情景算例]]、[[04-风险评估与案例/硅谷银行2023年案例|硅谷银行2023年案例]]保留为可选教学/历史参照，不替代当前证据。

## 复核与来源

资料、评价标准、对象条件或制度变化时保留旧版本并复核，记录下次触发。标准八字段与事实/判断/情景区分来自[[sources/S17-用户金融风险通用研究框架V1.0|S17-用户金融风险通用研究框架V1.0]]；多类信息和压力分析参照[[sources/S07-IMF金融稳健指标指南|S07-IMF金融稳健指标指南]]。本页不声称模型或预警有效性已验证。
