# 金融风险通用研究框架 V1.0

状态：用户于2026-10-21确定的当前基准。以下执行结构依据[[sources/S17-用户金融风险通用研究框架V1.0|S17-用户金融风险通用研究框架V1.0]]，并明确区分原文规定与本库落地约定。适用于货币、银行存款、债券、股票、金融机构和金融体系；复用研究流程，对象分类与监测选择允许不同。

## 总体架构与编号

**研究对象定义 + 风险分类表 + 风险源、核心变量与传导机制表 + 风险监测指标表 + 风险评估。**

五模块位置编号为0—4；下面六环节编号为0—5：

| 编号  | 研究模块       | 核心问题                | 分析依据           | 主要输出                 |
| --- | ---------- | ------------------- | -------------- | -------------------- |
| 0   | 研究对象定义     | 研究什么？研究边界是什么？       |                | 对象、主体、视角、评价标准、期限、边界  |
| 1   | 风险分类       | 研究对象面临哪些风险？         | 损失的性质与形成机制     | 风险定义、类型、损失机制和适用范围    |
| 2   | 风险源与核心驱动变量 | 风险从哪里产生？哪些变量改变风险状态？ | <br>风险产生的根源或冲击 | 风险源、驱动因素、核心变量及多对多关系  |
| 3   | 风险传导机制     | 风险通过什么路径产生、传播和放大？   | 风险作用与传播的机制     | 路径、条件、方向、时滞和潜在结果     |
| 4   | 风险监测指标     | 如何观察风险变化？           |                | 指标、数据来源、监测与预警规则      |
| 5   | 风险评估       | 风险处于什么状态？未来可能如何演化？  |                | 等级、趋势、情景、证据、置信度与不确定性 |

第二张表合并环节2与3，不增加第四张核心表。

## 三张核心表的标准结构

**表1：金融风险分类表**

**目标：识别对象风险，避免遗漏与重复分类。**

| 标准字段 | 内容说明 |
| --- | --- |
| 风险ID | 风险的唯一标识 |
| 风险名称 | 如利率风险、信用风险 |
| 一级分类 | 市场风险、信用风险、流动性风险等 |
| 二级分类 | 利率风险、汇率风险、违约风险等 |
| 风险定义 | 对风险概念的明确界定 |
| 损失形成机制 | 风险如何转化为经济损失 |
| 适用对象 | 适用于哪些金融资产或金融主体 |
| 参考依据 | 监管框架、学术文献等 |

通用登记见[[通用风险分类索引|通用风险分类索引]]。

**一级分类与二级分类对比**

| 比较维度 | 一级分类 | 二级分类 |
|---|---|---|
| 分类层级 | 风险大类 | 风险子类 |
| 分类依据 | 主要损失形成机制 | 大类下的具体风险形式 |
| 抽象程度 | 较高 | 更具体 |
| 主要用途 | 建立完整风险体系 | 精确识别和管理风险 |
| 示例 | 市场风险 | 利率风险、汇率风险 |
| 示例 | 信用风险 | 违约风险、信用迁移风险 |

来源：[[sources/S18-一级分类与二级分类对比截图|用户提供的分类层级对比截图]]。本表用于说明分类层级；具体风险是否适用仍以研究对象和评价标准为准。

**表2：金融风险源、核心变量与传导机制表**

**目标：解释风险产生的原因、演化动力以及损失形成的路径。(风险解释模型)**


| 标准字段 | 内容说明 |
| --- | --- |
| 关联风险ID | 对应表1中的风险类型 |
| 风险源 | 风险产生的结构性条件或潜在冲击 |
| 风险驱动因素 | 改变风险发生可能性、强度或演化方向的因素 |
| 核心变量 | 对该风险具有重要解释力的关键变量 |
| 变量变化方向 | 上升、下降、扩大、收缩等 |
| 传导渠道 | 利率、信用、汇率、资产价格等渠道 |
| 传导路径 | 从风险源到风险结果的因果链 |
| 传导条件 | 什么条件下传导机制成立 |
| 传导时滞 | 即时、短期、中期、长期或不确定 |
| 潜在风险结果 | 可能发生的损失或风险状态变化 |

风险源是具有产生风险潜力的条件、事件或结构；驱动因素影响风险形成和演化；核心变量从驱动因素中选取，重点解释当前研究。相同因素可随情境承担不同角色，允许多对多关联。变量与指标独立管理。

表2仍在原路径[[02-风险基础知识库/风险驱动因素/风险驱动因素索引|风险驱动因素索引]]维护；新建[[02-风险基础知识库/风险源/风险源索引|风险源索引]]、[[02-风险基础知识库/全局变量/全局变量索引|全局变量索引]]、[[02-风险基础知识库/传导机制/传导机制索引|传导机制索引]]分别管理可复用单元，表2负责连接，不把它们当额外核心表。

**表3：金融风险监测指标表**
**目标：使风险研究具备可观察、可验证和持续跟踪的能力。(风险观测模型)**


| 字段名称 | 字段定义 | 是否必填 |
|---|---|---|
| 指标ID | 监测指标的唯一标识 | 是 |
| 指标名称 | 指标的标准名称 | 是 |
| 监测对象 | 指标用于观测的经济金融变量或风险状态 | 是 |
| 关联风险 | 指标所服务的风险类型，可关联多个 | 是 |
| 指标定义与口径 | 指标含义、统计范围、计算方法及单位 | 是 |
| 数据来源 | 数据发布机构、数据库或具体来源 | 是 |
| 更新频率 | 日度、周度、月度、季度等 | 是 |
| 监测属性 | 相对于监测目标的领先、同步、滞后或辅助属性 | 否 |
| 解释规则 | 指标变化的经济含义、作用方向及适用条件 | 是 |
| 预警规则 | 风险预警阈值、异常识别标准及触发条件 | 否 |
| 局限性 | 数据和指标解释可能存在的偏差或限制 | 是 |




登记见[[02-风险基础知识库/风险监测指标/风险监测指标索引|风险监测指标索引]]。例如[[02-风险基础知识库/全局变量/通胀预期|通胀预期]]是变量，不等同调查、互换或保值债券隐含指标；各代理有口径、溢价与适用限制。监测属性需相对于具体变量和期限说明，不能天然固定为领先或滞后。

## 输出模块：风险评估

| 评估字段 | 说明 |
| --- | --- |
| 评估日期 | 风险状态对应的日期 |
| 风险水平 | 低、中、高等，须有明确规则 |
| 变化趋势 | 上升、稳定、下降或不确定 |
| 主要风险来源 | 当前占主导的风险来源 |
| 核心变量状态 | 关键变量的最新变化 |
| 情景分析 | 基准、压力及其他合理情景 |
| 关键证据 | 支持结论的指标与资料 |
| 置信度与局限 | 数据质量、模型假设及不确定性 |

按[[01-研究方法论/风险评估方法|风险评估方法]]区分观测事实、分析判断、预测情景；低中高须有明确规则，无数据或无适用评级规则时写“未判断”，不得靠单一指标跳到结论。
