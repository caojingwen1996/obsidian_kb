# 金融风险通用研究框架 V1.0

**核心结构：1个研究对象定义模块＋3张核心研究表＋1个风险评估模块。**

本框架用于回答：在给定研究主体、评价标准和期限下，对象可能遭受哪些损失；这些损失由什么条件和变量驱动；用哪些证据观察；据此能形成什么判断，以及判断的边界在哪里。

当前基准来自[[sources/S17-用户金融风险通用研究框架V1.0|用户确定的V1.0框架]]。2026-10-22补充模块衔接、适配与交付规则，标准字段及设计范围保持V1.0；修订记录见[[01-研究方法论/框架版本与待办|框架版本与待办]]。

## 框架定位与适用边界

适用于货币、银行存款、债券、股票、金融机构和金融体系的风险研究。复用的是问题结构、概念关系与证据要求；具体风险、驱动变量、指标和阈值由研究对象决定。

框架有三个层次：

| 层次 | 框架规定什么 | 每项研究需要确定什么 |
|---|---|---|
| 固定结构 | 对象定义、风险识别、风险解释、风险观测、风险评估及其标准字段 | 各模块的具体内容与关联 |
| 对象化选择 | 在同一主体、标准和期限下组织分析 | 适用风险、关键条件、核心变量、数据代理和评级规则 |
| 动态结论 | 按证据强度表达风险状态、变化和不确定性 | 统计时点、当前读数、主导机制、情景与本期判断 |

完成一项研究，应得到“可追溯的判断与待验证问题”。只完成分类和机制分析时，可以交付研究设计；取得当期证据后才能形成对应时点的风险评估。

## 总体架构与编号

**研究对象定义 → 风险分类表 → 风险源、核心变量与传导机制表 → 风险监测指标表 → 风险评估。**

```text
模块0 · 定义对象：研究谁，以什么衡量损失
  ↓
模块1 · 识别风险：可能发生什么损失
  ↓
模块2 · 解释风险：变量怎样传导为损失
  ↓
模块3 · 观测风险：取得可核验的证据
  ↓
模块4 · 评估风险：状态、情景与不确定性
```

**复核反馈**：模块3的证据与预期不符时，返回模块2复核变量、代理与机制；模块4明确下一期需要观察的证据，反馈到模块3。研究主体、标准或期限改变时，返回模块0。

箭头表示研究成果的衔接；经济上的因果关系需要在表2中另行说明条件与证据。

**报告与模块统一使用0—4编号；六个分析环节保留0—5编号。** 二者对应如下，避免把环节编号直接混入报告目录。

| 环节编号 | 分析环节       | 分析依据                | 所属模块与成果         |
| ---- | ---------- | ------------------- | --------------- |
| 0    | 研究对象定义     | 主体目标、对象属性、评价标准与期限   | 模块0：研究对象定义      |
| 1    | 风险分类       | 损失性质、形成机制及适用范围      | 模块1：表1          |
| 2    | 风险源与核心驱动变量 | 潜在冲击、结构性条件及变量关系     | 模块2：表2的风险源与变量部分 |
| 3    | 风险传导机制     | 作用路径、成立条件、方向与时滞     | 模块2：表2的传导部分     |
| 4    | 风险监测指标     | 可取得的数据、指标口径与解释规则    | 模块3：表3及观测记录     |
| 5    | 风险评估       | 当期证据、机制解释、评价规则与情景假设 | 模块4：风险评估        |

## 模块职责与衔接

| 模块 | 输入 | 分析任务 | 输出及完成条件 |
|---|---|---|---|
| 0 · 研究对象定义 | 研究问题、对象资料与主体需求 | 确定从谁的视角、用什么标准、在多长期限内研究什么 | 六字段对象定义；能够明确哪些损失和情形在研究范围内 |
| 1 · 风险识别 | 对象定义、通用风险定义与适用依据 | 筛选风险，按损失机制分类，识别交叉与重复 | 表1；每项风险有适用理由和可说明的损失机制 |
| 2 · 风险解释 | 表1、潜在冲击、结构条件与机制资料 | 连接风险源、驱动因素、变量和条件性传导路径 | 表2；路径能够回到表1风险，并写清成立条件和待验证部分 |
| 3 · 风险观测 | 表2的核心变量、表1的风险状态、可用数据 | 选择代理，固定口径，规定解释方式并保存时点证据 | 表3及观测记录；关键变量有指标或明确的数据缺口 |
| 4 · 风险评估 | 对象定义、表1—3、当期证据及适用规则 | 综合判断主导风险、水平、趋势、情景和证据强度 | 八字段评估；每项主要判断可回溯证据与机制，缺证据处明确未判断 |

衔接遵循三条规则：

1. **定义一致**：各模块使用相同的研究主体、评价标准和期限；变更这些前提时，回到模块0复核后续分析。
2. **关系可追溯**：表2关联表1的风险ID；表3的“监测对象”指向已定义变量或风险状态，并通过ID或双链关联；评估引用相应指标、观测时间及传导条件。
3. **证据允许修正解释**：指标变化与预期路径不符时，检查口径、时滞、抵消因素和替代解释；证据不足的部分保留待验证状态。

一个风险可以对应多条传导路径，一个变量也可以由多个指标观察。共用同一数据来源的指标，不能直接视为多份相互独立的证据。概念边界见[[01-研究方法论/定义与边界|定义与边界]]。

## 前置模块：研究对象定义

**核心问题：这项研究如何界定对象与损失？**

先确定研究主体、视角和评价标准，再选择适用风险。一个名称可能包含多种对象；应根据需要区分资产、发行人、市场、持仓或交易策略。若不同视角的损失标准冲突，应分别研究。

| 研究字段 | 填写要求 |
|---|---|
| 对象名称 | 准确标识要研究的资产、负债、机构、市场或体系，必要时限定具体品种 |
| 研究主体 | 明确谁的利益、资产或义务可能受到影响 |
| 研究视角 | 明确持有者、债权人、股东、经营者等分析立场 |
| 评价标准 | 明确用市值、现金流、偿付、实际购买力或其他标准衡量损失 |
| 研究期限 | 明确观察和判断覆盖的时间范围 |
| 研究边界 | 明确纳入的情形、条件及排除范围 |

**完成条件：**相同价格或事件变化，对该主体意味着什么损失能够被说明；后续表格有共同的筛选标准。本模块不强制增加独立敞口量化与影响范围字段。

## 三张核心表的标准结构

### 表1：金融风险分类表——风险识别

**核心问题：对象可能以什么方式遭受损失？**

从损失性质和形成机制出发，筛选适用风险并保留分类层级。宏观事件、变量变化和指标读数，应通过表2、表3关联到风险类型。系统性、购买力等跨层级或评价视角应说明范围；同一损失不因多重标签重复计入。

| 标准字段 | 内容说明 |
| --- | --- |
| 风险ID | 风险的唯一标识 |
| 风险名称 | 如利率风险、信用风险 |
| 一级分类 | 市场风险、信用风险、流动性风险等 |
| 二级分类 | 利率风险、汇率风险、违约风险等 |
| 风险定义 | 对风险概念的明确界定 |
| 损失形成机制 | 风险如何转化为经济损失 |
| 适用对象 | 适用于哪些金融资产或金融主体 |
| 参考依据 | 监管框架、学术文献等 |

**完成条件：**每项风险有明确的定义、对象适用性和损失机制；对可能重叠的风险说明边界。风险定义复用[[0.通用风险分类索引|通用风险分类索引]]，对象研究负责筛选。

**一级分类与二级分类对比**

| 比较维度 | 一级分类 | 二级分类 |
|---|---|---|
| 分类层级 | 风险大类 | 风险子类 |
| 分类依据 | 主要损失形成机制 | 大类下的具体风险形式 |
| 抽象程度 | 较高 | 更具体 |
| 主要用途 | 建立完整风险体系 | 精确识别和管理风险 |
| 示例 | 市场风险 | 利率风险、汇率风险 |

### 表2：金融风险源、核心变量与传导机制表——风险解释模型

**核心问题：风险在什么条件下产生，又怎样传导为损失？**

以表1风险为终点，识别潜在冲击或结构性条件，筛选关键驱动因素和变量，再写出作用路径。每条主要路径应说明条件、方向与时滞，并在解释中保留替代机制和可反驳的证据要求。

| 标准字段   | 内容说明                 |
| ------ | -------------------- |
| 关联风险ID | 对应表1中的风险类型           |
| 风险源    | 风险产生的结构性条件或潜在冲击      |
| 风险驱动因素 | 改变风险发生可能性、强度或演化方向的因素 |
| 核心变量   | 对该风险具有重要解释力的关键变量     |
| 变量变化方向 | 上升、下降、扩大、收缩等         |
| 传导渠道   | 利率、信用、汇率、资产价格等渠道     |
| 传导路径   | 从风险源到风险结果的因果链        |
| 传导条件   | 什么条件下传导机制成立          |
| 传导时滞   | 即时、短期、中期、长期或不确定      |
| 潜在风险结果 | 可能发生的损失或风险状态变化       |

- **风险源**：具有产生风险潜力的条件、事件或结构。
- **风险驱动因素**：影响风险发生可能性、强度或演化方向的因素。
- **核心变量**：从驱动因素中选取，对当前研究具有重要解释力的可描述或可度量变量。
- **传导机制**：变量通过具体渠道影响风险结果的条件性路径。

同一因素在不同研究情境中可以承担不同角色，需按本次问题明确标注。可以用“在某条件下，某变量变化经某渠道影响某种损失”检查一条解释是否完整；尚未验证的路径应标为工作假设。

**完成条件：**每条路径关联风险ID，关键变量能交给表3观察，成立条件和不确定时滞有明确说明。相关性和模型拟合表现本身不足以确认传导机制。

表2的对象关系见[[02-风险基础知识库/风险驱动因素/风险驱动因素索引|风险驱动因素索引]]；可复用定义分别由[[02-风险基础知识库/风险源/风险源索引|风险源索引]]、[[全局变量索引|全局变量索引]]和[[02-风险基础知识库/传导机制/传导机制索引|传导机制索引]]维护。

### 表3：金融风险监测指标表——风险观测模型

**核心问题：用什么证据判断变量与风险状态发生了变化？**

从监测对象反推指标：先说明要观察哪个变量或风险状态，再选数据代理，规定口径、解释条件与局限。保留统计期、可获知时间和来源版本，使不同时间的判断能够复核。

| 字段名称 | 字段定义 | 是否必填 |
|---|---|---|
| 指标ID | 监测指标的唯一标识 | 是 |
| 指标名称 | 指标的标准名称 | 是 |
| 监测对象 | 指标用于观测的经济金融变量或风险状态 | 是 |
| 关联风险 | 指标所服务的风险类型，可关联多个 | 是 |
| 指标定义与口径 | 指标含义、统计范围、计算方法及单位 | 是 |
| 数据来源 | 数据发布机构、数据库或具体来源 | 是 |
| 更新频率 | 日度、周度、月度、季度等 | 是 |
| 监测属性 | 相对于监测目标的领先、同步、滞后或辅助属性 | 否 |
| 解释规则 | 指标变化的经济含义、作用方向及适用条件 | 是 |
| 预警规则 | 风险预警阈值、异常识别标准及触发条件 | 否 |
| 局限性 | 数据和指标解释可能存在的偏差或限制 | 是 |

“监测对象”同时容纳变量与风险状态，不限于表2中的核心变量。[[通胀预期|通胀预期]]可以由调查、互换或保值债券隐含指标辅助观察，各代理须分别说明期限、口径和溢价影响。指标的领先、同步或滞后属性相对于具体监测目标和期限判定。

**指标定义与观测记录分开：**表3保存稳定定义和规则，观测记录保存具体时点的读数、缺失与修订。复合指标或量化因子如被采用，也须说明输入、计算方式、用途和适用范围。

**预警是复核入口：**触发条件用于提示需要进一步检查的异常；阈值须结合对象、历史数据和误判情况验证。待验证规则标为原型，缺失值不视为正常。

**完成条件：**主要监测对象有可解释、可追溯的指标；缺失数据及不可比口径得到标注。指标登记见[[02-风险基础知识库/风险监测指标/风险监测指标索引|风险监测指标索引]]。

## 输出模块：风险评估

**核心问题：现有证据允许对什么风险作出多强的判断？**

围绕同一主体、标准和期限，先确认观测事实，再检验表2解释，形成条件性判断和情景。风险水平、变化趋势与置信度分别表达：水平较高但正在改善可以同时成立；证据充分也不等同发生概率高。

| 评估字段 | 说明 |
| --- | --- |
| 评估日期 | 风险状态对应的日期 |
| 风险水平 | 低、中、高等，须有明确规则 |
| 变化趋势 | 上升、稳定、下降或不确定 |
| 主要风险来源 | 当前占主导的风险来源 |
| 核心变量状态 | 关键变量的最新变化 |
| 情景分析 | 基准、压力及其他合理情景 |
| 关键证据 | 支持结论的指标与资料 |
| 置信度与局限 | 数据质量、模型假设及不确定性 |

**完成条件：**主要判断可追溯至风险ID、机制条件和带日期的证据；说明反证、关键缺口以及哪些变化会促使判断修订。使用等级时须有对象化规则，无数据或无适用规则时写“未判断”。

观测事实、分析判断、预测情景分别记录。具体方法见[[01-研究方法论/风险评估方法|风险评估方法]]；已有敏感度或压力算例可作为情景证据，须注明假设和适用范围。

## 跨对象适配与复用

将框架用于新对象时，保留五模块及字段关系，重新确定对象内容与适用条件。

| 适配事项 | 保持一致的部分 | 必须重新确认的部分 |
|---|---|---|
| 对象与损失 | 六字段定义和评价逻辑 | 主体、视角、期限、币种、损失标准与边界 |
| 风险识别 | 按损失机制分类、保留层级 | 哪些风险适用，交叉维度如何解释 |
| 风险解释 | 风险源—变量—条件性路径的关系 | 主导变量、反馈、抵消因素、传导条件和时滞 |
| 风险观测 | 指标定义、来源、解释与局限 | 数据代理、统计口径、频率、可得性和阈值 |
| 风险评估 | 事实、判断、情景及不确定性区分 | 评级依据、比较基准、证据强度和情景假设 |

复用已有定义时保留ID与来源；对象选择和路径关系写在本项研究中。一个指标对某对象有效，不代表其解释方向或预警阈值可以原样迁移到另一对象。

完整教学示范见[[03-研究对象/A-货币与货币形态/中央银行货币/人民币现金/人民币现金购买力风险研究-V1.0示范|人民币现金购买力风险研究示范]]；多视角对照见[[03-研究对象/A-货币与货币形态/货币单位/人民币/人民币风险研究示范|人民币风险研究示范]]。示范用于理解结构，实际研究须重新确定适用条件与证据。

## 统一报告结构

报告一级目录按五模块编排，具体专题放入相应模块的子章节。以下为通用组织方式，子章节可按研究需要调整；标准字段及其含义须保留，未知项注明状态与原因。

```text
0. 研究对象定义
1. 风险分类（表1）
2. 风险源、核心变量与传导机制（表2）
3. 风险监测（表3）
   3.1 指标定义与口径
   3.2 本期观测与数据缺口
   3.3 解释与预警规则（适用时）
4. 风险评估
   4.1 当前风险状态与变化
   4.2 主导机制与证据检验
   4.3 情景分析（可含敏感度分析）
   4.4 研究结论、置信度与局限
附录：数据来源、计算说明、更新安排与版本记录
```

例如，风险诊断归入4.2，利率敏感度情景归入4.3，预警规则归入3.3；更新流程和资料来源放入附录。它们是模块内的分析内容或维护资料，不增加核心表的数量。

## 三层知识组织

[[00-知识导航/知识层与模块关系|知识层与模块关系]]规定定义、对象关系和动态记录的分工：

| 知识层 | 保存内容 | 更新方式 |
|---|---|---|
| 通用知识层 | 风险定义、风险源、变量、机制与指标口径 | 定义或依据改变时修订，供多个对象引用 |
| 对象研究层 | 研究边界、适用风险、变量选择与三表关系 | 对象、制度条件或研究问题改变时复核 |
| 动态评估层 | 带日期的观测快照、风险评估、情景与历史案例 | 按数据披露、事件或复核安排追加，保留历史时点 |

流程上先完成对象与研究设计，再取得证据、作出评估，并记录下一次需要复核的条件；证据不符时返回相应模块修订。动态记录入口见[[04-风险评估与案例/动态评估层导航|动态评估层导航]]。
