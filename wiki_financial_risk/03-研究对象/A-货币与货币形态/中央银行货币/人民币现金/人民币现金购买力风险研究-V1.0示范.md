# 人民币现金购买力风险研究-V1.0示范

性质：教学示范，依据[[sources/S17-用户金融风险通用研究框架V1.0|S17-用户金融风险通用研究框架V1.0]]及[[1.1金融风险通用研究框架 V1.0|金融风险通用研究框架 V1.0]]；无实时读数、无当前评级。与原有[[03-研究对象/A-货币与货币形态/货币单位/人民币/人民币风险研究示范|人民币风险研究示范]]的存款/美元支付多视角对照分开。

## 前置模块0／环节0：研究对象定义

| 研究字段 | 本例定义 |
| --- | --- |
| 对象名称 | 人民币现金 |
| 研究主体 | 中国境内居民 |
| 研究视角 | 持有者 |
| 评价标准 | 国内实际购买力 |
| 研究期限 | 未来12个月 |
| 研究边界 | 关注人民币现金的购买力风险 |

边界只研究现金的国内实际购买力；本例不评价存款银行兑现或人民币对美元汇率，也不启动暂缓的独立暴露模块。现金不生息在教学中取名义收益为零，保管等成本暂不展开。

## 事实、判断与情景分离

- 观测事实：仅有框架与定义来源，本例没有当前价格/工资/预期读数。
- 分析判断：若相关价格累计上升且名义现金收益为零，实际购买力下降；是否发生、幅度和持续时间须取证。
- 预测情景：上表列出的基准/压力/抵消为研究假设，不能写成当前事件。

复核前先明确个人/全国篮子、目标12个月、具体代理与评级规则。可选量化教学另见[[04-风险评估与案例/人民币教学情景算例|人民币教学情景算例]]，不据其假设判断当前风险。迁移到美国国债时按[[1.2跨对象迁移方法|1]]重新筛选利率、信用等风险与变量，不迁移本例的全部指标。边界见[[01-研究方法论/框架版本与待办|框架版本与待办]]。
