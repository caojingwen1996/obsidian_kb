# 货币研究入口

| 分类         | 回答的核心问题           | 典型研究对象        |
| ---------- | ----------------- | ------------- |
| 货币单位       | 使用什么货币计价和结算？      | 美元、人民币、欧元     |
| 中央银行货币     | 央行发行和提供什么形式的货币？   | 现金、准备金、CBDC   |
| 商业银行存款     | 商业银行形成哪些存款货币？     | 活期、定期存款       |
| 国际储备资产     | 国家依靠哪些资产维持国际清偿能力？ | 黄金、外汇储备、SDR   |
| 非银行支付性货币工具 | 非银行机构提供哪些支付性价值载体？ | 电子货币、稳定币      |
| 货币研究主题     | 如何分析货币运行及相关风险？    | 货币供给、信用扩张、流动性 |
- 研究对象： 黄金
    
- 货币功能： 价值储藏、国际储备、历史上的货币锚
    
- 特定资产类别： 货币黄金
    
- 观测变量： 黄金价格、央行黄金储备量、黄金储备占比等
