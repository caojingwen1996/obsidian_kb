# 金融风险通用研究框架 V1.0

根据前面的讨论，我建议正式确定为「1+3+1 金融风险研究框架」。

这套框架适用于货币、银行存款、债券、股票、金融机构和整个金融体系，采用统一的研究方法，同时允许不同研究对象具有不同的风险分类、风险源、驱动变量和监测指标。

本版暂缓「风险暴露与影响范围」模块的独立设计，作为后续待办。

## 一、总体研究架构

- 前置模块·0：研究对象定义——研究什么？从谁的视角？以什么标准衡量？
- 核心表1：风险分类——研究对象可能面临哪些风险？
- 核心表2：风险源、驱动变量与传导机制——风险源（从哪里来）、核心变量（由什么驱动）、传导机制（如何传递）。
- 核心表3：风险监测指标——用什么数据监测风险源、驱动变量与风险状态？
- 输出模块·4：风险评估——当前风险程度如何？趋势、情景与不确定性是什么？

这是研究工作流的逻辑顺序。实际风险形成过程中可能存在反向反馈和多个因素共同作用，不能将图中的箭头理解为必然成立的因果关系。

## 二、六个研究环节的完整定义

| 编号 | 研究模块 | 核心问题 | 主要输出 |
| --- | --- | --- | --- |
| 0 | 研究对象定义 | 研究什么？研究边界是什么？ | 对象、研究视角、评价标准、期限 |
| 1 | 风险分类 | 研究对象面临哪些风险？ | 风险类型、定义、损失机制 |
| 2 | 风险源与核心驱动变量 | 风险从哪里产生？哪些变量改变风险状态？ | 风险源、驱动因素、核心变量及关系 |
| 3 | 风险传导机制 | 风险通过什么路径产生、传播和放大？ | 传导路径、条件、方向、时滞 |
| 4 | 风险监测指标 | 如何观察风险变化？ | 指标、数据来源、监测规则 |
| 5 | 风险评估 | 风险处于什么状态？未来可能如何演化？ | 风险等级、趋势、情景、证据与不确定性 |

编号2和3共同组成第二张核心表，因此仍然保持三张核心研究表的结构。

## 三、三张核心表的标准结构

### 表1：金融风险分类表

目标：系统识别研究对象面临的风险，避免遗漏和重复分类。

| 标准字段 | 内容说明 |
| --- | --- |
| 风险ID | 风险的唯一标识 |
| 风险名称 | 如利率风险、信用风险 |
| 一级分类 | 市场风险、信用风险、流动性风险等 |
| 二级分类 | 利率风险、汇率风险、违约风险等 |
| 风险定义 | 对风险概念的明确界定 |
| 损失形成机制 | 风险如何转化为经济损失 |
| 适用对象 | 适用于哪些金融资产或金融主体 |
| 参考依据 | 监管框架、学术文献等 |

风险分类需要保留层级和适用范围。例如，系统性风险属于金融体系层面的分析概念，购买力风险侧重实际价值，二者不宜与银行监管的核心风险类别直接并列为互斥类别。

### 表2：金融风险源、核心变量与传导机制表

目标：解释风险产生的原因、演化动力以及损失形成的路径。

| 标准字段 | 内容说明 |
| --- | --- |
| 关联风险ID | 对应表1中的风险类型 |
| 风险源 | 风险产生的结构性条件或潜在冲击 |
| 风险驱动因素 | 改变风险发生可能性、强度或演化方向的因素 |
| 核心变量 | 对该风险具有重要解释力的关键变量 |
| 变量变化方向 | 上升、下降、扩大、收缩等 |
| 传导渠道 | 利率、信用、汇率、资产价格等渠道 |
| 传导路径 | 从风险源到风险结果的因果链 |
| 传导条件 | 什么条件下传导机制成立 |
| 传导时滞 | 即时、短期、中期、长期或不确定 |
| 潜在风险结果 | 可能发生的损失或风险状态变化 |

这里需要将三个概念固定下来：

- 风险源：具有产生风险潜力的条件、事件或结构。
- 风险驱动因素：影响风险形成和演化的因素。
- 核心变量：从驱动因素中选取的、对当前研究最重要的可描述或可度量变量。

同一因素可以在不同研究情境中扮演不同角色，因此三者之间应允许多对多关联。

### 表3：金融风险监测指标表

目标：使风险研究具备可观察、可验证和持续跟踪的能力。

| 标准字段 | 内容说明 |
| --- | --- |
| 指标ID | 唯一标识 |
| 指标名称 | CPI、国债收益率、信用利差等 |
| 关联风险 | 主要监测哪些风险 |
| 关联核心变量 | 指标用于观测哪个驱动变量 |
| 指标定义与口径 | 定义、单位、计算方法 |
| 数据来源 | 官方机构、交易所、金融数据平台等 |
| 更新频率 | 日度、周度、月度、季度 |
| 监测属性 | 领先、同步、滞后指标或辅助指标 |
| 解释规则 | 变化意味着什么，适用什么条件 |
| 预警规则 | 阈值、变化率、异常程度等 |
| 局限性 | 可能出现误判的条件 |

核心变量与监测指标需要分别管理。

例如，「通胀预期」是研究变量，可以通过调查数据、通胀互换和通胀保值债券隐含数据等指标辅助观察。各指标具有不同的定义、风险溢价和解释局限。

## 四、研究对象定义与风险评估

这两部分分别作为框架的输入和输出。

### 前置模块：研究对象定义

| 研究字段 | 示例 |
| --- | --- |
| 对象名称 | 人民币现金 |
| 研究主体 | 中国境内居民 |
| 研究视角 | 持有者 |
| 评价标准 | 国内实际购买力 |
| 研究期限 | 未来12个月 |
| 研究边界 | 关注人民币现金的购买力风险 |

### 输出模块：风险评估

| 评估字段 | 说明 |
| --- | --- |
| 评估日期 | 风险状态对应的日期 |
| 风险水平 | 低、中、高等，须有明确规则 |
| 变化趋势 | 上升、稳定、下降或不确定 |
| 主要风险来源 | 当前占主导的风险来源 |
| 核心变量状态 | 关键变量的最新变化 |
| 情景分析 | 基准、压力及其他合理情景 |
| 关键证据 | 支持结论的指标与资料 |
| 置信度与局限 | 数据质量、模型假设及不确定性 |

风险评估应当区分观测事实、分析判断和预测情景，避免把单一指标变化直接视为风险结论。

## 五、用一个完整案例验证框架

案例：人民币现金购买力风险研究（仅用于展示框架，未对当前风险作实际判断）。

| 研究环节 | 研究内容 |
| --- | --- |
| 0. 研究对象 | 中国境内居民持有的人民币现金，研究期限12个月 |
| 1. 风险类型 | 购买力风险 |
| 2. 风险源 | 总需求过热、负面供给冲击等可能形成通胀压力的条件 |
| 2. 核心驱动变量 | 总需求增长、生产成本、通胀预期 |
| 3. 风险传导 | 需求或供给冲击 → 消费价格水平上涨 → 单位货币的实际购买力下降 |
| 4. 监测指标 | CPI、核心CPI、通胀预期、工资与成本指标 |
| 5. 风险评估 | 综合判断未来通胀压力、购买力下降的潜在程度及不确定性 |

这一案例体现了框架的可迁移性。将研究对象改为美国国债时，风险类型可以换为利率风险、信用风险等，相应替换驱动变量、传导机制和监测指标，研究流程保持一致。

## 六、知识库中的模块关系

| 知识层 | 职责 | 组成 |
| --- | --- | --- |
| 通用知识层 | 定义与复用 | 风险类型库·风险源库·全局变量库·传导机制库·指标库 |
| 对象研究层 | 关联与筛选 | 人民币研究·美元研究·债券研究·股票研究·银行研究·金融体系研究 |
| 动态评估层 | 证据与结论 | 风险评估记录·监测快照·情景分析·历史案例 |

这种结构允许不同研究对象复用同一条风险定义、核心变量或监测指标，并记录对象之间的差异。

### 最终确定

当前框架正式采用：1个研究对象定义模块 + 3张核心研究表 + 1个风险评估模块。

其中第二张表内部明确区分风险源、风险驱动因素、核心变量和传导机制，既保留你常用的「风险源—核心变量—传导」研究思路，也能与金融风险的标准分类体系衔接。

这就是建议作为Obsidian知识库中《金融风险通用研究框架 V1.0》的基准设计。
