# 金融风险研究

这个独立库把“研究什么”“怎样损失”“为什么发生”“如何观察”“怎样综合判断”连接起来。

## 在 Obsidian 中打开

打开 Obsidian 的库切换器，选择“打开本地仓库 / Open folder as vault”，选择 `/Users/cjw/dev/Obsidian/wiki/wiki_financial_risk`。选择此文件夹本身，不选择它的父目录。随后打开[[00-知识导航/总导航|总导航]]或[[index|index]]。

不需要导入插件。可启用内置反向链接面板和关系图谱；复制模板直接改名即可，内置模板功能也已指向 `99-研究模板`。不要把模板原件当成已完成研究。
