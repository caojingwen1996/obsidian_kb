## 一、结论边界

- 航运强国、通道安全、绿色与智慧航运证明国家方向资格，不直接证明中远海控的运价、份额或利润上升。
- 船队规模、全球港口网络和双品牌协同证明参与资格；只有单箱收入、利润率、现金流和同业相对表现共同改善，才证明利润获得能力继续增强。
- SCFI、CCFI近期回升是行业价格信号，不能脱离红海绕航、全球需求和新船交付单独外推全年盈利。
- 放量与上涨是资金结果；没有ETF、机构持仓和订单分档身份数据时，不能把行情全部归因于长期场外增量。

## 二、竞争格局“3层 × 5问”底稿

### 2.1 国家层

| 问题 | 核验结果 | 证据与边界 |
|---|---|---|
| 方向是否明确 | 是 | 交通运输部把交通强国、海洋强国和航运强国作为“十五五”开局方向，并强调国际物流供应链韧性、安全、绿色与数字化。 |
| 是否进入实施层 | 是 | 2026年水运工作部署、现代航运服务业指导意见和港口航道规划均进入部门实施与行业服务层。 |
| 资源是否实际配置 | 部分存在 | 港口航道、智慧港口、绿色船舶、航运金融保险与国际规则能力获得制度和基础设施资源；未取得财政、政策性信贷或政府采购直接流向中远海控的统一金额。 |
| 企业是否具备承接资格 | 是 | 公司是央企航运核心上市平台，经营集装箱航运与码头，网络覆盖全球主要贸易通道。 |
| 是否存在外部约束 | 是 | 贸易政策、地缘冲突、海外港口审查、碳减排资本开支和国际航运规则均可能提高成本或限制资源传导。 |

### 2.2 产业 / 行业层

| 问题 | 核验结果 | 证据与边界 |
|---|---|---|
| 利润流向哪里 | 向运价、航线网络、港航协同、端到端供应链和成本控制能力强的头部班轮公司集中 | 2026Q1中远海控仍保持盈利，而Hapag-Lloyd出现季度EBIT亏损，显示经营韧性分化。 |
| 供需结构是否有利 | 短期受绕航与扰动支撑，中期供给压力大 | 2025年末全球集装箱船订单簿/现有船队约34.5%；大量新船交付将压制正常化运价。 |
| 定价权是否强化 | 未确认 | 2026-08-14 SCFI、CCFI回升，但公司2026Q1国际航线单箱收入同比下降约15.3%，行业定价权尚未连续转强。 |
| 关键控制力在哪里 | 联盟、全球网络、港口枢纽、船队与客户服务 | 海洋联盟DAY9航线、钱凯港等枢纽、双品牌和端到端服务共同提高网络密度与客户黏性。 |
| 产业资本如何行动 | 头部公司继续订造绿色大型船舶，行业整体扩产 | 中远海控手持54艘、超过82万TEU订单；行业大订单簿既是绿色升级，也是未来运力供给压力。 |

### 2.3 企业层

| 问题 | 核验结果 | 证据与边界 |
|---|---|---|
| 相对规模与网络 | 有优势 | 2025年末自营590艘、约360万TEU，自有和光租运力占75%；全球主要贸易区域和港口节点覆盖广。 |

## 九、使用边界

- 本页是截至指定时点的研究快照，不是持续更新的数据终端。
- 腾讯盘中行情在收盘后仍可能出现结算字段更新；报告使用16:14快照并明确标注盘中。
- 周期公司静态PE会随运价和利润大幅波动，不能把10倍PE直接等同于低估。
