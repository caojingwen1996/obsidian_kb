## 估值输入与计算口径

- 总股本：34.67957405 亿股。
- 主方法：正常化归母净利润 × 周期 PE。
- 悲观 / 基准 / 乐观正常化归母净利润：90 / 105 / 120 亿元。
- 悲观 / 基准 / 乐观周期 PE：8.4 / 8.75 / 8.95 倍。
- 对应每股价值：21.8 / 26.5 / 31.0 元，报告区间取整为 22-31 元。
- PB 交叉验证：H1 归母净资产对应 BVPS 约 11.00 元，2.0 / 2.4 / 2.8 倍 PB 对应 22.0 / 26.4 / 30.8 元。
- 正常化现金收益率交叉验证：70-95 亿元正常化 FCF、9.0%-10.5%要求收益率，对应约 19.2-30.5 元。
- 当前市值按 8.8 倍周期 PE 反推正常化归母净利润约 107.9 亿元；按 9.75%现金收益率反推正常化 FCF 约 92.6 亿元。
