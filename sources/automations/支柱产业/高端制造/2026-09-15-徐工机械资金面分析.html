4. 交易方画像与数据层独立性

4.1 标的类型声明

徐工机械为深市大市值两融标的，日线、资金分档、融资融券和低频股东数据可用；账户级机构、北向、国家队、QFII及游资身份尚不能直接验证。

4.2 一句话交易方画像

可确认的是“杠杆账户净撤出、大额订单代理净卖、小额订单代理净买”；不能把它改写为“机构出逃、散户接盘”，因为只有融资层提供身份锚点，订单分档仍是金额代理。

4.4 核心结论

这是“有身份锚点的杠杆撤出 + 无身份锚点的大额卖出 + 小额代理承接”的结构。它能说明趋势交易的资金质量偏弱，但证据不足以认定机构一致性减仓。

4.5 交易方结构特征

  • 主买方：小额订单代理，1/5/20日+0.72/+1.09/+5.61亿元。
  • 主卖方：融资账户与大额订单代理，短窗方向一致。
  • 多空分歧：纯特大单20日仍+0.16亿元，而大额+特大单20日-2.84亿元。
  • 异常信号：9月15日特大单净卖1.56亿元，为短窗主要冲击。
  • 不可知主体：G/N/Q/H/I账户身份缺少直接数据。

4.8 交叉验证总结

  • 融资余额与价格方向一致，但融资买入和订单流有重叠，只算“一项身份证据 + 一项金额代理”。
  • 大额订单卖出与小额订单买入方向相反，支持结构性流出，不支持所有资金共振撤离。
  • 回购和股东户数提供独立低频旁证，但时间上不能替代当日承接。

4.9 信号冲突与不可知

  • 方向冲突：纯特大单20日小幅净买，但大额+特大单20日净卖。
  • 重复统计：融资买入包含在成交订单中，没有与F5求和。
  • 金额方向已确认，机构/散户身份未确认。
  • 下一身份验证点：龙虎榜席位、陆股通持股、基金季报与ETF份额。

6. 资金分歧与传导链

  • 主导链条：融资净偿还 + 大额订单净卖 → 风险偏好下降、承接减弱 → 股价跌破短中期均线 → 相对同行走弱 → 结构性流出。
  • 反向链条：小额订单代理净买 + 低频回购记录 → 局部承接仍在 → 尚未形成无差别流出。
  • 谁在承接：只能确认小额订单层，不可确认真实账户。
  • 潜在退出：若7.77—7.78元近20日低点失守，同时融资和大额订单继续净流出，趋势盘止损与杠杆偿还可能互相强化。

7. 支持证据、反证与缺口

支持当前状态的证据

  • F3当日/5日/20日净买入均为负。
  • 大额+特大单合计三个窗口均为负。
  • 价格跌破MA5/10/20，短窗相对同行落后。
  • 市场广度偏弱，承接环境不利。

核心反证

  • 纯特大单20日仍小幅净流入0.16亿元，并非全窗口全口径一致流出。
  • 小额订单代理三个窗口均为正，局部承接存在。
  • 当前价格仍处估值区间内，资金流出不等于基本面价值归零。

数据缺口

F7、个股北向、机构持仓、龙虎榜、大宗交易、实时解禁减持和筹码成本未完整取得；这些缺口使交易方身份与退出压力只能给中等置信度。

9. 下一验证点与失效条件

  • 每日：融资最新日补齐后，观察F3净买入、融资余额、大额+特大单净额、收盘与成交量。
  • 短期转稳：不再创新低，并收复8.08—8.13元；5日大额净额由负转正或显著收窄，融资余额止跌。
  • 趋势反转确认：突破并站稳8.57元近20日高点，同时5日F3、订单流与相对强弱至少两个独立层改善。
  • 继续恶化：放量跌破7.77元，5日融资净买入和大额订单净额仍为负，相对同行继续走弱。
  • 基本面验证：2026Q3/H2扣非利润、自由现金流、短债和海外利润率决定资金修复能否持续。
  • 当前判断失效：若获得ETF、北向或法定机构持仓的明确持续流入，并与价格转强一致，应重新判断为多空分歧或结构性流入。
