一、火电、核电、水电：先搞懂它们各自靠什么赚钱

1. 火电利润被挤压，是因为煤价涨了

他先抛了个问题：今年火电的发电量比去年还高、电价也没什么变化，为什么利润反而下降了？答案是煤价涨了——电价属于公共事业，变化非常困难，成本一涨，利润空间就被挤压。

2. 煤价为什么涨：因为石油涨了，它们是「竞品」

这一步是他讲得最有意思的：煤价上涨不只是「不让挖煤」这个原因，更根本的是石油涨价。因为烧油和烧煤是可以相互替代的，它们之间有化学能量当量的等效关系——油价一涨，天然气会涨，煤炭也会涨。原来烧油的（比如化工原料、取暖、烧炉子）会改成烧煤。

这就跟大米和白面的价格不会出现过大差异是一个道理。面不仅仅和面竞争，面还要和米竞争——面太贵了，人们就会从吃面改成吃米。

3. 推论：火电成本上升，边际上利好所有非火电

他让大家顺着想一层：火电的利润空间被挤压，会利好什么？答案是所有非火电——核电、风电、光伏，相对来说边际上都会变好，因为火电原本在发电成本上是有绝对优势的。

4. 核电的成本结构完全不同：铀占比很低，大头是折旧和财务成本

他问了个进阶问题：铀矿其实也在涨价（因为美国搞了很多核电来支撑数据中心），为什么核电受的影响不像火电那么大？答案是成本结构不一样——核电的燃料成本占比很低（他凭印象说20%多），剩下的主要是设备折旧和财务成本，因为前期建设需要大量投入。

5. 核心判断：核电本质上赚的是利差，类似准金融行业

这是他这段最核心的观点：

核电相当于一个准金融行业。它从银行获得长期贷款，建成核电机组发电，然后再还给银行——它赚的是利差。

他解释：核电建成后能源源不断输出电力，一年能卖多少钱、有多少利润是能算出来的，还完银行本息，剩下的就是长期利润。所以核电的主要成本受利息影响更大。而且在资产没地方去的低利率环境下，核电对银行来说是越来越优质的贷款。

他说水电更是如此——销售端极其稳定，上网电价国家有审核。区别在于水电还受枯水丰水、厄尔尼诺拉尼娜影响，发电量有波动；而核电几乎没有波动，年发电小时数是固定的。他还提了一句：对电网来说，稳定的电才是最好的电。

6. 煤炭和石油为什么难判断

他说煤炭和石油都很难把握，因为它们首先受国际形势影响，其次还受国内宏观调控影响，「判断未来价格走势几乎是不可能的」。但有时候会给你错配的机会——比如煤炭价格已经涨很高了，但相关标的却没涨，大家都还在害怕中，这时候就是机会。不过千万不要据此去预判它还会按现在的斜率一直涨。

二、什么才算他定义的「周期股」

1. 有周期现象 ≠ 是周期股

他先做了个严格的区分：不是所有有高潮低谷的行业都算周期股。煤炭、原油有周期现象，但受国际形势和宏观调控影响太大，判断不了；券商也有明显的周期现象，但受货币政策、财政政策、经济景气度、市场情绪等太多因素影响，同样很难判断什么时候反转。

我所说的周期股是一类很特殊的：它既有周期现象，而且它的周期是非常容易把握的——你可以非常容易地判断出现在已经到低谷了，下一步就要往上走了。

2. 所有周期股的根本成因：供需错配

他说这类周期股的形成原因只有一个——供需错配。供大于求就是周期低谷，供不应求就是周期高点。而错配可以来自供给端，也可以来自需求端。

3. 供给端造成的周期：产能只会被动退出，不会主动退出

他以养猪为例：需求端非常稳定，波动主要来自供给端。周期高点时大家拼命扩产，产能过剩后价格下跌，从特别赚钱到全行业亏损，亏到受不了才开始有产能被动退出。

大部分的产能都是被动退出的，很少有产能会主动退出。因为大家谁都不想第一个退出——你退出就把别人救了，所以大家都在扛，看最后谁挺不住谁退出。

他说这就是生产者的囚徒困境。所以你会看到行业低谷时出现大量全行业亏损、大量破产倒闭和重组——「挺到最后的胜者通杀，然后就开始进入下一轮上升期」。

4. 需求端造成的周期：结束的方式不是需求下降，而是产能跟上

他用光模块、存储芯片举例：这几年供给其实是在增加的，但因为AI导致需求突然增加，所以照样进入高景气周期。那这种周期会怎么结束？

不是由于需求重新下降才结束的，而是由于上行周期一定会刺激产能增加。需求在先，供给响应在后——因为建设产能是需要时间的。

他说等所有人的产能都出来了，就又变成产能过剩。而且每个企业都是根据自身理性判断扩产的：「我判断明年缺口是20%，那我就扩产20%」——但生产者之间没法协调，每个人都想把增长空间全部填满，结果必然过剩。

5. 为什么不能坐下来开个会协调？——那叫卡特尔

他说这正是囚徒困境的关键：厂商之间不能坐下来商量「明年缺口多大、大家按这个扩产、别让价格下来」，因为那就是垄断行为、就是卡特尔，是不允许的。

你别看他们打暗号，那暗号都是给别人打的——你让别人别增产，我自己该增产还是增产。其实所有人都是这么想的。

他还提到欧佩克是最典型的卡特尔，但即便是欧佩克也各怀鬼胎——俄罗斯、美国不是成员，阿联酋还退出了。

三、这一轮有色金属：不只是供需，更是货币现象

1. 关键提问：为什么所有金属会在同一时间供不应求？

他抛出一个很有杀伤力的问题：不同的金属有不同的供需关系，那为什么所有的金属会突然在一夜之间都供不应求、价格都开始上涨？

难道所有的有色金属都有一个统一的供需关系吗？显然不是。

他给出的答案是：这次上涨更多是受贵金属价格上涨影响，而贵金属上涨是宏观货币政策导致的。

换句话说，这次有色金属涨价，不是有色金属本身供不应求了，而是美元的币值在贬值。

他说贵金属的价格分析根本不用考虑供需关系，「它纯粹就是个货币现象」。因为其他国家的币值都用美元汇率衡量，而美元本身是用贵金属来衡量的——「你可以说是黄金在上涨，也可以说是美元在贬值」。他还提到自己2020或2021年就说过一个玩笑：「索罗斯狙击英镑，我去狙击一下美元」，而狙击美元的方式就是买入它的对立面——贵金属。

2. 上一轮铜的超级周期，是我们的房地产和基建撑起来的

他梳理了完整的历史：铜价顶点大概在2004-2005年，而矿业股的股价顶点大概在2007-2008年——中间那段就是「股价错位机会」，「05年随便买入一个矿业股，到07、08年就挣得盆满钵满，涨十倍的矿业股到处都是」。

上一轮的需求驱动是中国的基建和房地产大开发：建房子要拉电线，城市扩张要配电网，用电量增加还要建发电厂、特高压骨干网，对铜铝的需求呈巨大幅度增长。

3. 但2008年之后，需求一直在增加，铜价却跌了

他指出一个很多人忽略的事实：从2008年到2020年，我们的用铜量、用铝量每年都在大幅增加，但同期铜价、铝价却出现了下跌。为什么？

这就是我刚才讲的：由需求所导致的上行周期，会在供给跟上之后结束。

所以他批评那些只讲「人工智能会用多少铜」的分析是「自我降维」——只研究了需求那一面，没研究供给那一面。

4. 这一轮的供给端：不是减少了，是没跟上

他解释当前的供给端状况：2008年后铜铝长期低位，导致大型矿业公司勘探投资意愿降低，这些年很少有新矿被发现；老矿还面临品位下降、开采深度增加、成本上升的问题，有些矿就不具备经济可行性了。

但他强调这是会变的：

随着铜价上涨，原来不可行的就变成可行了。原来品位0.3才能盈亏平衡，现在可能0.2就可以了；原来不能采的现在可以采了。而且这个过程一定伴随着勘探投资增加，未来一定会有新发现。

他说你已经能看到那两家著名的铜矿在国外扩产，国际上其他大铜矿也都在扩产——「所以你未来会看到铜的供给会增加」。

5. 「这个资源要枯竭了」的故事，每一轮都讲过

他说这类故事在历史上无数次重复过：

我刚大学毕业的时候，大家都在讲石油40年之内就会枯竭。现在已经快到40年了。每一次能源资源行业到高景气的时候，都会讲这个故事。

他还给了一条通用规律：

所有的周期股在景气高点的时候，人们都不认为它是周期股，都会给它起个名字——或者叫成长股，或者叫周期性成长股，或者叫什么革命的、未来不可替代的投资标的。永远是这样。要不然的话，怎么可能有人以那么高的价格去买呢？

四、为什么他现在对有色转为「狐疑」

1. 变量在美国：沃什代表了一种博弈结果

他说自己现在已经不看空有色了（短期博弈角度），但未来的确定性不足以吸引他投资，原因就是美联储主席换成了沃什这件事。他说沃什一直坚持「美联储不应该承担过多的社会责任」，美联储的作用就是维持美元币值、解决通胀。

2. 什么是「美联储的看跌期权」

他专门解释了这个概念：

当美国股市出现大幅下跌的时候，美联储一定会采取宽松的货币政策来增加货币供给，从而让美国资本市场继续上行——这就叫美联储的看跌期权，相当于美联储给美国股市进行背书、给下跌买了个保险。

他说这是从伯南克搞QE开始的，而沃什当时就是美联储理事，正因为反对搞QE、反对这个看跌期权而辞职。所以他的取向非常明确。

3. 为什么最终提名的不是哈塞特而是沃什

他反问：哈塞特主张无限宽松，这个取向川普知道、参议员也都知道，那为什么最终提名的是沃什？他否定了那些流行解释（说川普转变了态度、说沃什被游说了、说两家私交好所以沃什会听话）：

提名哈塞特不是特朗普不想，而是在参议院通不过。

他解释背后的博弈：川普想搞弱化美元来解决美债问题——只要美元无限贬值，美债问题自然解决（他打了个比方：把100美元的钞票后面加个0变成1000美元，物价涨十倍，美债不就减少了）。但这么做会让资产所有者、尤其是持有流动性的人利益受损，华尔街那些「老钱」不会甘于被摆布。所以这是一场新钱和老钱的博弈，最终结果是妥协。

4. 由此得出的结论链条

他把逻辑串起来：沃什上来 → 从预期降息三次变成可能加息 → 美元强势 → 不利于黄金等贵金属 → 贵金属下跌压制有色金属价格。这就是他对有色态度转变的完整推理。

五、你所看到的都是假象

1. 芒格的这句话，他反复强调

你所看到的都是假象。真相是要用思考的，不是你能看到的。

他打了个段子式的比方来说明：一对夫妻非常恩爱、儿女成群，那你认为他们每天晚上在床上干什么？你能看到吗？你只能看到他们很恩爱、有很多孩子，剩下的真相你得自己去想。

2. 时间错配：你看到的，是人家两年前就看到的

这是他这段的核心警告：

你所看到的东西是人家两年前就看到的。当你看到的时候，人家开始卖了。

他说这就是为什么「我一买入它就跌，我一卖出它就涨」——因为你看得没有人家远。你今天讲的那些故事（光模块不够用了、存储芯片不够用了），人家一年前两年前就已经认识到了。

他还从对手盘的角度反推：

如果大家都没有认识到这些问题、行业还没到高景气，那我问你，他的货怎么出得掉？他必须得等你看好的时候，才能把这个东西卖给你。反过来也一样，当你不看好的时候，人家才买得进来。

3. 实操信号：看论坛热不热闹

他给了一个很具体的观察方法：

一旦某个标的的论坛开始热闹了，就说明大家都看好了——这就是一个危险的标志。如果那个论坛1个小时发50个帖子，你就一定要小心。

反过来，他描述自己买的那些标的：

你在那论坛里面放个屁，过两天你再回来一看，那味儿还在——因为那里就没有人。为什么要这个时候买？因为只有在这个时候你才能买进来。

他也顺带解释了自己为什么老去「捅马蜂窝」——就是去试试有没有马蜂：「你一捅什么都没有，你就可以在这里面安心待着了。」

六、「买入并持有」不是巴菲特的发明

1. 卖煎饼果子的老王两口子也是买入并持有

他用了一个非常接地气的比方来拆解这个概念：

我们家楼下卖煎饼果子的老王两口子，他们也是买入并持有——买入煎饼烙子以后，就一直在那烙煎饼。他不会说明天煎饼烙子贵了，我就把烙子和炉子都卖了，等便宜的时候再买回来。

他说巴菲特之所以买入并持有，是因为他买的是公司、体量太大、没有对手盘，不可能来回进出；而不是因为「买入并持有」本身是一种更高明的方法。

2. 还有一种「买入并持有」，其实是自己看不清高低

他指出另一种情况：有些人所谓的买入并持有，其实是因为自己没有能力判断这个东西现在是高估还是低估。他回应了那些嘲笑他「一会儿看空一会儿看多」的人：

价格高的时候我就看空，我认为它合算了我就又看多了，那不很正常吗？

3. 价格和价值的关系：人和小狗

他打了个经典的比方：

投资标的的价格和它的价值之间，相当于人和小狗的关系——有的时候狗会跑到前头，有的时候狗会拉在你的后头。

所以当价格冲到前面、超越基本面的时候你要慎重；反过来它落后了、大家又开始悲观绝望的时候，你就应该有信心了。这也再次印证了他那句「价值投资和逆向投资是一体两面」。

七、房地产低迷其实是有「红利」的

1. 居住成本下降，等于变相提高了年轻人的消费能力

他提出一个反直觉的观点：

大家都知道人口红利——年轻人多所以人工便宜。我告诉你，房地产低迷同样是有红利的。

他的逻辑是：房子便宜了，居住成本就下降了；居住成本下降，同样的工资，消费能力就提高了。他说现在年轻人结婚买房所支出的资产占收入的比例，和十年前完全不同——「你现在到二三线城市，哪怕在饭店端盘子当服务员也可以买房子了，十年前这些人敢想买房子的事吗？」

2. 净存款增加的原因：从净负债变成净存款

他解释宏观数据：原来大家买房都是长期按揭贷款，居民是净负债的，「你在为自己的未来打工，哪有钱消费」；现在居民净存款增加很快，这些钱慢慢都得消费。

你今年买的房子比前几年便宜了100万，那这一百万是不是变相增加了你的资产、增加了你未来可以消费的增量？

他还说房地产低迷会带来另一个结果：城市化会加快。所以他看好消费，但看好的是那种基层的、原来叫「低端消费」的部分。
