一、这场的正课：周期股为什么不能买龙头

他说这是前一天和人讨论时突然想到的，早上专门写了个帖子，直播里又完整讲了一遍。

1. 问题出在「有信仰的人太多」

有些特别有名的周期股里面是有一些拥趸的，有一些人对龙头有信仰。那么就会造成一个局面：当这个周期股在周期低迷的时候，这些人因为特别有信仰，所以他不卖。

他们不卖，股价就没有崩塌。而你作为投资周期股的人，一定是在周期低迷期买入的——那你就买不到便宜。

2. 投周期股的人不是来长期持有的

投资周期股的人并不是拿它当龙头、当什么毛来投的，所以并不会长期持有。你在这里面投资主要的目的是为了赚取差价。

差价有两个方面可以获利：卖价高、买价低，都可以造成差价。所以你在投资周期股的时候，主要看的是弹性——当然最主要看的是安全性。

3. 所以龙头的问题是：什么都占优，价格也占优

你能看上的那些东西，大家也都能看上。你知道它是龙头，大家也都知道它是龙头；你知道它是安全的，大家也都知道它是安全的。那我问你，差价在哪呢？没有人打折出售，你上哪儿去占便宜呢？

你什么都占优，你股价也占优——股价占优的话，那你弹性就不足。

他打了个很好懂的比方：

一个人如果是美女，你知道她长得漂亮，别人也知道她长得漂亮，那嫁妆就一定会多。如果一个美女，一看嫁妆特别少，那你就得想其他的问题了。

4. 但也不能买最末流的

周期低迷期的时候，你不是所有的都可以投的。处于这个行业竞争末流的那些企业极容易被淘汰，你投资它就冒着很大的风险。

有人问那能不能等看清楚谁会被淘汰再买，他的回答是：

那不行。等一切都透明化、你已经知道谁能淘汰谁不能淘汰的时候，你最好的时机就已经过去了。

所以他自己的做法是：

我给你们讲过，为什么我绝不投第一，要投第二和第三。因为我买的是周期股——第一弹性不大，第二第三才更有弹性。

你今天回看一下，从低点到高点拉个线，你看看是第一涨得多还是第二涨得多。是从15涨到45大，还是从5块涨到28大？

5. 航空公司那个例子：没跌，就是问题

疫情刚结束的时候有很多人要投资航空公司。我当时就提醒过：航空公司在疫情以后基本面肯定会好转，这谁都能想明白。但问题在于——航空公司在疫情期间压根就没跌，这就是问题所在。

他明明受到了那么大的经营冲击，那三年亏得裤衩子都快没了，为什么股价没跌呢？因为大家都不认输。那你指望他反过来的时候就会涨吗？不会。缓过来的时候，他首先要用钱去弥补亏损。

6. 所以博弈是「第二层次」的思考

你不是说「我这个企业一定是最好的」，天天分析这个也占优、那也占优。博弈的东西是第二层面的——你的思维要开阔，不是顺着你那条道跑到黑。

他还把这条规律推到了周期顶点：

有很多周期股，当周期的顶点真正来临的时候，它们反倒是下跌的。它可能在最初也跟着涨一段，但涨到头的时候可能不会再涨了，甚至可能会下跌，因为它的弹性很小。

你看多少周期股业绩非常好，它就是不涨，你骂说是科技股夺走了资金——那都没有用。每一个投资者都是理性的：你那个东西根本没跌，我凭什么去接你的盘呢？我有的是跌下来的、弹性很高的。

你也可以把股票理解为它们在竞争你们这些资金。你养猪养得好、挖矿挖得好，但是你的股价没有吸引力。

二、「利好出尽是利空」这句话本身就说错了

1. 他给了一个更准确的版本

不是「利好出尽是利空」，而是「所有人都知道的利好就是利空」。

因为总有一部分人是先知先觉、是先知道的。你应该想的是：你所知道的这个利好，你是第几个知道的？

2. 为什么必须等到所有人都知道

只有在所有人都知道利好的情况下，这个股票才是卖出的最好时机。如果还有一些傻狍子不知道利好的情况下就卖，那就卖可惜了。

3. 所以看着中报去买，是等着被套

今天科技股有很多回调的，是因为出的中报不好吗？你看科技股的中报哪个不好？哪个中报不是一增长就是百分之几百的？

如果你看着这个中报去买股票，那你不是请等着被套吗？人家把这个菜都准备好几年了，就等今天等你来上桌。

三、一个可以直接照着看的组合信号

1. 四个特征同时出现，说明在派发

基本面全是好消息，股东人数不断在增加，价格不断在下跌，成交量甚至也没有明显的缩减——这就说明这个股票里面在派发。

就是人均持股在下降，由有优势的投资者转到没有优势的投资者，由机构转到散户，就这么一个过程。

2. 转到散户手里之后会怎样

谁也不敢保证由机构转到散户就一定会下跌，但是这只股票再想上涨已经很难了。

因为散户的交易是非常随机的，它不会形成主导价格的合力。散户做的是布朗运动，形不成合力；只有机构才可以形成合力，才可以导致价格朝着一个方向持续运动。

无论多么好的基本面，如果这个股票的持股结构全部都是散户，它也形不成合力。

3. 他给这个过程起了个物理学的名字

股价在下跌，股东人数在上涨，然后全是好消息——这个过程实际上相当于这个股票的熵在增加。你要学过物理学就知道了，它是一个增熵的过程。

四、日元加息：为什么加息反而更宽松

1. 先说对美股的影响

日元一旦加息，就会导致借日元投资美股美债的这些资金在边际上失去套利的基础。对利息特别敏感的这些边际资金就会从美股和美债撤出，回流日本。

所以对美股来说，会造成一种流动性紧缩的效果，这对美股是一个打击。

他还说了日本这么做的动机：日元对美元不断贬值，而日本对外依存度非常高，所以造成了「输入性通胀」——「不是由国内经济过热导致的内生性通胀，而是由汇率变化导致的」。

2. 但他认为这解决不了日本的通胀

我认为加息对解决日本的通胀问题意义并不大。它可能会解决汇率问题，但解决不了通胀问题。

随着日元回流，汇率的贬值可能发生逆转、甚至可能升值，进口的东西可能便宜了；但问题在于日本国内的日元多了。所以日本加息以后，会导致国内的内生性日元增加——他越加息反倒流动性越宽松。

他和别的国家都不一样。别的国家加息会实现流动性紧缩，但日本加息反倒使它国内的日元流动性在边际上更加宽松。

所以他的推论是：「日本国内的通货膨胀可能不会缓解，反倒有可能更厉害。而最终通胀又会反映到汇率上——所以加息可能导致它的通胀不降反升，最终汇率也一样。」

3. 根子还是那件事：日元被商品化了

日元为什么能加息反倒宽松、加息反倒导致汇率贬值？一个主要的原因就是日元在过去二三十年被大量商品化。

日本借了那么多国债、发了那么多货币，日本央行甚至下场买过股票ETF，但日本依然通缩，为什么？因为他的日元发出来以后，并没有留在国内以货币的形态存在，而是被运到了国外以商品的形式存在。

他还给了个数字：「日本的国债和GDP的比值是所有发达国家里最高的，超过200%、240%，比美国高得多——发了这么多货币，最后居然还是通缩的。」

4. 他当年的那次判断

第一次日元加息的时候，大家都认为日元会升值、日本国内的通货膨胀会获得解决。我当时就下过结论：这次加息一定会导致它的汇率继续贬值，而且贬得更快，通胀会比以前还严重。

结果加完息，日元升一下，然后开始继续贬。一大堆人说日元反常地出现了贬值——我说不是反常，是因为你们理解的这个规律压根就不对。对日本这个国家的理解，和你们对一般主权国家的理解是不一样的。

五、这场最有分量的一段：美元指数是个「比烂指标」

1. 他反对那条流行的说法

有很多人跟你们讲，大宗商品和美元指数是反向关系——美元指数上涨，大宗商品就下跌。我从来不认为美元指数和大宗商品之间有什么必然联系。

我还给大家拉过一个图，从1980年到现在，大宗商品和美元指数之间并没有很强的关联性。我一直都不知道那些专家是怎么推导出来的。

2. 原因：美元指数根本不代表购买力

美元指数实际上是个汇率指标，或者说是个比烂指标。它并不代表美元的购买力，而是美元和六种货币之间比较时哪个币值更高的问题，它是一个相对指标。

如果所有的货币都贬值、比美元贬值还快，那么美元指数就会上升。它跟美元本身的绝对购买力是没有关系的。

3. 那美元购买力的真正镜像是什么

美元购买力的镜像，严格地说是所有的物质财富——如果做一个指标的话，其实是美国国内的物价指数。

当美国出现通货膨胀的时候，就意味着美元的购买力在下降，这跟美元指数没有什么关系。美国国内通胀、美元购买力下降的时候，可能其他货币下降得更快，所以这时候美元指数可能反而是上升的。

4. 真正和大宗商品反向的，是日元汇率

这是他当年那个预言的完整推理。第一步是日元为什么会成为避险货币：

日本所谓的失去多少年，其实是以通缩为基础的，或者说他没有通货膨胀。没有通货膨胀就意味着日元的购买力非常稳定、内涵价值几乎不变。所以当美国有风吹草动的时候，大家就买入日元——这就是它被称为避险货币的原因。

日元其实都没有利息，持有它是没有孳息的。但你为什么要买入日元？因为它的购买力稳定。

第二步是：还有什么东西能起这个作用？

这东西和黄金很像。所以当大家开始发现用黄金能更好避险的时候，大家就会抛弃日元。

所以他当年的结论是：

真正的大宗商品走势其实和日元的汇率是反向的——当日元汇率走高的时候，大宗商品就走低，而不是和美元指数反向的。

我当时的原话是：之所以现在日元没有保值功能、不会再成为避险货币，是因为全世界的资本找到了更好的玩具，那就是大宗商品。所以那个时候我预言了未来的大宗商品会上涨，包括黄金。

当日元出现贬值的时候，你最好的投资就是买入大宗商品。其实那也是我一直投资有色金属标的最底层的理论基础。

5. 但黄金有个问题：信仰太多

他在这里把这条线和开头的周期股接上了：

黄金以前也有这个功能，但黄金的问题在于它经过一次上涨，到1980年的时候价格就太高了——涨到800美元一盎司。按通货膨胀率折算的话，今天还没有涨到那个价格。

当某一个东西有很多人有信仰的时候，它就不是一个好的投资标的。当大家都崇拜黄金、对黄金有信仰的时候，你再用黄金去避险那就不对了，因为它已经被炒高了。

它不仅仅被炒高了，最主要是它没有下跌，所以它就不是一个好的投资标的。你要买入它，你就会承担巨大的风险，因为它一定会价值回归。这就跟我开头讲的周期股龙头为什么不值得投资，道理是一样的。

六、思维的清晰度：别给自己留混沌的地方

1. 「科技是未来的方向」这句话的问题

科技是未来产业的方向，这没错；是我们国家投资的方向，这也没错。但不见得是投资的方向，不见得是我们个人投资的方向。

你如果老说「科技是未来的方向」，慢慢你就容易傻乎乎地冲进科技股里面去买。

2. 所以他要求思维要「条块分割清晰」

你的思维一定要特别清晰，条块的分割特别清晰，不要有任何混沌的地方。你只要有一个混沌的地方，甚至你说话有混沌的地方，慢慢你就会自我洗脑——你没有分析清楚这事儿，自己就给自己洗脑了。

3. 芒格的鱼漂故事

芒格爱钓鱼，有一次上渔具店买鱼漂，那些鱼漂做得五颜六色、非常鲜艳。他就问渔具店老板：鱼真的喜欢这么五颜六色的鱼漂吗？老板说，我的鱼漂又不是卖给鱼的。

芒格讲这个故事是想说：你在思考的时候经常会陷入一些误区，你要时刻警惕——你觉得看似有理的地方，其实没有道理。

七、你到市场来是干什么的

1. 他对「你是什么派、主打什么方向」的回答

有人问我，老师你用什么方式投资？我说我投资主要的方式就是用挣钱的方式。问我主打什么方向？我主打赚钱的方向。

三脚猫老有门派之分。你看东邪西毒南帝北丐，谁是啥派的？是人家自己说过啥派？就他妈寒碜的，天天说自己是名门正派。

2. 把正事记住

你不是来养猪的，不是来挖矿的，也不是来造船的，你是来赚差价的。你唯一需要做的是低买高卖，别的都是为了服务这件事的。

你也不是为了知识科技发展的——你支持科技发展也是为了低买高卖，你长期持有也是为了低买高卖。你先别骗自己，先背诵一下你自己干啥来了，别把正事都忘了。

3. 以及一句自嘲式的提醒

你研究了挖矿，就天天觉得自己是矿业专家了。你懂矿？你下过井吗？

我有时候一看，咱中国最厉害的科技专家都在证券公司——那研究员最懂科技，啥都懂，中国的科技未来都在他们掌握之中。你问问他们投资的业绩咋样？

他还讲了个九十年代流传的老段子：有个老股民炒股亏得销声匿迹，多年后西装革履地回来给大家讲课，人家问他怎么翻身的，他说——

所以你要知道，研究员就是被骟了的基金经理。

4. 他对自己的定位

大家见过我捍卫过哪个股票吗？哪个股票也不是我的，越骂得多不是越便宜了吗？骂便宜了我不可以多买点吗？

我卖出了就告诉你有风险；如果我卖出了还告诉你它特别好，那我不是骗你们吗？我买入的时候当然就会觉得它好——这叫知行合一，说的和心里想的是一样的。

你不论买哪个股票，包括我自己买的，都是概率游戏，多多少少里面都有运气成分。你只是通过自己的思考，把运气成分排除到最低。

八、什么行业不能碰：清点不了的行业

1. 水产养殖最容易出问题，原因只有一个

水产养殖最大的问题是：你没办法清点。不是财务容易造假，是他的库存你不好清点——我告诉你这个湖里头有一万只王八，你去数，你咋数？

其实对于普通的养殖户来说，他自己也清点不了，这东西就是一个靠天吃饭的东西。

他举了海参做例子：「海参在捞之前，养殖户自己都不知道下面一共有多少、成活的产量是多少。而且海参有个机制叫自溶——一旦有某种疾病，它自己就化了，啥也没有了。」他还提到当年那家在鄱阳湖养甲鱼的公司，发洪水后先说甲鱼被冲走了、股价跌下来，过几天又发公告说清点完毕、甲鱼都趴在湖底没被冲走，还繁殖了不少。

2. 这条规律可以推广到整个养殖业和农业

由此你也可以推导到整个养殖行业都存在这个问题，养鸡也是一样——鸡舍里一共有多少只鸡，你怎么数？你今天数完这个鸡舍，明天再数那个的时候，我连夜把这些鸡拉到那边去，你可以随便数。

农业是靠天吃饭的，你在收成的那一刹那，谁也不知道今年收成是多少，抽样统计也不一定就准。

3. 所以最终要看的是人，不是合同

什么东西都能造假。所以巴菲特说你要投资的话，最主要是投资管理人员，你要找到一个诚实的人，而不是想办法把不诚实的人给束缚住。

根据我多年的法律从业经验：如果他想骗你，你把他绑上，他也能骗你。

交易最靠谱的东西根本不是写一个500页的合同。巴菲特买公司写的合同从来不超过一页纸——因为他根本不信用合同就能把人变得诚实。关键在于看交易的对手。

4. 由此他给了一条选股上的偏好

在判断管理层和所有者的信誉方面，国企要比私企强得多。不是说私企没有好的，是私企对于我们普通小散来说难以判断、选择太困难。

央企总的来说是没有个人利益的。他没有必要找一大堆人非要造假——造假以后利益他也得不到，最后责任还都是他自己担。

他还提到一个法律上的差别：「同样是把企业的钱拿回家，国企叫贪污，私企叫侵占，两者的刑期是完全不同的。刑期不同，震慑力就不同。」以及「国企有专门的机关看着，而这个反腐成本是外部化的；私企的反腐成本基本上是自己担」。

九、成本外部化：一个解释了很多事的概念

1. 先用造纸厂讲清楚这个概念

造纸的排放污染特别严重。对一个央企来说，他敢不敢把废水直接排到河道里？不敢——排放对他来说是为了省钱，可省下的钱不归他自己、归国家，责任却是他的，所以谁也不愿意干这件事。

而一个小的私营造纸厂不在乎这个，他就把废水直接排到河道里，抓住我再说，抓不住我就干一天是一天。他直接向江河湖海排污的这个过程，就相当于成本的外部化。

它本来应该有污水处理设备、达到排污标准才能排放，是要花一笔钱的。现在他直排了，成本就省了——那这个成本转嫁到哪去了？转嫁到大自然了，转嫁到国家了。

2. 所以竞争地位从一开始就不均等

同样生产一张纸，国企用一块钱，人家用八毛钱就可以了。那两毛钱的成本负担是被社会承担了。那你怎么在这个行业里和私营企业竞争呢？你竞争不了，国企就破产倒闭，私企就站住了。

他还举了第二个例子：

私企在雇佣员工的时候可以不交保险，国企做不到这一点。你国企不给人提供五险一金，你就违法了。

3. 他用这个概念重新解释了九十年代那段历史

1998年大量东北的工业企业倒闭，本身是因为和南方的私营企业竞争的时候并不处在同等的地位。东北的国企需要解决的问题非常多——不仅包括保险，还包括养老、采暖费，还有排污和各种社会责任都得承担；而南方的私企什么都不需要考量。

最典型的是当年纺织行业产能严重过剩，国家主导了一次「压锭」，相当于供给侧改革。但压锭最终压的都是国有纺织厂，而私人纺织厂根本不在乎、在此期间大量扩张。所以从那以后国有纺织厂全军覆没——而国有纺织厂是最大的劳动密集型产业，导致了大量职工下岗。

这些工厂下岗倒闭的成本是由东北来担的，而后来南方私人纺织厂的收益是由南方获取的。当产业转移的时候，我担的全是成本，你获得的全是收益——这对于不同地方的竞争来说，也是一种成本外部化。

别人一说就是「投资不过山海关」——你分析过当时的历史原因吗？他自然有效率低下的问题，但不全是。你今天在想这些问题的时候，要客观全面。

4. 同一个概念也能解释国际间的事

最近几十年美国科技获得极大发展，其中人才的主要来源是中国和印度。这也相当于成本外部化。

我上大学那会儿，清华北大得有一半学生最终都去了美国、没回来。那相当于我们是种瓜的，最好的瓜摘下来送到美国去吃——而种瓜的钱是我们出的。

他还顺带给了个判断：「如果长此以往，中国不再向他们输送这些最顶级的智能资源的时候，那他的科技怎么发展呢？」

十、别把结论口号化：美国、深圳与罗马

1. 美国最初有什么科技

别把美国想得像太阳似的、像天堂似的。他最初有啥科技？他们最初的科学家不都是欧洲去的吗？是因为两次世界大战，欧亚大陆都是战乱，你要想研究科技只能去美国。

2. 深圳工资高的真正原因

你说深圳工资高是由于科技——我告诉你科技是结果，不是原因。原因是那个地方是一个新出现的地方，它没有历史上的负担。

你把东北那些老头老太太都派过去，一个养老费、一个医疗费就把你拖死。深圳去的都是各地最好的年轻人，交医疗保险的人多、用医疗保险的人少，所以财政非常健康，所以什么都好——他是因为他没老。

3. 美国也是一样：它老了

美国今天也是一样。为什么王朝都是二百多年就完了呢？他也没老的时候什么都对——二次世界大战的时候他做啥都对。为什么今天做啥都不对了呢？你加息也不敢加，降息也不敢降，美债那么高——因为你老了。

4. 罗马和大观园

罗马还是天堂呢。你现在想古代最辉煌的罗马，那代价是有一大部分人是奴隶。罗马的天堂不是所有人的天堂，真正的罗马公民是很少的。

你们都合计大观园多好，贾宝玉、林黛玉天天吟诗作画、吃鹿肉。那你穿越回去，你咋不想着当丫鬟？晴雯有病了，就给你撵出去。

他的落点是：「你在下结论之前，先别口号化了。思考要全面，打开你的思维，别那么狭隘。」

十一、他自己的收尾

我讲的都是评书，你不能用来投资，也不能用来指导你的下单。我也不提个股，你别望文生义。

讲道理的时候有时候会举些例子，你别看到例子就开始拆、然后就开始投资了——那不行，你把裤衩子亏没了，这事不怨我。
