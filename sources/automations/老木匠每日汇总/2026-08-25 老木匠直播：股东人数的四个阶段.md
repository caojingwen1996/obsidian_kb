一、美国市场：现在还谈不到流动性危机

1. 昨晚美股科技股大跌，是怀疑而不是危机

现在还谈不到流动性问题，现在只是对未来AI人工智能是否能够持续产生盈利的一种怀疑。

他说纳斯达克整体没跌多少，但半导体芯片和光通讯跌幅非常大。至于原因，「我真的没找到什么明确的原因，感觉好像就是受A股昨天科技股大跌的影响」。

2. 什么时候才叫流动性危机：先搞懂保证金交易

美国市场基本上是保证金交易，你可以理解为它自带杠杆——比如给你50%的保证金额度，那就相当于两倍杠杆，你花50%的钱就可以买了。所以他们才有margin call这种东西，就是追加保证金。

当股票跌到一定程度，你存在那里的保证金不够了，就需要追加；如果追加不了就会强制平仓——那个时候才叫做流动性危机。

3. 和我们的融资完全不是一回事

我们即使上杠杆也是借钱，这个钱是真真切切存在的，只是不是你自己的，是从别人那儿借来的。但保证金交易压根就不需要这么多钱——你买股票花100万，实际上只要给50万就可以了，大家是一个对赌游戏，最后结算就完了。

他还点出这和昨天讲的代持制是连着的：

它之所以可以不用全款买，是因为这个股票压根就不在他名下，而是在中介机构名下，中介机构必须得全款买。

二、对贝森特那些操作的评价：小技巧，不是大智慧

1. 先说一个不正常的现象

他注意到现在很多本该由国务卿负责的事（谈伊朗制裁、外交、日本问题）都是财政部长在做：

国务卿在美国的政治地位实际上比副总统还要高。你看现在卢比奥大有被架空的势头，国防部长也很长时间不出来了——谈战争问题就是总统和财政部长，这事本身就不太正常。

这说明美国现在的政治体系非常不稳定，完全由个人偏好在决定。整个运作体系更像是一个家族，特朗普是按照管理他的家族企业的模式在管理美国。

2. 他对贝森特能力的判断

很多人对贝森特的能力赞不绝口，说他当年做空日元如何——他当年是个操盘手，背后是由老板来决定的，哪个东西是由他来定的？

把回购上限从20亿提高到40亿，然后在小纸条上写买入多少日元——这都是小技巧。跟人做生意你会发现，有些人是有小技巧，有的人是有大智慧。干这个事就属于没有大智慧。

3. 「拿TGA账户的钱去买国债」这个传言是胡扯

TGA是美国的经常账户，那是涉及整个国家运转的钱，相当于国家的钱包、相当于你日常开销的活期存款。你能把它拿出来都用吗？那平常遇着个风吹草动你咋办？

要能动的话，他要有那么有钱的话，他何必发国债借债？那里头的钱都是借来的。

4. 他怀疑这类消息是国内传的

我都怀疑这消息是咱们国内的人造的。这个东西在美国可能压根就没什么人信，但传到我们这就有很多人信。因为这就意味着好像美国又要宽松了，我们又要按照宽松这个模式去投资某些标的，所以科技又要涨了。

他给的验证方法很直接：「你看他说9500亿都要买国债的时候，美国国债收益率有啥变化吗？美国哪有人信。」

三、为什么谁来也治不了美国的通胀

1. 治通胀本身不难，难的是不衰退

加息治通胀这件事没什么难的，你使劲加息、使劲紧缩，它就能治理通胀。难在你治理通胀的同时还得保证它不衰退。

那就意味着你在治理通胀的时候，得有人给你承担这个成本。当年美国治理通胀的成本是由东南亚和我们来承担的，甚至也包括日本。那现在谁给你承担这个成本呢？

2. 沃尔克当年靠的是运气和外部条件

他把当年那条线完整梳理了一遍：改革开放、苏东剧变、军费压力骤减，「当年苏东的巨变其实是救了美国，包括我们是给美国打了很多年工」。

大幅加息一定会引起经济衰退。你要想在治理通胀的同时还不产生萧条，那只有一个条件——外来的输入发生了变化，有人给你提供廉价的商品。

他还往前推了一步：

沃尔克加息之前其实还有一件事，就是尼克松访华。如果当年没有中国和美国实现关系正常化，美国是没有机会的。这一切的东西你应该串起来看。

3. 布雷顿森林体系解体，本质就是一次币值重置

当年谈判的时候，各国是按35美元一盎司把自己的黄金运到美国的，你给了我美元、说可以随时兑换黄金。结果你美元越印越多，自己的黄金就不够了。最早看出来的是法国人，拿到美元就要兑换黄金，美国的黄金消耗非常快，最后布雷顿森林体系就解体了——实际上就是美国一次违约。

黄金从35美元涨到800美元，涨了二十多倍，那就相当于原来的1美元后来只值5美分——你的币值重置多厉害？

由此他给了一个和主流说法完全不同的判断：

所有经济学家给你总结说七八十年代美国的通胀是因为伊朗石油危机，那都是表象。它的本质在于美国的币值重置。你在这种美元的情况下，石油能不涨吗？

这个事儿现在其实还得再搞一次。币值重置当然不可避免，因为只有币值重置才能解决美国的债务危机。

4. 通胀就是一种赖账方式

对于美元来说，通货膨胀本身就是赖账的一种方式。他印美元的时候大米是一块钱一斤，他收美元的时候大米变成两块钱一斤——那不就相当于有一半赖掉了吗？

你今天为什么治理不了通胀？是因为大家现在拿着你的借条，不觉得那么可靠了，都需要把这个借条兑现。你一年生产的东西，现在有两年的GDP创造的钱准备兑现，你怎么控制通胀？

5. 但他真正担心的不是这个

我最害怕的是——沃什他有理想。他有理想我就想试一把，那这个过程就要人命。他试一把就有可能产生危机。

那产生危机了，那顺理成章的我再宽松呗，那我还成大救星了。

他还提醒了当年的教训：「保罗·沃尔克刚上台的时候，大家也都认为你根本不敢加息，加息就完了。没想到后来沃尔克玩是真的，最后把利息加到两位数。」

6. 一条更根本的常识

谁也不能通过金融这种方式创造财富。金融只是财富的度量，它不会创造财富。你用发货币、收货币的方式能让大米生产出来吗？能生产出衣服吗？

唯一能拉动经济的是生产，剩下的东西都是为生产服务的。无论出口、投资还是消费，这三驾马车都是为了刺激生产。你经济的总量代表的是你生产的能力。

他还用了个家庭的比方：「你看哪家说我们家邻居就是特别能消费，所以他们家最厉害？他得有生产的，要不然他不得借去吗？美国就是这个道理——他特别能消费是因为他能印钱，而他印出来的钱对全世界来说就是借条。」

四、这场的重头课：股东人数的四个阶段

这是他第一次把「为什么要看股东人数」从头到尾讲完整，可以当作前面所有「筹码」话题的总纲。

1. 第一阶段：股东人数最多的时候，恰恰是最低迷的时候

股东人数最多的时候，是这个股价极度低迷的时候——这个票已经长期没人看了，也没有机构在里头了，已经全是散户了。

虽然股东人数最多，但它的交易是很低迷的。因为大部分持有股票的散户都处在被套状态，他们基本没有交易的冲动。

他描述了这个阶段的形态：

那都是上一波人家出货，货都出没了压到底下，然后有些散户零星交易把价格压下来——套得实在受不了了就卖一点，再受不了再卖一点，但底下没有承接盘，所以价格越来越跌，表现为阴跌。然后横盘，就是再也没有人想卖了，买卖达成平衡，会横盘很长时间。

所以这个时候这样的股票容易产生低估值。这就是彼得·林奇说的十倍股为什么产生在机构不跟踪、研究员不追踪的地方。这就是我说的坑，你就得找这样的东西。

2. 第二阶段：股价没涨，但股东人数已经开始下降

突然有人发现这个行业还很低迷，而且未来前景不差，这时候就会有人开始进来买入。当机构进来买入的时候，它一买就会涨。

所以你会发现一个现象：它突然有一天出现放量大涨，但很快又回来了。为什么？因为这时候机构持股很少，它进出非常不方便，一买就会涨。所以我买一下冲上去我就再等，等你跌回来我再买。

这个时候如果你能看到实时的股东人数，你会发现虽然股票价格没涨，但股东人数已经开始下降了。

3. 第三阶段：股价慢慢抬升，靠「解套-回落」反复清洗

在底下买它就没有了、买不着了，没有人卖了。那你想买就得拉升股价——拉升股价谁在卖呢？解套的散户在卖。

一旦股价到某个散户的解套区间，这些散户就开始卖了。然后就在这个套牢区间里反复波动：让你解套、再让你回来，让你解套、再让你回来，这样你就根本拿不住。散户的筹码就这样逐渐倒到了机构手里。

4. 第四阶段：铺天盖地全是好消息，而股东人数仍在减少

大约持续一两年，突然有一天铺天盖地全是关于这个行业的消息，所有人都知道业绩变得非常好了，股价开始大幅拉升。但这个时候股东人数如果你能看到的话，它仍然是减少的。

因为这个时候机构主要是要影响价格，为未来的出货拉出一个空间。大家一定要明白：出货不是说你拉到十块钱、十块钱就能出的。你要想十块钱出货，你可能得拉到20。

这个时候股东人数已经非常集中了，所以稍微买一点点股价就会大幅上涨。表现为成交量快速放大、股价快速上涨，但股东人数还是下降的。这时候舆论、研究报告最热闹，散户会发现这是一个好股票——星辰大海的故事就来了：未来不可替代、值得一生持有、改变全人类。

5. 然后是顶部：那一根巨量

直到有一天你突然发现它到了一个尖儿，在顶部突然放了个巨量，然后出现下跌——那就意味着机构的出货开始了。

但我告诉你他出不去，在顶部这么出是出不去的，他只是第一次出了一点而已。而且即便他出这点货获得的钱，最终也还得把这些股票再买回来——这次出的钱实际上是未来用来维持股价的成本。

他解释了为什么维持股价需要成本：「当你出货的时候它跌得多了，你还得把它买上去再拉起来。所以你会发现跌下来冲一点，再跌下来再冲一点。」

五、什么才叫抄底：得把这锅水晾凉

1. 他这次给了一个很形象的标准

抄底你得把它晾凉，让它彻底凉透，你才能抄底。现在抄啥底？水刚开完，从100度刚刚降到70度，你就来抄底。

散户所谓的抄底都是扯淡，他根本就不知道什么是底。真正到底的时候，他根本就不敢买。

2. 高位那个价格根本不是用来成交的

所有这种东西的顶部都不是为了交易的，它是用来给你看的，是给你做心理锚的。我拉到1000，其实我出货就想800出——甚至我本来就想500出。

为啥要拉到1000呢？因为从1000跌到500的时候，所有散户都认为这个股票原来值1000、现在500就能买，非常便宜。

3. 所以「腰斩之后」才是最危险的时候

他提醒大家回想他之前说过的话：

我说过科技现在不危险，再过几天腰斩才危险。

高高在上的时候它根本不危险，所有散户都知道它贵、不会去追高买。那个时候不是散户买的，那是人家机构自己做着玩儿出来的。

你看这两天它跌的时候你觉得不危险，过两天咔嚓又来一个上涨，你心里头那草长的，让你难以自主。

他用有色做了个现成的对照：

有色也是一样，45的时候并不危险；跌到23再涨回到35，那才是危险的。

4. 所以你研究的基本面是滞后的

你研究的基本面就不对——等你研究基本面的时候，黄瓜都凉了。

六、科技牛市与「不要让自己成为税基」

1. 他重申了对科技牛市的态度

科技的牛市是没有任何问题的。但是你买不买科技股，那取决于你自己。因为科技股的特点就是赔率高而胜率低。

我提示大家风险是从个人角度上来说。我认为科技应该涨，但我不会买。

2. 为什么这件事在宏观上是对的

我们现在财政这么困难，房地产低迷之后各个地方政府财政都很困难。你不靠股民来给科技投钱，靠财政，财政哪有钱再投？

他还回顾了自己早年的一个说法：

我以前说过，茅台和五粮液是美国锁死我们外资、锁死我们科技的两个质子——就像《三体》里三体人为了锁死地球科技发了两个质子来。当年所有资金全部聚集到酱香科技、浓香科技上，那些年我们的股市对科技是没有贡献的。

既然散户都是亏钱的，那亏在科技里要比亏在白酒里好得多。起码你亏在这儿是有意义的。

3. 高房价是一种税

他把这条老观点又讲了一遍，并把逻辑补全：

高房价大部分是因为土地出让金高。不是房地产开发公司挣了多少钱——土建成本、开发利润没有多少。土地出让金去哪了？那属于财政收入，只是我们人为规定它叫非税收入。非税收入和税收收入，对财政来说有啥区别？

所以为什么叫土地财政？你今天中国的基建做得这么好，高铁、高速公路，钱从哪来的？那不都是你们买房子的钱吗？

4. 所以真正该防的是：别让自己成为税基

你在社会上无论是投资也好、升值也好，第一件事应该考虑的是——不要让自己成为税基。

收税对我来说是最好的一件事，但前提是这个税不是从我身上收的。为什么2021年不能买房子？因为你2021年买房子就是成为税基了。那你今天买某些股票，也会成为税基。

5. 顺带：对自己诚实

有的人说我就是为了给科技做贡献——那是因为你买完被套了。你买的时候肯定不是想着做贡献，你是为了赚差价，只是没赚着、被套里头了，为了安慰自己又扯什么做贡献。那你为啥当年不给科技捐款呢？

七、做有色的那个隐含假设：人民币也得跟着重置

1. 这是他这场最锋利的一个提醒

做有色得有一个假设：美元崩，我们得跟着美元崩才行。美元币值重置，人民币也得跟着币值重置，你才能做有色的股票。

因为你计算有色金属这些公司的利润是以人民币作为本位币的。那我问你，如果有一天人民币不跟着美元重置呢？人民币要升到3呢？同样的黄金价格，以人民币计价是不是得折一半？

他强调这只是个思维训练：「我说的这东西不太可能。我是跟你讲这个道理，你得知道人家在想什么。你天天想的是国外又创新高了——国外当然创新高了。那我问你，你敢保证人民币币值一定重置吗？」

2. 所以「只看挖多少矿」是不够的

有人说分析宏观没有用，你知道挖多少矿就行了。你挖多少矿，不得拉回来以人民币计价吗？知道啥叫汇兑损益不？你大量的资产都是美元，如果人民币大幅升值，你的资产就得有减值损失——这就叫汇兑损失。

我只是告诉你，分析不是那么简单的，不是知道能挖多少矿、够不够用就行。

3. 人民币升值会带来什么：中国核心资产上涨

他把这条推到了国外投资者的视角：

假如美元币值一定重置，那持有美元的人最好是换成黄金、换成实物资产。但除此之外容量都太小了——全世界的黄金能有多少？

我告诉你，人民币资产就是最好的避险资产。这跟当年美元去买日元资产道理是一样的——当年为什么大量美元去买日元资产？因为日元在升值。

对国外投资者来说，我买入一个国内的核心资产，我不指望它股票涨多少。只要人民币不跟随美元贬值、甚至贬值速度慢于美元——比如美元一年贬20%、人民币只贬10%——那对我来说我就赚了，股价都不需要涨。

他说债券也是同理，并借此解释了日本当年的情况：「日本债券收益率那么低为什么还有人买？因为它对美元在升值，持有美元的人买入日本债券再换回来就是一个收益。」

4. 但我们不会重蹈日本的覆辙

那种情况我们的人民币也会被商品化，那对国内的通缩是一个巨大的促进作用。我们不能允许通缩这种事件发生。

八、货币国际化的代价

1. 被商品化的货币，会同时带来通缩和通胀风险

你现在全世界有多少人拿着美元是当资产在储存的？这些美元都被商品化了。你对商品化就有通缩的势头，那你防止通缩就得狠印钱。等这个趋势有一天反转过来、形成反向正反馈的时候，那你就会通货膨胀，就像今天这样。

所以你别以为成了国际货币就一定好。你国际货币得控制好，控制不好那个代价是非常大的。

他由此给了一个对日本的判断：

当年日本为什么后来有失去的三十年？最主要的原因就是在他不具备力量的时候，先实现了本国货币的国际化。

你货币国际化变成自由兑换货币，就相当于在财政管理和金融管理上国门大开——你把一切都交给市场了。国门大开取决于什么？取决于你的力量。

2. 所以港币的定位是「人民币的稳定币」

港币不会升值，它现在和美元是联系汇率。我说过港币就是人民币的稳定币，未来它的地位就是人民币的衍生货币——因为拿着港币可以没有监管，但又可以投资中国资产。这样我们实际上就相当于进退有度。

3. 「最强的人都希望没有秩序」

这是他这场里最好懂也最锋利的一个道理：

IMF虽然叫国际货币基金组织，但实际上是受美国控制的。当你出现金融危机他给你贷款的时候，条件都是要求你减少监管、放开金融市场——那些条件都是美国定的。

那个时候为什么美国都要求你放开市场？因为那个时候美国是最强的。最强的人都希望没有秩序。

就像两个小孩在一块玩，有一个小孩说咱谁也不许打谁——这个小孩一定是因为打不过别人。那个如果所有人都能打过的，他就会主张咱们可以随便打。

他用这条逻辑解释了今天的转变：

那今天为什么他又开始玩关税这一套了？因为他打不过中国了。所以他现在开始说咱不能随便打，咱得有价值观、得实现世界贸易平衡。无论他说得多么好听，都是这个原因。

现在谁是自由贸易的主导者？你看看现在是谁天天在说应该自由贸易。

九、又一次的「预期课」

1. 周末的一致预期，又一次落空

昨天有多少人认为今天黄金和有色的股价会大幅上涨？这两天给你们上这个课上得咋样？

2. 该问的不是「为什么不涨」，而是「谁在卖」

你以为的东西为什么没有出现，那你得去反思。大家周六周日认为黄金股票应该涨停，那为什么它不涨呢？那你也想，它不涨一定是想卖的人多——那你告诉我谁在卖？

你应该去想：这次为什么我判断错了？和我原来设想的框架哪里不一样？你应该吸取教训、重新调整自己，而不是跑来说这市场不对。

他还给了那句他反复讲的话的又一个版本：

市场从来不跟你讲理，也从来不试图说服你，他只是简单地消灭你。市场才不会跟你掰扯说我对还是不对，他只是消灭你拉倒。

3. 一个具体的追问

前两天有色不涨的时候你赖科技；这两天科技也跌了，有色还是不涨——你告诉我，你这回你赖谁？

4. 他自己的立场说明

他解释了为什么只说看空、不说看好：

我原来看空、现在不看空的，我都会告诉你，这主打一个有始有终。但我不能告诉你我看好哪个——我一看好就有人冲进去，说是我推荐的。

我说我不看空有色了，我都得加一句：那不代表我就马上买入。为什么？我怕你们说「你看你说的不看空了，就意味着我可以买了」。我可没告诉你买。

他还提到一个已经明确的时间点：「不管美国加不加息，日本九月份加息基本上是铁板钉钉的。如果九月份日本真加息，那你需要看的戏还多着呢。」以及对黄金的定性：「我说的风险是黄金的波动性风险，我不认为黄金现在就涨到头了，但是你能受得了它的波动吗？」

十、他自己的说明

我今天讲的东西是比较干的，当然也没有计划，就是想起来哪儿讲到哪儿。我发现有很多人对这些东西误解太深了——说巴菲特不了解宏观，你就不了解宏观。巴菲特那个时代美国就是世界中心，他需要了解啥宏观？别人都得围着美国转。

我讲的都是评书，都是演绎。本讲座纯属虚构，如有雷同纯属巧合，据此投资责任自负。股市有风险，入市需谨慎。
