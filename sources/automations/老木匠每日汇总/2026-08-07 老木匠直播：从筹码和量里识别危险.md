一、日元与美国内部博弈：不确定性就是风险

1. 上一次干预动用了870亿美元

他说日元汇率又反弹了一下，现在压到158点多。当天早上他看到一个消息：上一次日本干预汇率动用了870亿美元，「这数可是比较大的」。他还提到前一天晚上日元突然又开始贬值，可能跟一则传闻有关——有接近沃什的人说他已经决心准备加息了。他强调自己不确定这个消息真假，但市场的反应本身就值得看。

2. 财政部拿的是手枪，美联储拿的是炮

他从这件事里看出美国内部博弈之激烈：

贝森特实际上是希望日元汇率走贬的。但美联储如果不配合，你这种努力在美联储的武器面前毫无招架之力——美联储拿的是炮，财政部拿的是手枪，根本不在一个量级上。问题是他俩现在不能协调。

3. 三条路全都被堵死了

他把当前的死局梳理了一遍：想救日元汇率，唯一的办法是美国降息，但沃什现在一直在想的是怎么加息；另一个选项是日本自己加息，但日本一加息就会导致大量日元回流——那些原本已经换成美元、留在美国资本市场上的钱会被甩卖，美国的资本市场流动性就会缩减。

所以现在美国既想维持日本的汇率不变，又不想让日本去加息，那就只能美国降息——但美联储又不配合。所有这些政策都在互相牵制。

他说最终结果谁也判断不了，「那都是博弈的结果，既包括不同国家之间的博弈，也包括美国内部不同利益集团的博弈」。他补充说沃什代表的就是「老钱派」——这些人持有的是流动性、是债券和货币资金，货币一贬值对他们就是一种洗劫。

4. 关键推论：判断不了，就等于风险

这是他这段的落点：

你能判断出美国国内各个不同利益集团最终的博弈结果吗？肯定判断不出来。判断不出来，这对你来说就是不确定性——而不确定性，我翻译一下，不确定性就是风险。

他说全世界（包括他自己）都认为沃什这件事最终做不成，现在黄金上涨交易的就是「他做不成」这个预期。但关键在于：

他做不成，他也要试一试。而这个努力的过程，就会对全世界的市场产生很大的影响。

他说一旦加息，不光有色金属受压，纳斯达克的冲击也会非常大——「它们都是同样一个来源，来源就是美联储的利率政策」。这也是他现在对有色「不敢买」而不是「不想买」的原因：按现在的价格，有色标的都很便宜，但你判断不了未来，那就是在冒险。

二、都说供不应求，为什么库存越来越高

1. 美国有100万吨铜库存，这个数字该怎么解释

他抛出这个反问：大家都说铜供不应求、实体需求非常旺盛，那为什么现在美国有100万吨铜库存？

就像当年说我们的白酒供不应求，结果你打开经销商的仓库，里头屯的全是白酒——那你的供不应求是从哪来的？

他给出的答案是：这里面有大量投机性的囤积居奇。而这类需求是有反噬的：

囤积居奇的这些人是因为价格在上涨才囤的。一旦价格开始反过来下跌，他们就会开始甩卖，和你形成一个竞争性的卖盘——价格弹性会非常高。

2. 存储芯片同理，而且更难统计

他说这不只是铜的问题，存储芯片也一样，「你别说存储器供不应求，有很多都是被囤积了」。而且更麻烦的是根本没法统计——铜好歹还有显性库存，隐性库存你怎么算？

现在厂家都提高了自己厂内的库存，都怕铜涨价。我是做电缆的，那我就多买点铜先留着。你囤两吨、我囤两吨，最后加起来这个数就很大。

他说自己的态度是：「我不赌，我是一个损失厌恶型的，我对所有的风险都保持非常大的警惕。」

三、人为干预的痕迹太重，这不是好现象

1. 事出反常必有妖

他说当天的开盘方式让他觉得非常危险：

他一切做的这些东西都和你想的不一样，这就叫事出反常必有妖。明明已经有很多消息对你非常不利了，你却还要硬拖着他——这个反倒更危险，这说明有人出不来。

2. 干预改变不了方向，只会让你更跑不掉

他把这个道理和日元的干预对照起来讲：

你看日元跌得好好的，突然被拉起来，那是市场自然交易的结果吗？典型不是。正常他就应该贬，但是不想让他贬，就人为干预——那你能改变啥？不越来越危险吗？

他说这种干预最终会有一个很坏的后果：

原本有些人认为没有机会了、准备跑了就拉倒，可能是亏点钱或者少赚一点。结果你老是用这种干预的方式，他就不忍心走了。最终这种干预把你害了——你老是没办法跑。

3. 怎么观察：看宽基ETF的量，不看涨跌

他给了一个具体的观察方法：去看那些科创类的宽基ETF最近的成交量。

这个东西不是看上涨下跌，主要是看量。你看它的量是突然放起来的，而且是从哪天放起来的，是有迹可循的。

他特意说明这不是推荐，「这些东西我认为我都不会买，我是让你们观察一下」——「不是大家不知道该看什么吗？我这不是在教你们该看什么吗？」

4. 有人组织小号来骂，反而是个信号

他提到自己前一天说「人为干预的迹象很明显」之后被大量小号围攻，他的解读是：

越是有小号组织来骂我的时候，你反倒越应该警惕。无利不起早，组织小号来骂我也是需要成本的。

他还教了个识别方法：这些账号往往只有一个关注的人，最近几天发了十几条帖子，再往前就什么都没有了——「这东西实际上非常容易看」。他说原来自己还有点狐疑，「但是现在就是踩着他们尾巴了」。

四、突发消息出来时，优势资金为什么反而先拉一把

1. 第一步：散户判断不了消息是利空还是利好

他从一个前提开始推：

当一个消息突然出现的时候，散户实际上判断不了这个消息究竟是利空还是利好。或者判断了以后他也不敢直接相信，心里是非常狐疑的。

2. 第二步：所以散户会用「价格」来反推消息的性质

他接着问：在你判断不了的时候，如果价格上涨了，你会不会自然而然地认为「这就是一个利好消息」？他说大家都遇到过这种现象。而一旦你认定这是利好，你就会有买入的冲动——或者本来想卖的，现在不想卖了。

你可能不买，但你可能持有。原来你觉得这个消息判断不好、准备想卖，但突然看股价上涨了，你是不是就不想卖了？这两个是等效的。

3. 第三步：能影响价格的人，知道你会这么想——而且他知道真相

这是整个推理的关键转折：

能够操纵、能够影响价格的投资者，他知道你是这么想的。但有一点和你不一样：他知道这到底是利空还是利好。

他推演：假如我是大资金，我知道这是个利空消息。如果我现在卖，股价就会下跌，那就等于告诉所有散户「这是利空」，大家会跟着一起卖，股价会大幅下跌——那我实际上是卖不出去的。

所以这个时候最理智的办法是反向操作：你不仅不能卖，反倒应该买一部分。

4. 所以你才会见到「明知是利空却涨了好几天」的走势

你明明知道它是个利空消息，但它突然上涨了，而且还涨了好几天，最终才开始下跌——你看过太多次这样的走势了，背后的原因就是这个。

他强调一个容易被忽略的点：

不要以为一个标的只有在下跌的时候优势投资者才在出货。很多时候是它在上涨的时候，他就开始出货了——而且越涨越利于他出货。

5. 最典型的例子是新股

他说新股最能说明这个道理，因为它刚上市那天根本没有价格锚：

你打新中了以后，你告诉我这个应该卖多少钱，你知道吗？那不是由人家控制吗？人家给你定多少钱就是多少钱。

他的建议是：「新股来的时候，人家在做局，你差不多就撤了，别老想吃到最后。」并用东北话补了一句——「你别老想着好吃不下桌，好吃不下桌，你最后容易买单」。

6. 讲这些不是让你学着做，是让你别上当

他专门声明了用意：

我给大家讲的这些东西都不是希望大家用这种方式来赚钱，这都是旁门左道。但是你要知道，你不能被这些东西所骗。你干不了这个，这不是你干的事儿。

五、斑马什么时候最安全

1. 你不是狮子，但你得摸透狮子的套路

你不是草原上的狮子，你别老合计干捕猎那种事儿。但你要明白狮子做这件事的步骤是啥——你即使是一只斑马，也要了解狮子的规律。

2. 答案：刚刚有别的斑马被扑倒的时候

他问「斑马什么时候最安全」，有人说是狮子吃饱的时候，他说不对：

最安全的是它们刚刚扑倒一只斑马的时候。这道理不是很简单吗？

3. 推论：别老想着「跟庄」，那等于离狮子最近

你平常要研究狮子捕猎从哪个地方下水、经常从哪个地方开始，你就离那个地方远一点。别老是跟庄——那你不相当于离狮子最近了吗？

他还补了一句：「找老斑马在一块是非常危险的，狮子专门找老斑马和小斑马下手。」

六、这一场最干的一段：高度控盘的东西为什么怕高位放量

1. 先明确前提：高度控盘 = 筹码集中度高

他一步步往下推。第一步：所谓高度控盘，就是筹码相对集中在有资金优势的人手里，换句话说外边散户持有的已经很少了——「否则他做不到高度控盘」。

2. 推论一：所以拉升阶段反而会「缩量上涨」

既然散户手里筹码已经很少，那这些大资金如果还想买入，外面能卖给他的人就不多了。

这时候量就会很小，而且价格弹性会非常高——你买一点它就涨很多。这就是缩量上涨。

他给大家留了个作业：

你回过头去看那些大牛股，看有没有经历过一段缩量上涨的过程。而且这段缩量上涨的涨幅往往是最快的——因为外面已经没有多少筹码、没有多少对手盘了。

3. 推论二：所以高位突然放量，只有两种可能

他说既然散户手里已经没货了，那高位突然放量就只能是这两种情况之一：

第一种：大户A把筹码卖给了大户B。第二种：所有的大户都开始卖了。

在高位突然放量了，只有一种可能就是大户开始卖了。当然买的人不一定是散户，也可能是其他的大户。

4. 两种可能，都是危险信号

他分别拆了这两种情况的含义：

第一种，如果大户A把筹码卖给大户B，这说明高位的筹码已经开始不稳定了——有人抱团抱不紧了。早晚有一天大户C也会卖给大户B，最终大户B也受不了，这就是散团的过程。

第二种更可怕：所有的大户都认识到不能再持有了，都想把这些东西倒给散户。

他强调：

无论是哪种情况，它都预示着一种危险。我不敢保证它一定会下跌，但这个时候你需要重视。

5. 他当初判断有色有风险，用的就是这套方法

他说自己今年1月份提示有色风险，凭的就是这个：成交量放大，同时年报公布出来，那些著名标的的股东人数急剧增加、甚至是翻倍增加。

成交量增大了，然后股东人数成倍增加，那是为啥？那是因为有人在卖，大户在卖。甚至有的公募基金人家都告诉你了，我开始减仓了——那不危险吗？

他说而那个时候大家还在跟他算「一年能采多少铜、能卖多少钱、利润是多少」：

那都没有用。他正是利用现在所有东西都好的时候，才能出得去。等他的利润下来的时候，他再想出还能出得去吗？谁会买？

6. 三个信号一起出现，就要格外小心

他把可以观察的信号总结在一起：股东人数大幅上升 + 论坛帖子数急剧增加 + 任何看空言论都会遭到围剿。

我一般认为，如果我看中的大户已经开始出了，那我也先出来看看。

7. 再次声明：这是用来「少挨骗」的，不是用来赚钱的

这都是我思考的结果，不是从任何地方看来的。这东西不一定对，但它可以让你少亏。你想用它赚钱是不对的——你别合计我这回学会倚天屠龙了，你只能把它用在少挨骗上。

七、埋人是一层一层埋的

他解释为什么行情要在高位反复维持：

什么东西都是埋得一层一层的。所谓温水煮青蛙也是这个道理——你不用温水，是煮不了青蛙的；咔嚓一下下来的话，他也跑不了。不维持在这个地方，筹码能交换吗？

他还描述了自己看这个过程的心态：「你们能不能挺住？现在前棚天天敲锣打鼓、天天吹喇叭，那大红绸子来回舞，你们能不能挺住？」他说自己挺得住，而且乐呵——「我就想，这帮小子在后棚都要急疯了，怎么也没人来，怎么整？」

八、价格会影响审美

1. 从别墅到黄金，都是同一个道理

他说这是自己讲房地产时提过的一个观点：

房子贵的时候，大家都会晒我的大花园、我的大平层。价格一开始下跌，大家一看到大花园大平层就烦了——扫地费劲、还得擦灰、花园里天天长荒草、一楼还有虫子有蚊子。

他说黄金也是一样：

我年轻的时候，黄金被认为是非常土的东西，黄金没有白金贵。那时候结婚谁买黄金戒指？那是暴发户干的、乡镇企业家戴的。所谓「穷戴金、富戴表」，真正有品位的人得戴手表。现在黄金是白金的好几倍，所以大家就觉得黄金好了。

他还举了茅台和五粮液的例子：自己年轻时有一段时间五粮液比茅台贵，喝五粮液的人比喝茅台的多，「大家都认为喝茅台是很土的」——后来是茅台的股票涨起来了，也导致了审美的变化。

2. 奢侈品是精神消费，跟东西好坏没关系

你背个LV包，就相当于你把10万块人民币串成串儿拎在街上走一圈，让别人都知道你有10万块钱没地方放。买10万块钱黄金戴手上也好，买一块大家都知道值10万的表也好，道理都一样——是情绪价值，是一种精神消费。

他补了一句：「我认为所有的包都不如蛇皮袋——要从装东西的角度来说，最好用的就是蛇皮袋。」他还举了拿破仑的例子：当年招待大臣吃饭，别人用银杯子，他自己用铝杯子，因为那会儿铝贵。

九、方法论：不要自我降维

1. 复杂的问题没有简单的答案

他在收尾时讲了这个观点：

你所有把分析都停留在某一个片面的、很窄的方面的时候，你都是在自我降维——你都是在把一个复杂问题试图简单化。复杂的问题没有简单的答案。

他说尤其像市场这种众多人数参与、总体处在混沌状态的地方，「你试图把一个复杂的问题简单化，这种努力是不对的」。他举的反例就是那些只算「一年采多少矿、卖多少钱」而不看价格和货币政策的分析。

2. 没有一条策略能贯穿始终，包括他自己的判断

所有的东西都是有相对性的，没有东西是放之四海而皆准的。市场是千变万化的，没有一条策略能够贯穿始终。所有的东西都在不断变化，包括我的判断——我没有任何一条道跑到黑的判断。

他说自己看到风险的时候会告诉大家，而从哪天开始认为没什么风险了，也一样会告诉大家。

3. 防风险，而且是「在场内防风险」

最后他反复强调的还是这三个字，并且澄清了一个常见的误解：

有人说，那我防风险就干脆空仓了——那你就相当于不做了，那还叫什么防风险？你空仓持有资金，你不就是退出市场了吗？防风险是说我在市场中防风险，你退出还防啥风险？

他说正因为要在场内防风险，你才必须看懂那些可能让你陷入危险境地的态势——「要不然你咋防？」

十、题外一则：不要把自己行业的秘密讲给外人听

这一场开头他讲了段行规，虽然不是市场话题，但他自己把它和投资串在了一起，所以一并录在这里。

他说自己做律师时从不把经手的案件当故事讲给别人听，这不符合职业道德也不符合行规；他反感的是那些「靠揭秘自己所在小群体的秘密来吸引眼球」的人——比如专门在自媒体上揭秘魔术怎么变的魔术师。

如果现实中你遇到一个这样的人，我告诉你这个人没有底线做事。而且靠揭秘魔术来混日子的人，第一在魔术界一定是混得不好的，第二他已经混不下去了。

他说这类人讲这些的时候「是带着一种优越感的，是在告诉你：你们这些傻子啥都不懂」。他还引了《江湖丛谈》里的那句老话——「宁舍一锭金，不给一句春」，意思是不要把自己的职业秘密讲给行外人（「空子」）听。

顺带他极力推荐了这本书：

你在这个市场上生存，如果只能看一本书的话，我就推荐你看《江湖丛谈》。看完你就豁然开朗——今天所有市场上发生的一切，没有一件事是新鲜事。

他还说那些看似专业的术语，本质上和江湖黑话没什么区别：「他们说的都是黑话，你以为那些分析师说的不是黑话？又是ROE，又是20天均线，又是这个浪那个浪的。」

关于读书，他还转述了自己从芒格那里学到的习惯：

你没看人家芒格和巴菲特，基本上什么书都看，就是不看金融类的、不看市场类的。

他说自己就是因为芒格推荐才看的《自私的基因》，觉得写得非常好，同一作者的《盲眼钟表匠》写得更好。而对被广泛推荐的《枪炮、病菌与钢铁》，他评价是「盛名之下其实难副」，并指出其中有意识形态成分——「他最基础的结论是南北美的印第安人不是白人杀的，是带去的细菌害的，把这个东西粉饰到这种程度。得病死的和被杀死的，那在道德的负罪感上是完全不一样的」。
