一、除权除息：它调整的是历史价格，不是未来价格

1. 很多人连这个基础概念都搞反了

他一上来就被「分红是不是拿自己的钱分给自己」这个讨论气着了。他说这些人根本没搞明白除权除息解决的是什么问题：

除权除息它不是规定未来的价格，它是调整以前已经发生的价格。你没发现除权除息的时候，最高价什么的都会跟着变吗？它调整的是历史价格。

他举了个具体的：昨天收盘价5.1元，现在分一毛钱，今天把昨天的收盘价调整成5元。那明天的价格是多少？

明天的价格跟这个一点关系没有。明天的价格不都是重新交易出来的吗？

2. 更根本的一层：净值本身就只是个习惯性的计价方式

他把这个问题往下推了一层，讲了个很值得记住的观点：

真实的计价方式是：我持有某只股票100万股，完了。这100万股究竟值多少钱，取决于你卖的时候的价格。

他说你今天收盘看到的100万净值，是用当天收盘价乘以股数算出来的——「那我问你，明天一开盘，你敢保证这100万还是100万吗？」所以：

价格只有在撮合交易那一瞬间对你有意义。平时的价格变动只对你未来判断买卖时机有意义，除此之外对于你计价手里的资产是没有任何意义的，它只是一种习惯而已。

他还用房子做了同样的类比：你小区现在有个平均价，那是邻居卖房形成的公允价格，「那我问你，你真正卖的时候一定能拿到这个钱吗？说不定还比这个多」。

3. 一个更好懂的比方：卖房子时那笔没收的房租

你有个房子租出去了，有一年的房租后天才付，但今天你把房子卖了。买家知道这笔房租还没给，那你俩是不是可以就这笔房租磋商一下——如果房租给买家，那房价上是不是就得有点折扣？

他说这就是分红的道理，「这是孳息，是历史上产生的孳息」，不存在什么「拿自己的钱分给自己」。

二、从转基因说起：什么叫从底层逻辑开始理解

这一段他花了很长时间，但落点始终在思维方式上——「你稍微有一点科学素养，你自己就会得到自己的判断」。

1. 先问机理：吃进去的基因凭什么影响你

你吃什么东西的基因就受什么影响？那你这些年吃猪肉，猪肉里全是猪基因，我也没看你变猪。

他解释：基因就是脱氧核糖核酸，进入人体以后就被消化分解了，「它又不是活体植在你身体里」。基因本身没有毒性，有毒的是基因表达出来的东西（比如蛇的基因产生蛇毒）——「那你通过转基因培育出含毒素的植物，那当然不能吃，但那跟普通有毒植物没什么区别」。

2. 他讲的一个大部分人不知道的点：转基因主要是为了跟农药配对

他说抗虫、抗倒伏、高产这些性状问题只是目的之一，「但这都不是转基因最主要的原因」：

转基因最主要的用途是要和农药配对。相当于在基因上做了个记号，然后生产一种农药——这种农药什么都能杀，就杀不死这个植物。所以农药一撒下去其他东西全死，只有这个植物不死。

他说这会带来两个后果。第一是**生态链被改变**：「原来依赖杂草生存的小虫这一套食物链就没了，没有虫子就没有青蛙」——所以有人说转基因的地里连老鼠虫子都没有了，那是农药破坏了生态，不是这个食物本身能把青蛙毒死。

第二是**种子安全**：

农药在这个地里是有残余的。你明年不买这个种子，你种什么它都不长。农药在地里残留十年，你这十年什么都不长，只能种那一种东西——所以为什么我们国家反复强调种子安全？光有地不一定就能长东西。

他还顺带纠正了一个直觉：非转基因反而需要撒更多农药，「因为你那地里什么杂草都会长起来，你要杀这种草、杀那种草」。他自己买豆油专挑转基因的，因为便宜——「非转基因豆油对我来说就是智商税」。

3. 同类的例子：压榨油 vs 化学浸出，酿造酒 vs 勾兑酒

他说大家都觉得「古法的、天然的」就一定好，其实不见得。化学浸出的油出油率更高、更纯，而且过程中不会被细菌感染；压榨出来的东西反而不纯，杂质也会被一起压出来。

酒更典型：

对于便宜的酒，勾兑的更安全。因为勾兑用的是食用酒精，工厂化生产提纯得非常纯，里面没有杂醇。而土法酿造过程中既有乙醇也有甲醇，甲醇是有毒的——为什么小烧酒作坊做出来的酒容易上头？就是因为杂醇多。

他说酿造和勾兑真正的区别在香味物质（酯类和芳香烃决定口味），而这些现在用化学方式一样能做出来、分不出来。他还补了个冷知识：黄酒本身是不黄的，那个黄是加的焦糖色，「跟红烧肉做法是一样的」；黄酒杂醇多是因为它不是蒸馏酒——「蒸馏其实就是提纯的过程」。

4. 落点：别一听风就是雨

我主要是给大家讲一件事：你别什么事一听风就是雨，一说这事儿就来了、就是别人都想害你。你稍微有一点点科学素养，你自己就会得到自己的判断。

三、真相要靠自己思考，没有人会告诉你真相

1. 他自己举的例子：彼得·林奇为什么13年就退休了

他讲了个自己推理的例子，用来说明什么叫「自己去想」：当年富达基金的总裁想把位置传给儿子，而彼得·林奇在公司里的威信太高。

所以我觉得是因为这个原因，彼得·林奇才不得已辞职走的。而且我认为他一定得到了一大笔钱，因为他后来就没再工作了。当然他对外不能说这话，对外一定说我觉得工作太累了不做了。

他说林奇自己从来没说过这些事，是他从书里那些和总裁儿子聊天的情境描写中感觉出来的。

2. 芒格那句话，他又强调了一遍，而且推进了一层

你所看到的都是假象，而且你所看到的都是很多人想让你看到的。真相需要你自己去思考——动用你的理性，动用你的抽象思维能力，透过现象看本质。真相藏在你看到的东西的背后；如果你一看到就认为是真相，那就永远没有真相。

他还讲了更让人警醒的一层：

有的时候你突发奇想的想法，你以为是独立思考来的，其实都是别人在你心里种的种子发芽了。就跟《盗梦空间》一样，说不定昨天晚上有人在你梦里植入了一个念头，你早上突然就觉得科技股好了。

四、一个非常具体的自测标准：你是不是合格的投资者

1. 他给的判断方法（新手不算）

这是这场最实用的一段。他说如果你投资已经超过五年了，可以用这个标准自测：

如果你这五年头四年都没赚钱，但今年突然赚了很多——我告诉你，你的新手期还没过，你不合格。如果你投资十年了还是这种结果，那你更完了，我劝你干脆卖了就别来了。

反过来：

如果你过去五年是赚钱的，今年没怎么赚，当然也没有亏——我认为你就是一个合格的投资者。

2. 为什么今年赚太多反而是问题

你今年赚太多，说明你没有进行风险补偿、没有风险意识，说明你赌性太强。不能说你今年赚了钱你就厉害了——你买彩票中奖也可能赚钱，那能说明你厉害啥？

3. 还有一条：最近一年从不被套，也是危险信号

有人说自己最近一年基本不被套，他的回应是：

说明你这个人投资不合格，你没有进行风险补偿，你买的标的现在都是风险非常大的。你最近一年如果一直没被套的话，我认为你离被清除出这个市场已经很近了。

他说自己买的东西经常被套：「去年我在有色金属里套着，前年我在券商里套着，嘲笑我的人多了去了。我也想买在最底部，但我没这个能力。」

4. 给新手的话：先别总结经验

假如你今年进来半年就挣了100%，我只劝你一件事：等活过五年以后你再总结经验。你现在先别总结说「我就看准了科技」或者「我把某个浪整明白了」——千千万万别总结。

他说新手最要命的一件事就是：

我进来半年就挣100%，这赚钱也太容易了，我这就是天选之子，那我回家把房子卖了继续干——我觉得你离开市场已经很近了。

他建议：把本金拿出去，留一部分在里面，看看五年能不能亏光。

五、防风险、不亏钱，赚钱是副产品

1. 顺序不能颠倒

市场上真正需要你每天练到的是防风险、是不亏损，赚钱是在这两个基础上的副产品。你首先第一件事进来就是防风险、不亏损；至于什么时候能赚钱，那不是你能定得了的。

他又引了那句孙子兵法：

不可胜在己，可胜在敌。你不亏钱这件事你自己能定，剩下的你都定不了。你就是武功天下第一，也不敢保证一定能打过别人——那得等别人犯错误。

2. 「防风险就是空仓」，这是理解错了

他这次说得比之前更直接：

你空仓就离开市场了，那叫什么防风险？你不是属于不玩了吗？我说的是你上场的时候要注意风险、你在参加比赛的时候要注意风险。你待在替补席上坐着，你还防个屁风险。

他还补充了一个实际的理由：

你空仓几天，你对市场就没感觉了，很快就无感了。

3. 顺带：模拟盘为什么没用

他看到有主播建议新人先做模拟盘，很不认同：

你玩CS和真打仗能一样吗？你认真玩CS它也不是打仗，因为你心里知道你死不了。模拟盘你就敢冒险，真钱你就不敢冒——模拟盘赔没了哈哈一笑，真钱亏没了可没人给你还回来。

他讲了个真事：同事家小孩打电脑CS特别厉害，绝招是一出来就不停跳，别人瞄不上他。

后来我们去公园打真人CS，他出来也一直跳。你跳两下，舌头都得吐出来了，你能跳得动吗？——所以你在模拟盘里认为是绝招的东西，在现实当中根本没用。

他还是用那个走钢丝的比方收尾：50米高和5厘米高走同一根钢丝，理论上没区别，「但你唯一忽略了一点——人的主观性是带入到这个市场里头的」。

六、你是第几个知道这件事的

1. 这是他反复强调的一个自问

无论你知道啥，包括财务报表，你都要问自己：你是第几个知道这件事的？

他举了报表的例子：

哪个公司的报表超预期能保密？你告诉我一声。那会计知道不？会计他三舅知道不？三舅的亲家最后知道不？

2. 所以「利好出尽是利空」的底层逻辑是什么

因为这个消息没出来的时候，已经有很多人知道了，真不是今天才知道的，两年前人就知道。人家两块钱买完了，然后一顿拉干到20块，然后告诉你这东西未来不可替代——你也跟着背「未来不可替代」，然后你冲进去了，20块全卖给你。

3. 一个很锋利的追问

他对那些拿基本面说事的人有个反问：

你要认为这东西还会继续增长，那你为啥不原来就认为它继续增长呢？为啥等到好消息出来的时候，你才判断它会继续增长？

那个东西股价五块钱的时候，你咋不知道它供不应求？等到25了，你现在开始天天念叨供不应求了。

他还回忆说，当年他讲铜会供不应求的时候，「多少人跟我讲铜这玩意儿可回收，所以不存在供需缺口」；现在反倒是别人来给他讲供不应求了。

4. 看中报，要看的不是利润增长了多少

他提醒即将到来的中报该看什么：

那些著名公司的股东人数是否还在继续增加，这是需要你看的。你不是看它今年利润又增长多少——人家两年前都预计到今天的增长了。现在卖出的人考虑的是：未来一年它是否还像现在这么增长。

如果未来一年还这样增长，那时候进来的傻子会更多，我卖给他们；但如果未来一年已经不增长了，那接盘的是不是会越来越少？那你还卖给谁？那不得趁热乎的时候现在就卖吗？

七、加息这件事：你该问的不是「会不会」，而是「有没有可能」

1. 预测加不加息没有意义，判断可能性才有意义

美联储加息这件事，对你判断未来行情只有一件事有意义——就是它有没有加息的可能。如果有加息的可能，这件事你如何应对，这才是对你有意义的。

他做了个前后对照：去年这个时候你可以非常肯定地说没有加息可能，所以那时候有色处在低位、业绩又好，你可以做出明确判断。

那你今年还敢吗？现在华尔街的交易员押注加息和降息的比例基本上接近50%。人家都分析不出来，你是根据啥分析的呢？

2. 散户判断的依据，全称叫「感觉」

你无非就是蒙，给自己壮胆儿——我持有的是受利息影响的标的，那我就希望它不加息，所以给自己壮胆说它肯定不能加息。散户得出这种依据的全称叫做感觉。

3. 慎言，因为说着说着你自己就信了

这是他讲的一个很有意思的心理机制：

你不要随便说那种没有依据的判断，那种不严谨的话尽量少说——因为说来说去你自己就信了。你说十回美联储不能降息，这事儿就刻在你骨子里了，你就认为它真的不会降。那我问你，一旦降了你怎么办？一旦加息你怎么办？你做好准备没有？

他自己的态度是：「我也判断不了，但是你要对所有的东西都做好准备。」他还提醒了一个事实：欧洲央行已经加息了、澳大利亚加息了、日本也加息了，「怎么美联储就不能加息呢？」

4. 顺带纠正一个流传很广的说法

你别动不动就说美国不能加息、加息国债受不了，那都是以讹传讹。美国已经发出去的国债都是按票息付息的，跟加不加息一点关系没有。加息只影响当期新发的国债——财政部发国债是一级市场，跟二级市场没有关系。

八、通胀化债：那笔被减免的债务，总得有人出

1. 先看清楚这件事的实质

他说通胀可以化债这件事本身没错，「这不很简单，都不用去分析了」。他用自己的经历讲了机理：

我年轻时买房子贷款贷几十万，那时候工资只有八百一千块，一个月还几百块钱就觉得挺多了。后来通胀就相当于把你这个债务全给你减免了——东西贵了，你工资也高了，但债务不会增加。

2. 关键的追问：这笔钱是谁出的

你的债务被减免了，你相当于得到一笔钱——那这个钱谁出的？它一定得有人出。

他给的答案是：银行贷出去的贷款购买力降低了，而银行的钱是老百姓的存款，「所以是由存款这些人来承担的」。他还指出银行本身是通胀的受益者：「银行计价完全不计购买力。通胀多了意味着钱多，钱多了存贷款基数就多，利差的基数多了，利差就多了。」

3. 更值得警惕的一层：过程中会不会有抖动

这是他引申出来的问题：

如果一直平稳地通胀下去，相当于所有人平摊这个成本。但问题在于——你和真正的大资本，在政治上的地位是平等的吗？会不会在中间产生什么抖动，让你先承担得多一些？这些问题你去思考。

4. 推论：重资产行业也是通胀的受益者

这是个很实用的推论：

重资产行业——资产负债率很高、有大量银行贷款、同时有大量固定资产的——这些固定资产在通胀过程中都会增值，但是在资产负债表里看不出来，因为它不会总去重估。这就叫隐含资产。

他举了核电的例子：「以前建一个核岛用100亿，未来建一个核岛要500亿了，那你原来那个是不是得按500亿计价？但它还是按100亿计价的。」而且通胀的时候电价也会增高。

九、他自己的取舍：任何标的都只是一个「罐子」

1. 他怎么看待自己换仓

有人质疑他「原来不是看好某个东西吗，怎么又卖了」，他的回应很干脆：

任何一个东西它都是你的一个道具而已。哪个东西更有性价比，你就换到哪个上。你来这个市场是来赚钱的，不是来当持股模范的。

每一只股票无非相当于一个罐子，哪个罐子的性价比高，你就把钱扔在哪个罐子里头，就这么回事。

他还举了个具体的思路：如果现在持有医药，而原来卖掉的东西跌回了很低的位置，那就可以把医药卖了再换回去。

2. 他不碰科技和创新药的真实原因

他澄清了一个被反复误解的事：

有人说我从去年就看空科技，那不胡扯吗？我去年从来都是告诉大家：科技这东西我看不了。因为我不知道它们之间的因果关系，我没有那个研究能力，所以对我来说确定性不足、不符合我的投资标准，仅此而已。

他说创新药也是一样——「对我来说确定性不足，但如果大家去赌一把，那是你们自己的事」。他也明确说了自己看好的大方向是医药、必选消费、公用事业这类，「但别提个股」，而且强调医药是慢功夫，「你不能指望一进去它就该涨多少」。

3. 周期股不能看静态估值

周期股看静态估值是没有任何意义的。2020、2021年的时候，远洋运输集运的市盈率跌到什么程度了？它该不涨一样不涨。你看到的只是静态的，人家大资金早看到的是动态的——等你看到的时候，都已经是滞后的东西了。

十、历史一遍遍重复，连标点符号都没改

1. 券商那一轮，他完整讲了一遍

他回忆2023年底自己说某上海券商是好时机时被骂得很惨（当时正好出了造假争议），而到了2024年10月8号之后所有人一致看好券商，「多少人来问我券商，我说我现在不看好了，因为性价比不高」。

那时候券商直播间里的主播自己都说券商是个渣，都不看好——又是降工资、又是裁员、又是「券商屠夫」，说以后券商就没戏了、同质化严重、严格监管、好日子已经结束了。说完这话没过几个月……

他说自己2024年10月28号就已经没有券商了，「从那天以后我就不关注它，那时候正好是券商最受关注的时候」。

2. 然后是有色，剧本一模一样

你回首这些事的时候，就觉得特别有意思，世界就是这样一次一次的轮回。连标点符号都没改过——也别说改词了，连标点符号都没改过。一遍一遍地重复。

他说自己今年1、2月份就把有色清掉了，「现在也没有了，也不看了」。他还提到那些人前几天科技被抛售时呼天喊地，「这两天有色涨两天又跑到我这来踢场子，一脸嘲笑地问我还看不看空」。

3. 「别人恐惧我贪婪」的又一次纠正

看到某有色公司高位下来后有人喊「别人恐惧我贪婪」，他的反应是：

你看现在哪个像恐惧的样子？十分钟能发20个帖子，还恐惧？你们是因为都贪婪。什么别人恐惧我贪婪——你他妈就是别人。

十一、一个很妙的回答：牛还在吗

有人问他「牛还在吗」，他的回答值得单独记一笔：

你只要还在，牛就还在。牛不在了的最大标志是你先不在了——你问我这句话，就说明牛还在。

最后没人问了，我这直播间里都没有人了，那就彻底完了。

十二、几个题外的观点

这些不是市场话题，但他讲得比较系统，也能看出他一贯的思维方式，一并录在这里。

1. 关于生育政策

他认为奖励生育和对无子女征税在本质上是同一件事：「大家一起收的，你生了税收返还，没生那不就相当于收了吗？税收本身就具有调节二次分配的功能。」他还预判审美会变：

你别以为怎么的，我们这个宣传机器是非常厉害的。你现在觉得单身时髦，过两天你觉得单身你出不了门。

2. 关于阶层

你改变不了你的祖先，也改变不了你的父辈，你只能改变你自己，而不是去埋怨社会不公平。难道你希望你努力完了以后跟没努力的人是一样的？

他还提到一个对比：「解决上下层流动最好的就是我们中华文化，没有长期固化的门阀——欧洲的贵族可以几百年，中国哪有？科举制就是解决上下层流动的最好办法。」

3. 关于「你去过吗」

他最反感那种用「你去过吗」来堵人嘴的说法：

去过和没去过没有什么区别，你去过也不见得就更了解。你去趟美国旅游能调查啥？你在中国生活这么长时间了，你了解中国吗？

了解一个东西需要靠阅读，你得知道它的历史来龙去脉。我刚才说的你又忘了——你所看到的都是假象，真相是需要用思考来得到的。感性是代替不了理性的。

他举了个很实在的例子：看风景，你在现场其实没有在纪录片里看得清楚——「人家用无人机给你拍，又给你讲这个地貌是怎么形成的；你到现场走马观花转一圈，看着别人的后脑勺，你能看明白啥？」他补充说不是否定去现场，「兵马俑那气势压人，不到现场看不出来」，只是「你别迷信这件事」。
