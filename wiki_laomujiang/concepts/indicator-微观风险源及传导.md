# indicator-微观风险源及传导

## 一句话定义

识别具体企业、受托管理关系及交易账户中损害现金创造能力、偿付能力、投资者权益或交易流动性的驱动力，并用可核验指标检查其传导是否成立。

**概念本质：找到致险变化 → 识别企业或持仓暴露与传导条件 → 核验实际损害及缓冲能力。**

## 概念来源

- **来源明确提出（以整理稿转述为限）**：客户信用与退货条件影响回款；受托人与投资者可能存在利益冲突；地方财政压力可能影响企业资金安排；核心管理人离任需要重新审视；出口成本变化会削弱竞争优势；行业涨价不代表所有生产商受益。另有个股融资下降与卖压、下跌相互强化，以及股东人数须结合价格位置、成交和持仓变化理解的转述。逐项来源见下文。
- **来源间接支持**：这些材料共同指向企业现金流、经营能力及投资者权益的脆弱环节，并非只讨论股价波动。
- **整理者归纳**：六类基本面路径及两类资金面路径、传导简图、指标及反证是跨文章提炼，不是老木匠明确提出的“六大风险源”体系。沿用 [[wiki/concepts/冰冰小美-framework-风险观察|风险观察]] 对“风险形成驱动力”的定义，以及 [[wiki/concepts/冰冰小美-indacator-宏观风险源与传导路径|风险源与传导路径]] 对关键变量、观测指标的区分。
- **分类口径**：按本次确认，企业经营与治理归入**微观—基本面**；行业供需与竞争格局属于中观，财政、货币与汇率等整体环境属于宏观。宏观风险源页面用于外部起因与方法定义，本页承接企业与具体标的层面观察；个股融资去杠杆归入**微观—资金面**。既有主题页中将企业经营与治理归入中观的旧表述尚待同步。
- **待验证**：所引直播稿为第三方整理，具体企业案例、政策状态、合同条款及会计判断未逐项独立核验。本页沉淀观察方法，不判定当前风险等级。

## 概念要解决的问题

1. 企业受到什么变化的伤害，而不只是出现了什么财务现象？
2. 同样的外部冲击，为什么有的企业受损、有的企业受益？
3. 哪个变量决定损害发生、扩大或停止，用什么证据观察？
4. 什么条件可以阻断传导，什么情况说明原判断需要撤回？

## 核心内涵

### 1. 来源层级与受影响层级分别记录

| 层级或维度 | 本页口径 | 示例 |
|---|---|---|
| 宏观起因 | 整体财政、货币、汇率与贸易政策变化 | 地方财政压力、汇率变化 |
| 中观传导 | 行业供需、产业链与竞争格局变化 | 行业成本上升、供应链受阻 |
| 微观—基本面 | 企业经营、财务、治理及权益保障 | 回款恶化、现金受限、产销量下降 |
| 微观—资金面 | 标的及账户的持仓、杠杆、赎回与交易约束 | 被迫减仓、集中赎回 |

例如：财政压力（宏观）→ 客户延迟付款 → 某企业营运资金缺口（微观—基本面）。最后一环落在企业，不会把前面的宏观起因改成微观。企业现金短缺也不自动等于二级市场交易流动性不足。

基金受托管理关系适用第二项的代理风险检查；它损害的是持有人权益，不直接代表被投企业的基本面恶化。由此引起的抱团或被迫卖出，需要另外记录资金面路径。

### 2. 风险源、关键变量与指标不能互相替代

| 项目 | 要回答的问题 | 回款风险示例 |
|---|---|---|
| 风险源 | 什么变化正在推动损害？ | 客户偿付能力下降或退货条件被触发 |
| 传导条件 | 怎样影响到目标企业？ | 销售尚未回款，同时上游付款刚性较强 |
| 关键变量 | 什么决定损害大小与持续时间？ | 可回收比例、回款时间、账期差 |
| 观测指标 | 用什么证据判断变量？ | 期后回款、逾期账龄、退货率、现金转换周期 |
| 结果及缓冲 | 已造成什么影响，能否承受？ | 经营现金缺口；可用现金及授信能否覆盖 |

### 3. 微观—基本面：六类风险源及传导

以下为整理者归纳的观察路径，均须结合具体对象验证，不能作为自动买卖信号。

#### ① 客户信用恶化与销售回款条件变化

- **传导**：客户支付困难或退货增加 → 回款延迟、收入撤回或信用损失 → 营运资金缺口 → 融资成本和偿付压力上升。
- **关键变量**：客户偿付能力、退货条件、应收可回收比例、收付款账期差。
- **观测指标**：应收账龄与逾期比例、期后回款、退货情况、客户集中度、经营现金流及短债到期安排；结合合同、附注与期后披露。
- **反证与边界**：回款正常、信用保障有效或账期匹配，可削弱风险判断。应收规模大本身不足以判定风险；退货权的收入确认影响须核实具体条款，不能沿用整理稿中的绝对表述。
- **来源**：[[sources/automations/老木匠每日汇总/2026-08-19 老木匠直播：应收账款该怎么看|2026-08-19 老木匠直播：应收账款该怎么看]]。

#### ② 代理冲突与治理约束失效

- **传导**：管理人收益与投资者长期利益偏离 → 扩张、关联安排或风险承担失当 → 现金、资产质量或持有人权益受损。
- **关键变量**：激励一致性、控制权制衡、关联交易约束、受托管理合同及执行情况。
- **观测指标**：报酬与考核方式、关联交易和资金占用、投资范围偏离、产品费用、审计及监管披露。
- **反证与边界**：有效监督、透明且公平的交易安排、可执行的责任约束可阻断传导。不能仅凭规模扩大推定侵害；基金最低仓位等约束应按具体产品合同核实。
- **来源**：[[sources/automations/老木匠每日汇总/2026-08-08 老木匠直播|2026-08-08 老木匠直播]]；[[sources/automations/老木匠每日汇总/2026-09-26 老木匠直播：美债收益率、铜关税与A股牛市展望|2026-09-26 老木匠直播：美债收益率、铜关税与A股牛市展望]]。

#### ③ 地方财政压力向企业现金与权益传导

- **传导**：财政支付或资金安排承压 → 企业回款推迟、现金使用受限或承担额外资金需求 → 偿债及股东回报能力下降。
- **关键变量**：财政相关客户和业务依赖度、企业现金支配权、关联资金安排与实际偿付能力。
- **观测指标**：政府相关应收及账龄、受限资金、关联往来、担保、现金与债务期限、分红支付来源。
- **反证与边界**：款项按期收回、现金可自主使用、关联往来可核验且未侵害权益，可削弱风险判断。地方国企身份或“不分红”不能独立证明资金被占用。
- **来源**：[[sources/automations/老木匠每日汇总/2026-09-29 老木匠直播：美债利率、黄金持有成本与股市生存法则|2026-09-29 老木匠直播：美债利率、黄金持有成本与股市生存法则]]；[[sources/automations/老木匠每日汇总/2026-08-19 老木匠直播：应收账款该怎么看|2026-08-19 老木匠直播：应收账款该怎么看]]。

#### ④ 核心管理人依赖与接班失效

- **传导**：核心人物离开且能力未完成组织化 → 客户、技术或组织执行能力流失 → 订单、效率及长期现金创造能力下降。
- **关键变量**：关键能力对个人的依赖程度、接班质量、团队和客户稳定性。
- **观测指标**：核心团队流失、客户续约、订单兑现、研发与产品进展、经营效率；结合离任前后的可比期间。
- **反证与边界**：能力已制度化、团队稳定且经营表现保持，可否定“离任必然损害价值”。同时排除行业周期等替代解释。
- **来源**：[[sources/automations/老木匠每日汇总/2026-10-11 老木匠直播：资金虹吸、自我降维与人对企业的作用|2026-10-11 老木匠直播：资金虹吸、自我降维与人对企业的作用]]，第六节。

#### ⑤ 成本优势消退与转嫁能力不足

- **传导**：关税、汇率、退税或要素成本变化 → 企业实现售价与成本差额收窄 → 利润、现金流及订单竞争力下降。
- **关键变量**：定价权、净外汇敞口、生产布局、客户替代成本及成本转嫁速度。
- **观测指标**：产品和地区毛利率、实际成交价格、订单变化、单位成本、实际税负、套保及结算币种。
- **反证与边界**：提价、套保、进口成本下降或产地调整可抵消冲击。不能把人民币升值或关税变化等宏观方向直接等同于某企业亏损；折算口径参见 [[wiki_laomujiang/concepts/基本面-微观-汇兑损益|汇兑损益]]。
- **来源**：[[sources/automations/老木匠每日汇总/2026-08-23 老木匠直播：热闹的地方就是险地|2026-08-23 老木匠直播：热闹的地方就是险地]]。

#### ⑥ 自身生产或交付能力受损

- **传导**：自身停产、疫病、运输或出口受阻 → 可售产量下降、恢复费用增加 → 行业价格即使上涨，企业现金流仍可能下降。
- **关键变量**：自身受损比例、可售产量、恢复时间、恢复成本与替代交付能力。
- **观测指标**：停产公告、产销量与交付、产能利用、单位成本、库存可售状态、保险赔付条件。
- **反证与边界**：企业未受损、库存可售或替代产能足以承接，可能转为受益者；必须核对价格上涨能否抵消销量和成本损失。
- **来源**：[[sources/automations/老木匠每日汇总/2026-09-19 老木匠直播：加息的传导与筹码的哲学|2026-09-19 老木匠直播：加息的传导与筹码的哲学]]，第十九节。

### 4. 微观—资金面：个股融资持仓与去杠杆风险

**个股融资余额是观测指标，不是风险源本身。**观察对象是该股融资持仓及相关账户的资金约束，不是上市公司的经营借款。

- **风险源**：杠杆持仓过度集中、担保缓冲不足且补仓能力有限，或融资条件收紧，使持有人更容易被迫减仓。其中持仓与缓冲是脆弱性条件；价格下跌、担保物价值下降及合同条件变化可能触发压力。融资条件变化是否存在，须另行核验。
- **关键变量**：潜在减仓规模、账户担保缓冲、补充资金能力、融资续接条件，以及卖压相对于市场承接能力的大小。个股公开汇总数据通常不足以直接识别账户集中度、补仓能力和追保位置，不能从余额反推出这些未知值。
- **传导路径**：股价或账户其他担保物下跌／融资条件收紧 → 担保缓冲缩小 → 主动减仓或触发追保 → 无法及时补足时可能被迫卖出 → 若买盘承接不足，价格进一步下降 → 更多账户承压，形成去杠杆反馈。
- **触发边界**：是否追保或平仓取决于实际账户担保资产、合同及适用规则；不能仅凭某股下跌判断其融资持有人必然被平仓。

| 观测指标 | 口径与作用 | 使用限制 |
|---|---|---|
| 个股融资余额及变化 | 同一标的、同一口径，记录日期、金额及增减，观察融资债务存量 | 不代表全部杠杆；不包含所有场外借款，也不是融资持仓市值 |
| 融资余额 / 流通市值 | 同日计算，辅助观察融资规模相对可流通股票市值的大小 | 流通市值与自由流通市值不可混用；价格下跌也会推高该比值，不等于新增融资 |
| 融资余额 / 近20个交易日日均成交额 | 以同币种金额计算，观察债务存量相对近期交易规模；记录窗口及停牌处理 | 只是承接压力代理指标，不是实际清仓天数，也不是未来确定卖压 |
| 融资买入额、偿还额及净变化 | 同期对照买入与偿还，识别融资扩张或收缩 | 偿还可能来自现金还款，不能全部视为卖券；余额下降不等于被迫平仓 |
| 成交额、换手、价格冲击及买盘深度（可得时） | 与融资变化同步观察，判断交易承接是否变弱 | 放量下跌不能独立证明强平；成交额大也不保证流动性充足 |
| 账户担保比例、补仓资金与融资合同（获授权可得时） | 直接核对追保条件、资金缺口、利率及期限 | 无法获得时标记未知；不得用全市场或个股平均数代替账户数据 |

**反证与缓冲**：融资有序下降、现金还款充足、担保缓冲改善且交易承接稳定，可削弱短期负反馈判断。融资余额在急跌中下降也可能是风险正在释放、卖压正在兑现，不能直接判为安全。余额高不自动意味着高风险，余额低也不排除其他杠杆或非融资卖压。

**来源与归纳边界**：[[sources/automations/老木匠每日汇总/2026-08-10 老木匠直播：降杠杆的正反馈与凡事要证据|2026-08-10 降杠杆的正反馈与凡事要证据]] 第一节直接讨论个股融资数据及去杠杆正反馈；上述相对指标、账户核验步骤与融资条件情景为整理者扩展，未设定经验买卖阈值。原稿“慢慢下跌就不会强平”的绝对说法不作为规则采纳。

全市场“2万亿元”是特定时期的市场判断，不能迁移成个股阈值；口径见 [[wiki_laomujiang/concepts/资金面-宏观-融资余额风险线|融资余额风险线]]。具体标的的持仓结构可结合 [[wiki_laomujiang/concepts/资金面-微观-筹码结构|筹码结构]] 观察，但股东人数也不能代替融资账户集中度。

### 5. 微观—资金面：筹码结构与股东人数变化

**筹码结构指股票在不同持有人之间的分布及其交易约束；股东人数变化是观察这种结构的低频代理指标，不是风险源本身。**观察对象是可交易持仓、退出意愿与市场承接能力，不能只按人数多少判断安全。

- **风险源**：集中持有人减仓或原有稳定持仓转向退出；持有人面临相似的赎回、止损或杠杆约束，容易同步卖出；新增买盘不足以承接潜在供给。集中或分散本身只是结构特征，需要结合持有人行为、约束变化才构成具体风险判断。
- **关键变量**：实际可交易持仓集中度、潜在卖出规模与速度、持有人资金期限及退出约束、新增承接资金的持续性。股东人数不能直接测量投资者身份、持仓成本或真实控制关系；这些信息不足时应标记未知。
- **传导路径一——持仓扩散与承接减弱**：原集中持有人持续减仓 → 若由更多小额持有人承接，可能出现人数增加、户均持股下降 → 当原卖压继续而新增买盘减弱时，价格承压 → 部分持有人止损或去杠杆，卖压进一步扩大。人数变化是中间观测线索，不能独立证明减仓主体或后续下跌。
- **传导路径二——集中持仓同步退出**：持仓集中且资金约束相似 → 赎回、追保或策略调整触发同步减仓 → 卖出规模超过即时承接能力 → 价格冲击加大 → 引发其他账户减仓反馈。因此人数减少也可能伴随拥挤风险，而非风险必然下降。

| 观测指标 | 口径与用途 | 不能直接推出什么 |
|---|---|---|
| 股东人数及跨期变化率 | 同一证券、同一股东范围，变化率＝本期人数 / 上期人数－1；同时记录统计截止日和公告日 | 人数增加不能直接证明机构出货；人数减少不能证明主力吸筹 |
| 户均持股 | 对应范围股份数 / 对应股东人数；分子与分母范围不匹配时不计算，核对股本变化 | 平均数不是典型账户的持股量，也不能识别大户与小户分别如何变化 |
| 前十大流通股东持股及变动 | 核对同日流通股本、持股数量、占比和披露范围，辅助观察较大持有人变化 | 十大名单不覆盖全部持有人，名单进出也不一定等于全部买入或清仓 |
| 已披露减持、持仓及解禁信息 | 区分减持计划、实际执行和新增可流通供给；核对数量及时间 | 计划不是实际卖出，解禁也不是必然卖出 |
| 同区间价格、成交额与换手率 | 将人数统计区间与交易区间对齐，观察价格位置、成交冲击及承接变化 | 成交放大不能识别交易双方，也不能单独证明派发完成 |
| 融资变化与资金约束证据 | 配合上一节检查是否存在去杠杆叠加；账户或产品约束仅在可核验时采用 | 股东人数不能替代融资账户集中度，不能据此推算强平点 |

**数据使用边界**：优先采用公司可核验披露，区分全部股东、某类股份股东等统计范围。数据只能在公告后用于当时决策，历史回测不能提前使用尚未公布的人数。第三方“实时股东数”或“筹码成本分布”估算不能替代登记数据；上市、增发、回购、股份类别和流通范围变化都需要检查是否影响可比性。

**反证与缓冲**：人数增加，但已披露大股东持股稳定、潜在卖压没有扩大且交易承接持续，则削弱“集中持有人持续退出”的假设。人数下降且持有人资金期限稳定、无同步退出压力，也不能仅因集中而认定危险。低位人数多、高位人数少都可能存在，必须结合区间与约束；长期低迷、人数多也不证明已经见底或完成股东出清。

### 6. 从线索到判断的证据门槛

文章中的机制只构成候选解释。至少需要明确观察对象、变化时间、暴露程度、传导环节及反证，才能判断该对象风险是否增强。指标应与企业历史、季节性和同业口径比较，不设置跨行业通用阈值。

财报、合同和公告用于核验事实；本文与直播整理稿用于提出问题。估值下跌、股价下跌或情绪变化可能是后续结果，不能反过来证明以上某项风险源已成立。

## 判断标准 / 使用检查表

| 检查项 | 要判断的问题 | 通过标准 | 不通过时的含义 |
|---|---|---|---|
| 对象与层级 | 损害谁，起因在哪里？ | 企业或持有人明确，外部来源与微观影响分开 | 对象含混，容易误用宏观结论 |
| 致险变化 | 什么发生了不利变化？ | 有可核验变化，而非仅一个静态指标 | 只能保留线索 |
| 暴露与传导 | 为什么该对象会受损？ | 合同、业务、资产或资金关系能支持路径 | 不能从行业直接推到企业 |
| 关键变量 | 什么能改变判断？ | 变量变化可强化或阻断传导 | 尚未找到有效观察项 |
| 观测证据 | 数据是否对口？ | 期间、单位及口径可比，来源可追溯 | 不宜判定趋势或等级 |
| 缓冲与反证 | 有什么可以抵消损害？ | 核对现金、授信、套保、替代能力等适用因素 | 容易高估风险或遗漏解除条件 |
| 判断边界 | 是否把转述当事实？ | 作者观点、整理推断和已核事实分开记录 | 需回源验证，不直接给交易结论 |
