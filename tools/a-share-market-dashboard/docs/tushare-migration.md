# 看板 Python 数据接口替换

实施日期：2026-11-06。看板调用用户指定的 `/Users/cjw/dev/Obsidian/wiki/tools/tushare-data`，Tushare取数不需要启动MCP服务。共享目录负责请求、凭证、分段历史、复权、单位和沪深汇总；看板的 `scripts/shared_market_data.py` 只负责证券映射、已收盘日期和页面格式转换。

## 兼容入口与运行

看板继续通过自身本地服务提供页面所需的HTTP响应，后台再调用共享Python。这些是看板兼容路由，不是给共享目录新增HTTP服务器。

| 看板入口 | 实际行为 |
| --- | --- |
| `/api/eastmoney-kline?secid=0.159941&limit=4000` | 名称兼容旧前端，实际读取Tushare基金日线与因子 |
| `/api/eastmoney-kline?secid=1.000300&limit=3000` | 国内指数日线；另外支持上证及中证全指的既有secid |
| `/api/csindex-performance?indexCode=000922&startDate=20250101&endDate=20261105` | 仅000922价格日线切换；其他指数估值请求继续中证原接口 |
| `/api/dividend-signal?code=515450` | ETF价格走共享Python，现金分红继续原来源 |
| `/api/liquidity` | 默认`tushare`模式，7条基础序列走共享Python，其余保留原源；ETF申赎保持Wind MCP |

配置与启动见 [[tools/a-share-market-dashboard/README|看板README]]，共享函数参数、字段、单位及错误契约见 [[tools/tushare-data/docs/api-reference|Python接口文档]]。凭证仍复用既有解析，不复制Token，不向浏览器发送Token。修改后需重启本地服务；本次已重启原49888/49889服务并验证接口。

国内价格只请求北京时间15:30之后的当日数据，之前截止前一自然日，再由实际返回交易日决定末日；不为节假日造数据。资金面继续使用既有各市场收盘时间过滤。ETF复权基准为本次请求中最后一个价格日，刷新时替换整段复权历史。回测日线按需要区间更新，备份旧文件，保留区间外历史及其来源记录。

默认模式下，已迁移项失败不会自动请求旧供应商。旧资金面缓存不会因为仍在缓存时限内就被当成Tushare成功结果；请求失败可展示旧来源、旧日期并标记`stale`，不计分。显式配置`DATA_PROVIDER="free"`可使用保留的旧公开源适配器；`wind`仍是导入模式。页面必须经本地服务打开，直接打开HTML不走上述Python路由。
