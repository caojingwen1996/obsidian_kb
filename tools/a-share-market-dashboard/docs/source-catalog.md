# 指标与数据源清单

入口：左侧“温度计 → 指标与数据源”。按2026年11月6日现有实现整理77项记录，记录可以包含一组共用来源的派生指标；并非77条已连通的数据接口。

支持按指标名称、来源、用途与口径搜索，多个关键词同时匹配；支持按栏目筛选。桌面按四列阅读，手机逐项显示字段标签。“历史计算模块”和“风险大屏指标”默认收起，搜索或指定栏目时展开。清除筛选恢复全部记录并将焦点放回搜索框。

## 关键边界

- 清单说明当前接入与计算方式，不请求上游数据，不替代各指标页面的本次来源与可用状态。
- 同名指标按页面分别记录，例如总览美元指数来自Tushare，资金面及风险大屏DXY来自Yahoo；融资余额现统一优先使用Tushare；融资占流通市值仍保留同一东财报表的分子和分母。
- 数据日期为交易日、估值日或统计期；更新时间为本机成功读取时间，不是上游发布时间。ETF每日09:00任务已暂停，页面不再调用Wind。
- 当前红利评分使用绝对股息率与股债倍数，参数以保存的策略为准；历史分位不参与现行评分。515450现金分红率不是跟踪指数股息率。
- “待接入”“待验证”和历史模块均明确区分。停用Wind后保留既有评分规则，缺少输入的指标不补零。
