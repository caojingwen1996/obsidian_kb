# 温度计

这是一个规则透明、可回溯的 A 股大盘监控工具，用历史分位回答：当前整体更偏便宜还是偏贵。评分不预测明日涨跌，也不构成投资建议。

## 推荐启动方式

Windows 双击 `启动面板.cmd`；Mac 双击 `启动面板.command`。启动器会：

1. 从系统 `PATH` 或 Codex 工作区运行时定位 Node.js，并重新构建 `a-share-market-dashboard.html`；
2. 使用系统中的 Python 3 启动仅监听 `127.0.0.1` 的本地服务；
3. 自动选择一个可用端口并打开默认浏览器；
4. 让面板通过同源 `/api` 获取公开数据，绕开浏览器对本地 HTML 的 CORS 和 JSONP 限制。

不需要安装 pip 包，但系统需要 Python 3。系统 Node 与 Codex 内置 Node 均不可用，或看板构建失败时，启动器会停止而不会继续打开旧看板。命令窗口必须保持打开；关闭窗口后实时刷新停止，浏览器中的最近成功快照仍可展示。

Mac 启动器优先使用系统 Node.js / Python 3，并支持 Homebrew 常用路径；未找到时尝试 Codex 内置运行时。也可在终端执行（无需可执行权限）：

```bash
bash "/Users/cjw/dev/Obsidian/wiki/tools/a-share-market-dashboard/启动面板.command"
```

若复制文件后双击提示没有执行权限，在面板目录执行 `chmod +x 启动面板.command`。浏览器打开后保持终端窗口运行，按 `Ctrl+C` 停止服务。

`a-share-market-dashboard.html` 仍是完整的单文件 artifact，可以直接双击查看示例数据或已有缓存。要稳定获取联网数据，请使用启动器。

股息率回测页的“打开信号源（Excel）”通过本地服务直接打开 `sources/automations/中证红利信号/中证红利每日信号.xlsx` 原始工作簿。Mac 上明确使用 Microsoft Excel（需已安装），启动失败时提示错误；其他系统使用默认表格应用。请使用启动器打开看板；直接双击 HTML 时会提示启动方式。

工作簿已保存冻结前两行的 Excel 窗格设置；2026-10-14 已在 Microsoft Excel 重新打开原文件并跳到第70行，确认前两行保持可见。Excel 当前未激活时仍可只读查看，编辑和保存需激活。此前 Numbers 导入该 `.xlsx` 时未恢复冻结表头，Mac 看板入口已改为指定 Microsoft Excel。

左侧使用树形导航，一级为“温度计 / 策略 / 产业 / 我的 / 更新日志”。“温度计”下保留市场总览、红利信号、每日跟踪、风险大屏和主题；“策略”下提供富贵策略、小美策略和股息率回测；“产业”下按冰冰小美三大产业方向分为“战略 / 新兴 / 支柱”，对应战略资源、新兴产业和支柱产业；“我的”下提供仓位管理、持仓跟踪与复盘日记。展开一个分组时会收起另一个分组，并在本次页面打开期间记住各分组最后访问的子页。“更新日志”直接打开看板自身的更新记录。

仓位管理支持新增、编辑和删除持仓，并按记录的数量、成本价和现价计算持仓成本、当前市值、浮动盈亏与仓位占比；持仓跟踪可维护“持有 / 观察 / 计划加仓 / 计划减仓”状态与关注要点，并从个股研报读取“公允价值区间”和“交易定价偏离”。顶部“每日监控”只打开最新的组合汇总 HTML。“每日估值监控”列使用中文状态作为主标签，触发或修改原因作为次要信息，点击状态可打开对应逐标的 HTML；研报列显示可用的“个股研报”入口，并在独立的“三要素判断”列展示竞争格局、流动性和情绪位置。复盘日记页会汇总 `workbench/journal/*-复盘日记.md`，显示最新复盘时间、记录数和最近正文，并通过 Obsidian 打开日记。通过启动器打开时，个人数据保存在本机 `data/portfolio.json`；直接双击单文件时降级保存在当前浏览器，但复盘文件的读取和写入仍需启动器。本地个人数据不会提交到公开数据接口。

产业页采用信息流布局，包含细分方向标签、产业研报看板、日期时间线和研报卡片，并支持当前页内搜索与标签筛选。

## 产业研报自动加载

构建时只扫描以下三个固定根目录：

- `sources/automations/战略资源/`
- `sources/automations/新兴产业/`
- `sources/automations/支柱产业/`

每个根目录的一级子目录会直接成为筛选标签；其下更深层级的 HTML 仍继承该一级标签。根目录直属 HTML 只在“全部”下显示。文件名包含“完整分析报告”的 HTML 显示在顶部“产业研报”区域，其他 HTML 进入日期信息流；Markdown 等非 HTML 文件不会加载。新增目录或移动研报后，重新双击启动器即可自动构建并同步页面；也可以手动运行构建脚本，无需修改代码中的产业关键词。

主题页的“打开主题”使用 Obsidian 本地协议打开对应 Markdown；系统已将 Obsidian 注册为默认处理程序时，会直接跳到 Obsidian 中的文档。

通过“启动面板.cmd”打开看板时，本地服务器仅额外提供 `sources/`、`wiki/` 与 `workbench/` 三棵白名单目录内的文件；其他仓库文件以及目录外路径仍拒绝访问。

航天电子机构级研报采用“每日同步 + 盘中增强”方式：直接双击 HTML 时显示每日任务写入的价格与判断；从大盘本地服务打开时，盘中行情卡通过固定白名单接口获取航天电子价格，每 60 秒刷新。接口失败只影响盘中卡，不会覆盖每日同步值。

## 红利加权评分与参数设置

红利模块提供“查看 / 股息率回测 / 任务监控”三个页签；查看与回测分工如下，监控说明见本文“中证红利任务监控”：

- **查看**：从“温度计 → 红利信号”进入，先看“当前信号”：“信号1：股息率”与“信号2：布林线”平铺并置，分别标注数据日期，手机纵向排列；评分保留等级、综合分、核心指标及参考评分标记，布林位置保留最新收盘、三轨和真实%B，并以轨道标记辅助阅读。随后是浅色的指数与股息率走势图，区间统计放在图下。评分贡献和公式放入默认折叠的“评分拆解”；年度表、月度详情入口及对照指数放入默认展开的“年度收益与历史统计”。全市场刷新情况可单独展开。股息率评分使用每日记录的策略版本，布林轨道独立使用最新可用日线计算。
- **股息率回测**：从“策略 → 股息率回测”或查看页的“股息率回测”进入，集中维护两项权重、打分锚点和C/B/A等级阈值，并提供本地保存、每日应用、撤销、恢复默认、打开 Excel 信号源、来源验证信息和信号效果回测入口。尚无信号记录时也可配置参数。

两页切换保留本次未保存的编辑；参数编辑不改变查看页的每日记录。无效参数即时提示并禁止保存／应用及回测。

买入规则为“仅综合A级可买入”：A买入区间、B观察区间、C等待区间、D不买入。B/C/D均不发出买入提示；该规则同步用于查看页、管理页和后续每日信号。评分权重、锚点及C40/B48/A65分界不变。各等级回测保留假设买入收益供对照，不表示均可买入。

页面已移除连续确认交易日数、相关帮助和确认状态；等级分界区只保留C/B/A三项，按当天综合评级判断。旧配置字段与历史确认记录保留兼容，回测页面的参数快照不再展示该字段。

月度收益日历的年份选择旁显示该年总体收益，使用年度表相同的年度收益值，切换年份同步更新；完整年份标为“年度总体收益”，未结束年份为“年内累计收益”，成立首年单独标注。手机将总体收益排列在年份控件下方。

历史收益区域默认展开，右上方提供“收益日历：年 / 月”。默认“月”展示最新有数据年份的12个月收益及该年总体收益；切换到“年”显示年度收益与年内最大回撤。年份可在下拉框中选择，下拉框两侧箭头分别切换上一年、下一年，没有对应年份数据时禁用；到达边界后焦点回到年份选择。本次页面打开期间保留所选模式和年份。月视图只使用已保存且通过年度复合收益校验的月度数据，数据不足不填零，未结束月份标注“月内累计”，未来月份显示“未开始”；缺失或校验失败时提示切回年度表核对或重新读取。原年度表点击年份查看月度详情的入口保留。

当前信号卡片默认只展示结论、综合分或收盘点位、核心指标及各自日期，买入规则简写为“仅A级买入”。不再逐项显示用途、单位注脚和公式，也不重复展示“已接入”“当前策略重算”等正常状态；历史试算、数据不足、日期未对齐、更新失败与未收盘动态值仍明确可见。两个信号分别提供“详情”，按需查看完整买入规则、公式、来源、%B定义、记录日和重算说明；原始数值、评分与布林算法不变。

离线HTML只内嵌最新评分快照，避免重复携带整份评分档案；原始评分JSON保留全部记录，回测仍通过本地服务读取完整Excel。股息率及指数走势历史继续随页面提供。

当前信号下方同时展示中证红利000922指数收盘价（蓝线、左轴点位）和股息率（棕线、右轴百分比），两条线按日期对齐。仅综合A级标记赭色“场外假设买入点”，按记录日之后首个交易日的指数收盘价定位，与回测的“（假设）买入日”一致；股息率曲线仍按估值日绘制。悬停或键盘聚焦分别显示假设买入日、信号估值日、记录日、买入参考点位及信号股息率，避免将买入日当日股息率误读为评分输入。同一估值日保留最早记录，同一买入日合并圆点并保留全部来源提示。兼容旧版A级的“重点买入”“重点配置区间”，旧B级结论不再标记；待验证、C/D和缺失结论亦不标记。图例显示A级信号数与假设买入日数；标记只读取文件中的综合结论，不随浏览器参数编辑改变。

指数日线快照保存在 `sources/automations/中证红利信号/中证红利指数日线.json`，布林线补充历史保存在 `data/红利信号/中证红利布林日线.json`，两者均保留中证指数官网接口地址和抓取日期，构建时合并内嵌，离线也能显示。进入红利页后使用已有 `/api/csindex-performance` 接口读取近400个自然日的000922日线，页面打开期间每5分钟更新，重复进入的请求间隔不少于1分钟；读取失败保留快照并显示错误与真实数据日期。评分刷新和参数应用会合并保留较长历史。走势图按股息率估值日期范围展示，买入日通过实际交易日历确定；目标买入日缺收盘价、记录日期无效或尚无区间内下一交易日时不标记，图例提示原因，不顺延到其他有价格的日期。指数收盘仅为场外申购的参考，不是实际基金净值。修改工作簿或快照后重新构建面板。

周线布林线固定使用 **BOLL(20, 2)**：按周一至周五聚合，每周取最后一个有效交易日收盘价；中轨为最近20个有效交易周（含当前周）的简单均值，上／下轨为中轨加／减2倍总体标准差（除以20）。空交易周不补值，未来日期、周末和无效点位不参与计算；历史不足20周时显示数据不足，三轨留空。当前交易周在北京时间周五15:00之前标为“本周未收盘（动态值）”，后续收盘价会改变本周三轨。最新收盘与三轨比较后展示下轨下方、下轨至中轨、中轨至上轨、上轨上方，恰好位于轨道时单独标注；`%B = (最新收盘 - 下轨) / (上轨 - 下轨) × 100%`，轨道外可以小于0%或大于100%，三轨重合时不计算%B。轨道位置为相对位置展示，不自动合成为买入信号。计算口径参考 [Bollinger官方说明](https://www.bollingerbands.com/bollinger-bands)。

红利信号使用V1连续加权评分：历史分位45%、绝对股息率30%、股息率相对10年国债的倍数25%。五个锚点之间线性插值，两端截断0～100；综合等级分界40/60/80，等级按原始精度判定，页面显示一位小数。各项当前值、子分数、权重贡献与计算依据均显示在红利页。

看板与每日自动任务统一读写 `sources/automations/中证红利信号/策略参数.json`，与每日Excel同目录；未应用自定义参数时使用技能的 `strategy-v2.json` 默认值。旧位置 `data/红利信号/strategy-settings.json` 仅用于首次自动迁移，迁移前备份到Excel同目录的 `备份/策略参数迁移/`，原参数、版本和历史原样保留，新文件存在时优先使用新文件。看板优先读取 `sources/automations/中证红利信号/评分记录.json`；没有结构化产物时从原Markdown兼容重算，并标为历史数据试算。首次本地快照保留实际数据日期，替代口径标为参考评分。缺失指标保留原权重，显示总分区间而不评级；日期不一致不参与连续确认。

管理页的“策略详情”开放全部数值参数：三项权重、打分锚点与内部得分、C/B/A分界、确认天数。参数修改时立即校验；合计权重非100%、锚点非递增、等级分界错误等情况下标出字段错误并禁止保存。端点0/100固定。已移除本地实时测算卡片，不再展示当前编辑参数对应的当日试算分数、分差和等级变化。

“保存本地参数”仅保存在当前浏览器当前站点，不改变每日任务、每日文件或总览卡片。“保存并应用到每日测算”会保存每日配置，立即按新策略重算当前Excel全部记录，并同步查看页结论、分项评分和走势图买点；后续每日任务继续使用新策略。重算前在信号目录的“备份/保存并重算-时间-编号”中保留原Excel、评分JSON、Markdown和策略，写入失败回滚。原始指标、数据日期、冻结窗格、筛选及其他Excel内容保留；历史重算标为历史数据，不充当当时已发布或连续确认的每日信号。恢复V1默认值先只改变编辑参数，点击应用才更新文件。启用新接口后需重新启动启动面板，直接双击HTML不能应用每日配置。浏览器存储不可用时只保留本次会话；更换浏览器或启动端口不保证共享。每日信号的连续确认默认3个实际交易日，依据有效评分记录和交易日历判断；证据不足明确提示。

现有回测属于样本内信号效果观察，尚不能证明参数的样本外收益表现。每日配置保留各版参数及应用时间，相同参数重复应用不重复升版，但仍重新读取并重算当前Excel；参数校验失败或版本冲突不覆盖配置。旧每日评分记录保留，新重算记录单独标记；Excel旧结论可在备份恢复，单次任务固定使用开始时取得的参数快照。查看页通过只读接口加载最新Excel结论和评分文件，重新打开页面也保持一致。

详细方法、数据口径和维护规则见 `.agents/skills/zzhl-dividend-signal/SKILL.md`，旧研究记录不用于证明V1收益更优。

## 红利信号效果回测

逐条明细的“计算起止”位于最后一列。其余字段可用表头按钮切换升序/降序：综合等级与得分分别排序，三项指标的原始值与子分数也可分别排序；等级升序为D/C/B/A，状态按显示文字排序。数值使用原始精度，缺失值双向置后，同值保留原顺序。排序只改变当前表格显示，不重新读取Excel或重算回测，保留明细展开和横向滚动；重新回测继续使用当前排序字段及方向。

在“策略 → 股息率回测”点击“读取Excel并回测”，先查看各等级信号的后续表现。参数默认折叠，展开“评分参数”后可按权重、打分规则、等级分界编辑，点击“用这些参数回测”比较；无需先保存，也不会保存／应用策略或修改Excel。编辑参数后旧结果会提示重新回测，切换页面及参数区刷新保留已有结果与参数区展开状态。

## 评分规则

- 位置层 40%：上证指数 10%、沪深 300 15%、中证全指 15%。计算 `当前收盘价 / MA250 - 1`，再求所选 1/3/5/10 年窗口内的历史分位；买点得分为 `100 - 偏离分位`。
- 估值层 35%：沪深 300 TTM PE 12%、前瞻盈利收益率 10%、ERP 13%。TTM PE 越低得分越高；前瞻盈利收益率和 ERP 越高得分越高。
- 情绪层 25%：上涨家数占比 7%、涨停/跌停强弱 6%、全市场成交额分位 6%、融资余额变化 6%。先计算贪婪度，再以 `100 - 贪婪度` 计入买点评分。
- 单项缺失时不填 0、不估算，剩余有效权重自动归一化。
- 原始有效权重低于 70% 时，仅显示不完整试算，顶部结论固定为“数据不足，暂不判断”。

结论阈值、公式、原始权重、有效权重、分位、贡献、数据时间、抓取时间、来源和状态都显示在面板中。

本地代理只允许固定数据路由，不支持任意 URL 转发，也不监听局域网地址。本地文件只开放当前知识库的 `sources/`、`wiki/` 与 `workbench/` 三棵白名单目录；解析后的路径必须仍位于对应目录内，任何试图通过 `../` 越界到知识库根目录或其他位置的请求都会返回 404。为适应全市场分页请求，前端在本地模式下使用 60 秒超时并按数据域顺序刷新，避免免费上游的连接池拥塞。

2026-07-17 的实际链路验证中，腾讯返回 3000 条指数日线，新浪返回 5527/5527 条 A 股行情；最终有效覆盖率为 77%，评分能够形成结论。未达到 100% 的原因是前瞻 PE 按规则保持缺失，不是网络错误。

第三方免费接口仍可能变更字段、限流或暂时不可达。工具会在“数据审计”中记录真实失败边界，不会把请求失败解释为“市场没有数据”。

## 缓存与离线行为

每个数据域独立写入浏览器 `localStorage`。如果浏览器禁止本地文件持久化，工具会退回当前页面生命周期内的内存缓存。示例数据不会写入真实缓存；“示例数据”标记下的数值不能当作最新市场结论。

### Mac 自动打开浏览器

当 Mac 默认浏览器是 Chrome 时，启动面板优先指定日常 Chrome 用户目录及最近使用的常规配置，用新窗口打开，避免自动化 Chrome 实例接收请求；失败或未收到页面请求时回退到系统默认打开方式及 Python 浏览器接口。其他默认浏览器沿用系统打开方式。终端继续显示请求日志是正常行为，关闭窗口会停止服务。启动提示仅代表已向系统发出打开请求，不保证浏览器已切到前台。

打开浏览器的诊断记录同时输出到终端及 `data/proxy.log`：`BROWSER_OPEN_ATTEMPT`（尝试）、`BROWSER_OPEN_ACCEPTED`（系统接受请求）、`BROWSER_OPEN_ERROR`（异常及原因）、`BROWSER_OPEN_FALLBACK`（回退）、`BROWSER_OPEN_FAILED`（最终失败）。包含时间、网址、打开方式、退出码或异常类型；ACCEPTED 不表示已核实窗口显示。

每次启动给网址附加独立的 `launch` 标记。HTTP 服务先开始响应，浏览器实际请求该标记对应的面板后记录 `BROWSER_PAGE_REQUESTED` 与 `BROWSER_OPEN_CONFIRMED`；超时记录 `BROWSER_OPEN_UNCONFIRMED`。确认表示页面已由服务器返回，不能单独证明窗口已到前台或页面脚本全部执行。Chrome 启动输出保存在 `data/browser-launch.log`，通用诊断保存在 `data/proxy.log`。

回测页“数据来源与验证边界”中的“指数日线”显示实际来源、价格截止日期、最近成功获取时间（北京时间）和最近一次更新结果。另列最近尝试时间；更新失败使用本地数据、价格不足停止回测、尚无更新记录分别标注，刷新页面后保留状态。状态保存在日线同目录的 `中证红利指数日线更新状态.json`，仅在对应日线获取时间匹配时采用。
