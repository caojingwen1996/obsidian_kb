# 温度计

这是一个规则透明、可回溯的 A 股大盘监控工具，用历史分位回答：当前整体更偏便宜还是偏贵。评分不预测明日涨跌，也不构成投资建议。

## 推荐启动方式

Windows 双击 `启动面板.cmd`；Mac 双击 `启动面板.command`。启动器会：

1. 从系统 `PATH` 或 Codex 工作区运行时定位 Node.js，并重新构建 `a-share-market-dashboard.html`；
2. 使用系统中的 Python 3 启动仅监听 `127.0.0.1` 的本地服务；
3. 自动选择一个可用端口并打开默认浏览器；
4. 让面板通过同源 `/api` 获取公开数据，绕开浏览器对本地 HTML 的 CORS 和 JSONP 限制。

不需要安装 pip 包，但系统需要 Python 3。系统 Node 与 Codex 内置 Node 均不可用，或看板构建失败时，启动器会停止而不会继续打开旧看板。命令窗口必须保持打开；关闭窗口后实时刷新停止，浏览器中的最近成功快照仍可展示。

Mac 启动器优先使用系统 Node.js / Python 3，并支持 Homebrew 常用路径；未找到时尝试 Codex 内置运行时。也可在终端执行（无需可执行权限）：

```bash
bash "/Users/cjw/dev/Obsidian/wiki/tools/a-share-market-dashboard/启动面板.command"
```

若复制文件后双击提示没有执行权限，在面板目录执行 `chmod +x 启动面板.command`。浏览器打开后保持终端窗口运行，按 `Ctrl+C` 停止服务。

`a-share-market-dashboard.html` 仍是完整的单文件 artifact，可以直接双击查看示例数据或已有缓存。要稳定获取联网数据，请使用启动器。

红利信号页的“打开信号源（Excel）”通过本地服务直接打开 `sources/automations/中证红利信号/中证红利每日信号.xlsx` 原始工作簿。Mac 上明确使用 Microsoft Excel（需已安装），启动失败时提示错误；其他系统使用默认表格应用。请使用启动器打开看板；直接双击 HTML 时会提示启动方式。

工作簿已保存冻结前两行的 Excel 窗格设置；2026-10-14 已在 Microsoft Excel 重新打开原文件并跳到第70行，确认前两行保持可见。Excel 当前未激活时仍可只读查看，编辑和保存需激活。此前 Numbers 导入该 `.xlsx` 时未恢复冻结表头，Mac 看板入口已改为指定 Microsoft Excel。

左侧使用树形导航，一级为“温度计 / 策略 / 产业 / 我的 / 更新日志”。“温度计”下保留市场总览、红利信号、每日跟踪、风险大屏和主题；“策略”下提供富贵策略和小美策略；“产业”下按冰冰小美三大产业方向分为“战略 / 新兴 / 支柱”，对应战略资源、新兴产业和支柱产业；“我的”下提供仓位管理、持仓跟踪与复盘日记。展开一个分组时会收起另一个分组，并在本次页面打开期间记住各分组最后访问的子页。“更新日志”直接打开看板自身的更新记录。

仓位管理支持新增、编辑和删除持仓，并按记录的数量、成本价和现价计算持仓成本、当前市值、浮动盈亏与仓位占比；持仓跟踪可维护“持有 / 观察 / 计划加仓 / 计划减仓”状态与关注要点，并从个股研报读取“公允价值区间”和“交易定价偏离”。顶部“每日监控”只打开最新的组合汇总 HTML。“每日估值监控”列使用中文状态作为主标签，触发或修改原因作为次要信息，点击状态可打开对应逐标的 HTML；研报列显示可用的“个股研报”入口，并在独立的“三要素判断”列展示竞争格局、流动性和情绪位置。复盘日记页会汇总 `workbench/journal/*-复盘日记.md`，显示最新复盘时间、记录数和最近正文，并通过 Obsidian 打开日记。通过启动器打开时，个人数据保存在本机 `data/portfolio.json`；直接双击单文件时降级保存在当前浏览器，但复盘文件的读取和写入仍需启动器。本地个人数据不会提交到公开数据接口。

产业页采用信息流布局，包含细分方向标签、产业研报看板、日期时间线和研报卡片，并支持当前页内搜索与标签筛选。

## 产业研报自动加载

构建时只扫描以下三个固定根目录：

- `sources/automations/战略资源/`
- `sources/automations/新兴产业/`
- `sources/automations/支柱产业/`

每个根目录的一级子目录会直接成为筛选标签；其下更深层级的 HTML 仍继承该一级标签。根目录直属 HTML 只在“全部”下显示。文件名包含“完整分析报告”的 HTML 显示在顶部“产业研报”区域，其他 HTML 进入日期信息流；Markdown 等非 HTML 文件不会加载。新增目录或移动研报后，重新双击启动器即可自动构建并同步页面；也可以手动运行构建脚本，无需修改代码中的产业关键词。

主题页的“打开主题”使用 Obsidian 本地协议打开对应 Markdown；系统已将 Obsidian 注册为默认处理程序时，会直接跳到 Obsidian 中的文档。

通过“启动面板.cmd”打开看板时，本地服务器仅额外提供 `sources/`、`wiki/` 与 `workbench/` 三棵白名单目录内的文件；其他仓库文件以及目录外路径仍拒绝访问。

航天电子机构级研报采用“每日同步 + 盘中增强”方式：直接双击 HTML 时显示每日任务写入的价格与判断；从大盘本地服务打开时，盘中行情卡通过固定白名单接口获取航天电子价格，每 60 秒刷新。接口失败只影响盘中卡，不会覆盖每日同步值。

## 更新日志维护

需求清单数据集中保存在 `data/需求清单/`：`todo.json` 是看板实际读取和写回的数据文件，包含活动需求与归档；`todo.xlsx` 保留原有表格。移动目录后需重新构建看板并重启本地服务。

市场总览本地数据集中保存在 `data/市场总览/`：`event-calendar.json` 为事件日历，`nasdaq-day-statistics.csv` 为纳指年度统计，`nasdaq-etf-anchor.json` 为固定前高锚点，`nasdaq-etf-history.json` 为对应历史行情证据。修改这些数据后需重新构建看板。红利信号继续读取 `sources/automations/中证红利信号/` 的自动化产物；实时行情、浏览器缓存和共用数据源保持原有机制。

看板更新记录维护在 `src/changelog.json`，与知识库根目录的 `log.md` 分开。每条记录包含日期、星期、类型、标题、摘要和可选明细；构建时按日期倒序生成时间线。修改该文件后重新运行构建脚本，独立 HTML 产物中的更新日志会同步刷新。

## 红利加权评分与参数设置

结论卡片下方同时展示中证红利000922指数收盘价（蓝线、左轴点位）和股息率（灰线、右轴百分比），两条线按日期对齐。A／重点买入为金色，B／加大买入为绿色，买点只放在对应日期的指数线上；悬停或键盘聚焦可查看日期、指数点位、股息率、买点等级和原始结论。兼容旧版“加大买入区间”为 B 档；“未进入”、待验证、C／D 和缺失结论均不标记。图例显示买点数量；标记只读取文件中的综合结论，不随浏览器参数编辑改变。

指数日线快照保存在 `sources/automations/中证红利信号/中证红利指数日线.json`，保留中证指数官网接口地址和抓取日期，构建时内嵌，离线也能显示。启动本地服务后，进入红利页时若快照未覆盖信号起止日期，使用已有 `/api/csindex-performance` 接口补读000922日线；请求失败保留快照。休市日或点位缺失时不以相邻交易日替代、不推算买点，图例提示缺失数量。修改工作簿或快照后重新构建面板。

红利信号使用V1连续加权评分：历史分位45%、绝对股息率30%、股息率相对10年国债的倍数25%。五个锚点之间线性插值，两端截断0～100；综合等级分界40/60/80，等级按原始精度判定，页面显示一位小数。各项当前值、子分数、权重贡献与计算依据均显示在红利页。

每日自动任务优先读取 `data/红利信号/strategy-settings.json` 当前策略；未应用自定义参数时使用技能的 `strategy-v1.json` 默认值。看板优先读取 `sources/automations/中证红利信号/评分记录.json`；没有结构化产物时从原Markdown兼容重算，并标为历史数据试算。首次本地快照保留实际数据日期，替代口径标为参考评分。缺失指标保留原权重，显示总分区间而不评级；日期不一致不参与连续确认。

“策略详情”开放全部数值参数：三项权重、打分锚点与内部得分、C/B/A分界、确认天数。参数修改时立即校验；合计权重非100%、锚点非递增、等级分界错误等情况下标出字段错误并禁止保存。端点0/100固定。已移除本地实时测算卡片，不再展示当前编辑参数对应的当日试算分数、分差和等级变化。

“保存本地参数”仅保存在当前浏览器当前站点，不改变每日任务、每日文件或总览卡片。“保存并应用到每日测算”经本地服务保存每日配置并同步浏览器参数，下一次每日运行开始使用；当前每日记录和旧历史保留原版本。恢复V1默认值先只改变编辑参数，要用于每日任务仍需点击应用按钮。启用新接口后需重新启动启动面板，直接双击HTML不能应用每日配置。浏览器存储不可用时只保留本次会话；更换浏览器或启动端口不保证共享。每日结果的连续确认默认3个实际交易日，依据有效评分记录和交易日历判断；证据不足明确提示。

参数尚未经收益回测验证。每日配置保留各版参数及应用时间，相同参数重复应用不重复升版；参数校验失败或版本冲突不覆盖配置。同日新版本测算仍保留旧版本的JSON/Excel结果，单次任务固定使用开始时取得的参数快照。

详细方法、数据口径和维护规则见 `.agents/skills/zzhl-dividend-signal/SKILL.md`，旧研究记录不用于证明V1收益更优。

## 评分规则

- 位置层 40%：上证指数 10%、沪深 300 15%、中证全指 15%。计算 `当前收盘价 / MA250 - 1`，再求所选 1/3/5/10 年窗口内的历史分位；买点得分为 `100 - 偏离分位`。
- 估值层 35%：沪深 300 TTM PE 12%、前瞻盈利收益率 10%、ERP 13%。TTM PE 越低得分越高；前瞻盈利收益率和 ERP 越高得分越高。
- 情绪层 25%：上涨家数占比 7%、涨停/跌停强弱 6%、全市场成交额分位 6%、融资余额变化 6%。先计算贪婪度，再以 `100 - 贪婪度` 计入买点评分。
- 单项缺失时不填 0、不估算，剩余有效权重自动归一化。
- 原始有效权重低于 70% 时，仅显示不完整试算，顶部结论固定为“数据不足，暂不判断”。

结论阈值、公式、原始权重、有效权重、分位、贡献、数据时间、抓取时间、来源和状态都显示在面板中。

## 数据来源与边界

| 数据域 | 本地代理来源 | 失败处理 |
|---|---|---|
| 指数历史行情 | 东方财富；不可用时切换腾讯行情；沪深 300、中证全指另有中证指数官网备援 | 独立快照或缺失 |
| 沪深 300 TTM PE | 中证指数官网 | 独立快照或缺失 |
| 中国 10 年期国债收益率 | 东方财富数据中心 | 独立快照或缺失 |
| 市场宽度、涨跌停、成交额 | 东方财富全量分页；不可用或响应不完整时切换新浪财经全量分页 | 独立快照或缺失 |
| 融资余额 | 金十数据公开汇总 | 独立快照或缺失 |
| 航天电子盘中行情 | 东方财富固定个股行情接口；不可用时切换腾讯行情；仅允许 `600879.SH` | 两个行情源均失败时，研报保留每日同步值并明确显示实时连接失败 |
| 沪深 300 前瞻 PE | 暂无满足公开访问和可核验要求的数据源 | 明确缺失；相关两项退出评分 |

本地代理只允许固定数据路由，不支持任意 URL 转发，也不监听局域网地址。本地文件只开放当前知识库的 `sources/`、`wiki/` 与 `workbench/` 三棵白名单目录；解析后的路径必须仍位于对应目录内，任何试图通过 `../` 越界到知识库根目录或其他位置的请求都会返回 404。为适应全市场分页请求，前端在本地模式下使用 60 秒超时并按数据域顺序刷新，避免免费上游的连接池拥塞。

2026-07-17 的实际链路验证中，腾讯返回 3000 条指数日线，新浪返回 5527/5527 条 A 股行情；最终有效覆盖率为 77%，评分能够形成结论。未达到 100% 的原因是前瞻 PE 按规则保持缺失，不是网络错误。

第三方免费接口仍可能变更字段、限流或暂时不可达。工具会在“数据审计”中记录真实失败边界，不会把请求失败解释为“市场没有数据”。

## 缓存与离线行为

每个数据域独立写入浏览器 `localStorage`。如果浏览器禁止本地文件持久化，工具会退回当前页面生命周期内的内存缓存。示例数据不会写入真实缓存；“示例数据”标记下的数值不能当作最新市场结论。
