# 股息率回测页 surface brief

- 模式：**Operate**。
- 范围：`src/index.html` 的 `#dividend-management-view`，及 `src/app.mjs` 的股息率回测、评分参数、回测汇总渲染与 `src/styles.css` 对应局部样式。
- 类型：既有界面的 distill / clarify；不是新产品、全站换肤或视觉身份替换。
- 依据：用户反馈页面太乱，并曾不理解回测汇总表列名与用途；其余约定来自现有实现。无 `PRODUCT.md`，未开展产品访谈或已确认用户研究。
- 视觉继承：[DESIGN.md](../DESIGN.md) 的本页蓝灰 token 与系统中文无衬线字体；补充响应信息见 [design.json](design.json)。

## 用户任务与完成标准

用户应能找到“读取Excel并回测”，读懂不同等级信号之后的指数表现；需要调整时再展开参数。首次阅读能够辨认每行分组、计入收益的样本数量、四项表现与来源口径；检查依据时能逐层展开完整信息。

## 首屏与流程

1. 保留“查看 / 股息率回测”页签。
2. 参数摘要默认折叠，展示当前参数概况和编辑入口。
3. 回测是主要任务：标题、简短用途、明确回测按钮与状态提示；无需先保存参数。
4. 完成后先展示截至日期、比较问题、可用/完成/待观察/缺价格概况与六列汇总。
5. 汇总后保留区间重叠、持有时长不同、指数表现不等于策略资金收益的边界说明。
6. 按需展开“怎么看这张表？”、“样本与数据检查”、“逐条信号与未纳入原因”、“计算口径与参数快照”；数据来源与验证边界保留独立展开入口。

编辑参数 → 用编辑值回测 → 比较结果 → 用户明确点击“保存并应用到每日测算”才触发既有应用流程。保存本地参数、撤销与恢复默认位于本地工具展开区；仍使用原有作用范围。

## 六列汇总与解释

| 字段 | 表达内容 |
| --- | --- |
| 等级与分位来源 | 同一等级、同一历史分位来源为一组；来源并入等级单元格，继续分别统计。 |
| 计入收益 / 全部 | 已计算收益的信号数 / 本组全部可用信号数；待观察与缺价格在同格次行注明。 |
| 平均收益 | 已计算样本的算术均值。 |
| 中位收益 | 已计算样本收益排序后的中间值。 |
| 上涨比例 | 最终收益大于零的已计算样本占比。 |
| 最大回撤 | 各样本计算期的最大回撤中最严重的一次，不等于最终亏损。 |

从原十列整合为六列只改变信息组织：来源、样本状态与四项表现均仍可见或可展开检查。高等级是否更好需要先比较同一来源，再看样本量、回撤与证据边界。

## 响应式与可访问性

- 大于 900px：六列表格，最小宽度 680px，数值右对齐；等级与来源左对齐。
- 701–900px：最小宽度 600px，单元格内边距 12px 8px；局部容器必要时横向滚动。
- 700px 及以下：同一份表格数据改为两列字段布局；表头视觉隐藏但仍在 DOM，单元格由 `data-label` 显示标签；空态跨两列。等级/来源与样本数量形成首行，随后四项表现按两列排列。
- 窄屏回测按钮占满可用宽度；权重与打分规则改为单列，等级起点保持两列；帮助定义列表改单列。
- 逐条信号是审计明细，保留其横向滚动，不把所有明细挤入首屏。
- “计算起止”放在最后；其余列提供排序按钮，综合等级/分数及指标值/子分数分别可选。SVG双箭头显示排序能力，选中按钮使用action蓝并突出当前方向，表头aria-sort说明当前方向；手机按钮最小高度44px。排序仅替换明细表，保留展开状态和横向滚动，焦点回到当前排序按钮。
- 数值按未舍入值排序；等级升序D/C/B/A，状态按显示文字排序。缺失值在两个方向均置后，同值保留原顺序；不改写回测输入、分组统计或计算口径。
- 原生折叠保持键盘展开与焦点；动态状态保留 `role="status"` / `aria-live`，忙碌状态保留 `aria-busy`。数值输入标签、只读和校验继续有效。

## 数据与行为不可变边界

- 不更改 Excel 和本地日线来源，不引入外部数据或新增网络调用。
- 不改变评分权重、锚点、阈值、确认天数的意义、校验、算法、分组或样本排除规则。
- 不改从记录日后首个交易日收盘进入、统一截至 Excel 最后交易日的既有计算口径；缺价格/待观察不填零。
- 不把收益字段改成资金策略收益、年化收益或独立样本结论；保留区间重叠与样本不足边界。
- 回测使用本次编辑值，仍不保存、不应用、不改写 Excel。
- “保存并应用”保留自动备份、重算、查看页刷新与每日任务更新；本地保存仍只作用于当前浏览器站点。
- 不删逐条记录、指标分项、未纳入原因、参数快照、原始来源入口或验证边界。
- 不将本页折叠次序和六列表格推广为全站设计规范。

## 维护检查

后续变更先确认：六列含义不变；手机仍是同一数据；表格读法就近可得；详细依据可展开；空值不伪装为零；键盘焦点可见；回测与保存应用边界清楚。此文档是实现提炼，不代替运行验证记录。

- 日期文案：逐条明细区分“信号估值日”和“收益起算”，独立“（假设）买入日”列显示实际entryDate并支持排序；末列“收益计算区间”，收益及回撤明确标为“信号后”，避免将信号日期误作收益起点。

- 假设买入日及买入价并排放在信号后收益前，entryClose以两位小数加“点”显示、按未舍入值排序；估值日期与评分列浅蓝，买入两列、后续收益、最大回撤、状态与收益计算区间共六列浅绿，同时文字说明分组含义。

- 买入价第二行显示“较前日”涨跌幅，以前一交易日收盘为基准；缺少前收盘显示破折号，不影响已具备价格的后续收益计算。

- 假设买入日标记“场外买入”，买入价标记“指数收盘参考”；未接入具体基金净值，保持指数收益及回撤的事实口径。
