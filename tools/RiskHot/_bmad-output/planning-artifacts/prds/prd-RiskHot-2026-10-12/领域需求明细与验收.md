## B. 统一术语与责任边界

| 术语 | 含义及边界 |
| --- | --- |
| 信源 / 来源信用 S | 获准接入的发布主体及其长期信用；不在每次事件分析时重算 |
| 原始资料 Information | 正文、附件及出处/时间；可支持零至多个事件 |
| 事件 Event / 更新 EventUpdate | 前者表示同一宏观行动或事实身份，后者保留进展、补充或纠正 |
| 事件的观测主体 Target | 事件分析中被观测、用于记录事件作用及变量变化的主体；与事件行为主体、风险观察对象分别表达（2026-10-12 用户确认名称） |
| 共享变量 Variable | 可复用的稳定因素定义；不等于某次指标数值，不固定归属一个 Target |
| 指标与观测值 | 支持变量判断的观测口径及数据；一个变量可有多个指标 |
| 金融意义 M | 事件在宏观观察范围和研究期限下的重要性；不是风险等级、行情方向或收益概率 |
| 纳管风险 MonitoredRisk | 具有稳定身份、定义、范围、机制和长期观察配置的风险，跨事件/周期存在 |
| 风险观察对象 / 潜在损害主体 | 风险判断针对的对象 / 可能沿机制受损的主体或系统，两者可不同 |
| 实际受影响主体 / 已发生损害主体 | 已有影响证据 / 已有损害事实证据；不得与潜在损害主体混用 |
| 风险源 / 风险维度 | 来源分类 / 分析维度；不直接给出当前风险等级 |
| 长期变量关系 | 变量在具体风险中的驱动、传导、缓冲、损害验证角色及成立条件 |
| 跟踪状态 | L1 的 observing / monitoring / paused / closed 跟踪安排；不是强弱或阶段 |
| 当前态势 / 风险快照 RiskSnapshot | 截至评估时间的程度、阶段、实际范围、持续性及解释和证据 |
| 变量当前状态 / 当前风险作用 | 依据指标/事件形成的运行时状态判断 / 结合具体风险机制解释的作用，不能直接互推 |
| 历史变化 | 与可比历史相比的方向和持续性变化；不等于当前状态 |
| 减弱节点 | 需支持与反证检验的减弱信号或候选节点；一次减弱不自动构成确认 |
| 有效快照 / 可比等级 | 可供消费的上游快照 / 统一规则口径下可比较等级；具体有效性规则待确认 |
| 风险列表 / 风险报告 | 动态派生查询 / 独立管理周期、内容、版本及发布状态的信息产品 |

词义依据：S0 §1—4；S1 §1、§3.4、§4；S2 §1、§3—4；S6 §3。D6 旧分域名称及变化用词与 L2 存在差异，本文按业务含义叙述，未裁决字段/枚举兼容方案（Q-12）。

## C. 产品能力与功能需求

### 4.1 可信信息与事件处理（L0）

本组把获准来源转换成可累积证据的事件；先判断身份与增量，再按需评价金融意义。

#### FR-001 信源准入与长期信用

按白名单、准入档位、启停和采集范围接入资料，保留发布主体、原始出处及可选长期信用 S。〔S0 §1.2、§2.2.1、§3.1〕

**完成条件：**未准入/停用来源不进入分析；已知转载能追溯原发布者；长期信用不因每次事件分析重算。准入细则及 S 量化见 Q-02。

#### FR-002 资料、版本与时间留存

保存正文/附件、来源、发布时间、采集时间和可定位出处，区分重复采集、增加来源及原文修订。〔S0 §2.2.1、§4.5.2〕

**完成条件：**同来源同版本重复抓取不产生重复业务更新；不同来源保留各自出处；未知发布时间为空，不用采集时间替代；修订关键数字后仍可查旧版。

#### FR-003 事件抽取与同一性

结合主体、行为、作用对象、时间范围和行动标识区分新事件或同一事件。〔S0 §2.2.2、§3.2〕

**完成条件：**一份材料中的独立决定分别成事件；计划/预期、已宣布、推进中及已发生事件均可保留，记录阶段及时间语义，不能把预计时间当实际发生；同一行动从宣布到落地保留身份及更新；相同机构/标题/关键词不足以合并；没有宏观事件时保留资料后结束。阶段不预设完整线性迁移。

#### FR-004 不确定归组与校正

无法可靠归组须保留依据并待判定/复核；新证据或复核导致合并、拆分时留审计。〔S0 §2.2.2、§2.2.4、§5.1〕

**完成条件：**不强行合并；一项待复核不阻塞其他独立事件；重新归组可回溯前后关系。身份迁移细则见 Q-03。

#### FR-005 对象身份与不完整关联

按名称/代码、辖区、类型和范围识别并复用 Target；不能将所有提及主体都视为作用对象。〔S0 §2.2.3、§3.3—3.4〕

**完成条件：**不同事件可共享 Target；对象不确定时允许为空；对象已知但变量未知时保留已知对象事实，不虚构变量。**待确认：**EventTarget 的正文要求与决策表“补充建议”存在状态差异（Q-03），此处不批准具体数据表。

#### FR-006 事件直接变量与候选

仅关联事件直接涉及、宣布改变或有来源支持变化的变量，先匹配共享定义，无定义时提出候选和依据。〔S0 §2.2.3、§3.4〕

**完成条件：**候选未审核不冒充正式 ID；不推导下游传导变量；变量不固定隶属 Target；所引资料属于该事件。候选治理遵循 FR-019。

#### FR-007 增量分类与动作区分

区分新事件、进展、实质补充、纠正、仅增来源、重复和无法判定，并分别处理。〔S0 §2.2.4、§3.5〕

**完成条件：**新事件有首条更新；进展/补充追加更新；纠正保留旧版本、追加纠正记录，并更新当前事件描述/展示状态；仅增来源默认沿用评级且不冒充实质进展，复评例外须先澄清 Q-04；重复不重复更新/通知；无法判定返回归组。

#### FR-008 金融意义与用途评价

在明确的宏观观察范围和研究期限下评价 M，说明投资、融资、投机情绪等用途，允许多用途或无法判断。〔S0 §2.2.5、§3.6〕

**完成条件：**用途不自动决定 M；M 不表达为风险程度、行情方向或收益概率；规则不完备时保留依据和限制，不伪造确定分数。

#### FR-009 复评与评级历史

初评及受新进展影响的复评须保留时间、规则版本及历史依据。〔S0 §2.2.5、§4.5.10〕

**完成条件：**仅增来源不触发虚构评级变化；影响依据的进展可复评；权重未确认时总分可空，保留维度/草案。五维、权重、锚点与阈值不能直接用原文试算值定案（Q-04）。

#### FR-010 L0 校验与交付

对事件及关系、更新、评级完成结构、引用、时间和幂等性校验，再保存并供检索和变更消费。〔S0 §2.2.6、§5.2、§6〕

**完成条件：**正式事件至少有一个可追溯来源；下游可定位原文；校验失败进入复核/重新处理；下游不能改写 L0 原始历史。通知名称、承载方式及重试策略未定。

### 4.2 风险识别与纳管（L1）

本组管理稳定风险身份和长期观察配置，判断风险存在及跟踪安排；当前风险状况由 L2 判断。

#### FR-011 一次形成完整候选

承接事件、有效更新或人工发起后，一次输出零至多个候选，包含稳定定义、机制、观察对象/范围、潜在损害、风险源/维度、关键变量、依据和不确定性。〔S1 §2.2.1—2.2.2、§4.6.1〕

**完成条件：**先完整定义再匹配；名称不含当前等级；允许无风险或待判断；一项待复核不阻塞其他候选；作用对象、观察对象、损害对象不机械复制，损害对象不明可空并说明。

#### FR-012 身份匹配与准入

以风险问题/潜在损害、观察对象及范围判断同一性；匹配成功复用身份，确属新风险且满足准入才创建。〔S1 §2.2.3、§3.2〕

**完成条件：**名称相同不足以合并；未检索到匹配风险不等于可以自动准入；范围部分重叠或机制冲突无法解释时待复核；新来源/事件不自动形成新风险。自动准入及最低条件见 Q-05。

#### FR-013 完整档案与一致交付

纳管须保留完整定义、潜在损害及机制/证据、长期变量与初始事件关联，由系统产生或复用正式身份和纳管时间。〔S1 §2.2.4、§4.3、§4.6.3〕

**完成条件：**不只存标题/摘要；身份、必要配置或初始关联不完整不交付 L2；AI 不伪造 ID；必要变量待审核时暂缓该风险纳管，其他独立风险继续。

#### FR-014 风险事件多对多关联

正式风险与事件多对多关联，保留理由、首次依据和通向原文的引用链。〔S1 §2.2.4、§4.5〕

**完成条件：**更新引用属于本事件；首次依据不被后续更新覆盖；重复输入不重复建相同关联；关联本身不代表风险加剧、减弱或解除。

#### FR-015 跟踪状态与风险结论分离

L1 维护 observing、monitoring、paused、closed 的跟踪安排；当前等级、阶段、变化由 L2 判断。〔S1 §1.4—1.6、§3.1、§5.2〕

**完成条件：**减弱或节点不自动关闭风险；关闭后出现线索先检查历史身份；恢复条件未定不默认自动恢复。进入、暂停、关闭、恢复及审批矩阵见 Q-05，本文不补状态机。

#### FR-016 跨层交接与维护反馈

向 L2 交付身份、定义/范围、损害解释、风险源/机制、长期变量、关联增量和跟踪信息；L2 维护线索反馈 L1 或共享治理。〔S1 §3.4.11、§5.2—5.5；S2 BR-L2-16〕

**完成条件：**新纳管、关联新事件、跟踪状态变化的业务原因可区分；未确认建议不覆盖定义；下游不擅改身份/范围/共享变量/长期关系；同输入不重复分发。协议和触发细则待定。

### 4.3 共享变量与知识治理

本组支持跨事件、跨风险复用因素定义，并保留各风险中的作用条件。初期采用 AI 提议、程序校验、人工审核。〔S1 §3.4〕

#### FR-017 共享变量检索与复用

联合名称、别名、定义、分类、范围、口径及替代历史检索，区分同义、上下层、范围差异与新因素。〔S1 §3.4.3—3.4.4〕

**完成条件：**同含义不因使用方不同重复创建；正式匹配使用有效身份；宽泛、歧义、废弃匹配需复核；相同候选聚合证据和提出历史；启用因素具定义/边界、分类及观测/分析口径。

#### FR-018 分类、分解与风险角色分离

分类、因素分解、具体风险关系分别表达；驱动、传导、缓冲、损害验证属于变量在具体风险中的角色。〔S1 §3.4.2、§3.4.7—3.4.8〕

**完成条件：**分类无循环；可独立分析的上层因素有自己的定义；不把同类/父子关系当因果；上层状态不自动由子状态平均、求和或投票；同证据和父子因素压力不重复计量。

#### FR-019 候选审核与并发查重

新增、别名归并、拆分、合并、重新分类和机制修订，初期须人工审核后生效，保留材料、原因、主体、时间和映射。〔S1 §3.4.5〕

**完成条件：**支持复用、新增、转维护、退回/暂缓、拒绝；落地前再次查重；实质变化不得沿用旧审批；候选不作正式引用；变量审核、风险准入、具体风险关系维护分别判断。

#### FR-020 变量生命周期与身份演化

Candidate 不正式引用，Active 校验适用性，Deprecated 留历史且不供新增引用；身份不回收用于其他含义。〔S1 §3.4.6、§3.4.10〕

**完成条件：**含义范围不变的维护保留身份并版本化；实质含义变化用新身份；拆分/合并保留替代关系；恢复重新审核；拆分不机械复制风险关系，变量合并不自动合并风险。

#### FR-021 版本还原与兼容复用

分析固定适用定义、长期关系、机制、证据及可获得时间；复用状态和比较历史前判断范围、口径、窗口、截止时间、版本与方法相容性。〔S1 §3.4.8、§3.4.10—3.4.12〕

**完成条件：**同 ID 不足以证明状态可复用；新版本/纠正不覆盖旧快照；当前任务锁定输入及版本，若改用新版本则须显式重分析；缺失、过期、冲突和不兼容不写为中性或零影响；必要条件缺失不冒充完整结果。

#### FR-022 因果知识的证据与治理

因果关系须表达方向、成立/失效条件、滞后及支持/反对证据，未经验证保持为假设。〔S1 §3.4.9〕

**完成条件：**相关、同类或同时变化不直接证明因果；单轮推断经治理才进入共享知识；不以循环自证或无限递推生成事实。存储和计算方式另行设计。

### 4.4 风险态势分析（L2）

先判断当前状态，再比较历史。证据不足、无基准和技术失败分别处理，不能统一输出为稳定。

#### FR-023 观察触发与准备

承接新纳管、有效事件更新、指标更新、定期观察和人工发起，先查处理记录，再固定风险、范围和截止时间。〔S2 §2.2.1、BR-L2-01〕

**完成条件：**重复请求不重复生成/发布同次结果；身份或引用失效先修复；无新闻或无新数据不直接判稳定。触发阈值、周期及暂停/关闭风险触发条件见 Q-06。

#### FR-024 按截止时间准备证据

取得适用变量/机制、观测值、必要事件及后续相关更新、历史基准和缺口，只用截止时间可获得材料。〔S2 §2.2.1、BR-L2-02/04、§5.1〕

**完成条件：**不得将指标定义当作实际观测值；指标证据充分时无须补充事件；有后续相关更新时不只读首次关联依据；宣布、预计、发生、发布时间和记录时间不混用；部分缺口可带限制继续，必需输入见 Q-06。

#### FR-025 变量事实与风险作用分别解释

先据指标/事件判断变量状态，再结合具体风险机制和条件解释本轮作用，保留证据、解释及不确定性。〔S2 BR-L2-03/05、§4.4.1；S1 §3.4.12〕

**完成条件：**指标方向不直接变风险方向；长期缓冲角色不保证当期已缓解；缺失/冲突不默认中性；无正式风险变量关系的候选不冒充快照正式明细；复用证据不重复计量。

#### FR-026 来源力量与应对效果

分析推动风险形成扩大的因素和传导条件，分别判断治理措施是否出现、实施及产生效果。〔S2 §2.2.2、BR-L2-06〕

**完成条件：**仅宣布措施进入条件展望，不视为缓解已实现；未显效不直接证明无效；措施规模不机械抵减风险；判断可定位变量或事件依据。

#### FR-027 两股力量比较

结合当前来源压力与有效应对，解释相对关系或无法判断的原因。〔S2 §2.2.2、BR-L2-06〕

**完成条件：**力量比较不替代风险等级、历史方向或持续性变化；不套用未确认抵减公式。来源占优、应对占优、大致均衡等属讨论方案，正式枚举和比较方法见 Q-07。

#### FR-028 影响与损害验证

分别说明观察对象、潜在损害主体、实际受影响主体和有证据的已发生损害，保留渠道和范围限制。〔S2 §1.5、§2.2.2、BR-L2-07〕

**完成条件：**局部损害不扩张成全系统损害；潜在损害不等于兑现；证据缺失不表示确定无损害；新主体/机制线索留痕反馈，不自动扩张纳管对象。

#### FR-029 四维当前状态

快照分别表达程度、阶段、实际范围、持续性；综合说明包含来源、应对、力量比较、损害验证、反证与限制。〔S2 §2.2.2、BR-L2-09/10、§4.3〕

**完成条件：**程度不由变量/措施数量或重复证据机械决定，未出现实际损害不自动等于低风险；阶段不替代等级，不预设线性迁移；规则或证据不足允许待判断；不新增已取消的独立可信度分数和兑现程度字段。分级及阶段规则见 Q-07。

#### FR-030 条件性持续展望

说明风险持续条件、有依据的时间/窗口，以及缓和、解除或延长的改变条件。〔S2 BR-L2-11、§4.3〕

**完成条件：**无日期依据时说明无法估时并保留条件，不编造结束日期；实施预期与见效时间分开；未来计划不冒充已发生效果。

#### FR-031 可比历史与方向变化

形成当前状态后，对同风险可比历史的程度、阶段、范围及依据作比较，独立判断加剧、维持、减弱或待判断。〔S2 §2.1、§2.2.3、BR-L2-12〕

**完成条件：**当前仍处于高风险，也可能较此前减弱；等级未跨档也可变化；首次无基准保留当前状态、变化待判断；定义/机制/范围实质变化时说明可比性限制。主基准、显著性和窗口见 Q-08。

#### FR-032 持续性变化

比较时间预期及持续/改变条件是否被证据实质修订，说明改变原因。〔S2 §2.2.3、BR-L2-13〕

**完成条件：**自然经过一天或剩余天数减少不独立构成预期缩短；仅条件变化不硬换算时间；无基准或不可比时待判断。正式枚举和条件冲突比较规则未定。

#### FR-033 减弱线索与下一轮重点

综合方向、持续性、驱动、应对及支持/反证识别信号或候选节点，保留后续验证变量、事件、条件和缺口。〔S2 BR-L2-14/16、§5.2〕

**完成条件：**单次减弱不自动确认节点；首次无基准不作确定节点判断；节点不自动关闭风险；维护线索交 L1。确认、失效和时间规则见 Q-08。

#### FR-034 一致保存、异常分流与消费

校验风险、时间、证据、变量关系和基准，保持快照、变量明细及附属变化引用一致；正式保存后提供消费。〔S2 §2.2.4、§2.3、BR-L2-15、§6.2〕

**完成条件：**数据/引用错误回准备，分析/比较问题回相应环节，机制问题交 L1；合法待判断与技术失败分开；变化分析失败而当前结果有效时保留可用结果并记录异常，不伪装稳定。能否单独发布当前结果见 Q-09。Timeline 只从可消费历史结果派生。

### 4.5 风险产品与发布（D6）

读取上游结论，提供三类列表及日、周、月报，不重新识别或评级。未定发布规则保留为条件性需求。

#### FR-035 最新风险列表

每风险只取最近一次有效快照，按评估截止时间倒序；无快照风险不参与该排序。〔S6 §3.3 A〕

**完成条件：**同风险多快照只出现一次；不以建档时间替代评估时间；最新评估不等于今日新增风险，后者按 L1 纳管时间。〔S2 §5.4〕

#### FR-036 最严重风险列表

以最新有效、可比等级按统一严重度排序；同等级按快照时间倒序，必要时用风险身份稳定顺序。〔S6 §2.3、§3.3 B〕

**完成条件：**空等级/不可比项单列待评估/不可比较；不兼容规则的等级不混排；D6 不重新评分。严重度和可比性见 Q-07、Q-12。

#### FR-037 完整目录与筛选

包含全部纳管风险，含 observing、monitoring、paused、closed 和无快照者，支持市场、风险源、风险维度、跟踪状态和风险等级筛选。〔S6 §1.4、§3.3 C〕

**完成条件：**暂停/结束跟踪及无快照对象不从目录丢失；无快照不伪造等级。默认榜单只含活动对象仅是建议，见 Q-10。

#### FR-038 展示解释、引用及时效

条目呈现名称/身份、观察对象、市场、跟踪状态、最新有效等级、变化、当前说明、评估截止时间和快照引用。〔S6 §3.1、§3.3〕

**完成条件：**可追溯风险与快照，并查看四维当前态势、变量状态/作用/证据和限制；历史展示能说明变化所用基准与原因。旧高等级同时呈现时间/时效，不冒充新判断；跟踪安排与风险状态分别表达。过旧阈值、有效性及空值展示见 Q-10。〔S2 §5.4〕

#### FR-039 日报、周报、月报

提供独立周期报告：日报汇总每日重要状态与变化，周报总结持续演化，月报总结整体格局及主要变化，保存周期、截止、栏目、内容和身份。〔S6 §1.3、§2.3、§3.1—3.2〕

**完成条件：**报告不是无身份/版本的实时列表；周期与数据截止可区分；可说明纳入原因。周期边界、时区、重要性门槛、纳入规则和生成时间见 Q-11，不由报告名推定自动调度。

#### FR-040 报告依据与内容一致

条目保留风险、当前/对比快照引用语义、纳入原因及摘要；生成内容接受结构、关联与上游结论一致性检查。〔S6 §2.5、§3.1〕

**完成条件：**不重定级或改变上游结论；能定位实际引用结果；缺基准时不伪造对比快照。字段必填性和无基准条目能否纳入见 Q-11，不从模型图补推。

#### FR-041 发布、撤回与版本

报告独立管理内容版本和发布状态，具有发布与撤回的业务能力。〔S6 §3.2—3.3〕

**完成条件：**身份、版本及发布状态可区分并可核对内容来源。**条件性需求：**发布前置条件、审核职责、状态迁移、修订、冻结/替换、撤回规则未给定；Q-11 未决前不能宣称本项具备完整验收标准，也不批准自动发布。
