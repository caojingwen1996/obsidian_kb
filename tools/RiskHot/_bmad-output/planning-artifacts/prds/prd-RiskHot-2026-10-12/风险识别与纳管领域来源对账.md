## 已修复发现（保留审查历史）

### 1. L1 能力组引言误将当前风险判断归入 L1

- 位置：`领域需求明细与验收.md` §4.2 引言，L123；影响 FR-011—016。
- 当前：本组“分别判断风险存在、跟踪安排与当前风险状况”。
- 来源：S1 §1.5—1.6，L72、L80–82；§4.3 L773。L1 负责稳定定义、准入与跟踪安排，变量当前状态和风险当前状态由 L2 判断。后文 FR-015 与 NFR-07 已正确说明，属于组引言与正文不一致，而不是需求整体越界。
- 最小替换：**“本组管理稳定风险身份、纳管与长期观察配置，并维护跟踪安排；当前风险状况由 L2 判断。”**
- 严重性：应修正，防止按能力组分工时误派当前态势判断。

### 2. “变量当前状态”不宜直接定义成“观测事实”

- 位置：`领域需求明细与验收.md` §B 术语表，L47；关联 FR-021、FR-025。
- 当前：“变量当前状态 / 当前风险作用｜观测事实 / 结合风险机制解释的作用”。
- 来源：S1 §3.4.1 L485–503 区分因素、指标/实际值和事件证据；§3.4.8 L612–625 将变量状态定义为“L2 依据证据形成运行时判断”，并要求范围、时间、依据与不确定性。核心因素可能依赖多项指标或定性证据，状态不是未经分析的原始事实。
- 最小替换：**“依据观测证据形成的因素状态判断 / 结合具体风险机制与条件解释的当前作用；两者不能直接互推。”**
- 严重性：应修正概念，避免把“美元流动性偏紧”等分析判断当成原始事实重复引用。FR-025 的先判断状态再解释作用本身没有问题。

### 3. 配置更新不应强制所有执行中任务重新分析

- 位置：`领域需求明细与验收.md` FR-021 完成条件，L193。
- 当前：“执行中版本更新须显式重分析”。
- 来源：S1 §3.4.10 L659 及 §3.4.12 L689：当前任务保留已经锁定的输入版本；生效更新供后续任务使用，只有当前任务需要采用新配置时才显式重新分析。
- 最小替换：**“执行中保持已锁定的输入版本；需要采用新版本时显式重新分析，不在同一结果中混用新旧定义。”**
- 严重性：应修正限定条件，避免将来源的版本一致性约束升级成“任何配置变更都中断所有运行任务”。

- FR-012/013、Q-05 保留风险自动准入和最低观察条件未决；FR-019 明确人工审核的是共享变量治理，没有错误要求所有风险/L2 结果均人工批准。（S1 §1.6 L82、§2.2.3 L277–297、§3.4.5 L563–580）
