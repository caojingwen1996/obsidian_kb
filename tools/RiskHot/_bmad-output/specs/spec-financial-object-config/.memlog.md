- (direction) 用户要求先写功能设计文档：新增可手工维护的金融对象配置表及配置中心，观测对象从配置目录筛选建立观察；本轮不实施代码、迁移或页面。
- (direction) 用户已确认系统共享一份观察清单，不按个人维护，也不自动为每个用户复制观察记录。
- (note) 输入为本轮用户文字与目录树截图；截图体现分层组织，但研究主题/入口不能直接当成金融对象。
- (constraint) 项目要求功能设计正文进入docs/system-design/03-系统功能架构，BMAD摘要留在规格工作区并采用正文为伴随契约，不另复制一份正文。
- (note) 现有L0 §3.3定义Target为从事件识别核定的金融观测对象；information.target被跨事件复用，EventTarget保存具体事实关联。刚完成页面当前亦支持直接手工写Target，本需求要求收拢该职责。
- (decision) 区分金融对象配置项、事件Target、系统共享对象观察记录；观察引用配置对象稳定身份，无事件时也可建立观察。
- (decision) 采用一个逻辑配置目录承载目录节点与对象条目；目录组织不等于金融包含关系。对象条目可选来建立观察，目录节点与研究主题/入口不可选。
- (constraint) 沿用六大业务分类与现行一级/二级配对规则；截图中法定货币/货币性资产可作为组织目录，不静默替换既有分类口径；不恢复已被撤回的Target分类表。
- (capability) CAP-1：维护树形金融对象配置目录，支持新增/编辑/移动/排序，禁止循环、孤儿及将对象作为目录父节点。
- (capability) CAP-2：手工配置金融对象的名称、别名、金融分类、辖区、范围、状态与版本，草稿不供选择，完整启用后供观察选择。
- (capability) CAP-3：通过配置中心搜索和核对同名对象，保持跨事件稳定身份；同名不同范围不自动合并，完全重复条目需复用或人工处理。
- (capability) CAP-4：在内容侧从启用的具体配置对象添加系统共享观察；可多选，一项对象仅一份共享观察，重复请求不重复建档。
- (capability) CAP-5：共享观察支持观察中/已暂停/已结束、恢复及历史审计；无事件不是失败或禁止观察的条件。
- (capability) CAP-6：依据已核定配置对象到事件Target的同一性映射展示关联事件，数量与明细采用全部来源权限，默认允许查阅已有历史事件。
- (capability) CAP-7：事件提取继续保存Target与Fact/证据；无配置匹配不阻断Event保存，也不自动创建配置对象或共享观察；人工补齐配置与核定映射。
- (capability) CAP-8：配置停用阻止新观察/恢复，正在观察的项目转为配置停用导致的暂停；重新启用后需显式恢复，保留原先手工暂停/结束状态。
- (capability) CAP-9：配置版本变化保留历史引用；身份范围变化建立新对象，不能把既有事件/观察静默改成另一对象；同身份定义澄清需要人工确认观察采用版本。
- (capability) CAP-10：配置维护、观察管理、事件核定与只读职责分别授权并审计，目录/表单/选择器提供明确空/失败/冲突状态。
- (decision) 建议同一身份与范围的配置对象与正式事件Target建立零或一对零或一的已核定映射；历史重复或多义映射作为冲突处理，不能为凑数量自动归并。
- (decision) 首版关联动态只包含核定的直接对象身份映射，不因目录父子、共同分类、关键词或经济常识扩大事件范围。
- (decision) 暂停/结束观察不停止F01/F02采集与事件保存，不冻结或删除事件历史，也不产生风险消失的结论。
- (constraint) 本轮只定义逻辑配置、观察与映射关系，不确定物理表名、SQL、索引、接口路由、模块编号或新AI任务编号。
- (decision) 正文必须记录现有直接写Target页面的待改造方向、存量盘点/映射/回退要求，并不把已配置或已抽取对象自动视为已观察。
- (assumption) 本稿建议观察管理沿用授权操作职责，普通读者只读；具体权限标识在技术设计中确认。
- (question) 待功能评审确认：允许哪些身份内定义澄清直接生效，哪些必须暂停并确认采用；本稿按影响观察口径时暂停待确认处理。
- (question) 待技术/UI设计确认：配置逻辑对象、共享观察与核定映射的物理存储、权限标识及入口路由；默认不扩展为自动抓取、通知或风险分析。
- (decision) 交叉校验补充：Target可在候选/Fact核定阶段形成，不要求Event已保存；对象移动不改身份，但若进入未启用分支须先确认影响，再暂停观察，新增AC-31。
- (event) 自校验第一轮（连贯性）：10项能力均有intent/success，非目标与共享范围明确；修复目录移动进入未启用分支和观察状态不变之间的冲突；状态、范围与当前实现边界一致。
- (event) 自校验第二轮（需求保全）：用户的配置表、独立配置中心、树形组织、从目录筛选建立观察及系统共享要求均已进入正文与规格；截图主题/入口保留边界说明；31项验收连续唯一，双链/锚点、UTF-8通过；src摘要与编写前一致。
