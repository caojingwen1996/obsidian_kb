## 执行结果

执行 `pnpm test:e2e --reporter=list`：**3 个场景通过，0 失败，13.0 秒，退出码 0**。使用本机 Chrome、独立 `riskhot_e2e` 数据库和 4312／4313 测试端口。测试记录为合成夹具，不写开发库。

| 场景 | 验证内容 | 结果 |
| --- | --- | --- |
| B-01 | 首次登录、资料→事件→纳管→观察分析→审核→报告发布、导出及撤回 | 通过 |
| B-02 | 错误密码、正常登录退出、手机导航和布局 | 通过 |
| B-03 | 配置／策略分区及下表全部检查 | 通过 |

| B-03 检查点 | 操作与断言 |
| --- | --- |
| 分类边界 | 配置目录只有风险源、风险类型、市场分类和模型接入；没有宏观对象或评估规则入口 |
| 定位与返回 | 风险类型使用 `?view=dimension` 直达，刷新保留选择；策略子页返回恢复评估规则 |
| 固定表单类型 | 从“新建风险类型”进入，无跨类型选择器；保存后的真实记录 kind 为 dimension |
| 条件字段 | M 评分显示权重；减弱确认显示确认条件与校准证据；时效显示小时数；等级规则显示等级顺序 |
| 切换清理 | 故意输入无效权重 JSON，再切换类别；旧错误解除，提交载荷没有 weights 或 max_hours 残留 |
| 服务端纠错 | 重复等级代码被后端拒绝并展示错误；修正后能保存为规则草稿 |
| 规则审核 | 编辑可读回原类别和等级；批准后保留原 ID，状态为 approved；编辑按钮消失，停用入口出现 |
| 模板独立 | 分析模板只显示名称、编码、用途和模板正文等相关字段；真实保存为 prompt |
| 既有记录 | 原货币条件风险源、流动性类型、经济体和政策利率变量仍能在各自新入口读取 |
| 无效入口 | `/config?view=rule` 回退到配置中心默认风险源，不在配置页显示策略记录 |
| 数据入口 | 数据管理能发现观测数据导入入口 |
| 手机布局 | 390×844 下四个页面无整页横向溢出；长表格在自身区域横向滚动；侧栏底部账号与退出入口可达 |
| 页面运行 | 无未捕获的浏览器页面错误 |

首次执行 B-03 发现手机页面横向溢出，原因是表头隐藏的“操作”标签脱离表格滚动容器定位。为新页面表格容器设置相对定位后，重跑全部三个场景通过。

`pnpm typecheck`、`pnpm build`、`pnpm verify:boundaries` 均通过。构建未产生契约或生成客户端的版本差异。本次为前端页面修改，没有改动领域命令或数据库结构，没有重跑后端 46 个场景或 Temporal 演练；此前结果仍保留在原报告中。
