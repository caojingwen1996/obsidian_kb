## 已观察到的差异与解释边界

- S01旧领域属性将relation_note记为可空；S02当前存储设计和S03 SQL要求非空。该差异是材料现状，不新增“统一完成”的结论。
- S02要求引用正式主体和变量；S03未声明target_id/variable_id到正式字典表的直接外键。S04按有效定义集合核验并保存快照，不能由缺少直接外键推断应用完全未校验定义。
- S03仍有event_target及依赖它的关系表，S04仍分两步提交主体/变量关系。现有代码不能通过只删除DDL中的一张表完成提案。
- S02明确本轮未提及关系不等于删除旧关系；因此“零新增”与“清空历史关系”必须分开评测。
- 独立主体关系消失导致按主体查询漏出该事件，是基于提案的数据可表达性推导；不是已测得的线上故障。
- ETV-012和ETV-015是未决规则题，不伪造唯一标准答案。全部预期由本次整理生成，尚未由用户逐例复核。
