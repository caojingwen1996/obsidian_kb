## Platform

web

## Product Purpose

RiskHot M1 信源管理中心原型用于查看和维护信源，并按用户要求提供 L0 信息接入任务入口与监控页面。任务监控呈现概览、异常和执行详情。

## Operating Context

现有本地 HTML 原型使用示例数据，刷新重置。用户确认本次扩展沿用现有浅色绿色风格，并提供统计卡片、抓取状态及信源概览参考截图。

## Capabilities and Constraints

信源管理与任务运行职责分离；M1 提供监控及任务启停入口，当前启停仅模拟本页状态；实际接入归 F01，调度与重试归运行侧。新增监控页面不发起真实网络采集。保留既有目录、编辑、启停与历史行为。

## 时间批次统计口径（2026-10-24，当前生效）

按用户澄清，任务以计划执行时间对应的接入批次为主体，一个批次可包含多个信源；此前按单信源组织任务的说明由本节取代。

列表按计划时间倒序展示日期时间、任务编号、批次状态、完成信源数、异常信源数与已确认保存资料数。查询按开始/结束日期、批次状态及任务编号组织；四项概览仅按所选计划日期范围统计任务批次、运行中批次、含异常批次和待执行批次。一个批次内多个信源异常仅计一个异常批次，运行中批次也可能含有异常。

信源名称与各自六步进度移入批次详情，不作为任务列表的主键或分组维度。开启、暂停与继续作用于批次中的待执行/运行项，已完成结果与既有失败记录保留，计划时间不因手动开启而修改。所有启停仍仅本地模拟。

专项验证按新口径重新编写：33项检查覆盖当日5批次、跨日6批次、时间倒序、日期异常、批次异常去重、多信源详情、批次启停及权限/离线/重置。当前四张列表与详情截图以本轮为准；此前信源口径的暂停/确认截图仅为历史产物，不用于当前验收。页面异常与外网请求为0。
