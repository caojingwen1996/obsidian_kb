# M1 信源管理中心 · 交互原型说明

## 信源数据维护

- [[tools/RiskHot/src/data/source-catalog.js|信源清单]]：40条信源的稳定标识、名称、网址、等级、分组及关注内容，从《金融信息》信源章节整理。
- [[tools/RiskHot/src/data/source-demo.js|信源演示配置]]：六维分类、初始启停与技术接入预设、示例使用关系；仅供原型演示，不代表真实业务状态。
- 原型按顺序引用以上两个共享数据文件，再由 `app.js` 生成当前页记录；信源数据在 `src/data` 维护，原型资源目录不保留副本。新增、编辑和启停仍只改变本页内存，刷新或重置重新读取共享数据。

## 体验步骤

1. 统一信源目录中所有40个条目均已登记；可搜索名称、发布主体或稳定编码，按分类和启用／停用筛选。
2. 默认专题研究，按钱的数量、钱的价格、钱的流向组织；搜索、筛选与四个视图按钮合并在同一工具区。点击“全部”按唯一信源平铺，隐藏树和展开／收起操作；搜索筛选继续生效。也可切换信源等级或日常监测，无须先手动选择主题。金融属性、观察层级、关注优先级逐层缩进并有连接线，分类可展开、收起，当前结果一次展示全部；数量按身份去重。
3. 直接打开任一条目查看档案、技术接入、使用关系和变更记录，无再次登记步骤。FRED 也是在册条目，辅助查询仅为用途，不统一认定为 T1。
4. 选择停用来源后启用，或选择启用来源后停用，理由选填，未填也可确认，操作时间、操作者及状态变化仍记录。没有暂停或恢复入口；再次启用不自动补采。
5. 管理员可编辑在册资料；未在册的新来源使用“新增信源”，保存后直接纳入同一目录、默认停用。查重仍防止编码冲突和同源重复。
6. 预览设置可切换角色、加载／空／失败／离线、保存失败／版本冲突／响应未知；未知结果先查询，避免重复提交。

## 示例与边界

- 40个入口沿用旧配置清单，均赋予演示身份和编码。初始仅2个示例启用，其余停用，便于体验两态管理；不表示这些真实来源已获实际授权。
- 六维分类、依据、引用和技术结果仅为演示配置。新增默认停用，普通编辑留版本，主体／范围／关键依据变化提示重核验，定位变化提示技术复检。
- 默认管理员兼启停权限，也可切换只读研究员、管理员或启停人员。
- 技术就绪独立；L0 检测、采集、补采和真实跨模块业务未接入，显示说明。来源链接只在主动点击时打开。
- 修改只保存在当前页内存，刷新或重置恢复示例。旧静态图为历史，以当前原型及[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/EXPERIENCE|交互契约]]为准。

## 目录操作归属（2026-10-22）

“新增信源”与“展开全部／收起全部”位于列表标题行右侧，顶栏保留面包屑和预览设置。手机将操作组放到数量下方；平铺视图继续隐藏分组操作，新增沿用管理员权限。详情与弹窗操作不变。


## L0 信息接入任务监控（2026-10-24）

信源目录上方新增“信源目录／L0 信息接入任务”工作区入口。任务页支持 `#intake-tasks` 直达、刷新和浏览器返回；切回目录保留目录筛选及选中信源。

- 参考用户截图的信息布局，沿用确认的浅色绿色风格；不复制截图中的实时计数。
- 活跃信源数读取当前在册记录；运行中、异常与近期计划来自固定任务快照，页面明确标注示例。
- 任务按名称或编号、执行状态、信源组合筛选；异常提示和信源概览可联动筛选。
- 执行详情逐项展示 F01 六步进度、本次结果及后续处理。仅已确认保存的资料显示数量，未知显示“—”。
- 预览设置支持正常、加载中、空记录、读取失败、无权限及离线；失败不显示虚假的零任务统计，离线保留快照提示。
- 任务启停按演示角色授权，操作仅改变本页状态；刷新状态重读本页数据，刷新页面或重置示例恢复初始值，不执行真实采集或调度。历史任务不随当前业务启停改写。

实现文件为独立的 `intake-monitor.js` 与 `intake-monitor.css`，复用当前信源目录和全局预览场景；原有目录脚本保持不变。业务依据为[[tools/RiskHot/docs/system-design/03-系统功能架构/F01 信息接入与标准化模块功能设计 V2.1|F01 六步接入流程]]；验证记录见[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/验证/L0任务监控验证记录|L0 任务监控验证记录]]。


### 任务启停补充（2026-10-24）

按用户反馈补充任务行及详情中的“开启任务／暂停任务／继续任务”。待执行任务可以开启或暂停，运行中任务可以暂停，已暂停任务可以继续；已完成记录不提供重启按钮。开启或继续前核对信源业务启用、自动接入与技术就绪，缺少条件时禁用按钮并说明原因。

操作使用页内确认，取消不改变状态并恢复触发按钮焦点；确认时再次校验权限、读取状态、信源条件及任务状态。暂停保留步骤，继续从原步骤恢复，尚未开始的任务开启后进入资格核对。统计、筛选结果、详情和本页操作记录同步更新。

管理员＋启停权限、启停授权人员可操作；只读研究员和仅资料管理员不显示任务启停控件。离线不可操作。权限与运行回执仅为原型演示，不代表后端授权机制已经实现。


## 时间批次统计口径（2026-10-24，当前生效）

按用户澄清，任务以计划执行时间对应的接入批次为主体，一个批次可包含多个信源；此前按单信源组织任务的说明由本节取代。

列表按计划时间倒序展示日期时间、任务编号、批次状态、完成信源数、异常信源数与已确认保存资料数。查询按开始/结束日期、批次状态及任务编号组织；四项概览仅按所选计划日期范围统计任务批次、运行中批次、含异常批次和待执行批次。一个批次内多个信源异常仅计一个异常批次，运行中批次也可能含有异常。

信源名称与各自六步进度移入批次详情，不作为任务列表的主键或分组维度。开启、暂停与继续作用于批次中的待执行/运行项，已完成结果与既有失败记录保留，计划时间不因手动开启而修改。所有启停仍仅本地模拟。

专项验证按新口径重新编写：33项检查覆盖当日5批次、跨日6批次、时间倒序、日期异常、批次异常去重、多信源详情、批次启停及权限/离线/重置。当前四张列表与详情截图以本轮为准；此前信源口径的暂停/确认截图仅为历史产物，不用于当前验收。页面异常与外网请求为0。
