# M1 目录操作区优化验证

日期：2026-10-22。

## 修改与依据

用户指出三个目录按钮紧跟面包屑导致导航与操作混杂。按 Impeccable Operate 模式就近分组：顶栏保留位置与预览；去重数量位于列表标题行左侧，展开／收起为次操作，新增为右侧唯一实底主操作。移动端操作组在数量下方自然换行。

修改现行 HTML、ui-v2.css 和共用 top-actions.js，后者仅增加 data-local-actions 的就地保留支持。未修改 M1 业务脚本、来源数据及 M2/M3 原型。共用标题规范、设计规范和交互说明同步 M1 例外，不把例外扩展到其他页面。

- 共用迁移与领域展示夹具：82 项通过，含就地按钮保留、监听、反复同步、弹层表单归属和 M1/M2 权限状态；此套不验证浏览器布局。

- 桌面与手机截图已目视检查。截图来自本地原型真实渲染，见目录操作区截图/1440.png和390.png。

- Impeccable布局检测只有既有dialog内边距提示，本次新增操作组未报布局问题；未扩展为既有弹窗重设计。
