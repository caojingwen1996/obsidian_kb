按用户截图移除页面大标题、目录标题及其说明，新增按钮移到搜索工具区。JS语法与Chrome桌面1440／手机390检查通过：旧标题元素不存在，40条数据仍可读取，新增窗口正常打开，无横向溢出和页面异常。此轮未重复全量24项交互回归。

## 默认专题展示（2026-10-13）

初次打开、重置均默认专题研究；无金融属性筛选直接分组展示全部信源，不再提示先选择。可选筛选仍缩小范围，未分类保留待补充分组；多属性重复分组按唯一身份去重。JS语法和24/24交互回归通过，零异常和自动外网请求，已保存桌面与手机默认画面。

## 金融属性与分层修订（2026-10-13）

金融属性只保留钱的数量／钱的价格／钱的流向；旧风险偏好、资源配置不转成其他属性，保留为空并归待补充。树增加逐层缩进、维度标签、父子连接线及三级底色／字重。现有M1-UI-04增加三项筛选枚举、层级横向位置递增与父级折叠子级隐藏检查；24/24回归通过，零异常及自动外网请求。截图：[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/验证/三属性分层-1440.png|桌面层级]]、[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/验证/三属性分层-390.png|手机层级]]。
