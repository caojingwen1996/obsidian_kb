## 首轮问题与修正

首次 20/24，通过记录保存在[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/验证/原型验证结果-首次.json|首次验证结果]]。

- 多个筛选面板同时打开遮挡条件标签：改为同一时间只展开一个，增加“完成筛选”和外部点击收起；测试按正常关闭步骤移除条件。
- 专题多属性筛选的测试预期误计为 5，实际是 6 个唯一身份：修正断言，保留多组重叠与去重口径。
- `FRED` 检索也会命中 `Freddie Mac`：测试明确选择 FRED 条目，保留正常子串搜索。
- 官方账号参考条目未提供直接 URL：详情补充原清单已有核验入口，登记测试明确填写材料定位后确认预填。

目视检查后主从列表和详情改为独立滚动，底部操作常驻；提交未知时锁定表单及重复检查，查询后只确认一次身份。修正后 24/24 再次通过。
