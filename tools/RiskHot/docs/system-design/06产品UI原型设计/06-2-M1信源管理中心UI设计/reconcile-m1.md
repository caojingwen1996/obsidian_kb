# 信源管理中心页面与功能职责对照

本表是 [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/EXPERIENCE#页面功能与操作主责映射|统一页面契约]] 的反向追踪，说明功能由谁负责、在哪个页面呈现、操作交给谁。页面都在信源管理中心，业务主责仍分别归M1、F01、S01。本轮仅修改文档，新增页面和命令尚未实现，不扩大旧原型验证范围。

## 编号与范围

- 页面统一用`UI-M1-xx`；原页面S号与当前页的迁移关系见 [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/EXPERIENCE#编号命名与旧号迁移|旧号迁移表]]。
- 模块用`M1`、`F01`、`S01`；功能一律完整写出模块前缀，不再用裸F号指代M1功能。UI-M1-02、UI-M1-03已退役，不作为功能落点。
- 页面编号仅标识界面承载位置；表中列出接入/运行功能不代表新增M1业务功能。一个页面组合多个模块时，各模块保留原数据与命令主责。

## 同页操作的受理分流

| 用户动作 | 页面承载 | 命令/事实主责 | 协作约束 |
|---|---|---|---|
| 新增/编辑信源、启用/停用 | UI-M1-05、UI-M1-07 | M1 | 不修改S01计划/运行，不替代F01在途校验 |
| 查看技术状态 | UI-M1-04 | M1-F09只读，结果来自F01 | 不因连接失败自动停用 |
| 检测连接 | UI-M1-04 | F01-SF01.02，S01提供执行 | 不将检测写成M1业务动作 |
| 配置接入任务和正式计划 | UI-M1-16 | F01校验接入参数；S01维护任务/计划 | M1建议频率不是正式计划 |
| 补录资料、历史补采 | UI-M1-14、UI-M1-15 | F01校验/保存；S01受理运行 | 真实信源与证据必须有效；历史取得时间不伪造 |
| 重试、补交付、取消运行 | UI-M1-17 | S01执行控制；F01提供业务资格/回执 | 补交付不重采，取消不删除已保存事实 |
| 查看运行与业务结果 | UI-M1-09～UI-M1-13 | S01运行信息→F01业务监测→中心展示 | 页面不自建任务状态；运行/业务/交付分层 |
| 业务复核决定 | UI-M1-13中定位原业务事项 | 原领域命令；S01只投影与唤醒 | 通用确认/已读不能代替批准 |
