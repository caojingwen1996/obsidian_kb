允许来源的指标与在途任务数量尚未取得，不视为 0。以下为确定的处理规则。

  • 新采集

    暂停期间不再启动该信源的新采集。

  • 在途响应

    L0 提交时重新校验状态；暂停后的响应可留待查，不继续分析。

  • 历史证据

    已保存的资料、证据与结论保留，历史来源版本仍可追溯。

  • 后续恢复

    恢复需重新核验，不会自动补采；补采需另行进入运行计划。

理由将与操作人、时间、前后状态及版本一起留存。

确认时重新校验权限及当前版本；失败不改变业务状态。
