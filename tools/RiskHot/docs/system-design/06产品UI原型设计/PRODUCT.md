# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

系统管理员按操作授权维护定义，授权阅读者查询资料与历史。M1原型中的管理员/启停人员/研究员为演示权限组合；不据此新增正式业务角色。

## Product Purpose

M1管理信源档案与使用资格，M2管理风险源/变量/指标/风险类型的共享定义，M3管理协作策略、AI分析定义与版本评估。三个中心为L0～L3提供横向支撑，不代替业务事实拥有模块或运行基础设施。

## Operating Context

现有三套本地静态HTML/CSS/JavaScript交互原型，无真实服务端、持久化或模型调用。刷新还原演示数据。三中心采用本地相对链接互通。

## Capabilities and Constraints

用户2026-10-16明确将重构范围扩展到M1、M2、M3。先规范，再改界面，只重构UI。业务数据及处理逻辑保留；后续M3 C01允许调整展示函数，按函数及事件区段核对，领域数据文件逐字节保留；字段、状态、权限、校验、版本、候选处理、启停、在途锁定及评估结果不变。业务源文档不修改。

M1保持工具区合并、四视图、无重复大标题、六段档案、960px详情抽屉、结果未知处理。M2保持三个目录入口、候选列表与审核抽屉、AI观测逐项审核后统一入库、指标嵌入变量详情及既有暗色适配。M3保持三个工作区、系统/场景分层流程、6:4及独立紫色AI。

## Brand Commitments

继承已完成M3视觉：绿色品牌、深绿导航、白内容面及暖灰背景；AI使用紫色，区别系统绿色。中文专业治理工具，保留各模块不同任务组织。

## Product Principles

- 来源、共享定义、策略各自拥有明确职责，正式业务事实仍归对应领域模块。
- 视觉一致不改变任务流程；未知、未决、失败和历史引用应如实表达。
- 以原有回归断言与文件哈希核对业务不变，视觉检查单独记录。
