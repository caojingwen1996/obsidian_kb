## 设计假设与14项未决

| 原编号 | 本次 UI 处理 | 后续确认 |
|---|---|---|
| D-M3-01 | 页面仅使用原型内存对象 | 正式领域对象、表、DSL/JSON |
| D-M3-02 | 用草稿/审核中/已生效/已停用演示 | 正式状态枚举 |
| D-M3-03 | 单策略单范围一个生效版，明确为假设 | 灰度、A/B与范围冲突规则 |
| D-M3-04 | 使用后继选择，不虚构表达式语言 | 可引用字段、表达式及校验 |
| D-M3-05 | 保留AI-01与分层编号 | 全局编码规范 |
| D-M3-06 | 普通演示Prompt可看，修订仅为草稿 | 存储、敏感内容权限、发布流程 |
| D-M3-07 | 展示逻辑工具许可 | 与运行侧真实Tool权限映射 |
| D-M3-08 | 展示演示模型/版本和比较限制 | 配置引用、实际模型和路由绑定 |
| D-M3-09 | 构造案例均注明演示 | 金标、来源与维护责任 |
| D-M3-10 | 指标口径示例，无正式达标阈值 | 公式、方向、适用项和版本 |
| D-M3-11 | 生效人工确认，不按评分自动判断 | 是否强制最近评估与最低门槛 |
| D-M3-12 | 生产运行区域独立且未接入 | 反馈自动归集和层次划分 |
| D-M3-13 | 不擅自增加M2 AI任务编号 | M2策略与任务是否纳入首版 |
| D-M3-14 | 页面按较新的M3范围设计，保留差异说明 | F02/F08边界同步总览 |

## 演示数据声明

系统全景与六条分场景业务步骤按总览及四份领域文档整理，十六项AI职责及专属Prompt依据领域任务定义，剩余15项另借鉴AIHOT第6章提示词的方法与表达；Prompt仍是待评审的原型基线，未完成模型质量评测或正式发布。Schema字段片段依据领域逻辑字段整理，未定包装及规则保留待定；具体版本、状态、时间、运行记录、评估指标、Skill、案例及操作人均为 UI 演示构造。`DEMO-*`、演示模型 A/B 和 @1.0 资产不是生产注册对象。94%等指标不是 RiskHot 实测质量。
