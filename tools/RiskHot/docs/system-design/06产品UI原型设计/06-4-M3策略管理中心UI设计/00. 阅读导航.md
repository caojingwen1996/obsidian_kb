## 评审边界

这是一套 UI 设计与可操作演示，不代表 M3 已开发完成。真实模型执行、权限鉴权、持久化、并发治理、完整 Schema/规则验证、自由拖拽画布均未接入。策略版本、案例、指标和运行数量为明确标注的示例。

设计保留业务文档中的待定事项，不擅自确认发布门槛、指标公式、灰度策略或任务对象结构。生产实现应按功能对照逐项验收，而不能用原型检查替代系统验收。
