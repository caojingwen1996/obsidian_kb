# 流水线独立只读子菜单

日期：2026-10-16。按用户要求将“业务流程全景”更名“流水线”，移至策略管理中心子菜单，与三个管理工作区并列。目录及详情的全景入口已移除，菜单独立选中。

## 修改文件

- M3策略管理中心交互原型.html：流水线子菜单，沿用原panorama动作。
- 原型资源/app.js：删除重复入口，更新标题/选中/导航；流水线视图的系统及场景均只读。
- 原型资源/styles.css：清理旧入口样式，手机底部改四列，修正选中子项悬停高亮。
- 规范、交互说明、导航和验证同步；根交付检查维持前后哈希链。

领域数据flow-data.js逐字节一致。原事件处理仅增加菜单导航分派条件；治理与数据写入处理不变，初始数据仅剔除已授权的只读条件差异后逐字一致。[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-4-M3策略管理中心UI设计/验证/流水线子菜单业务保护.json|业务保护证据]]明确记录变化，不声称app.js全文件未改。
