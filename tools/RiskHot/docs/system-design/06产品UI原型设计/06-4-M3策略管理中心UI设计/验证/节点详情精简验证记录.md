# M3 全类型节点详情精简

## 修改内容

承接 AI 节点的精简风格，覆盖 PROGRAM、CONDITION、HUMAN、START、END、MODULE 六类节点。只保留一个主标题和独立职责摘要，删除重复执行职责、阶段与节点编码小字、重复的规则引用标签和通用技术说明。节点输入输出、规则、全部流向、缺失出口提示和关键配置继续呈现。人工节点保留“处理人：系统管理员”，以及批准、退回、暂缓或已有业务出口。

文档依据改为默认折叠，展开可查原文件与章节；待确认事项继续直接显示，避免被折叠隐藏。正文、字段标签、流向和规则为14px。标题悬停可查看所属阶段。节点配置按原角色、版本状态限制编辑。

## 修改文件

- `原型资源/app.js`：节点详情与来源依据展示。
- `原型资源/styles.css`：精简详情排版。
- `验证/节点详情精简验证.mjs`：六类型与桌面/手机专项检查。
- `验证/原型交互验证.mjs`：原业务层小字断言改为标题悬停信息断言。
- `DESIGN.md`、`02. 交互原型说明.md`、`EXPERIENCE.md`：补充现行规则。
- 项目 `index.md`、`log.md`：导航与维护记录。

## 复验

在M3原型目录执行：

```bash
node --check 原型资源/app.js
node 验证/节点详情精简验证.mjs
node 验证/AI任务内嵌验证.mjs
node 验证/原型交互验证.mjs
python3 验证/检查文档.py
```

专项脚本可额外传入修改前原型目录，以核对HTML、flow-data.js和写入处理指纹。本次基线为 `/var/folders/hh/5jrmgmsx377fsl_56cz7q13w0000gn/T/riskhot-nodes-before-9_wsoj0o`。
