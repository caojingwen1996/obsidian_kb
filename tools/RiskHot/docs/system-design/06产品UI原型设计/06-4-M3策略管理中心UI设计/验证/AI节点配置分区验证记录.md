# AI节点配置与流向分区

## 变更

将原来固定显示在五个Tab下方的节点说明改为独立的“节点配置与流向”折叠区，默认收起；输入输出业务说明只放在输入输出Tab。上游映射显示真实前驱节点的输出参数到当前输入参数，下游映射结合既有条件与后继节点显示当前输出到下游输入；继续保留汇合依赖、规则和来源。当前仍使用原型已有的context级参数，不补造字段级映射。

折叠区内复用原节点表单。切换Tab不重建表单，也不改变折叠状态；切换AI节点或策略版本恢复默认收起。已生效版本及阅读角色仍只读。输入输出Tab保留C02通用上下文与Schema，并展示当前蓝图已有的输入/输出说明，不写入共享AI任务资产。

## 修改文件

- `原型资源/app.js`：复用原表单，新增独立折叠区与上下游映射展示，调整输入输出Tab。
- `原型资源/styles.css`：折叠入口、映射行及区块间距。
- `验证/AI任务内嵌验证.mjs`：补充默认收起、状态保持、映射与定义分区、编辑和窄屏检查。
- `验证/原型交互验证.mjs`：调整到达折叠区的操作，保留业务断言。
- `DESIGN.md`、`02. 交互原型说明.md`、`EXPERIENCE.md`：当前交互规范。
- 项目`index.md`、`log.md`及本验证记录：导航和变更记录。

## 验证结果

- AI专项102项通过，覆盖五Tab、默认折叠、展开映射、参数变更后同步、角色、版本及六种屏宽。
- 原有交互93项通过；其他节点专项60项通过。
- 非AI页面11组逐像素对比一致；HTML、flow-data.js、原始共享任务与策略数据、权限条件、完整性校验和全部表单写入处理指纹一致。
- 人工检查桌面默认收起、输入输出Tab、展开态及手机截图；五Tab和折叠入口可用，无横向溢出。
- JS语法、文档链接与编码检查通过；浏览器JS错误和外网请求均为0。
