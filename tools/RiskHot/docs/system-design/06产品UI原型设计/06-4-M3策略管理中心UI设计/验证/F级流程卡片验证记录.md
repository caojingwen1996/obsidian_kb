# F级流程卡片与折叠验证记录

用户提供流程卡片参考图，要求将F级模块改为同类卡片并支持收起。依据既有RiskHot Knowledge项目上下文和F01～F08职责分工，在当前浅色RiskHot界面中采用模块卡头、描边、连接箭头及虚线分支容器。

## 修改文件

- 原型资源/system-panorama.js：为L0～L3补充八个模块展示分组，按实际模块归属整理节点，不修改业务后继或Step编号。
- 原型资源/app.js：模块details/summary渲染、折叠状态保留、跨模块定位自动展开；连接箭头只对应实际相邻后继，条件箭头显示判断结果。
- 原型资源/styles.css：模块标题、步骤范围、展开/收起方向、焦点和响应式样式。
- 验证/流水线全景验证.mjs及结果JSON：增加模块完整性、实际渲染唯一性、折叠与跳转状态、原业务图对照检查。
- 交互原型说明、EXPERIENCE、DESIGN、项目index.md与log.md：同步交互与维护记录。

## 交互

默认八张卡片均展开。点击卡头或Enter/Space切换开合，收起后保留模块编号、名称、说明及Step范围。折叠状态仅保留在当前页面会话；角色切换和工作区往返不清空，刷新页面还原。

从右侧后继跳转到已收起的模块时，先展开目标卡片再选中步骤。手机查看详情后“返回当前步骤”同样展开所属模块并恢复节点焦点。两种角色均可折叠浏览，全景始终只读。
