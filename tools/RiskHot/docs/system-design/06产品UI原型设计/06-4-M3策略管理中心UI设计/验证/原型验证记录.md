# M3 UI 原型验证记录

## 验证结论

2026-10-15 使用本机 Chrome 和 Playwright，从本地文件打开原型。**91 项交互检查通过，0 个页面 JavaScript 异常，0 个外部网络请求。** 完整断言名称与结果见同目录 `原型验证结果.json`；可复验脚本为 `原型交互验证.mjs`。

这仅验证原型交互，不是 M3 业务系统验收，也不是安全或性能审计。真实模型、数据库、运行调度、权限系统及后端未参与。

## 总览及领域文档校订

本轮按用户指定以系统功能架构总览和L0～L3领域设计为业务主依据。新增系统端到端只读全景，并独立整理6条场景流程；原67项交互检查按真实节点关系调整，并补充14项来源、逻辑依赖与未决项检查，共81项通过。

`检查流水线依据.mjs`另外核对7套蓝图、122节点和5份来源文件，覆盖来源字段、ID唯一、后继存在、入口可达、布局无遗漏、关键分支和汇合依赖，结果见`流水线依据检查结果.json`。已目视系统全景与L2领域依赖截图；逻辑并行不代表实际调度已实现。

## 6:4比例与执行主体底色

按用户要求调整为桌面左侧流程图60%、右侧详解40%，扣除栏间距后比例为6:4；手机仍纵向排列。程序浅蓝、AI浅绿、人工浅橙、条件浅紫；选中时保留角色底色，右侧摘要同步着色。更新宽度断言，新增程序/AI底色及选中人工节点底色检查，83项交互检查通过。

## 分层重构

桌面保持6:4，系统全景改为L0～L3阶段容器，横向治理独立呈现；场景按业务环节分组。次要路径默认折叠，右侧跳转自动展开；导航定位及右侧层级标签已检查。更新流程页样式、阶段展示元数据与渲染，九组业务图校验及原交互继续通过。新增8项分层/导航/隐藏路径检查，总计91项；来源校验另检查所有122节点在阶段中无遗漏且不重复。

