## 侧栏查看只读流水线

点击侧栏与“策略管理中心”同级的“流水线全景”，直接查看RiskHot整个业务流程；M1和M2提供同级直达入口。全景独立选中、顶栏同步名称，地址#panorama支持刷新定位。顶部不再提供流水线选择、策略版本切换、完整性检查或返回策略目录工具；通过侧栏切换工作区。具体策略及历史版本仍在“策略设计与管理”中查看和维护。

全景按L0～L3展示118个业务节点及M1/M2/M3横向治理。L0接入、事件与评级28步；L1识别及纳管13步；L2当前状态与历史变化27步；L3查询产品与报告发布13步。每层从Step 1重新编号，A/B/C表示同一步内的分支；分支内多项处理用“.1、.2”区分。展开模块后可查看主流程及条件出口，不再收起为笼统的“其他路径”。

分层导航可定位各业务层；程序、AI、条件和边界节点均可点击，右侧展示输入、产出、文档与实际流向。逻辑可并行的分析保留真实汇合依赖，首次/不可比、无具体风险、重复与待复核保留各自语义。查询与报告按需要或请求进入，撤回属于后续独立授权动作。M1/M2/M3治理跨层复用，不编号为L3之后的必经阶段。

F01～F08分别组织为八张可折叠流程卡片，默认收起。收起时卡头仅显示F编号、模块名称和展开箭头，高度48px；隐藏说明文字、Step范围和“展开”文案，并缩小卡片间距。实际相连的模块卡片之间仅显示连接箭头，不显示“按业务条件交接”文字；各层底部不显示“交付”标题和产出汇总说明，层间只保留连接箭头与紧凑留白。点击标题或用键盘Enter/Space展开后显示说明及具体步骤，桌面卡头同时显示Step范围；同一页面会话中切换角色、离开并返回全景保留折叠状态。卡内保留步骤、真实连接箭头、条件分支及独立出口。右侧跳转到收起模块中的步骤时自动展开目标卡片。

L0～L3仅以12px弱化的单行分组标签显示，不再展示层级说明段落或步数统计；描述保留在标题悬停信息中。首次进入不预选隐藏步骤，右侧先显示“展开模块并选择步骤”的提示。

桌面左60%为流程、右40%为固定详情；手机点击步骤后定位到下方详情，使用“返回当前步骤”回到选中位置，并展开所属模块。全景复用六条原有业务蓝图并补充总览定义的F01、F07与横向治理，组合数据位于system-panorama.js；策略节点及业务写入规则保持原实现。

## 体验路径一：设计一条协作流水线

1. 在策略目录筛选 L2，打开“风险状态分析策略”。
2. 查看 V2.0 草稿；左侧显示依据领域文档整理的逻辑并行、汇合和条件出口，默认选中结果结构与引用检查节点。点击程序、AI、条件和交接/暂停节点，右侧同步显示职责、输入输出、规则及路径。
3. 点击 AI 节点，右侧原地展示引用任务的“任务定义、Prompt / Skill、输入输出、工具与约束、引用与版本”五个标签，默认任务定义。内容来自 C02 的固定版本，始终只读，无需跳转；输入输出定义集中在对应Tab；下方“节点配置与流向”独立折叠，默认收起。
4. 展开右侧“节点配置”，在草稿中把某条后继设置为“未配置”，应用配置后切到“版本治理与生效”，点击“提交审核”，观察阻断结果。
5. 恢复后继，或刷新页面重置；再检查完整性。
6. 使用“添加节点”体验新节点未连接的校验状态。新建策略和复制策略都不会直接生效。

## 体验路径二：版本治理

1. 打开风险状态分析的 V2.0 草稿，进入“版本治理与生效”，点击提交审核，填写说明并核对影响。
2. 提交后版本进入审核中，节点不可继续编辑。
3. 点击“审核并生效”，查看当前生效版本、新运行影响和在途任务版本。
4. 确认后进入“规则与 AI Task 引用”，验证 DEMO-RUN-017 仍锁定 V1.2。
5. 使用“创建新修订”，检查原生效版本保持只读；历史页保留原因和操作记录。
6. 可在生效版本的“版本治理与生效”中执行“停用版本”，不会删除旧定义或自动回退到历史版本。

所有治理变化均为本地内存演示，刷新还原。说明至少5字是本次 UI 输入规则，不是来源文档规定的业务门槛。

## 体验路径三：AI任务与评估

1. 进入 AI 智能分析管理，按编号搜索任务，查看 Prompt、输入输出、约束和使用关系。
2. 创建任务修订，编辑 Prompt 和有效 JSON 示例；保存为 @1.1 草稿后，@1.0 内容和策略引用保持不变。
3. 进入策略评估，查看固定 V1.2 / V2.0 结果，可加入 V1.0，或预览模型不一致的比较限制。
4. 筛选退化候选，打开“风险变量身份歧义”，查看输入、执行路径、输出、校验和人工结果。
5. 在评测集中创建新修订，然后查看历史记录仍引用 @1.0。
6. 新建评估请求会引用新评测集版本，状态为“等待运行”，不会调用模型或生成新评估结果。
7. 切换右上角“授权阅读者”，检查新建、修改、审核和生效按钮不可用。

## AI 任务内嵌详情

- 适用于侧栏“流水线”的六条场景和策略设计中的“流水线编排”。
- 点击节点只替换右侧详情；切换任务标签只更新任务正文。左侧选中、折叠及滚动状态保留，右侧 AI 详情可独立滚动。切换标签不会丢失尚未应用的节点配置。
- 切换节点或策略版本后，任务详情回到“任务定义”。程序、人工、条件及边界节点沿用原详情。
- 以任务编号和节点固定版本查找 C02 定义。找不到时显示“引用版本不可用”，不回退到最新版本或草稿。
- “引用与版本”按各策略版本的实际节点引用列出使用关系，内嵌模式仅查看；C02 保留独立修订入口。
- 任务标签支持方向键、Home、End；窄屏折行显示五标签，详情区域可键盘滚动。
- 当前 C02 仍是 @1.0 的原型定义。16项任务的Prompt / Skill和输入输出已按L0～L3逐项补充。输入输出提供字段表、来源与待定项及可展开的输出Schema片段草案；Skill与占位技术映射仍待设计，Schema未确定的包装、必填、枚举及嵌套结构明确标注待定，尚不构成完整运行契约。

## 交互边界

- 流水线使用可选择步骤、条件分组和后继配置，不支持拖拽、缩放、自由布线或删除节点。
- 系统全景与六个场景分别据总览、L0～L3文档整理；源码中没有按AI任务清单拼接六份通用尾部。场景步骤是业务蓝图，实际DSL、调度与调用方式仍待设计。
- 固定版本比较只展示三个版本和三个代表案例，不执行任意策略计算。
- 新评测集修订可以记录新增案例，但不形成真实外部快照仓库。
- 工具许可、指标口径和大部分任务定义为展示设计；任务发布流程待确认。
- 角色预览不提供真实鉴权；无持久化、远程调用、模型运行、服务端审计或并发控制。

## 2026-10-16 · AI 详情精简

AI 详情只保留一个节点主标题，移除阶段小字、重复任务标题、来源解释和重复执行职责；任务编号与固定版本合并一行，保留只读标记。内嵌任务定义去掉重复的分析问题与模型调用说明，保留完成标准、分析步骤和后续处理。正文为14px，收紧摘要、标签及区块间距。五标签、节点映射与流向、独立滚动、固定引用和权限规则保持；C02 独立页面仍显示完整任务说明。任务名称可在编号悬停提示中核对。


## 2026-10-16 · 全类型节点详情精简

程序、条件、人工、开始/结束及业务模块节点沿用 AI 详情的单标题与简洁分区：去掉阶段小字、重复执行职责、节点/后继编码小字和通用配置说明；保留独立摘要、输入输出、所有流向、规则与节点配置。阶段信息可悬停标题查看。人工节点显示处理人及获授权的处理出口；缺失后继和待确认事项继续显式提示。

## 2026-10-16 · AI任务定义与节点配置分区

AI节点的输入输出说明集中在“输入输出”Tab，与C02上下文及输出Schema一起查看。说明沿用现有业务蓝图，Prompt、Skill、Schema和固定任务资产仍复用C02；不新增或修改共享任务数据。

五标签区域之外只保留一个独立的“节点配置与流向”折叠入口，默认收起。展开后展示上游输出到本节点输入的映射、当前输出到下游输入的映射及分支条件、必须汇合的依赖、规则引用和文档依据；草稿编辑表单也收在该区域中。原先的“需要什么输入／产出什么”说明不再在公共区域重复出现。

映射按已保存的节点参数和真实连线展示，当前原型仍为简化的context级映射，不推断字段级契约。切换Tab保留折叠状态和未提交表单；切换AI节点或策略版本重新默认收起。非AI节点维持现行简洁详情。

## 2026-10-23 · 直接展示任务定义原文章节

全景节点与 M3 目录的“任务定义”直接展示 L0 §6.1.1～§6.1.5 对应章节中的“分析职责与步骤”，按原文有序列表显示；保留章节原文跳转。任务定义不展示任务编号、触发条件、输入输出字段、交付边界或附注；输入输出仍在独立标签查看。
