## 系统端到端流水线全景

默认全景按L0～L3分层展示F01～F08，主要模块与交付物优先，业务条件和其他路径可展开；横向支撑及跨层输入单独标注。右侧展示职责、输入输出、规则、来源文档及章节；该架构视图只读。可切换六条分场景业务流水线。
