## 业务边界

M2 维护共享定义，不提供风险源推荐变量前置清单；全局变量跨风险复用，角色由 L1 的具体关系管理。指标实际值属于 L0，风险当前状态与作用属于 L2，判断方法属于 M3。候选治理不自动建立风险或长期观察关系。

八类风险源及四类风险类型的名称、编码、核心问题沿用功能基线；具体定义文案、变量、指标、版本和引用均为明确标记的演示记录。正式权限、持久化、并发治理及跨模块生效未接入，设计交付不代表产品批准或业务系统验收。
