# M2 风险源管理中心 · 交互原型说明

[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/M2风险源管理中心交互原型.html|打开原型]]。直接用浏览器打开，无需服务端；保留同级“原型资源”，图标、样式和脚本均本地加载。

## 体验步骤

1. 在“风险源目录”查询八类宏观基线，正式风险源默认可用，无启用／停用操作、状态标识和状态筛选；点击条目查看定义、核心问题、同层父分类及边界。首次打开直接显示八类风险源，系统预置，无需用户初始化。四类风险类型同样直接预置。
2. 切换“全局变量库”，变量详情显示对应字段标签：逻辑字段、后端数据、原型扩展或界面计算；标签不代表全部已定版物理表字段。按 Active／Deprecated 筛选；别名、定义、范围都可搜索。未分类的定性变量仍能查询，废弃变量保留替代说明与历史。
3. 点击“进入候选审核”打开列表，支持名称搜索、审核状态及提议来源筛选；默认待核对、每页20条，可选50／100条。点击行内“审核”打开详情抽屉，去掉横向候选按钮；关闭按钮、Esc或点击外侧关闭后，列表条件、页码和滚动保留。先审核“离岸美元融资条件”，范围不同阻止直接复用；关闭后在列表审核“美元资金可得性”，可填写理由确认等价，正式变量数量不增加。未提交输入按候选保留，更换对照项须重新确认。
4. 对候选可选择复用、新建、转维护、退回、暂缓、拒绝。记录结论更新背景列表，抽屉保持打开，可点击“审核下一项”在当前搜索及筛选范围内连续处理。身份已确认且观测待补时可继续审核，身份结论不能重复提交；获批／拒绝的单项结论只读。审核理由与人工核对确认必填；原材料保留。接受新变量只产生 DEMO 演示身份，不自动纳管风险。
5. 在“关键指标”查看统计对象、范围、单位、频率、时间规则、允许来源与逐条映射解释。“居民消费价格指数”展示一指标映射两个变量，以及允许来源停用的独立缺口；不是实时数值或风险评分页。
6. 风险源、指标和风险类型点击“新增定义”使用弹框录入；可保存草稿或校验后提交审核。取消、关闭、Esc或点击遮罩可关闭，背景目录和筛选保留，焦点回到新增按钮；校验失败保留弹框与输入。手机弹框表单单列，底部操作保持可达。从定义详情选择“修订定义”，保存草稿或校验并提交审核；顶部“修订审核”可重新查看当前定义与提议差异，当前生效定义不被覆盖。变量主要从AI分析进入候选，本页没有手动新增变量按钮；审核可接受候选为新变量。
7. 首版移除“使用关系”标签及独立变更影响查询。定义详情仅保留“定义与边界”“历史版本”；维护反馈仍可从详情底部进入。
8. 在“历史版本”选择 v0.9 查看演示旧定义；当前版本保持不变。维护反馈按缺口类型记录建议主责方，本原型不会真的发往其他模块。
9. 在手机宽度体验单列目录与详情、顺序对照及审核。保存失败校验保留表单输入；返回目录保留筛选。详情选择在窄屏会定位到详情区域。

## 示例与未接入范围

- 初始 8 个风险源、5 个演示正式变量（4 Active、1 Deprecated）、3 个指标、4 个风险类型、3 个候选。身份以 DEMO 开头；候选没有正式 variable_id。
- 所有正式变量／指标、数量、引用与历史为演示夹具；风险源和类型的详细定义也是 UI 文案示例，不代表已批准的生产配置。
- 原型在当前页内存保存。刷新恢复基线，未使用数据库或自动外网请求。聊天版的宿主设计调节不是保存版必需依赖；保存版默认紧凑密度。
- 页面提供变量身份与逐项观测结论模拟、新指标定义独立确认、草稿与差异查看、维护反馈；没有真实审批权限、版本冲突处理、原子发布、变量拆分合并执行、在途阻断或跨模块接口。
- 候选首次观测方案支持本地演示审批、来源选择与映射生效，正式指标详情可查看获批关系；尚无完整关系维护编辑器和真实 M1 查询；“缺口反馈”只形成演示维护记录，不发送消息。不能将本地交互检查当作后端验收。

## 首次观测配置体验

1. 在“离岸美元融资条件”确认“接受为新变量”，自动进入“2 · 观测方案”；也可在身份确认前查看 AI 建议，审批控件此时不可用。
2. 查看美元融资利差建议，分别核对映射解释、范围及局限，选择确认并填写理由、勾选本项核对。其余建议仍保持待审。
3. 对新调查指标先展开并确认定义与允许来源，再确认其变量映射；两项提交独立。允许来源停用、新指标尚无正式身份、指标版本变化或变量失效会阻止新映射确认。
4. 可暂缓或退回某项并关闭抽屉；列表将变量身份设为全部，按观测方案待确认／部分确认筛选，再点击“继续审核”。输入、正式身份、获批项和缺口保留。
5. “美元资金可得性”选择复用后沿用已有映射，额外调查指标仍需审核。“政策沟通一致性”提供事件证据方案，可独立确认，不强配量化指标。

所有新增身份、来源、审核人员、材料版本及关系均为演示数据，刷新恢复基线；没有真实 AI 调用、数据采集或后台发布。
