## 源资料差异保留

- 旧“风险源推荐核心变量”和固定变量树不作为本版前置要求，采用最新 L1 的全局字典与动态选择原则。
- M1 两态启停不直接套用到变量 Candidate／Active／Deprecated；修订待审状态也不替代变量生命周期。
- 来源启用不等于 L0 已接入；实际观测值不进入 M2 指标定义表单。
- 审批权限、指标／分类状态枚举、发布方式仍待定；受控申请不能冒充已实现生效流程。
