# M2 首版原型验证记录

执行日期：2026-10-15（Asia/Shanghai）。本轮先修改业务规则，再移除风险类型启停标识与使用状态筛选；正式类型默认可用，保留搜索、修订及历史版本。

## 当前结果

- 风险类型默认可用，列表及详情无启用／停用标识，列表仅标注版本；使用状态筛选已移除，旧页面保存的类型状态筛选不隐藏定义。风险类型名称搜索、定义修订和历史版本检查通过，桌面与390px手机页面已目视，手机无横向溢出。
- 已先修改主功能文档 §4.3.3 审核-02／04／05、单页约定、§4.4.2 来源说明与相关验收，再实现原型；“来源与缺口”改为“数据来源与待解决问题”，“变量处理与统一确认”改为“变量审核”。
- 待核对候选未分配正式身份时即可审核指标／事件证据。指标审核区域只保留审核通过／审核不通过，移除单项暂缓、退回、更多处理及独立重新审核按钮；两种结论均须理由，通过还需人工核对；新指标定义与来源先单独审核，全部结论留在候选内，不提前创建正式变量、共享指标或映射。
- 每项均通过／不通过且至少一项通过后，点击“确认变量及观测指标”统一入库；待审、空方案及全不通过均阻止新建。候选退回、暂缓或拒绝不必先完成指标审核，也不创建档案。
- 提交前复查材料、指标版本和来源、变量名称／别名重复、新指标名称及等价关系；任一失败无部分建档。仅通过项入库，不通过项保留记录；定性事件可独立满足首次观测要求。重复提交不重复建档，定义通过但适用关系不通过不会生成孤立指标。
- 入库前用原有通过／不通过按钮重审单项，新定义核对入口位于数据来源列，历史保留；入库或候选处理后只读。关闭重开保留输入与候选内结论，列表可按待审核／部分审核／待统一确认查询。
- 201／201 项本地交互检查通过，零 JavaScript 异常、零自动外网请求。脚本语法、文档链接与业务规则检查通过。覆盖两个审核按钮、旧暂缓／退回注入被阻止、原按钮重审、最终版本／来源冲突、重复提交、无方案和全部不通过，以及既有目录、维护、分页保护。
- 已目视桌面审核按钮与统一提交、390px手机卡片及底部提交按钮；320px表单无横向溢出。截图调整等待布局绘制后再捕获，避免窗口缩放时原生抽屉的瞬时绘制残影；19张现有截图文件数量不变。
- 本次为页面内存演示，刷新恢复基线；真实AI、M1查询、权限、数据库事务、幂等并发、持久化与跨模块接口未接入。本地校验不代表真实业务系统验收。
