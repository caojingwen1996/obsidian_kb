# M2 关键页面示意

以下页面采用同一套本地原型资源，可点击查看；截图来自保存到 RiskHot 后的原型检查。当前演示交互以[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/M2风险源管理中心交互原型.html|完整交互原型]]为准。

## 风险源目录与定义详情

[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog.html|打开目录示意]]：四类定义同级入口，风险源列表配定义、核心问题、边界和历史版本。风险源默认可用，无启停按钮／状态标识或状态筛选；没有推荐变量子表。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog.png|风险源目录桌面]]

## 候选与语义治理

[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-governance.html|打开候选治理示意]]：候选表格提供名称搜索、状态／来源筛选与分页，列出名称、来源、范围、提交时间、状态及审核操作；点击行内审核打开详情抽屉，无横向候选按钮。列表条件和页码保留，详情比较定义、范围、粒度，可连续审核当前筛选范围内下一项。

## 手机布局

侧栏收起，目录和详情上下排列；候选列表纵向显示字段，筛选及分页仍可用。点击审核打开全屏详情抽屉，候选材料、匹配变量、差异、处理动作按顺序呈现。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog-mobile.png|手机目录]]

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-governance-mobile.png|手机候选治理]]

## 新增定义弹框

风险源、指标和风险类型的新增操作共用原生弹框；变量候选主要由AI分析流程提出，本页不提供手动新增按钮。背景列表与筛选保留，桌面居中；表单内容滚动，标题和底部操作保持可达。手机为单列弹框，关闭后回到新增按钮。修订示意仍对应详情中的修订工作区。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/new-definition-desktop.png|新增定义弹框桌面]]

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/new-definition-mobile.png|新增定义弹框手机]]

## 观测指标建议与独立确认

候选抽屉内先确认变量身份，再逐项审核观测方案。已有指标显示口径与来源；新指标先确认定义与允许来源，再确认映射。暂缓和退回保留已确认身份及观测缺口，定性变量可确认事件证据方案。
