# M2 关键页面示意

以下页面采用同一套本地原型资源，可点击查看；截图来自保存到 RiskHot 后的原型检查。当前演示交互以[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/M2风险源管理中心交互原型.html|完整交互原型]]为准。

## 风险源目录与定义详情

[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog.html|打开目录示意]]：风险源、变量、类型三个同级入口，风险源列表配定义、核心问题、边界和历史版本。风险源和风险类型默认可用，无启停按钮／状态标识或状态筛选；没有推荐变量子表。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog.png|风险源目录桌面]]

## 候选与语义治理

[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-governance.html|打开候选治理示意]]：候选表格提供名称搜索、状态／来源筛选与分页，列出名称、来源、范围、提交时间、状态及审核操作；点击行内审核打开详情抽屉，无横向候选按钮。列表条件和页码保留，详情比较定义、范围、粒度，可连续审核当前筛选范围内下一项。

## 手机布局

侧栏收起，目录和详情上下排列；候选列表纵向显示字段，筛选及分页仍可用。点击审核打开全屏详情抽屉，候选材料、身份处理、逐条指标审核按顺序呈现。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-catalog-mobile.png|手机目录]]

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/mockups/key-governance-mobile.png|手机候选治理]]

## 新增定义弹框

风险源和风险类型的新增操作共用原生弹框；变量候选主要由AI分析流程提出，本页不提供手动新增按钮。背景列表与筛选保留，桌面居中；表单内容滚动，标题和底部操作保持可达。手机为单列弹框，关闭后回到新增按钮。修订示意仍对应详情中的修订工作区。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/new-definition-desktop.png|新增定义弹框桌面]]

## 观测指标建议与独立确认

候选页先核对资料，再在五列表格逐条审核指标与事件证据，最后统一确认变量及通过配置。新指标定义、来源和适用关系分别在候选内审核，提交前不建档。待审项阻止新建；空方案或全不通过保留缺口。定性事件证据通过即可参与统一确认。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/governance-observation-desktop.png|单页指标审核桌面]]

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/governance-observation-mobile.png|单页指标审核手机]]


## 变量内指标查看与维护

顶层不再提供“关键指标”tab。变量详情的“观测指标”按映射显示共享指标，点击“查看与维护”打开弹框；可分别提交共享定义、允许来源或当前变量映射的维护材料。当前定义与关系在审核前保持不变。

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/variable-indicator-desktop.png|变量内共享指标详情桌面]]

![[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/验证/variable-indicator-mobile.png|变量内共享指标详情手机]]
