# M2 页面与交互契约

> **首版范围调整（2026-10-14）**：按用户要求，使用关系及独立依赖／变更影响查询移出第一版。M2-F18、AC-M2-22 保留为后续版本追踪；当前界面只提供定义与历史标签。


依据 [[tools/RiskHot/docs/system-design/03-系统功能架构/M2风险源管理中心功能设计|M2 功能设计]]。方案为会话生成的 UI 设计，本次按用户要求保存到项目；功能与审批待定项没有因保存动作而获批。实现差距见 [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/reconcile-m2|功能对照]]。

首版直接预置八类风险源、四类风险类型；没有初始化预览按钮或初始化工作区，后台预置另行验证。

## 设计选择

比较了三种组织方式：

| 方案 | 优势 | 代价 |
| --- | --- | --- |
| 同级目录＋列表与详情（采用） | 延续 M1；分类、变量、指标、类型边界清晰；连续查阅快 | 候选审核在抽屉中连续处理，复杂修订使用独立工作区 |
| 六能力平铺为一级页面 | 功能查找直接 | 治理与历史与对象割裂，页面跳转增加 |
| 以关系网络作为主入口 | 可以探索映射关系 | 容易混淆分类、因果与实际使用；不适合首版治理 |

采用四类定义同级导航，全局变量内嵌候选治理入口；新增定义通过弹框完成；候选通过列表搜索、筛选和分页查找，点击审核后在侧边详情抽屉内比较与处理，背景候选列表保留；定义修订仍在完整工作区展开，历史从对象详情进入。不同业务对象使用各自的状态语义。

## 视觉摘要

- 背景 `#f5f5ef`；纸面 `#fffef8`；正文 `#233b34`；次级文字 `#647067`；分隔 `#dfe4d8`。
- 主操作 `#295c47`；选中背景 `#f0f4e7`；侧栏 `#edf0e6`；警告 `#856019`；错误 `#a1392c`。
- 深色模式使用对应的深绿纸面和高对比文字。颜色与文字共同表达状态，不给四类风险类型配置严重度颜色。
- 字体沿用 PingFang SC / Microsoft YaHei，正文 14px，标签 12–13px，页面标题 24px；编码使用等宽字体。
- 4/8/12/16/24/32px 间距；5–9px 圆角；以细分隔、轻背景区分层级，避免概览图表和装饰统计卡占据治理空间。
- 默认紧凑布局；会话版提供舒展密度的设计调节，保存版默认紧凑。主按钮每个动作区一个；停用、废弃不使用快速开关。

## 关键交互契约

### 风险源、变量、指标、类型

正式风险源默认可用，不展示启用／停用按钮、标识或使用状态筛选；默认可用不等于将草稿或待审修订自动生效。点击风险源、指标、类型的新增定义，打开原生弹框，背景目录及筛选保留。保存草稿或校验通过提交后关闭弹框，更新目录计数；取消、关闭按钮、Esc或遮罩关闭不提交。关闭后焦点回到新增按钮，页面滚动位置保留。校验失败时弹框保持打开且保留输入。返回目录保留对象定位、关键词和适用的筛选。搜索匹配名称、编码、别名、定义、范围。风险源 analysis_level 无默认值；同层父分类可选，跨层不可选；中观／微观标为范围待定，演示不擅自开放正式纳管。

风险源详情没有推荐变量清单。首版不反查或展示实际使用关系；全局变量没有固定所属风险源，也没有全局 risk_driver 等角色字段。“修订审核”工作区中的待审核材料与目录当前可用状态分别显示。

变量候选主要由AI分析流程提出，正式变量页和候选列表不提供手动新增入口；候选经过语义审核才可模拟取得 DEMO 正式身份；分类与标签允许为空。定性变量可以使用可核验事件证据，单位区分未填写与不适用。Deprecated 保留历史查询，禁止新增正式映射。

### 候选治理

点击“进入候选审核”或全局变量下的“候选审核”切换到列表，与“正式变量”同级切换，无需返回操作。列表展示名称、来源、适用范围、提交时间、状态和审核／查看操作；默认仅待核对，按提交时间倒序。名称搜索与状态、来源筛选可组合；默认每页20条，可选50／100条，筛选或每页条数变化回首页。空结果显示提示，上一页／下一页在边界禁用；处理后总数减少时自动修正失效页码。

点击行内“审核”打开详情抽屉；身份已确认且观测待补的候选显示“继续审核”；已结束项显示“查看”，身份结论不能重复提交。抽屉没有横向候选按钮，关闭按钮、Esc或点击外侧结束查看后，保留列表筛选、页码、滚动位置，焦点回到当前审核行；行已移出结果或当前页时回到搜索框。各候选未提交输入分别保留，更换对照变量保留理由与处理方式但须重新确认核对。记录结论更新背景列表，并可点击“审核下一项”处理当前搜索及筛选范围内的待核对项；筛选范围内无待核对项时不显示此按钮。正式变量筛选与候选列表条件独立保留。手机列表纵向显示各字段，详情抽屉全屏、比较与表单单列。

本地原型对页面内演示数据进行搜索、筛选及分页，仅渲染当前页。真实数据量增长后的服务端分页查询、统计与接口尚未接入；生产实现应按搜索／筛选与页码查询所需数据，不一次加载完整库。未提交内容仍只保存在本次页面内存。

候选材料 → 检索正式库 → 比较定义／范围／粒度 → 校验当前材料版本 → 人工处理。名称近似只提示候选匹配，不显示未经评测的置信分或自动合并阈值。

处理动作：复用已有、接受为新变量、转维护、退回、暂缓、拒绝。审核理由必填；复用必须选 Active 匹配项且确认语义等价；新建须具备稳定名称、定义、范围、粒度、可解释观测依据，缺失时保留候选。拒绝与退回保留材料；复用不增加变量数量；候选审核不自动纳管风险或建立 L1 长期关系。

候选或正式定义版本改变、同义变量并发入库、权限变化必须重新核对。演示提供局部校验与状态变化，真实并发、权限与原子生效仍须业务联调。

### 指标与映射

指标详情优先呈现统计含义和时间规则。一个指标可观察多个变量，一个变量可关联多个指标；每条关系必须有解释、适用范围、局限与版本。可选允许来源引用 M1 的有效身份与业务状态；来源已启用与技术接入状态分开；来源缺口不等于风险缓和。

M2 不编辑实际值、修订原值、风险评分或判断阈值。实际数据入口属于 L0，只读导航需后续真实路由接入。原型不伪造可用业务链接或网络接口。

### 修订、生效和状态动作

草稿 → 字段校验 → 差异与影响检查 → 提交审核 → 批准／退回。审核绑定材料和版本；演示默认不允许直接把定义编辑为生效。非变量的审批粒度仍受 D-M2-03 约束，不将本设计建议当作已批准规则。

废弃、拆分、合并仍须满足身份保护及必要的有效性校验。首版不提供通用引用浏览器或独立影响清单；不具备必要校验时不能通过隐藏界面绕过业务约束。恢复亦须重新审核，不能通过撤销绕过治理。版本回退若实施，产生新生效记录，保留旧历史。

### 系统状态与权限

| 状态 | UI 表达 | 可用动作 |
| --- | --- | --- |
| 加载中 | 保留目录标题与筛选，骨架行＋加载文案 | 筛选输入可保留，提交暂不可用 |
| 尚无数据 | 预置内容尚未加载或尚未建档，与搜索无结果分开 | 重试／联系维护；新增草稿 |
| 无搜索结果 | 保留关键词与筛选，显示匹配为零 | 清除筛选 |
| 读取失败 | 明确错误和重试；不显示空库 | 重试，保留输入 |
| 无权限 | 标明无权限查询或维护 | 只读访问已授权范围 |
| 版本冲突 | 当前版本与本地输入对照 | 保留草稿，重新核对 |
| 结果未知 | 状态待查询，不按失败重复新建 | 查询原操作结果／安全重试 |
| 来源／映射缺口 | 呈现具体缺口及主责模块 | 形成维护反馈 |

真实权限由后端校验；隐藏按钮不构成权限控制。演示不实现真实角色管理。

## 响应与无障碍

900px 以上为侧栏＋列表＋详情；900px 及以下 列表与详情上下排列。手机端隐藏侧栏，四类定义入口换行，候选比较按候选材料、匹配定义、差异、动作顺序呈现；表单单列。所有操作使用原生按钮与有标签输入；焦点清晰、保存错误可定位、返回恢复发起控件焦点；不依赖 hover。

## 原型与评审边界

可点击演示覆盖：四类目录切换、搜索筛选、对象详情、候选对照与六种结论、当前与历史定义、草稿表单、缺口反馈及手机布局。

完整拆分合并编辑器、真实跨模块跳转、审批权限矩阵、并发唯一性、实际版本发布／回退、持久化、业务通知、L0 数据接入不在本地演示范围内。保留 M2 原文 D-M2-01–11，不替代产品审批或业务系统验收。

## 评审检查

- 四类定义同级；候选在全局变量下；没有推荐变量前置条件。
- 生命周期、修订状态、配置可用状态不混为一个状态字段。
- 候选没有正式变量 ID；示例身份有 DEMO 标记。
- 语义、范围、粒度明确比较；无自动置信评分或强制合并。
- 指标定义与实际值分开；映射逐关系解释，允许来源与接入分开。
- 历史版本保留；首版移除使用关系及独立影响查询，不展示演示引用计数。
- 演示结果与真实业务验收明确区分。


## 保存版实际能力

保存版可离线浏览并执行本地交互；刷新重置演示材料。草稿、待审差异和维护反馈可重新查看；常规修订提交不会立即替换有效定义。加载／失败／无权限／版本冲突／结果未知仅在本契约中规定，尚无故障场景切换器。关系维护、真实来源查询、并发审核、批准发布及跨模块通知需要后续实现。


## 变量详情字段标记

变量详情的八项信息直接显示字段标签，标签描述当前原型映射和依据状态，不修改真实数据结构：

| 页面信息 | 标签字段名 | 标签类别 |
| --- | --- | --- |
| 定义 | `definition` | 逻辑字段 |
| 适用范围 | `range` | 原型扩展 |
| 观察粒度 | `grain` | 原型扩展 |
| 别名 | `alias` | 原型扩展 |
| 可选标签 | `tags` | 原型扩展 |
| 观测依据 | `evidence` | 原型扩展 |
| 分类与语义边界 | `boundary` | 后端数据 |
| 观测方式 | 无独立字段 | 界面计算 |

`definition` 对应 [[tools/RiskHot/docs/system-design/02-业务架构与领域设计/RiskHot_L0_信息处理层_业务架构与领域设计V1.0|L0 §4.5.5 变量字典]]的逻辑字段；`boundary` 在 [[tools/RiskHot/packages/domains/reference/index.ts|现有后端变量数据校验]]中使用。现有数据库采用JSONB数据载体，标签不宣称这些名称都是独立物理列。

“原型扩展”表示业务信息要求存在，但正式存储结构尚未定版；“界面计算”表示根据观察粒度拼接显示，不虚构独立字段名。标签只用于当前变量详情，其他目录、候选审核与弹框保持已有交互。


## 首次观测配置审核（2026-10-14）

候选列表分别显示“变量身份”和“观测方案”，增加观测状态筛选；查询已确认身份的待补方案时，将变量身份筛选为全部，再按待确认／部分确认查询。仍采用搜索、来源筛选、20／50／100条分页和行内抽屉，不恢复横向候选按钮。

抽屉内提供“1 · 变量身份”“2 · 观测方案”两个步骤。第一步比较语义并确认身份；第二步展示 AI 建议的已有指标、新指标或事件证据及解释、适用范围、局限、来源和材料版本。身份通过后自动进入观测步骤，身份未确认时可以查看建议，但不能批准。关闭、切换步骤或再次打开保留各项未提交输入。

观测建议逐项确认、暂缓、退回或拒绝，各项理由与结果独立记录。修改解释、范围、局限或新指标定义／来源须重新勾选确认。新指标先确认统计定义与允许来源，取得演示指标身份后仍须单独确认映射；复用变量沿用已有配置，额外建议不自动生效。部分通过只生效获批项；仍有待补项显示“部分确认”，全部处理完但有拒绝项显示“部分生效”；暂缓／退回保留缺口，列表可继续审核。定性事件方案不生成量化指标。确认结果保留操作者、时间、材料和定义／关系版本；配置获批不代表数据已接入。
