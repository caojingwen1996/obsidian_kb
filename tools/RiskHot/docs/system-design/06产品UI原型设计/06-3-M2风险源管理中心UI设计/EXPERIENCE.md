# M2 页面与交互契约

> **首版范围调整（2026-10-14）**：按用户要求，使用关系及独立依赖／变更影响查询移出第一版。M2-F18、AC-M2-22 保留为后续版本追踪；当前界面只提供定义与历史标签。


依据 [[tools/RiskHot/docs/system-design/03-系统功能架构/M2风险源管理中心功能设计|M2 功能设计]]。方案为会话生成的 UI 设计，本次按用户要求保存到项目；功能与审批待定项没有因保存动作而获批。实现差距见 [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/reconcile-m2|功能对照]]。

首版直接预置八类风险源、四类风险类型；没有初始化预览按钮或初始化工作区，后台预置另行验证。

## 设计选择

比较了三种组织方式：

| 方案 | 优势 | 代价 |
| --- | --- | --- |
| 同级目录＋列表与详情（采用） | 延续 M1；分类、变量、指标、类型边界清晰；连续查阅快 | 候选审核在抽屉中连续处理，复杂修订使用独立工作区 |
| 六能力平铺为一级页面 | 功能查找直接 | 治理与历史与对象割裂，页面跳转增加 |
| 以关系网络作为主入口 | 可以探索映射关系 | 容易混淆分类、因果与实际使用；不适合首版治理 |

采用风险源、全局变量、风险类型三个同级入口，变量详情提供观测指标，全局变量内嵌候选治理入口；风险源和类型新增通过弹框完成，指标定义在候选建议表格内独立确认；候选通过列表搜索、筛选和分页查找，点击审核后在侧边详情抽屉内比较与处理，背景候选列表保留；风险源、变量和类型修订在完整工作区展开，指标修订在变量内弹框完成，历史从对象详情进入。不同业务对象使用各自的状态语义。

## 视觉摘要

- 背景 `#f5f5ef`；纸面 `#fffef8`；正文 `#233b34`；次级文字 `#647067`；分隔 `#dfe4d8`。
- 主操作 `#295c47`；选中背景 `#f0f4e7`；侧栏 `#edf0e6`；警告 `#856019`；错误 `#a1392c`。
- 深色模式使用对应的深绿纸面和高对比文字。颜色与文字共同表达状态，不给四类风险类型配置严重度颜色。
- 字体沿用 PingFang SC / Microsoft YaHei，正文 14px，标签 12–13px，任务/对象标题 20px、顶栏模块名 14px；编码使用等宽字体。
- 4/8/12/16/24/32px 间距；5–9px 圆角；以细分隔、轻背景区分层级，避免概览图表和装饰统计卡占据治理空间。
- 默认紧凑布局；会话版提供舒展密度的设计调节，保存版默认紧凑。主按钮每个动作区一个；停用、废弃不使用快速开关。

## 关键交互契约

### 风险源、变量、指标、类型

正式风险源和风险类型默认可用，不展示启用／停用按钮、标识或使用状态筛选；默认可用不等于将草稿或待审修订自动生效。点击风险源、类型的新增定义，打开原生弹框，背景目录及筛选保留。保存草稿或校验通过提交后关闭弹框，更新目录计数；取消、关闭按钮、Esc或遮罩关闭不提交。关闭后焦点回到新增按钮，页面滚动位置保留。校验失败时弹框保持打开且保留输入。返回目录保留对象定位、关键词和适用的筛选。搜索匹配名称、编码、别名、定义、范围。风险源 analysis_level 无默认值；同层父分类可选，跨层不可选；中观／微观标为范围待定，演示不擅自开放正式纳管。

风险源详情没有推荐变量清单。首版不反查或展示实际使用关系；全局变量没有固定所属风险源，也没有全局 risk_driver 等角色字段。“修订审核”工作区中的待审核材料与目录当前可用状态分别显示。

变量候选主要由AI分析流程提出，正式变量页和候选列表不提供手动新增入口；候选经过语义审核才可模拟取得 DEMO 正式身份；分类与标签允许为空。定性变量可以使用可核验事件证据，单位区分未填写与不适用。Deprecated 保留历史查询，禁止新增正式映射。

### 候选治理

点击“进入候选审核”或全局变量下的“候选审核”切换到列表，与“正式变量”同级切换，无需返回操作。列表展示名称、来源、适用范围、提交时间、状态和审核／查看操作；默认仅待核对，按提交时间倒序。名称搜索与状态、来源筛选可组合；默认每页20条，可选50／100条，筛选或每页条数变化回首页。空结果显示提示，上一页／下一页在边界禁用；处理后总数减少时自动修正失效页码。

点击行内“审核”打开待核对候选，正式身份分配前即可审核指标；已处理项使用“查看”。关闭、Esc或点击外侧保留筛选、页码、滚动位置和候选输入，焦点返回审核行，行不可见时回到搜索框。统一处理后更新背景列表，可按当前范围审核下一项。手机资料和表单单列，底部提交按钮可达。

本地原型对页面内演示数据进行搜索、筛选及分页，仅渲染当前页。真实数据量增长后的服务端分页查询、统计与接口尚未接入；生产实现应按搜索／筛选与页码查询所需数据，不一次加载完整库。未提交内容仍只保存在本次页面内存。

候选材料 → 核对候选定义／范围／粒度 → 校验当前材料与重复名称 → 人工处理。2026-10-15 按用户要求移除相似变量检索对照功能及其复用／转维护入口。正式变量库仍可独立检索；新建检查名称和别名重复，命中时阻止创建并提示退回或暂缓。

处理动作：接受为新变量、退回、暂缓、拒绝。审核理由与人工核对必填；新建须具备稳定名称、定义、范围、粒度、可解释观测依据，缺失时保留候选。与有效正式变量名称或别名重复时阻止新建。退回、暂缓及拒绝保留材料，不创建身份；候选审核不自动纳管风险或建立 L1 长期关系。

候选或正式定义版本改变、同义变量并发入库、权限变化必须重新核对。演示提供局部校验与状态变化，真实并发、权限与原子生效仍须业务联调。

### 指标与映射

指标详情优先呈现统计含义和时间规则。一个指标可观察多个变量，一个变量可关联多个指标；每条关系必须有解释、适用范围、局限与版本。可选允许来源引用 M1 的有效身份与业务状态；来源已启用与技术接入状态分开；来源缺口不等于风险缓和。

M2 不编辑实际值、修订原值、风险评分或判断阈值。实际数据入口属于 L0，只读导航需后续真实路由接入。原型不伪造可用业务链接或网络接口。

### 修订、生效和状态动作

草稿 → 字段校验 → 差异与影响检查 → 提交审核 → 批准／退回。审核绑定材料和版本；演示默认不允许直接把定义编辑为生效。非变量的审批粒度仍受 D-M2-03 约束，不将本设计建议当作已批准规则。

废弃、拆分、合并仍须满足身份保护及必要的有效性校验。首版不提供通用引用浏览器或独立影响清单；不具备必要校验时不能通过隐藏界面绕过业务约束。恢复亦须重新审核，不能通过撤销绕过治理。版本回退若实施，产生新生效记录，保留旧历史。

### 系统状态与权限

| 状态 | UI 表达 | 可用动作 |
| --- | --- | --- |
| 加载中 | 保留目录标题与筛选，骨架行＋加载文案 | 筛选输入可保留，提交暂不可用 |
| 尚无数据 | 预置内容尚未加载或尚未建档，与搜索无结果分开 | 重试／联系维护；新增草稿 |
| 无搜索结果 | 保留关键词与筛选，显示匹配为零 | 清除筛选 |
| 读取失败 | 明确错误和重试；不显示空库 | 重试，保留输入 |
| 无权限 | 标明无权限查询或维护 | 只读访问已授权范围 |
| 版本冲突 | 当前版本与本地输入对照 | 保留草稿，重新核对 |
| 结果未知 | 状态待查询，不按失败重复新建 | 查询原操作结果／安全重试 |
| 来源／映射缺口 | 呈现具体缺口及主责模块 | 形成维护反馈 |

真实权限由后端校验；隐藏按钮不构成权限控制。演示不实现真实角色管理。

## 响应与无障碍

900px 以上为侧栏＋列表＋详情；900px 及以下 列表与详情上下排列。手机端隐藏侧栏，三个顶层入口换行，候选审核按候选材料、身份处理、指标建议顺序呈现；表单单列。所有操作使用原生按钮与有标签输入；焦点清晰、保存错误可定位、返回恢复发起控件焦点；不依赖 hover。

## 原型与评审边界

可点击演示覆盖：三个目录与变量内观测指标切换、搜索筛选、对象详情、候选资料审核与四种处理结果、当前与历史定义、草稿表单、缺口反馈及手机布局。

完整拆分合并编辑器、真实跨模块跳转、审批权限矩阵、并发唯一性、实际版本发布／回退、持久化、业务通知、L0 数据接入不在本地演示范围内。保留 M2 原文 D-M2-01–11，不替代产品审批或业务系统验收。

## 评审检查

- 三个顶层入口；候选和观测指标在全局变量下；没有推荐变量前置条件。
- 生命周期、修订状态、配置可用状态不混为一个状态字段。
- 候选没有正式变量 ID；示例身份有 DEMO 标记。
- 语义、范围、粒度明确比较；无自动置信评分或强制合并。
- 指标定义与实际值分开；映射逐关系解释，允许来源与接入分开。
- 历史版本保留；首版移除使用关系及独立影响查询，不展示演示引用计数。
- 演示结果与真实业务验收明确区分。


## 保存版实际能力

保存版可离线浏览并执行本地交互；刷新重置演示材料。草稿、待审差异和维护反馈可重新查看；常规修订提交不会立即替换有效定义。加载／失败／无权限／版本冲突／结果未知仅在本契约中规定，尚无故障场景切换器。关系维护、真实来源查询、并发审核、批准发布及跨模块通知需要后续实现。


## 变量详情字段标记

变量详情的八项信息直接显示字段标签，标签描述当前原型映射和依据状态，不修改真实数据结构：

| 页面信息 | 标签字段名 | 标签类别 |
| --- | --- | --- |
| 定义 | `definition` | 逻辑字段 |
| 适用范围 | `range` | 原型扩展 |
| 观察粒度 | `grain` | 原型扩展 |
| 别名 | `alias` | 原型扩展 |
| 可选标签 | `tags` | 原型扩展 |
| 观测依据 | `evidence` | 原型扩展 |
| 分类与语义边界 | `boundary` | 后端数据 |
| 观测方式 | 无独立字段 | 界面计算 |

`definition` 对应 [[tools/RiskHot/docs/system-design/02-业务架构与领域设计/RiskHot_L0_信息处理层_业务架构与领域设计V1.0|L0 §4.5.5 变量字典]]的逻辑字段；`boundary` 在 [[tools/RiskHot/packages/domains/reference/index.ts|现有后端变量数据校验]]中使用。现有数据库采用JSONB数据载体，标签不宣称这些名称都是独立物理列。

“原型扩展”表示业务信息要求存在，但正式存储结构尚未定版；“界面计算”表示根据观察粒度拼接显示，不虚构独立字段名。标签只用于当前变量详情，其他目录、候选审核与弹框保持已有交互。


## 首次观测配置审核（2026-10-14）

候选列表分别显示“变量身份”和“指标审核”。未入库候选的指标状态为待审核、部分审核、待统一确认或待补方案；入库后为已确认或部分生效。待核对候选使用“审核”入口，已处理项使用“查看”。保留搜索、来源筛选与20／50／100条分页。

2026-10-15 用户确认：先核对变量资料，逐条审核指标，再统一入库。页面按变量资料、变量审核、AI 观测指标审核表排列，无步骤标签或详情跳转。选择接受为新变量时底部显示“确认变量及观测指标”；其他方式显示“确认处理结果”，退回、暂缓、拒绝不要求先完成指标审核。

观测建议只逐项通过或不通过，理由和结果独立保存。单项通过及新指标定义确认均不分配正式身份。最终各项均通过／不通过并至少一项通过后，统一生效通过项；待审项须继续处理；退回和暂缓仅保留在候选整体的变量审核中。定性事件方案不创建量化指标，配置生效不代表数据已接入。

上述为本次页面内存演示；刷新重置。真实 AI、M1 身份查询、权限、并发、原子发布、持久化版本与历史快照锁定尚未接入。完整关系维护与来源治理仍待后续实现。


## 指标入口收敛（2026-10-14）

移除“关键指标”顶层 tab，保留底层共享指标库。变量详情按“定义与边界／观测指标／历史版本”组织；观测指标显示当前变量的关联指标、统计口径、来源状态与关系版本。多变量使用同一共享指标 ID，不复制定义。

“查看与维护”打开原生指标弹框，可查看共享定义、允许来源、多对多映射及独立历史。修订共享定义／来源说明影响其他采用变量；维护当前映射只针对当前变量。关联已有共享指标及各项维护先形成待审材料，未批准不改有效关系；新指标仍在候选建议表格内单独确认。关闭、Esc及点击外侧回到原变量观测指标，保留筛选、选中项和入口焦点。定性变量保留事件证据，缺映射显示缺口。旧宿主指标页状态迁移到变量观测指标。

上述仅为页面内存演示，无真实共享库接口、权限、发布、持久化或历史快照回放。指标文件名 key-indicator 保留兼容，但页面内容改为变量详情的观测指标示意，不作为独立目录。


## AI 观测指标审核与统一入库（2026-10-15）

变量详情中的按钮统一称为“添加观测指标”，弹框和维护记录使用同一名称；仍从已有正式指标中选择，形成待审关联建议，不复制共享定义，也不自动批准映射。

候选抽屉统一展示“AI 观测指标审核”，事件证据通过行类型区分。五列包括指标／事件证据、定义与口径、为什么适用、数据来源与待解决问题、审核；完整定义、时间规则和引用材料可行内展开。待核对候选无需正式身份即可审核，每项通过／不通过均须理由，通过还须勾选核对。新指标先在候选内审核定义与允许来源，再审核适用关系，不提前建立共享指标或正式映射。指标审核只保留“审核通过／审核不通过”，不提供暂缓、退回、更多处理或独立重新审核按钮；新定义核对入口位于数据来源列。各项均通过或不通过且至少一项通过后，点击“确认变量及观测指标”，重新校验版本、来源和重复项，一次入库变量及通过配置；失败不部分生效。空方案和全不通过保留缺口并阻止新建；事件证据通过也可入库。入库前可通过同一组通过／不通过按钮重审并保留历史，候选处理后只读。关闭重开保留输入及候选内结论，手机按卡片显示。业务依据见主功能文档 §4.3.3 审核-01～08。

正式流程由 AI 随候选提出观测方案；指标可以复用已有定义，无法复用时提出新定义建议。当前原型显示预置演示数据，未连接真实 AI 服务，界面对此明确标注。
