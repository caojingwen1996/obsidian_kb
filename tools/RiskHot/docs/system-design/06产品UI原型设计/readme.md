- [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-2-M1信源管理中心UI设计/M1信源管理中心交互原型.html|M1 信源管理中心可点击原型]]：40条在册信源、全部平铺与搜索筛选共用工具区、单一目录、新增查重、编辑及两态启停（操作理由选填）与版本查看；25项本地交互验证通过，刷新重置演示数据。
- [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/00. 阅读导航|M2 风险源管理中心 UI 设计]]：按 M1 目录结构保存，包含视觉与交互契约、关键页面、功能对照及桌面／手机示意；共享定义与候选治理的边界明确；首版移除使用关系，保留实施待定项。 变量详情附字段标记，区分既有字段、原型扩展和界面计算。
- [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-3-M2风险源管理中心UI设计/M2风险源管理中心交互原型.html|M2 风险源管理中心可点击原型]]：四类目录（八类风险源、四类风险类型直接预置，无初始化入口）、候选双栏核对、变量身份与观测方案分别确认、新指标定义独立审核及六种身份结论、指标口径与映射、新增定义弹框、草稿差异、历史版本与维护反馈（首版移除使用关系）；本地资源离线运行，刷新重置演示数据，138项本地交互检查通过，验证范围见模块记录。
