# 标题区域全页面检查记录

依据[[tools/RiskHot/docs/system-design/06产品UI原型设计/标题区域设计规范|标题区域设计规范V1.0]]，依次检查 **M1 → M2 → M3**。覆盖现行页面模板、详情页签、弹窗、场景入口及下表数据/状态样本；**406 个命名样本 × 3 种宽度 = 1218 次检查，全部通过**，保存 231 张截图。样本数包含同一模板的不同对象、节点和状态，不等于 406 个独立页面。

## 检查范围与结果

| 顺序 | 现行页面与组件 | 命名样本 | 三宽度检查 | 结果 |

| M2 | 风险源/正式变量/风险类型目录及17个定义；对应详情页签；风险源与类型新增；三类修订及反馈；指标定义/历史与4种维护、添加观测指标；候选目录、3项审核及4种处理选择、处理后状态、AI观测区；修订记录、暗色目录；4个现行场景入口 | 67 | 201 | 通过 |

宽度为 **1440px、390px、320px**。每个样本测量唯一模块 h1、57px顶栏、14px/600/21px模块名、20px/600任务及弹窗标题、20px正文顶留白、标题横向可读性、页面整体溢出、顶栏工具和弹窗横向边界。流水线另外检查只读及桌面6:4。共采集 3329 条可见主标题测量。

层级中的15px分区、12–16px字段/节点标签和内嵌AI的17px子标题按组件角色保留，不把所有h3升级成任务标题。标题与说明排列、间距、长标题换行和关闭按钮位置结合桌面/手机截图人工复核。

## 发现与修正

| 问题 | 原状态 | 修正 |
|---|---|---|
| M3策略对象标题偏大 | 桌面24px、手机22px | 两处均改20px |
| M3手机弹窗标题缩小 | 手机19px | 改20px，与桌面一致 |
| 现行文档残留旧字号 | 共用规范/M3视觉规范中28px模块名、24px流水线；M2交互契约中24px页面标题 | 同步14px模块名、20px任务/对象标题，链接独立规范 |

UI仅修改M3 `原型资源/styles.css` 的上述3处字号声明。M1不恢复正文模块大标题；M2「修订审核」仍在顶栏；流水线仍只读、6:4、按L0～L3分层。系统绿色、AI紫色及程序/人工背景保持。

检查脚本适配了现行入口、抽屉外部提交按钮和折叠节点。只读检查使用实际 `:disabled` 状态，识别fieldset继承的禁用语义，避免将输入框自身属性误判为可编辑。脚本适配不修改页面业务行为。初检保存两类字号偏差；最终结果以复验和补检为准。

## 验证与业务保护

- 本轮完整逐页检查1218次：无标题不合规、标题横向裁切、页面横向溢出、工具越界或运行异常；无外网请求。
- 三中心既有六宽度检查重新运行：48次视口检查、6项导航/外壳检查，37张截图，全部通过。
- M3原有交互检查重新运行：93项通过。M1的25项、M2的201项是已有通过基线，本轮未重新运行这两组业务测试；三中心交付检查沿用合计319项基线，不宣称319项全部在本轮重跑。
- 标题修改完成时，26份UI源文件中仅M3样式表改变；全部HTML和6份JavaScript逐字节不变。对应时间点及本轮业务保护见[标题区域业务保护.json](标题区域业务保护.json)。
- **并行编辑单独记录**：检查期间M3脚本与样式另出现AI任务内嵌改动，本轮保留，未覆盖；已补检五个页签的三种宽度（15次），并从当前源码核对业务初始数据与提交处理仍和本轮前一致。不能将并行M3脚本变化描述为本轮标题修改，也不能宣称最终M3脚本整体字节未变。
- 静态样式检测保存1项warning、17项advisory。warning命中既有tab的3px底部选中线，实际规则圆角为0，且侧栏覆盖该旧tab规则，不是圆角卡片的厚装饰边；其他advisory为既有色阶/尺寸及旧工具侧车记录，未新增配色或扩大修正。此处不宣称静态检测零告警。

### 范围边界

M1 `mockups/key-catalog、key-record、key-registration、key-status-confirm`为已标记历史稿，不改写或作为现行验收页；M2四个mockups仍为现行可运行场景，已检查。配置模块不在本轮M1/M2/M3范围，既有两处配置入口缺失单独留在交付检查报告。

这是本地原型的标题/布局检查，不覆盖所有角色×业务版本×数据组合，不是后端验收、全WCAG认证或真实手机触摸测试。浏览器模拟宽度，未连接模型、运行服务或真实业务数据。M2暗色目录进行了复核，不代表全暗色组合覆盖。
