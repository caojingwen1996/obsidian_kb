## 发现与修改

- M2新增、候选审核、维护反馈、定义修订、添加观测指标和表单动作被共用迁移器放入面包屑顶栏，修订审核也位于导航右端。
- M3返回、版本、保存、复制、完整性检查、AI任务修订和评估操作与路径同排，窄屏依赖导航横向滚动。
- 为两个模块增加正文独立工作区操作栏。M2在定义目录导航后，M3在当前页面内容前；导航只承担模块定位，M3保留预览角色。操作容器和ID保持稳定，页面切换沿用原有更新规则。
- 窄屏自然换行，版本选择独占可读行，操作至少44px高；无操作的M3全景隐藏整栏。弹层的取消、提交、关闭仍归属自身标题行。
- M2重绘后优先把焦点交给新内容中的新增按钮，再迁移至工作区；共用迁移器重挂载节点时保留焦点，防止旧节点清理后失焦。
