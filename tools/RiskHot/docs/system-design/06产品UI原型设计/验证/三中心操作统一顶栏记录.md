# 三中心页面与页签操作统一顶栏

依据用户确认，将M3的顶栏操作布局扩展到M1、M2、M3全部现行页面，并写入[[tools/RiskHot/docs/system-design/06产品UI原型设计/标题区域设计规范|标题区域设计规范V1.1]]及[[tools/RiskHot/docs/system-design/06产品UI原型设计/DESIGN|共用UI规范V2.2]]。

## 覆盖清单

| 中心 | 页面／页签／弹层 | 顶部操作 |
|---|---|---|
| M1 | 全部、事实核验、日常监测、专题研究目录 | 新增信源；分组视图的展开／收起 |
| M1 | 信源档案、技术接入、使用关系、变更记录 | 编辑资料、启用／停用；技术页的L0记录与刷新；关系页的查询操作 |
| M1 | 手机信源详情 | 操作进入详情弹层顶部，关闭动作继续只在弹层显示 |
| M1 | 新增／编辑、启停确认、历史版本弹窗 | 取消、查重、保存、确认、返回等进入各自标题行 |
| M2 | 风险源目录、风险类型目录及其定义／历史页签 | 新增定义、维护反馈、修订定义 |
| M2 | 正式变量的定义／观测指标／历史页签 | 反馈、修订；观测指标页增加“添加观测指标”；候选审核入口 |
| M2 | 候选目录、候选审核抽屉 | 目录保留筛选、分页及逐项审核入口；抽屉统一确认、下一项、完成位于抽屉顶部 |
| M2 | 指标详情／历史，以及定义、来源、映射、反馈、添加指标弹窗 | 修订、维护、反馈、取消及提交进入指标弹窗顶部 |
| M2 | 新增定义弹窗、修订页面、修订记录、维护反馈页面 | 返回、取消、保存草稿、校验提交、记录反馈进入当前页面／弹层顶栏 |
| M3 | 策略目录；策略基本信息、流水线、规则引用、版本治理页签 | 新建、版本选择、复制保存／修订；编排检查／添加节点；治理审核／生效／退回／停用 |
| M3 | 系统全景及六条场景流水线 | 场景／版本选择、打开策略详情、完整性检查与返回 |
| M3 | AI任务五标签；评估对比、评测集、指标、历史页签 | 任务修订、新建评估、当前评测集修订 |
| M3 | 新建／复制、审核／生效／停用、任务修订、节点添加、评估及案例弹窗 | 取消、提交及关闭等进入各自标题行 |

搜索筛选、列表行按钮、逐项指标审核和节点内部配置表单保持对象上下文。未增加业务能力。历史mockups和旧截图不属于现行交互页面，保留历史状态。

## 实现与文件

- 共用原型资源/top-actions.js及top-actions.css：移动已有DOM节点，不复制控件；显式保留所属表单及提交意图，清理已失效页面操作。应用顶栏保持57px单行，弹层操作组同排；空间不足仅操作所在区域横向滚动。
- 三个交互原型HTML：在模块脚本之后加载共用布局文件。M3已实现的pageTools继续管理自身页面操作。
- M1及M3应用脚本与本轮开始时完全一致；M2应用脚本仅调整两处恢复焦点的检索范围，使其包含新顶栏。
- 更新共用与模块规范、阅读导航、项目索引和日志。
- 验证脚本：新增三中心操作栏验证；调整M1启停定位、M3弹窗提交按钮的显式form定位，以及标题审核对合法顶栏横向滚动的判断。保留原断言目的。

## 验证结果

```sh
node 验证/三中心操作栏验证.mjs
node 06-4-M3策略管理中心UI设计/验证/顶栏返回验证.mjs
```

79项共用检查与160项M3检查通过，共239项。共用检查包含节点迁移的幂等性、移动／重开／关闭生命周期、过期操作移除、表单关联与提交意图，及M1四目录／四页签／四角色、受限读取状态和M2现有渲染入口。M3检查覆盖页面、页签、版本状态、权限、导航、修订与保存。

共用布局机械扫描返回空问题列表；相关JavaScript语法通过。[[tools/RiskHot/docs/system-design/06产品UI原型设计/验证/三中心操作栏验证结果.json|共用检查结果]]及[[tools/RiskHot/docs/system-design/06产品UI原型设计/验证/三中心操作栏业务保护.json|业务脚本保护结果]]保存本轮证据。
