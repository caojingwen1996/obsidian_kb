## 入口与演示方式

在浏览器打开同目录的 `M4金融对象配置中心交互原型.html`。全部样式和脚本为本地相对路径，无需启动正式服务。默认展示法定货币目录、美元列表项和定义详情。导航可切换“金融对象配置中心”“观测对象”“全部动态”；信源和流水线入口指向现有相邻原型。

顶部“原型场景”是评审辅助控件，可切换只读、配置维护、观察管理、映射核定等演示职责，以及空目录、空清单、读取失败、部分来源不可读、添加部分失败、结果未确认、编辑版本变化。与业务操作区分开，不作为正式产品菜单。

操作只影响当前页面内存，重载或点击“重置演示数据”回到基线。选择器关闭时，未提交选择可放弃；结果未确认的已提交操作保留“查看原操作”入口。

## 页面信息架构

| 页面 | 主要信息 | 主要操作 |
| --- | --- | --- |
| 金融对象配置中心 | 目录树、名称/别名搜索、配置状态、对象范围、观察状态、版本 | 新建目录/对象、编辑定义、移动、启停、核对映射 |
| 目录管理 | 路径、下级数量、正在观察数量、历史 | 新建下级、改名、移动、排序、启停 |
| 新建/编辑表单 | 名称、别名、成对金融分类、辖区、范围、说明 | 保存草稿、保存并启用、保存修改、取消 |
| 观测对象 | 系统共享标识、观察中/已暂停/已结束、搜索、范围、关联状态 | 添加、暂停、结束、恢复、查看详情 |
| 观察详情 | 原采用版本及范围、备注、关联动态、观察记录 | 编辑备注、暂停/结束/恢复、查看对象配置 |
| 添加观察选择器 | 路径、可选性、范围预览、已选数量、逐项结果 | 逐对象选择、核对范围、恢复原观察、确认、重试 |
| 映射核对 | 配置与事件对象对比、辖区、范围、依据 | 明确核定、保留未解决 |

## 关键评审路径

1. 新建金融对象：填名称、辖区、范围、分类和保存说明，启用保存。回到配置详情，确认没有自动建立观察或生成事件。也可只填名称和说明保存草稿，观察按钮不可用。
2. 添加观察：切换观测对象，点击“添加观察”，选择人民币或欧元；核对右侧范围后提交，查看逐项结果。没有事件也能建立观察；映射未核定显示待核定。
3. 手工生命周期：暂停或结束观察，填写共享操作说明；切换对应状态页，恢复原记录。共享清单不随演示角色变化。
4. 停用影响：在目录“货币与货币形态”管理中停用，查看美元的影响清单并确认；重新启用目录后，美元仍暂停，需要明确恢复。
5. 定义版本：编辑美元范围，确认仍为同一对象并填写说明。观察暂停，映射待核定；恢复前核对原采用和当前版本。若实际上换了对象，取消并另建配置。
6. 映射：人民币的“核定与动态”支持核对后一致性批准；美国国债与“美国国债市场”范围冲突，不能核定。美元映射已核定，可查看直接关联的演示事件。
7. 异常：批量部分失败场景同时选择人民币、欧元，第一项版本变化失败，成功项保留；重新核对失败项后再提交。结果未确认场景重试原操作，不生成重复观察。
8. 编辑冲突：编辑版本变化场景保留输入，点击核对最新版本，返回后重新保存。未保存离开有确认提示。

## 功能到页面的对应与工程边界

“原型体现”表示页面或本地内存可演示，并非正式验收通过。下列全部场景仍需工程实现和真实权限/并发/存储验证。

| 功能验收 | 原型体现 | 后续工程验证 |
| --- | --- | --- |
| AC-01 | 手工表单与独立配置结果 | 不写Target、Event、Observation的事务边界 |
| AC-02 | 选择具体对象，允许零事件观察 | 共享观察持久化与空态 |
| AC-03 | 固定系统共享标识、切换角色同一清单 | 多账号访问同一记录 |
| AC-04 | 目录只导航，无整目录复选 | 服务端拒绝目录建立观察 |
| AC-05 | 草稿/停用/上级不可用禁选及原因 | 提交时全祖先状态校验 |
| AC-06 | 同名可按范围/辖区区分 | 身份冲突判定与重复保护 |
| AC-07 | 已有观察禁选、同回执重试复用 | 数据库唯一约束、真实并发与幂等 |
| AC-08 | 暂停/结束显示恢复原观察 | 并发恢复、历史连续性 |
| AC-09 | 停用确认及内存自动暂停 | 原子更新与审计持久化 |
| AC-10 | 启用提示不会自动恢复 | 后端状态机 |
| AC-11 | 已手工暂停/结束状态保留 | 原因保留、竞争更新处理 |
| AC-12 | 移动不列自身和后代，模型再次拒绝 | 服务端环检测及并发树操作 |
| AC-13 | 移动/排序保留对象ID和金融分类 | 全引用与排序事务 |
| AC-14 | 定义修订、旧快照与恢复采用确认 | 不可变版本与消费状态 |
| AC-15 | 编辑同一身份确认、新建提示 | 同一性人工审核与限制 |
| AC-16 | 明确配置与事件独立，无自动联动 | F02待补配置提示与事件正常保存 |
| AC-17 | 映射对比与核定依据 | 正式映射服务及审计权限 |
| AC-18 | 货币/工具/市场范围示例与冲突阻断 | 真实同一性规则和反例 |
| AC-19 | 范围冲突保留未解决、不计动态 | 多候选冲突及基数约束 |
| AC-20 | 历史演示事件按原日期展示 | 历史查询和事件时间口径 |
| AC-21 | 受限来源场景过滤含受限源的整条事件及计数 | 正式来源权限、详情/搜索防泄露 |
| AC-22 | 按唯一演示事件集合展示 | 多Fact、多证据关联去重查询 |
| AC-23 | 选择版本留存、提交过期项逐项失败 | 提交时重新验证停用/移动/版本 |
| AC-24 | 批量逐项结果、仅重新核对失败项 | 真实部分事务、回执及恢复 |
| AC-25 | 配置维护角色隐藏观察操作 | 后端授权拒绝越权写入 |
| AC-26 | 观察管理角色隐藏配置编辑 | 后端授权与映射核定角色独立 |
| AC-27 | 加载失败、待核定、冲突分别提示 | 真实故障、超时、无映射等响应契约 |
| AC-28 | 暂停/结束保留历史阅读与采集继续说明 | F01/F02与观察解耦集成验证 |
| AC-29 | 只提供组织目录与具体对象，不导入研究入口 | 存量目录清洗与准入 |
| AC-30 | 新原型使用添加观察，配置编辑入口集中 | 旧Target入口切换、存量迁移/回滚 |
| AC-31 | 移动说明、目的目录状态、影响确认和内存暂停 | 真实目录移动事务、引用与审计 |

## 后续开发输入

以本原型的页面动作整理接口草案，再确定配置条目、配置版本、共享观察、核定映射的数据模型。先迁移配置与存量映射，再接入只读页面、配置维护和共享观察写操作，最后受控关闭旧Target混合写入入口。该顺序只说明依赖，完整工程切换计划仍需另行设计确认。
