## 配置维护

新建目录后可建立具体金融对象。草稿允许定义未补齐；启用需要明确范围、有效金融分类及辖区或“不限定”确认。金融分类由一级和二级成对维护，目录路径不能代替金融分类。名称、范围及辖区均相同的重复记录提示先核对复用，同名而范围不同不自动合并。

新建或编辑保存要求说明；编辑定义时确认仍为同一对象，若实际换了身份则另建。保存配置不自动建立观察或生成事件。对象编辑不通过所属目录字段绕过移动影响核对。

停用条目或祖先时，列出受影响的正在观察对象并要求确认。移动对话框展示目的目录状态、说明可能暂停观察，并要求确认潜在影响；当前尚无随目的目录变化而更新的逐项影响预览。模型执行移动时再次校验，未确认则拒绝，确认后暂停失去可用性的观察。原来手工暂停或结束的记录保留；重新启用不自动恢复。移动目标排除自身、后代与金融对象，排序只改变组织顺序。

## 共享观察生命周期

“添加观察”只选择启用且祖先可用的具体对象，目录不可整组选择。已观察对象禁选并说明原因；已暂停或结束的对象进入恢复原记录，不建立另一份清单。没有事件的对象也能建立观察。

提交前可以阅读对象路径、范围和可选性；选择时留存版本，提交时模拟再次验证。批量操作逐项反馈成功或失败，成功项保留，失败项重新核对后再提交。结果未确认时显示“查看原操作”，重试复用原演示回执，不能直接宣称失败或成功。

暂停、结束和恢复先说明这是共享操作，要求操作说明，历史事件仍可阅读，信息采集继续。对象定义变化时先保留原观察快照；恢复前对照原采用与当前范围，明确确认后更新采用版本和快照。正式工程仍需实现完整不可变版本及历史采用依据，不能用此内存演示替代。观察备注只记录关注目的，不修改配置对象定义。

## 映射与动态阅读

核定界面对照配置与事件对象的范围、辖区及身份，要求核定依据和一致性确认。金融工具与市场等明显范围冲突不提供核定提交，不凭关键词相似建立关联。待核定、冲突、已核定和读取失败分别表达；动态仅使用已核定的直接关联演示事件，展示原事件日期。

部分来源不可读场景过滤含受限来源的整条演示事件及其数量。该保守演示过滤不发布正式来源权限或证据脱敏策略，工程阶段仍需验证列表、搜索、详情与计数的一致性。

## 状态、异常与可访问性

| 状态或操作 | 实际反馈与保护 |
| --- | --- |
| 空目录/空观察 | 明确说明当前没有内容，并提供建立目录或从配置添加的下一步。 |
| 读取失败 | 单独失败提示和重新加载，不显示成空库。 |
| 编辑冲突 | 保留输入并提供核对最新版本，确认后重试保存。 |
| 角色切换 | 隐藏不属于演示职责的操作，共享数据不随角色切换；本地模型再检查对应职责。 |
| 模态层 | 原生 dialog、显式标题和关闭按钮；支持 Esc，关闭时尝试恢复触发点，部分入口回到主要内容焦点。所有状态变化下的焦点连续性仍需工程阶段完整辅助技术验收。 |
| 详情页签 | tablist/tab/tabpanel 语义，左右方向键、Home、End 切换并恢复详情页签焦点。 |
| 观察状态页签 | 文字状态和数量，支持左右方向键、Home、End 切换；不是只靠颜色选择。 |
| 手机选择对象 | 纵向详情获得焦点并滚动到可读位置；目录可展开，分类表单不截断一级名称。 |
| 错误与反馈 | 页面使用状态提示，表单错误使用警报语义；字段标签、可见焦点和跳到主要内容入口保留；跳转入口将焦点移至主要内容，不触发业务路由。 |

普通按钮和输入桌面最小高 40px，手机主要操作增至 44px；部分紧凑图标和复选框采用标签及外围布局，不能将全页面宣称为每个独立元素均达 44px。减少动态效果偏好关闭现有过渡。未执行完整辅助技术评估。

## 原型工具与运行边界

“原型场景”独立承载只读、配置、观察、映射职责及异常切换，不是正式产品菜单。“重置演示数据”和浏览器重载恢复基线；“刷新视图”仅重绘内存，不读取后台。未保存表单在导航和浏览器离开时提供保护。

原型由本地文件运行，HTML 禁止连接请求，不调用 API、模型或正式持久化。内存权限、版本、回执与审计只是页面评审机制，不能验收真实多账号授权、并发恢复、数据库唯一约束、事务、幂等、审计持久化或 F01/F02 解耦。正式数据模型、接口、存量映射、迁移及切换需后续设计。
