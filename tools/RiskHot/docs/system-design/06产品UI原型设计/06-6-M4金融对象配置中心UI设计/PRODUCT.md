# M4 产品上下文

<!-- impeccable:product-schema 1 -->

## Platform

Web。本目录是现有 RiskHot 系统的页面与交互原型扩展，入口为 `M4金融对象配置中心交互原型.html`。

## Users

金融对象定义维护者、共享观察管理者、映射核定者和授权阅读者。原型中的职责选择只是演示操作组合，不发布正式角色或授权模型。一次共享观察操作影响系统所有使用者。

## Product Purpose

先维护“对象是什么”，再选择“系统观察什么”。金融对象配置中心提供层级目录、手工新建与编辑、范围和身份核对；内容分组的观测对象页面维护系统共享的一份观察清单，并阅读已核定关联动态。

配置项、事件 Target 和观察记录各有职责。目录负责组织；具体对象才可建立观察。建立配置或观察不制造事件，也不以名称相似自动认定同一金融对象。

## Operating Context

用户已确认：配置中心使用左侧目录树、右侧对象列表与详情；观测对象沿用事件列表组织并增加“添加观察”；系统共享清单，同时支持对象手工新建、编辑。

原型使用本地 HTML、CSS、JavaScript 和合成演示数据。操作保存在页面内存，重载浏览器恢复基线；“刷新视图”重绘当前内存。相邻信源与流水线入口采用本地链接。本轮未接入正式服务、数据库或身份系统。

## Capabilities and Constraints

- 配置：目录浏览与管理、名称/别名搜索、配置状态筛选、新建与编辑、草稿/启用/停用、移动与排序、定义及历史阅读。
- 观察：选择具体对象、核对范围、批量添加、逐项反馈，以及暂停、结束、恢复原观察、备注和历史阅读。
- 关联：对比配置与事件对象的身份、范围和辖区，明确核定后展示直接关联的演示动态；范围冲突保留未解决。
- 异常：演示空态、读取失败、版本变化、部分来源不可读、批量部分失败及结果未确认。
- 所有版本、回执、权限、去重与历史均为本地模拟，不构成真实授权、并发、幂等或持久化验收。

功能输入为 [[tools/RiskHot/docs/system-design/03-系统功能架构/M4 金融对象配置中心与观察管理功能设计|M4 功能设计 V0.1]]，其发布状态仍为草案。映射基数、权限角色及存量切换等未决建议保持待评审，页面可演示不等于业务规则已批准。既有实际 `/targets`、Target 接口与 F02 流程不在本轮修改范围。

## Brand Commitments

继承现有系统的深绿导航、暖灰画布、白色工作面、本地中文无衬线字体及紧凑操作风格。信息通过范围文本、状态文字、字重和细分隔组织。没有照片、插画或远程字体；图标为内联线条 SVG，验证 PNG 是截图证据。

## Product Principles

- 先核对身份与范围，再建立共享关注；目录关系不代表金融身份或风险传导。
- 操作影响、原采用定义和当前定义应能被阅读；失败与结果未确认分别表达。
- 延续既有系统视觉和模块任务组织，不以原型替代工程切换与验收。
