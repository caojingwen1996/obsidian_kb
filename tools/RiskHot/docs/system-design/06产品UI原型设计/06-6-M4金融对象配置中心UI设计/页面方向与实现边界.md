## 页面方向

这是供研究者反复操作的工作界面（Operate）。继承既有 RiskHot 的深绿导航、浅色画布、白色工作区和紧凑信息密度。此次是现有系统扩展，不重新建立品牌或更换页面风格；用户已经确定布局，因此直接以代码实现原型。

首屏先回答“当前在哪个目录、有哪些对象、选中对象具体指什么”。目录树只负责组织，列表显示对象范围和状态，详情提供身份核对与操作。观察清单则先呈现状态、对象、范围和关联动态；添加时必须先看到范围再提交。

本次不采用大幅插图或照片。目录、对象、来源、流程使用同组线条图标；金融对象范围文字才是核心内容。所有事件与来源均为明确标记的合成演示数据。

## 布局与交互契约

- 桌面：216px全局导航，目录树与对象工作区并排；对象列表和详情相邻。中等宽度缩窄导航并将详情置于列表之后。
- 手机：全局导航改为顶部排列，目录折叠为可展开区域，列表、详情依次展示；不压缩成横向大表格。输入字号16px、操作目标至少44px。
- 配置编辑：完整表单页面，长范围文本有足够空间；保存说明、草稿、启用区分明确。编辑不允许通过表单绕开“移动”影响核对。
- 共享观察：添加使用模态选择器；目录不是复选项。已观察对象不可重复选，暂停或结束记录进入原记录恢复流程。
- 跨状态操作：停用或移入未启用目录需要明确影响确认；启用不自动恢复。定义变化保留原观察快照，恢复时比较并确认采用新版本。
- 映射：核定前比较配置与事件对象的范围、辖区；明显冲突不能批准，不用关键词相似替代同一性判断。
- 可访问性：语义按钮、原生dialog、表单标签、焦点提示、跳转主要内容、Tab及方向键切换资料标签。状态同时有文字。

## 实现边界

交付物是可离线打开的HTML与本地资源，操作只保存在页面内存。刷新浏览器恢复演示基线；“刷新视图”只重绘当前内存。没有正式API请求、数据库迁移或权限系统接入。

原型中的版本、唯一记录、回执、审计和权限检查只模拟页面行为。不能据此宣称真实并发、幂等、审计持久化、来源授权或F02业务已通过验收。功能设计中有关映射基数、权限角色和存量切换的待确认建议继续保留原状态。

既有实际产品 `/targets` 页面与手工Target接口保持现状。本次页面方向获确认不等同于M4表结构、后端或迁移切换获验收。后续工程阶段需先补数据模型、服务接口、存量映射和切换计划。

## 质量检查契约

以1440px桌面、390px手机、320px窄屏为必查尺寸；补充选择器和编辑页截图。检查目录可辨识、对象范围可读、状态操作有依据、长内容可滚动且没有页面横向溢出。自动化检查与截图是本地原型证据，不能替代正式环境验收。
