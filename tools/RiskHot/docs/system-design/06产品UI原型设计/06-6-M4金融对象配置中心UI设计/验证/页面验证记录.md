## 自动化检查

执行 `node --env-file-if-exists=.env src/tests/m4-prototype.e2e.mjs`，使用已配置的独立Chrome for Testing/Chromium与任务临时数据目录；在finally关闭浏览器并移除本次临时目录。测试只启动白名单本地静态服务器，不启动正式API，不访问数据库，不写正式配置。

最终43项断言通过，详细名称、截图尺寸与结果保存在同目录 `自动化结果.json`。覆盖：独立新建配置、无事件观察、暂停/恢复、祖先停用及不自动恢复、定义修订快照/映射失效、人工核定/冲突阻断、来源过滤、三类职责、批量部分失败、结果未确认回执重试、编辑版本冲突、草稿补齐启用、未保存离开保护、空态与读取失败、移动目的地排除、7个截屏状态的横向溢出、脚本异常和外部请求检查。

本轮过程中修正了测试选择器误选已关闭弹窗控件、场景重置仅变更hash未重新初始化的问题；最终断言按独立重载和页面可见操作执行，未降低业务断言。实现方面修正场景面板遮挡操作、选择器名称/状态粘连、手机辖区复选布局、选中对象后的手机详情定位及草稿启用状态。

另以独立临时浏览器直接打开本地 `file://` HTML，3项检查通过：目录与资源加载、切换观察并打开选择器、无脚本异常；结果在 `离线入口结果.json`。此检查不启动本地服务器。
