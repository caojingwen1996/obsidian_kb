# 默认收起与层级信息弱化验证记录

用户要求F01～F08默认收起，只展示模块卡片，并弱化L1等层编号、标题及说明段落。

## 本轮修改

- `原型资源/app.js`：从实际模块定义初始化八项收起状态；首次进入不预选隐藏步骤，右侧先显示使用提示；系统全景的业务层头使用弱化单行结构，移除可见说明和步数。模块手动开合、会话内状态保留及跨模块自动展开保持。
- `原型资源/styles.css`：L0～L3编号和标题统一12px弱化色，去掉阶段头分隔线，收紧与模块卡片之间的间距；增加初始详情提示样式。
- `验证/流水线全景验证.mjs`及结果：检查默认八卡收起、初始无预选详情、四层不展示说明及步数，并保留既有完整性和业务保护检查。
- 7份既有浏览器验证脚本：进入全景后按需要点击模块标题，再测试具体步骤；初始状态断言改为模块卡片与操作提示。仅更新并完成语法检查，本次未重跑其完整旧套件。
- `02. 交互原型说明.md`、`EXPERIENCE.md`、`DESIGN.md`、项目索引与日志：同步现行默认行为。

## 验证

- 全景685项、顶栏状态144项通过，共829项。
- 17份JavaScript与验证脚本语法检查通过，布局检测无发现。
- 与修改前副本比较，flow-data.js与system-panorama.js字节一致；全部118个节点、后继、规则和Step编号未变，C01策略与业务写入处理保持。
- 实际浏览器首次进入及刷新后均有8张收起卡片，卡内114个业务步骤不展示；右侧没有预设步骤详情。
- 四个业务层头均为12px，保留编号和名称，不含说明段落与步数统计。
- 1920、1440、1024、768、390、320px实查无横向溢出，浏览器控制台无error/warn。
- 手动展开F01、选择输入类型分流并跨模块跳到F02时，目标卡片自动展开；手机Enter展开、查看详情和返回节点焦点通过。

原型布局与交互检查不代表生产业务系统验收。
