# 流水线全景独立目录迁移验证记录

用户要求新建“06-1-流水线全景ui设计”，集中存放全景设计、UI原型及相关资料；同时承接上一条全系统流程节点命名规范要求。

## 迁移与主责

- 迁移全景专属组合数据 system-panorama.js、业务文档与节点对照、全景验证脚本及结果、模块卡片／默认收起／卡头精简等设计记录。
- 迁移全景子菜单历史记录、同级导航专项及截图、去除交付说明／箭头与间距截图，以及原M3混合截图目录中的全景历史图片。
- 共计 30 个文件迁入；完整源路径与目标路径见同目录“目录迁移清单.json”。保留历史文件日期与原验证结论。
- 新建独立全景HTML与entry.js；直接打开及刷新均进入只读全景。M1、M2、M3的现行入口统一跳转本目录，旧M3的#panorama仍兼容。
- 全景拥有独立导航、视觉规范、交互契约、产品上下文、使用说明和截图入口；原M3全景专属设计章节迁入全景DESIGN，混合文档添加主责链接。
- 节点规范统一引用本目录当前的“04.RiskHot 流水线节点视觉与编号规范”建议稿；保留用户更新内容，导航和设计说明不另设重复规范。当前原型仍使用原有层内Step，新规范尚待评审与应用。

## 共用资源

M3中的app.js、styles.css、flow-data.js、task-prompts.js、task-contracts.js继续提供共用查看器、视觉、六条策略蓝图和固定任务定义，没有复制。system-panorama.js迁入新目录后两边引用同一份。迁移前后六份运行资源的SHA-256一致，包括迁移后的system-panorama.js。

上级top-actions.js/css仍供各原型使用。交付需保留同级M3和上级共用资源；本子目录不是可单独拷走的完整离线包。

## 验证结果

- 迁移后的流水线全景验证：682项通过，118个节点、八个模块、16项固定AI任务及分支／汇合保持完整。
- M3顶栏返回状态回归：144项通过，覆盖策略与版本上下文和权限；这是本地夹具检查，不含浏览器布局。
- 独立Chrome for Testing浏览器专项：46项通过，覆盖1440、1024、768、390、320px；独立无hash入口、刷新、旧入口兼容、三中心跳转、唯一选中、管理子菜单恢复、模块展开和只读详情。
- 浏览器无页面异常或HTTP(S)请求；使用临时专用数据目录，finally中关闭并清理。当前桌面与手机截图已目视复核，原型未见横向溢出。
- 新目录链接、本次迁移及改写引用、UTF-8、Markdown表格和脚本语法检查作为本次交付检查；不据此宣称全库历史断链已修复或完整系统验收完成。
