# F01六步流程同步记录

## 变更

依据[[tools/RiskHot/docs/system-design/03-系统功能架构/F01 信息接入与标准化模块功能设计 V2.1|F01 六步功能设计]]，全景F01改为六步：资格核对、资料获取、正文读取与标准化、重复与版本识别、保存、交付。完整性检查归入标准化，关联与资格复核归入保存，回执归入交付。

- 删除IN-KIND、IN-VALUE、输入A/B布局、F01→L2旧交付和M2→F01前置关系。
- 新增正文、版本、保存、交付及完成/恢复节点；F01共11节点，全景123节点。
- 同版已保存可跳过保存；已交付直接完成；保存失败与交付失败分别定位Step 5/6，回执失败优先恢复记录。
- 主线纵向排列，条件出口与主线连线分别展示，每个节点/关系只出现一次。模块标题保持无说明小字。
- F01详情均引用V2.1文档；F02～F08非展示业务字段、后继、固定AI版本保持，M2仅删除旧F01依赖。

## 修改范围

全景system-panorama.js；M3共用app.js/styles.css及flow-data.js的F01来源条目；两份全景验证脚本及结果/截图；全景设计、交互、产品上下文、节点规范与来源对照；F01同步状态；两级索引与日志。六份策略蓝图未修改。
