# 流水线全景页面与交互契约

## 工作区与入口

页面顶部仅保留“流水线全景”标题与角色图例，移除操作说明、只读状态条和跨层提示区。业务条件与跨层跳转保留在实际节点及详情中，避免重复解释。

全景与 M1、M2、M3 同级，使用独立原型入口。进入后顶栏与浏览器标题显示“流水线全景”，仅该主菜单选中，隐藏策略子菜单和无内容的工作区操作栏。默认不选择隐藏节点，右侧提示展开模块并选择步骤。角色选择只影响预览上下文，两种角色在全景均只读。

## 分层与模块

L0～L3为原生details/summary一级业务层容器，首次进入四层展开；16px / 600标题配12px职责说明。F01～F08为层内模块，默认均收起；48px卡头显示模块编号、14px / 600名称及展开箭头，名称下方无说明小字。展开后桌面保留真实动作的步骤范围及收起操作，节点内业务说明继续显示。层与模块可独立折叠，开合选择分别在本页会话内保留，刷新重置；支持Enter和Space。M为独立虚线治理区。

## 节点与定位

顶部层级导航定位对应层，并随滚动同步当前阅读位置。点击节点选择详情；后继和跨层引用显示业务层、模块与编号，以稳定节点ID定位。跨层或跨模块跳转先展开目标层和模块，再定位并恢复节点焦点。桌面左右6:4，右侧详情独立滚动；760px及以下纵向排列，选择节点定位到详情，使用“返回当前步骤”回到节点。主要折叠、导航、条件出口和交付控件触达至少44px。

判断节点通过有标注的实际支线或可点击引用展示出口；同一关系不同时重复为出口清单和主线箭头。条件及并行路径保留路径名与真实出口条件。F01保存交付完成后可定位F02接收环节，F07查询与F08报告独立触发、无串行连接；M无来自L3的串行箭头。真实依赖以业务蓝图中的后继和前置汇合为准。

详情保留输入、产出、流向、规则、来源和待确认事项。AI 节点共用 M3 固定任务版本，提供五标签只读详情，未知任务显示缺失提示，不回退到其他版本。

## 编号规范与实施范围

本次原型已按[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-1-流水线全景ui设计/04.RiskHot 流水线节点视觉与编号规范|节点视觉与编号规范]]实现层级、结构类型、角色配色和展示编号。规范原稿保持“建议稿（待评审）”状态；本地实现不代表正式业务批准，也不扩大到C01版本化策略编排。

L0～L3各自从Step 1起算，F01/F02按模块独立从Step 1计数，其他模块保留既有层内序列。实际动作与判断参与Step；起点、纯交接、结束结果与路径容器不占Step。路径用A/B/C，路径内动作按Step NA.1、NA.2编号。F01六步纵向排列，条件出口定位共享结果或恢复步骤。RISK-NONE因实际保存识别记录保留为真实动作，不机械按原END类型删除步骤。

展示元数据使用panorama前缀，与稳定业务身份、执行类型及固定AI版本分离；F01以V2.1六步契约重建，F02按最新七步功能设计独立重建；F03～F08非panorama业务字段、next和requiresAll保留。最新契约覆盖历史的“12px弱化层标签、模块15px、规范尚未实施”说明。

## F01六步现行契约（2026-10-22）

依据[[tools/RiskHot/docs/system-design/03-系统功能架构/F01 信息接入与标准化模块功能设计 V2.1|F01 六步功能设计]]，F01依次为核对信源资格与接入条件、获取原始资料、正文读取与资料标准化、识别重复与资料版本、保存标准化资料、交付标准化资料。固定为Step 1～6，F02按模块独立从Step 1编号。起点、完成出口及三类待处理/恢复出口不占Step。

删除输入类型A/B分流、IN-KIND、IN-VALUE及M2→F01依赖。F01仅交付标准化资料，完成出口可定位F02接收环节；保存与交付失败分别返回Step 5/6，同版已保存时跳过保存，已交付时直接完成。六步主线纵向排列，条件出口从所属节点横向引出；待处理和恢复节点位于对应步骤侧方，同模块共享目标由连线直接汇入，跨模块交付保留入口，保存和交付恢复以虚线回连Step 5/6。桌面与手机均保留主线、分支两列，换行与缩放后连线随实际位置更新。节点详情引用F01 V2.1，模块标题下不增加说明小字。

现行全景为123个节点（F01为11个、四层业务119个、横向治理4个），16项AI任务不变。F02～F08非展示业务字段、后继及固定任务保持，F01按新契约重建；M2仅移除旧F01入口。展示层Step可随F01步数改变，稳定节点ID仍用于定位。详见[[tools/RiskHot/docs/system-design/06产品UI原型设计/06-1-流水线全景ui设计/验证/F01六步流程同步记录|F01 六步原型同步记录]]。
