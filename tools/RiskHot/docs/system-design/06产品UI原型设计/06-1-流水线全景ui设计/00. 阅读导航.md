# RiskHot 流水线全景 UI 设计

流水线全景是与 M1、M2、M3 同级的全系统只读入口，集中展示 L0～L3、F01～F08 和横向治理。全景的设计、组合数据、原型入口与专属验证资料统一由本目录维护。

## 交付边界

当前原型展示102个节点、16项固定AI任务，已实现一级业务层独立折叠、默认收起的F模块、实际动作与判断Step编号、分支路径、条件出口、跨层定位及AI五标签。F01按V2.1六步、F02按V1.0最新七步契约更新；F03～F08及固定AI版本保留。节点规范原稿的“建议稿（待评审）”状态不变；原型实现不代表实际运行、模型调用、正式业务批准或完整系统验收。最新契约覆盖历史的弱化层标签及“尚未实施”说明。

专属历史验证及截图已迁入本目录的“验证”，保留其原日期、原结论和历史局限。M3 管理、AI 定义和策略评估的混合验证继续留在 M3；共同视觉与标题规范继续由上级目录维护。
