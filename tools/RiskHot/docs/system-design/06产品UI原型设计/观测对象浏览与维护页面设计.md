## 导航

“内容”下为“全部动态”“观测对象”；“配置”下为“信源管理中心”“流水线全景”。四个功能模块均在文字前放同尺寸线性SVG图标，装饰性图标对屏幕阅读器隐藏，保留文字名称与当前页状态。

图标分别表达动态、对象定位、信源档案、流程节点。不增加远程图标依赖。桌面保持深绿色侧栏；900px及以下采用两组分栏，四个入口全部可见，目标高度至少44px，320px宽度不产生整页横向滚动。

## 列表

入口 `/targets`。上方保留与事件页一致的位置栏和刷新操作；正文采用单一白色列表工作面，不加统计卡片。

- 名称/别名搜索；一级分类、使用状态筛选；20条分页。
- 每行展示名称、使用状态、分类、范围摘要、适用地区、关联动态数量和更新时间。
- 全行是通往详情的链接；范围摘要最多三行，详情保留完整文本。
- 搜索、筛选、分页记录在URL中，进入详情、表单及返回时保留；对象列表与关联动态使用独立页码。
- 有维护权限时在列表标题行提供“新建观测对象”。

空库、筛选无结果、请求失败分别表达，不把权限错误或服务失败显示为零个对象。

## 详情

先显示对象名称、状态、完整范围和编辑入口，再显示分类、地区、别名、定义版本及更新时间。下方为关联动态，沿用事件的标题、摘要与阶段表达，并提供正式事件详情链接。

关联数量和事件清单共用现有“全部采用来源可读”的权限规则；无权读取任一来源的事件不显示，也不计入数量。对象定义目录沿用既有全局可检索能力，不将候选身份建议当作已核定对象。

## 新建与编辑

采用独立表单页，避免长表单挤进弹窗。字段包含名称、适用地区、范围、多项分类、别名、使用状态和保存说明。名称、范围、至少一项有效分类、保存说明必填。

- 新建与编辑沿用AI-07现有的 `event_review` 权限，同时要求 `read`；只读账号不显示维护入口，接口独立校验。
- 人工新建明确名称/地区/范围完全相同的对象时返回重复提示；同名不同范围仍允许，不机械合并身份。此检查不替代AI-07语义核定。
- 编辑提交当前 `definition_version`。过期版本返回冲突，保留用户填写，不自动覆盖；有效修改递增版本并记录审计，不改历史Event采用的定义快照。
- 相同内容保存不额外升级版本；不提供删除对象操作。
- 每次保存绑定幂等键。未知结果保留原请求，刷新后仍可按原内容重试；重试前重新校验当前权限。
- 离开未保存表单提示确认；正常取消返回原列表或对象详情。

## 技术落点与验收

前端位于 `src/web/targets*`，导航图标样式为 `product-navigation.css`；查询和维护分别进入 `target-queries.ts`、`target-catalog.ts`，接口登记于 `runtime/targets.ts`。复用已有Target表、审计表和操作回执，不新建业务存储。

验证覆盖四页导航、320/390/1440布局、查询往返、分类/状态组合、关联事件权限、新建编辑、版本冲突、重复建档、保存响应丢失后的原键恢复、空/错/撤权状态。工程结果见[[tools/RiskHot/docs/verification/targets-ui|观测对象页面验证记录]]。
