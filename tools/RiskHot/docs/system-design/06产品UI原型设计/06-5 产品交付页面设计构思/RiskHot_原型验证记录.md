## 1. 验收范围

| 用户要求／可见能力 | 检查方式 | 证据 |
|---|---|---|
| 仅风险速览、观察报告两个入口 | 核对主导航数量与名称，实际切换 | 桌面及手机首屏 |
| 没有我的关注或配置负担 | 可见文案与控件检查，无表单、输入和偏好存储 | 首页、源代码检查 |
| 打开即可理解重要变化 | 首屏包含实际主判断、解释、程度及下钻入口 | 首页首屏 |
| 六段连续风险解读 | 实际点击与页面结构核对，无分割式页签 | 风险详情首屏、完整预览 |
| 按需解释术语与依据 | 点击和键盘展开／收起 | 依据展开预览 |
| 高位稳定不等于安全 | 阅读债务融资风险 | 语义断言 |
| 首次观察和待评估如实表达 | 进入两个不同对象，核对无默认等级和方向 | 待评估预览、语义断言 |
| 历史数据不混入未来观测 | 较早快照不含3月14日数据，月报不含三月观测 | 当期解读、月报截图 |
| 日周月是不同阅读内容 | 直接切换周期，核对周期、条目与摘要 | 观察报告、历史月报 |
| 返回保留阅读上下文 | 报告返回、浏览器返回、首页位置恢复 | 浏览器操作断言 |
| 手机自然阅读 | 390px及320px测量溢出，实际点击与触摸路径 | 手机速览、解读、报告 |
| 离线独立文件 | 直接从file URL载入，记录请求和脚本错误 | JSON结果与静态检查 |

## 5. 复跑方式

在当前目录使用已安装Node.js和项目依赖：

```sh
node 验证/build-reader.mjs
node 验证/reader-qa.mjs
```

构建命令只将“原型资源”同步回独立HTML。浏览器检查使用本机Chrome，更新结果和预览，不请求真实业务服务。
