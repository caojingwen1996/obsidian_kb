## 计算语义

- 状态由当前分档与所读周期的差值方向组成。首页与速览详情用日变化，周报与其详情用周变化。程度和方向不互相代替。
- 连续增强期数为末端连续正日差分的次数。例如政策 75→79→80→84→85→91，为连续增强 5 期，跨 6 次观测。
- 重要变化演示分界为 80 分；“首次进入”只指已有 8 期窗口，不声称全历史首次。跨入、持续增强、回落每类优先取一项，再补足至最多三项；同一信号不重复。无符合条件项时显示“本期未出现新的状态变化”。
- 历史位置只比较同一信号、同一口径此前有效观测，排除当前期，严格低于当前值计数，相等单列。演示最少要求 3 期；现有普通示例为此前 7 期。
- 10.16 当前快照的历史位置参照 10.09–10.15；10.09 历史快照参照 10.02–10.08。均为北京时间每日 18:00。
- 范围条使用固定 0–100 刻度，浅色区间为此前最小值至最大值，蓝色标记为当前值。当前点可以在此前范围外。
- 首次、缺失、过期不生成当前历史位置，也不纳入重要变化。缺失不补零。
- 全部数据、分档、最小样本数和归纳规则均为原型提案；短样本位置不代表长期分位、风险发生概率或未来预测。
