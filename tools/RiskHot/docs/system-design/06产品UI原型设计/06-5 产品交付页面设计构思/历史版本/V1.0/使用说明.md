# RiskHot 产品层页面设计交付包

先打开 `RiskHot_产品层交互原型.html`。这是独立 HTML 文件，可保存到 Mac 后用浏览器打开，不需要安装依赖，也不请求远程资源。

完整产品设计在 `RiskHot_产品理念与页面设计.md`，包含产品理念、页面结构、关键交互、首版边界与项目来源。

推荐体验路径：关注清单 → 美元融资条件收紧风险 → 切换历史基准 → 变量与证据 → 演化时间线 → 市场映射（规划）。周期报告支持日、周、月切换与 Markdown 导出。

所有数据、时间、数值、判断与来源名称均为虚构演示。该文件未连接 RiskHot 后台，不会回写项目文件。个人关注只影响本机阅读偏好。

市场映射为规划交互。真实投入使用前需要补齐相应上游分析与证据。验证范围和局限见 `RiskHot_原型验证记录.md`。
