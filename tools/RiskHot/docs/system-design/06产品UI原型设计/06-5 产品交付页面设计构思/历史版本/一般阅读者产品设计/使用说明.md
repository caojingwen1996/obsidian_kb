# RiskHot 产品阅读原型 V2.0

直接打开 **RiskHot_产品层交互原型.html**。这是可独立复制的离线文件，无需安装、登录或设置偏好。

## 两个入口

- **风险速览**：直接阅读重要变化、高位风险与仍需验证的信号；点击“读懂这项风险”进入通俗解读。
- **观察报告**：默认周观察，直接切换日／周／月；“阅读当期解读”保留报告引用时点。

依据、术语和历史在正文中按需展开。没有“我的关注”、收藏、订阅、配置或观察任务。返回时恢复本页会话内阅读位置。

- [[tools/RiskHot/docs/system-design/06产品UI原型设计/06-5 产品交付页面设计构思/RiskHot_产品理念与页面设计|产品理念与页面设计]]：新版定位、页面结构、交互与业务边界。

- PRODUCT.md、DESIGN.md：本目录阅读产品上下文和视觉规范，不覆盖管理端。
- 原型资源：可编辑样式、脚本与虚构数据；验证：构建、浏览器检查和结果。
- 历史版本/V1.0：原来的九份交付文件，保留旧设计与截图供对照。

所有数据、时间、判断和来源均为**虚构演示，非实时研究**。没有接入后台或真实发布流程。
