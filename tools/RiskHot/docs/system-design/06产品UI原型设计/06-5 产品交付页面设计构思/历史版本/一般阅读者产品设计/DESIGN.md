# Design System: RiskHot 阅读产品

## Overview

**Creative North Star: "可解释的风险阅读"**

以绿色品牌、平面浅底、中文衬线标题和无衬线正文，建立安静且有判断力的阅读表面。细线与底色区分内容层次，语义色只辅助表达变化与未知；正文承担解释，不由装饰图形代替。

这是对已完成离线原型的实物提取，沿用已确认的阅读方向。一般阅读者直接进入风险速览或观察报告；详情沿同一阅读路径按需展开依据。本次属于中途采用 impeccable 的交付收尾，没有进行概念抽签、批准效果图或审美选案访谈。适用范围仅为本目录，不继承或改写父级管理中心的视觉规范。

**Key Characteristics:**
- 中文衬线标题与宽松正文行距形成连续阅读节奏。
- 深绿重点区、浅色观察区和细线分隔构成平面层级。
- 文本、SVG 方向符号与语义底色共同表达变化，未知单独保留。
- 两入口始终直接可达；手机按内容顺序折为单列。

## Colors

暖浅底与深绿色文字形成阅读底盘；变化、未知、演示与历史信息保留独立语义。上方 frontmatter 是本目录的色值真值，包含 reader.css 全部已声明及内联颜色，避免隐式借用管理端色板。sidecar 的八阶 tonalRamp 是从这些颜色推导的面板预览，不是界面新增色值，也不覆盖此处的规范值。

### Primary

- **品牌阅读绿（green）**：主判断底色、当前导航、阅读链接、时间线节点。
- **品牌深绿（deep）**：源文件已声明，但当前选择器未引用；保留溯源，不将其升级为已使用状态。

### Secondary

- **压力红／压力浅底（red、redwash）**：压力增加标签。
- **缓解青绿／缓解浅底（teal、tealwash）**：有所缓解标签；不表示解除风险。
- **稳定灰绿／稳定浅底（stable-ink、stable-wash）**：变化不大标签。
- **未知暖灰／未知浅底（unknown-ink、unknown-wash）**：暂难判断与等待评估。
- **重点区浅字（lead-ink、lead-muted）**：绿色主判断区标题、入口和说明；**重点方向色（lead-status-ink、lead-status-line）**只用于该区的透明底方向标签。
- **演示棕（demo-text、demo-dot）**：虚构演示文字与圆点；**历史提示色（history-wash、history-line、history-ink）**只用于固定当期解读提示。
- **焦点棕（focus）**：键盘焦点描边。**琥珀色（amber）**为已声明但未引用变量，不是新的操作强调色。

### Neutral

- **阅读浅底（paper）**：全站背景与页头；**报告浅白（white）**：报告纸面和跳过导航入口；**正文墨绿（ink）**：主要文字与强调分隔线；**次要灰绿（muted）**：说明、时点、来源与辅助导航。
- **基础细线（line）**：文章、表格与页脚分隔；**观察浅绿（wash）**：验证条件、当前比较与报告摘要。
- **侧栏浅底／细线（side-paper、side-line）**：首页次要变化；**观察分隔线（panel-line）**：信号列、时间线和条件说明；**机制线（mechanism-line）**：作用路径边界。
- **导语墨色（intro-ink）**、**上期底色（previous-wash）**：详情导语及前后对比。
- **选择色（selection-wash、selection-ink）**只控制文字选择；**打印色（print-paper、print-ink）**只控制打印输出，不是屏幕主题。

**The Semantic Color Rule.** 方向标签同时保留文字、SVG 与色彩；红色表示压力增加，青绿色表示有所缓解，灰绿色表示变化不大，暖灰表示未知，不能用绿色统一代替风险结论。

## Typography

**Display Font:** Songti SC、STSong、Noto Serif CJK SC、serif。  
**Body Font:** PingFang SC、Microsoft YaHei、sans-serif。  
**Brand Font:** Georgia 加中文衬线回退。字体均为系统字体栈，没有外网字体依赖。

标题具有阅读出版物的辨识度；正文、时点与导航保持朴素。没有等比生成的字号系统：frontmatter 记录已观察角色，不应插值出不存在的字号。

### Hierarchy

- **Display**：详情标题，桌面（40px / 600 / 1.5），手机（30px）；最大宽度（19em）。
- **Page heading / Lead / Report title**：页面标题（38px）、主判断（37px / 500 / 1.5）、报告标题（35px / 600 / 1.5）。主判断在宽屏（41px），中屏（31px），手机（29px / 1.55）；页面与报告标题手机分别为（32px、28px）。
- **Headline / Title**：详情章节（26px），列表章节（25px），报告条目（23px / 600 / 1.5），风险列表标题（21px / 600 / 1.5）。手机章节以（24px）为主，列表与报告条目（22px）。
- **Body**：基础（16px / 1.85）；详情正文（16px / 2），最大宽度（42em）；手机详情正文（15px）。报告正文（15px / 1.95），手机（14px）。
- **Intro / Deck**：详情导语（18px / 1.95），报告导语（17px / 1.95）；手机分别（16px、15px）。
- **Link / Support / Label**：阅读链接（14px / 500 / 1.6）；辅助说明（13px）；方向标签（12px / 1.7）；一般时点（12px / 1.85）；报告引用提示（11px）。日期与数据表使用等宽数字特性，未使用独立等宽字体。
- **Brand**：RiskHot（29px / 700 / 1.1），字距（-.035em）；手机（26px）。

**The Reading Rhythm Rule.** 衬线字承担标题，无衬线字承担正文、导航与时点；正文宽度和行距优先服务连续阅读。

## Layout

内容居中，常规容器最大宽（1184px），横向总留白（96px）；正文区顶部留白（44px）。首页重点块左右比例（1.75fr : 1fr），风险条目为三列（1fr : 1.12fr : 1fr），稳态内容两列（1.2fr : 1fr），验证信号三列。详情和报告采用正文加目录：正文列（minmax(0,790px)），侧栏最小（180px），列距（72px）。页头黏在顶部，最低高度（88px）；文章目录顶距（124px）。

- **宽屏，min-width:1600px**：容器最大（1240px），总留白（120px）；主判断内边距（40px 46px）。
- **中屏，max-width:1050px**：总留白（64px）；重点块比例（1.55fr : 1fr）；阅读侧栏（180px），列距（40px）；报告内边距（32px）。
- **手机，max-width:760px**：总留白（40px）；页头改为普通文档流，导航换至下一行但保持两个入口。主判断、风险列表、稳态区、验证信号和正文都折成单列；侧目录隐藏。章节锚点滚动边距由（120px）改为（20px）。前后变化比较改为单列，箭头旋转（90deg）；机制路径保持横向，文字和间距缩小。
- **打印**：隐藏页头、页脚、目录、返回入口、报告周期与阅读底部入口；正文全宽，报告去边框和内边距，文章章节尽量不跨页。

间距以实际内容密度为准，既有（6、8、12、18、24、28、40px）常用节奏，也有文章专用细调；frontmatter 的 spacing 是现有取值清单，不是强加给后续页面的等比分级。长引用允许断词，数据表允许内部横向滚动。

## Elevation & Depth

屏幕界面无 box-shadow、渐变、模糊或拟物材质。深绿色重点区、温浅侧区、浅白报告和浅绿摘要通过色面与细线建立层次。黏性页头位于（z-index:20），键盘跳过入口为（z-index:100）；它们是阅读导航层级，不引入浮层阴影。

**The Flat Reading Rule.** 层级以背景色、边框、间距和字重表达，不引入悬浮投影来替代现有阅读层次。

## Shapes

以直线文章结构为主。重点容器与方向标签仅有轻微圆角（surface）；焦点时采用更小圆角（focus）。演示圆点及时间线节点为圆形（dot），不能推演成所有控件的胶囊形。常规分隔线为（1px），一级导航选中线（3px），周期选中线（2px）。正文与报告外框保留方直边缘。

## Components

### Two-entry navigation

只含风险速览与观察报告。默认次要字色，选中使用品牌绿、字重（600）及底部（3px）实线，aria-current 标示当前位置。桌面间距（40px），中屏（28px），手机（32px）；手机导航高度至少（47px）。悬停变品牌绿，焦点遵循通用焦点规则。

### Reading link

文字加内联 SVG 箭头，最小高度（36px），内部间距（12px）。悬停出现下划线，箭头水平移动（4px），只为这段位移设置（.2s cubic-bezier(.16,1,.3,1)）。prefers-reduced-motion:reduce 时取消该过渡，并将平滑滚动改为即时滚动。没有通用按钮或输入表单；不要从浏览器 button/input 字体重置推导出实际组件。

### Semantic direction badge

静态信息标签，内边距（2px 8px）、图文距（6px）、SVG（14px）。压力增加／有所缓解／变化不大／暂难判断／等待评估采用各自色彩及符号，不是筛选或可点击状态。绿色重点区单独使用透明底、浅字与细线版本，不改变方向含义。

### Disclosure

依据使用原生 details/summary：上下细线，标题区内边距（17px 0），字号（15px），右侧 SVG 在展开时旋转（180deg），没有额外旋转动画。正文底部留白（25px），条目内容（14px）。术语使用较轻的原生展开项：摘要（13px）、内边距（8px 0），正文（14px）。关闭和打开均保持内容在原阅读路径中。

### Mechanism line

三个机制节点与两个 SVG 箭头横向连接；节点等分，居中文字，上下边线，内边距（12px 5px），节点文字（14px）。手机图文间距（7px）、节点文字（12px）、内边距（12px 2px）、箭头（13px）。这是解释关系的静态内容，不是步骤输入器。

### Report period navigation

日观察／周观察／月观察为普通链接，默认（15px），内边距（7px 0），间距（26px）；手机（28px）。当前周期使用品牌绿、字重（600）和（2px）底线，aria-current 传达选中态。切换实际报告；下钻链接保留该报告当期引用。

### Report paper

浅白、细边框的连续文章容器，无阴影、无圆角，桌面内边距（42px 48px 46px），中屏（32px），手机（25px 23px）。摘要用浅绿平面，正文以线和段落区分条目，不复制成等规格仪表盘卡片。

所有链接与 summary 共享键盘焦点：焦点棕描边（3px），偏移（5px），焦点圆角取 focus。非交互信息不为了预览添加 hover、active 或 tab stop；当前界面没有额外 active 动画。

## Do's and Don'ts

### Do:
- Do 保留本地绿色阅读配色，主判断、状态和历史提示分别使用对应色彩角色。
- Do 用细分隔线、衬线标题、无衬线正文与宽松行距组织内容。
- Do 为链接与展开项保留可见焦点，并尊重减少动效偏好。
- Do 在手机上保留两个直接入口，并按主判断、次要变化、连续正文的顺序阅读。
- Do 将新状态与历史报告的适用时点写清楚，语义标签同时有文字说明。

### Don't:
- Don't 将父级管理中心的颜色、卡片或配置控件自动搬入本阅读表面。
- Don't 将变化不大、首次观察、未评估合并成同一种“安全”状态。
- Don't 为本原型增加我的关注、收藏、订阅、配置、提醒或输入任务。
