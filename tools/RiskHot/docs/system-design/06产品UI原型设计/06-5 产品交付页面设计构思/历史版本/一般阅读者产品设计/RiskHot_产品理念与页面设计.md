## 1. 产品定位与设计决策

RiskHot 面向一般阅读者，帮助用户理解当前重要风险及其变化，不要求具备宏观研究或系统管理经验。

用户已确认：一级入口仅保留“风险速览”和“观察报告”；移除“我的关注”；不增加收藏、订阅、个性化配置、提醒设置或观察任务。页面打开即呈现内容。

用户读完后，应能用自己的话说明：发生了什么、为什么变化、当前影响到哪里，以及什么新证据会改变判断。这是后续真实用户测试的验收方向，不是本轮已验证的阅读时长或理解率。

设计采用 impeccable 的 Read 模式：阅读顺序和熟悉导航优先，视觉服务于理解。前期代码曾以 frontend-design 落地，本轮已明确补齐 impeccable 的阅读模式、独立收尾评审及设计系统记录；不追认为此前已完成概念选案流程。

## 2. V1.0 到 V2.0 的变化

| 原方案 | 本次方案 | 对阅读者的作用 |
|---|---|---|
| 左侧管理式导航 | 顶部两个直接可见的入口 | 减少需要理解的功能分区 |
| 关注清单与风险表格 | 风险速览与解释性内容 | 先获得理解，再查看资料 |
| 个人星标与筛选配置 | 由产品组织本期内容 | 无需先设置才能使用 |
| 风险档案、变量观察独立入口 | 身份、变量和证据嵌入解读 | 减少跳转与术语负担 |
| 详情页签切割内容 | 六段连续解读 | 按自然问题逐步深入 |
| 市场映射规划页 | 从当前阅读产品中移除 | 聚焦已确认的风险阅读价值 |
| 泛化周期报告 | 独立日／周／月内容及固定引用 | 在相应时间背景下理解判断 |

V1.0 原始交付已保存于“历史版本/V1.0”，含归档文件哈希；不删除原始设计依据。

## 3. 信息架构

```text
RiskHot
├── 风险速览（默认）
│   ├── 本期重要观察
│   ├── 正在变化的风险
│   ├── 高位稳定与尚难判断的风险
│   ├── 待评估说明
│   ├── 接下来留意的信号
│   └── 风险解读（下钻）
│       ├── 现在是什么情况
│       ├── 这次改变了什么
│       ├── 为什么会这样
│       ├── 当前影响到哪里
│       ├── 接下来看什么
│       └── 依据与判断演变（按需展开）
└── 观察报告
    ├── 日观察
    ├── 周观察（默认）
    ├── 月观察
    └── 报告引用的当期解读（下钻）
```

详情不增加一级菜单。正文目录只用于定位段落，不构成工作区。报告周期切换属于阅读内容选择，不要求配置。

## 4. 风险速览

### 4.1 首屏任务

第一屏直接回答“本期最值得注意什么”。主判断、解释、当前程度和历史方向同时可见，提供清楚的“读懂这项风险”入口。

桌面以主判断和两项次要变化构成内容层级。主判断使用绿色背景承接品牌识别，次要内容保持平面阅读布局。手机依次呈现主判断与次要变化，保留文字语义。

本地示例以 2025-03-14 18:00（北京时间）为观察截面。显著标注“虚构演示·非实时”，不把示例截面伪装成今天的最新判断。

### 4.2 内容顺序

1. 本期重要观察：一句完整判断与一段通俗解释。
2. 哪些风险正在变化：逐项说明变化、当前程度及后续验证。
3. 没有新变化也不能忽略：保留高程度但方向稳定的风险，以及首次观察尚难判断的对象。
4. 待评估说明：明确尚无有效判断，可查看原因，无需用户补资料。
5. 后续信号：说明什么条件可能改变理解，不要求创建任务或设置提醒。
6. 观察报告入口：把当前内容放回一周的背景中阅读。

### 4.3 编辑组织与业务边界

原型重点条目由预置样例确定，不存在隐藏的综合评分、AI 置信度、热度排名或机会推荐。正式首页的重点纳入规则需单独确认；界面布局不替代业务规则。

当前程度与历史方向独立：高程度可同时继续增强或维持；有所缓解仍可能保留较高程度。首次观察不能默认稳定，未评估不能默认低风险。

本产品首页用于组织阅读，完整风险目录仍属于上游正式能力。本轮收敛页面入口不删除已有业务对象或修改纳管状态。

## 5. 下钻解读

### 5.1 阅读顺序

| 段落 | 用户获得的答案 | 呈现方式 |
|---|---|---|
| 现在是什么情况 | 一句话理解当前风险 | 标题、导语、明确程度与截止时间 |
| 这次改变了什么 | 与什么时间相比，有何变化 | 通俗解释；有基准时附简明前后对照 |
| 为什么会这样 | 推动压力和提供缓冲的因素 | 连续正文；确有机制时使用简单文字路径 |
| 当前影响到哪里 | 哪些主体和环节已有影响证据 | 指明样本范围及不能外推的部分 |
| 接下来看什么 | 什么条件会改变判断 | 改善条件、压力延续条件与未知 |
| 依据与判断演变 | 判断是否有依据，过去如何变化 | 原位折叠展开数据、历史和引用 |

### 5.2 通俗表达

可见正文优先使用“资金更难获得”“借款成本”“支持资金是否到达”等表达。专业名词在必要时提供原位解释，例如“融资溢价是什么”。完整研究措辞与指标口径保留在依据中。

“变化不大”与“有所缓解”都附解释：前者不等于安全，后者不等于风险解除。资产价格涨跌不由风险方向自动推导。

### 5.3 证据与追溯

依据展开后同时呈现：本轮判断依据、适用指标、示例来源、观测可用时间、不同信号和数据缺口。观测只读取截止时间之前已可用的样例，不把更晚数据放入更早快照。

历史轮次只展示已收录的状态与摘要。未收录历史逐项证据时直接说明，不能用当前证据补写历史。

稳定身份、快照编号、比较基准等放在“查看来源与时间信息”，保留核验能力，减少首层阅读负担。

### 5.4 特殊状态

- 首次观察：程度及方向按已有结果表达，缺少可比历史时明确待判断。
- 待评估：不提供等级、方向、机制图或影响结论；说明还没有有效判断。
- 已暂停或结束：醒目标注历史适用范围。当前管理状态仅作上下文说明，不证明当前风险低或不存在。
- 未知链接：提示找不到内容，提供返回速览的直接入口。

## 6. 观察报告

默认打开周观察，日、周、月入口直接可见。每类报告展示独立周期、摘要、条目、后续验证与引用，不让用户填写时间和生成参数。

本地样例：

| 报告 | 覆盖范围（北京时间） | 数据截止 | 内容 |
|---|---|---|---|
| 日观察 | 2025-03-14 | 2025-03-14 18:00 | 融资、需求、能源、新出现的资金信号 |
| 周观察 | 2025-03-08 至 03-14 | 2025-03-14 18:00 | 融资、需求、能源及持续高位的债务压力 |
| 月观察 | 2025-02-01 至 02-28 | 2025-02-28 18:00 | 当时的航运和存款流出历史判断 |

报告内容依次为：本期主题、周期与截止、“读完这一期记住什么”、各项通俗解读、下一轮验证及可展开依据。

“阅读当期解读”进入报告引用的固定结果，顶部明确按报告时点阅读，返回操作回到对应报告及阅读位置。月观察不会引用三月观测。

报告身份、版本、数据截止、示例生成和发布时点在依据中保留。本原型未执行真实发布、撤回、权限检查或服务器版本冻结；固定引用仅是本地演示实现。

## 7. 交互设计

| 动作 | 结果 | 减负方式 |
|---|---|---|
| 打开原型 | 直接显示风险速览 | 无登录、偏好设置或引导任务 |
| 阅读主判断或条目 | 进入连续解读 | 无流程选择或编辑表单 |
| 展开术语、证据、历史 | 原位出现补充内容 | 不强制弹窗与跨工作区切换 |
| 点击正文目录 | 滚到对应段落 | 不改变当前内容对象 |
| 返回速览或报告 | 恢复页面内阅读位置 | 避免重新查找 |
| 切换报告周期 | 直接读取预置当期报告 | 无筛选配置或生成设置 |
| 键盘操作 | 链接可聚焦，Enter展开依据 | 保留原生交互与明显焦点 |

不保存个人关注或偏好；阅读位置只在页面会话内保存。刷新重置阅读位置，深链接仍定位相应内容。

## 8. 视觉与适配

产品端使用独立的阅读型设计记录，不覆盖父目录三个管理中心的设计规则。实际视觉令牌与组件见本目录 DESIGN.md，元数据见 .impeccable/design.json。

正文采用本机中文无衬线字体；标题使用本机宋体／衬线字体。以暖白阅读底色和绿色品牌为基础，压力增加、缓解和未知保持文字及方向提示，不只依靠颜色。

桌面保留适当阅读栏宽与页内目录。手机改为自然单栏，两个一级入口直接可见，不隐藏进需要学习的菜单。页内证据可直接展开；数据表仅在自身容器内允许滚动。

动效只用于轻微方向反馈和段落定位，减少动效偏好时关闭平滑滚动。原型不请求外部字体、图片、模型或分析服务。
