# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
需要量化风险信号帮助判断形势、优先级和行动时机的用户。2026-10-16 用户明确修订定位并授权按上一轮方案实现。

## Product Purpose
交付风险排序、趋势、变化幅度、核心驱动、影响对象与改变判断的条件，帮助用户形成决策。

## Positioning
量化信号是入口，解释与证据服务判断；保留一般阅读者版作为独立版本。

## Operating Context
继承离线静态 HTML 原型交付方式，放在原目录下。用户给出深色风险源排行截图作为设计参照，明确要求用 Impeccable 重做页面与交互。

## Capabilities and Constraints
仅风险速览、观察报告两个主入口；无我的关注、订阅、资产录入和配置。原型全部数字、时间、阈值、影响解读均为虚构演示。正式评分公式、权重、阈值、可比口径和模型验证未确定。展示端不推导正式评级，不执行交易。

## Brand Commitments
RiskHot；中文专业清晰。采用用户参考图的深色监测界面和风险排行结构。

## Evidence on Hand
RiskHot Knowledge L2 风险态势分析领域资料提取：允许缺失、首次和不可比状态；区分当前严重程度与历史方向，保留截止时间和反证。新增量化分值仅为这次产品设计提案，不改写业务架构。

## Product Principles
- 打开即可判断优先级，无前置输入。
- 每个数字带单位、时点和可解释的比较基准。
- 不把缺失当零分，不把缓解当安全。
- 影响与条件有依据，预测和实际观测分开。

## V2 Scope
2026-10-16 用户授权增补状态表达、重要变化和自身历史位置。V1 HTML 和资源原地保留，V2 独立入口。继承既有视觉体系，不增加配置。历史位置使用已有同口径演示观测，明确样本数与窗口，不能冒充长期分位或概率。
