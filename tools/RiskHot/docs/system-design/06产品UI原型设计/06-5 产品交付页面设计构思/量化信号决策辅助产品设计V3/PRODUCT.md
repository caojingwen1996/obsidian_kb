# RiskHot V3 产品上下文

面向需要量化信号辅助决策的阅读者。两入口固定为风险速览、观察报告，无关注、登录、配置、阈值编辑或后台工作台。沿用用户接受的 V2 深蓝阅读界面，增加稳定风险观察对象。

核心任务：知道哪个具体风险需要先看，理解评估为何改变，沿事件证据追溯，查看关联来源及同源对象。打开即有默认排序与解读。

对象以稳定风险问题、目标和范围识别，后续事件持续归入同一对象；事件与评估记录分开。纳管状态不等于风险程度。风险源与对象多对多，关联不代表因果或贡献权重。对象独立评分，未评分不补零，新纳入不等于低风险。

只覆盖宏观目标。原型所有日期、分值、事件、文字均为合成演示，未接入真实数据与评分服务。来源沿用 DEMO-01，对象使用 DEMO-03。历史报告固定截至 10.09，所有跳转保持当期范围；10.16 为当前示例。

V2 及以前全部版本保留。V3 独立离线 HTML，源文件在同名目录。正式产品仍需统一模型校准、事件标识、证据原文、关联版本与服务端快照。
