## Direction contract

THESIS：将稳定风险对象放入主阅读流程，以对象演化解释量化判断；拒绝把新闻聚类当作可评分对象或新增管理工作台。

OWN-WORLD：保留深蓝背景、低反差面板、浅蓝关联链接、粉红增强与薄荷绿缓解。对象列表使用宽行，时间轴以日期与记录类型建立秩序。

STORY：先看本期变化，选择具体对象，理解历史位置与证据，再沿风险源探索同源对象。返回保留首页选择及临时筛选；报告关联保持历史截止。

FIRST VIEWPORT：顶部两个入口；标题与快照时间；三条重要变化；风险源背景与列表/预览双栏。手机纵向堆叠，选择对象滚动到解读并提供返回列表。

FORM：沿用已批准 V2，增量扩展，未运行新 seed。签名交互为稳定对象—风险源—关联对象的双向浏览，以及事件更新/评估更新分离的演化脉络。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
