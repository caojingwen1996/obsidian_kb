# RiskHot V4 产品上下文

沿用 V3 深蓝阅读产品，面向用量化信号辅助判断的阅读者。两入口为风险速览、观察报告；无个人关注、订阅、阈值、初始化或管理操作。V3 及以前版本完整保留。

本次增加核心驱动变量、变化原因、下一步观察重点。变量按来源因素/应对因素分角色，并按本风险当期评估表达压力、缓解或待判断。数值增减不是正式风险方向。判断引用演示评估记录，不由前端分差生成。

打开即有默认对象和解读。预览提供两项变量和首要观察条件，详情完整提供变量观测、作用、证据限制、综合判断与一至三项后续验证重点。证据、演化和详细口径按需展开，操作只服务阅读。

所有事件、评估、数值和说明均为合成示例 DEMO-04，未接入真实网络。10.16 为当前演示，10.09 为历史，历史变量、理由、Watch 必须来自当时独立记录。部分缺失不补零；过期值显示观测日期且不推断作用。量化校准、Momentum 和来源级正式评分仍待业务确认。
