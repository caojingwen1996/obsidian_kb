# V4 风险卡片增量契约

模式：Operate / Read；继承已批准 V3，局部增量，code-led；new-work 的 existing surface extension 分支适用，不重开视觉概念或 seed。

## Direction contract

THESIS：风险数字之后紧接“变量为什么影响判断，以及下一次应该验证什么”，把卡片变成可追溯的阅读路径。

OWN-WORLD：保留 V3 深蓝、浅蓝关联、粉红压力、薄荷缓解和系统字体；宽行变量代替同尺寸卡片堆叠，区块用留白与细线分组。

STORY：首页先读关键变量与首要观察点；详情逐项核对值、角色、作用和依据；原因中的变量链接可定位并展开对应证据。历史报告沿用独立当期变量/理由/Watch。

FIRST VIEWPORT：首页上方既有变化与来源，下方对象列表/解读；解读将关键变量与首要观察置于历史位置之前。详情首屏为判断和卡内阅读导航，主栏依次核心驱动变量、变化原因、下一步观察，侧栏保持历史与来源，时间线按需展开。

FORM：V3 局部扩展；no new seed under local-extension exemption。签名交互是变化原因定位变量依据，及连续浏览中保持报告截止。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope

只写 V4 文件；不修改 V3 及更早代码、设计记录、功能设计正文。全部内容是离线合成样例，使用真实本地 Chrome 截图检查，不交付 raster 视觉资产。
