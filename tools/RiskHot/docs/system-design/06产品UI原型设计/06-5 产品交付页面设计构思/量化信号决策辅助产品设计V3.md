# 量化信号决策辅助产品设计 V3

[打开交互原型](量化信号决策辅助产品设计V3.html)

V3 将 RiskHot 自下而上识别、身份匹配和纳管形成的稳定风险观察对象，融入量化决策辅助页面。沿用 V2 状态表达、重要变化和历史位置，两入口保持为「风险速览」「观察报告」。不增加关注、订阅、账户、阈值配置或管理操作。

## 页面与交互

- **风险速览**：本期重要变化 → 风险源背景 → 风险观察列表与对象预览。默认按可比分值风险优先，未评分不补零；也可临时按新纳入优先阅读。来源按钮只筛选当前列表，不保存个人配置。
- **对象详情**：当前判断、观察目标与范围、历史位置、事件与评估分离的演化脉络、强化/缓解条件、反证，以及关联风险源。依据按需展开。
- **风险源详情**：来源判断、来源历史、关联的去重对象。可由对象进入来源，也可从来源进入关联对象，保留报告截止期；返回首页保留选中项、筛选与排序。
- **观察报告**：按稳定对象组织当期变化，10.16 为当前示例，10.09 为历史。历史跳转不混入未来事件、新纳入对象或当前分值。

## 对象模型与表达边界

风险观察对象不是新闻标题或聚类标签。其稳定身份由风险问题、目标、范围决定；事件更新提供输入，评估更新解释判断是否变化。原型包含「新增事件但评估维持」与「新纳入但暂未评分」的情形。

风险源与对象为多对多，同源对象可以朝不同方向变化。对象分值不复制来源分值，也不由来源均值计算；同一对象跨来源只计一次。纳管状态与风险程度分开。结束跟踪不等于风险解除，数据过期不等于缓解。初期仅纳入宏观观察目标。

历史位置使用此前 7 期可比观测，不含当期，不声称长期分位。正式版若对象定义、范围或模型版本变化，应标明不可比并中断跨口径趋势。模型阈值、校准、权重、来源与对象评估关系仍需业务确认。

## 演示与实现边界

全部数据和解释为合成示例，不构成实际风险结论。原型内嵌数据，无网络请求；事件原文以明确标识的证据说明代替。实际服务需提供稳定 risk_id、event_id、snapshot_id、来源关联版本、证据可获得时间与模型版本。演化记录当前按日期和记录顺序展示；正式版需精确时间戳。

源文件：同名目录中的 signal.js、signal.css、build.mjs；检查记录见 verify.mjs、验证结果.json、验证记录.md；设计规范见 DESIGN.md。旧版本校验.json 保存已有文件摘要，用于确认 V2 与早期版本未被修改。
