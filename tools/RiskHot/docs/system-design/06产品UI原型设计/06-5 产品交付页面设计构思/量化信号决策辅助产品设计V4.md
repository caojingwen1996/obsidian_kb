# 量化信号决策辅助产品设计 V4

[打开 V4 离线交互原型](量化信号决策辅助产品设计V4.html)

V4 依据[[tools/RiskHot/docs/system-design/03-系统功能架构/风险产品与交付模块功能设计 V1.0|风险产品与交付模块功能设计]]，补齐风险卡片的核心驱动变量、变化原因和下一步观察重点。沿用 V3 深蓝界面，一级入口仍只有「风险速览」「观察报告」。V3 与以前版本保留。

## 本次设计

首页对象预览直接提供关键变量、综合原因和首要验证条件，历史位置与关联来源按需展开，避免新增信息挤占主阅读顺序。「风险优先」在 V4 改称「按风险程度」，含义更明确。

对象详情按当前判断、核心驱动变量、变化原因、下一步观察重点排列。当前判断补齐发展阶段、持续条件、当前影响；卡内三个定位按钮只帮助阅读，不增加一级入口。演化脉络保持事件与评估分离，默认收起，历史曲线与来源放在侧栏，手机纵向阅读。

- **核心驱动变量**：显示变量名称、来源/应对角色、本对象当期作用、当期值、前值、单位与限制。指标上升并不自动等于风险增强。每项观测依据可展开，查看合成证据标识、版本和可获得时间。
- **变化原因**：用综合判断解释哪些压力主导、哪些缓冲不足、仍保留哪些限制。点击对应变量名称会定位并展开该项依据。方向引用独立演示评估，不根据前端分差生成。
- **下一步观察重点**：每对象一至两项系统提供的验证条件，说明看什么、怎样强化或缓解判断、缺什么证据。没有关注、订阅、勾选、阈值设置或输入表单。

报告条目同时呈现当期原因与下一步重点。历史报告下钻使用独立当期变量、评估与观察条件，来源与同源对象继续保持报告截止范围，不复制最新内容补齐。

## 功能追踪与边界

核心驱动变量、原因与证据对应 F07-F08；Watch 对应 F07-F11；卡内定位和返回对应 F07-F12；报告当期内容对应 F08-F07。对象身份、来源关联、演化和历史位置继承 V3。正式评级、Momentum、发布管理或后端服务不在本次原型实现范围。

全部分值、变量、事件、依据与解读是 DEMO-04 合成示例。快照日期仍为 2026.10.16/10.09，不冒充今天实时监测。评分口径、跨对象可比性、来源级评价和阈值仍待业务确认。独立方向记录只是展示上游契约的原型样例，不代表模型已校准。
