## 变更与使用约束

1. 调用前核对契约版本、必填字段、权限及固定输入版本；未知版本明确拒绝，不按最新版本猜测解释。
2. 发布时需将现有设计字段固化为可验证契约，评估生产者、消费者和历史数据的兼容性；当前索引不代表发布已完成。
3. 涉及共享字段变更时先更新权威定义，再同步引用方及契约验证设计；模型输出必须经过程序验证才可进入业务提交。
