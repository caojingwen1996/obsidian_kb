# L0 关键机制验证设计

> V0.3 · 2026-10-24 · PoC方案，未实现、未运行。验证 ADR-L0-002 独立选定的目标技术组合；全部使用重新实现的隔离验证环境。

## 1. 验证问题

| 编号 | 要验证的机制 | 实验设计 | 通过证据 |
| --- | --- | --- | --- |
| POC-01 | 接收后可靠启动 | 接收事务成功后中止中继，再恢复；丢弃启动回应并重复启动 | 无丢命令、同逻辑执行身份，业务效果不重复 |
| POC-02 | 短事务正式提交 | 在正式对象、修订、候选状态与Outbox各写入点中断 | 全部回滚或全部可见，不存在半个正式事件 |
| POC-03 | 对象/数据库一致性 | 对象上传成功后数据库失败；版本提交后模拟对象不可读 | 暂存对象不伪装完成；不可读证据阻止新提交并可诊断 |
| POC-04 | 并发与代次 | 相同候选重复提交、同事件不同候选竞争、取消与迟到响应竞争 | 唯一回执、修订冲突重检、旧代次不得提交 |
| POC-05 | 工作流历史与升级 | 历史不可用后恢复未完成任务；新Worker读取旧任务包 | 由业务记录恢复，旧业务不重做；不兼容包明确阻止 |
| POC-06 | 模型适配器可观测性 | 正常、限流、拒答、截断、超长、格式错误 | 状态可区分，原始响应/结束原因/版本可追踪 |
| POC-07 | 原文映射能力 | 中文与非BMP文本、重复段落和修订，正文偏移回原件 | 码点索引一致、固定版本可解析、错引用拒绝 |

## 2. 范围与输出

PoC只回答机制是否成立，不能替代事件识别质量和业务验收。未来执行记录实际基础组件与适配器版本、运行参数、失败重现条件及证据引用；本轮不编写脚本、SQL、服务配置或性能压测。

首切片无需为PoC引入向量库、图库或自主Agent。若所选基础组件不能满足持久性或兼容要求，再通过ADR明确替代选型及迁移影响，不能通过降低验收要求解决。

## 3. 进入集成验证的条件

POC-01～10所选切片路径成立；对象存储、业务数据库及编排恢复职责明确；关键调用状态可观测；任务包版本兼容经过确认。时延/吞吐记录实测分布及资源限制，未完成测量不得承诺生产容量。关联[集成验证](../%E5%A5%91%E7%BA%A6%E4%B8%8E%E9%9B%86%E6%88%90%E6%B5%8B%E8%AF%95/L0%E5%A5%91%E7%BA%A6%E4%B8%8E%E9%9B%86%E6%88%90%E9%AA%8C%E8%AF%81%E8%AE%BE%E8%AE%A1.md)、[T08](../../../02-%E4%B8%93%E9%A2%98%E6%8A%80%E6%9C%AF%E6%9E%B6%E6%9E%84/T08-%E9%83%A8%E7%BD%B2%E4%B8%8E%E5%B7%A5%E7%A8%8B%E4%BA%A4%E4%BB%98%E6%9E%B6%E6%9E%84.md)。

## 4. 新增选型验证点

- **POC-08 契约执行一致性**：包含多余字段、字符串数字、缺失字段、超大整数与非BMP字符；HTTP与AI校验不得静默变更输入；响应Schema与序列化方言一致。
- **POC-09 权限与撤销竞争**：OIDC回调校验、对象读取越权、复核撤权与正式提交并发；撤权先提交则正式提交拒绝，反向顺序保留真实审计。
- **POC-10 空环境与故障域**：全新业务库/任务包/原件卷完成五项场景；不引用旧库和旧测试通过记录；模型Worker直接写正式表被数据库权限拒绝。

进入集成验证须同时满足 POC-01～10；本轮这些验证均未执行。
