# L0 模型与证据质量评测设计

> V0.1 · 2026-10-24 · 语义质量与程序可靠性分开评测，尚无实测分数或通过结论。

## 1. 两组实验

**受控响应组**：提供可确定预期的正常/异常模型输出，验证Schema、引用、失败分类、调用门槛和无副作用。它证明系统处理已知输入的机制。

**真实模型组**：冻结模型可见版本、参数、Prompt/Schema、输入样本及方法包，评估抽取、归组、直接关系、增量和评级解释。模型存在随机性，需记录多次运行与差异；不能仅挑选最佳一次。样本数量、重复次数与可接受语义阈值由评审在执行前确定，本稿不虚构达标值。

## 2. 样本与标注

使用[总方案样本](../L0%E6%9C%80%E5%B0%8F%E4%B8%9A%E5%8A%A1%E9%97%AD%E7%8E%AF%E9%AA%8C%E8%AF%81%E6%96%B9%E6%A1%88.md)，扩展不同来源长度、语言形式、时间歧义、同主题多决定、来源纠正、无事件及提示注入。人工标注候选边界、身份决定、允许原文范围和直接关系；有争议样本保留争议标签并双人或授权复核，不制造唯一标准答案。

训练/提示词调试样本与留出评测样本分开登记。任何提示词或方法变更均生成新评测版本，不能将旧结果冒充新任务质量。

## 3. 分任务指标

| 任务 | 观察项 | 关键反例 |
| --- | --- | --- |
| AI-01 | 候选精确率/召回率、切分准确性、无事件识别、时间未知保留 | 多候选压成一个；把背景观点当事件；失败当0 |
| AI-02 | 新建/复用/待定判断、错误归组率、歧义转复核、召回覆盖 | 同主题不同决定误合并；召回故障默认新建 |
| AI-03 | 直接关系正确性、定义复用、合法空结果、伪ID比例 | 把传导推测当直接变量；将发起者必然当Target |
| AI-04 | 七类混淆矩阵、同变化去重、纠正对象准确性 | 来源增加当进展；同一资料独立变化误去重 |
| AI-05 | 范围/期限遵守、证据支持、缺失值处理、用途合理性 | 规则未定编造分值；模型分值直接入库 |

统计前冻结指标单位：AI-01以标注候选为单位，AI-02以身份判断为单位，引用以证据项为单位；既报告分母也报告漏处理/失败数量。复核成本、时延与调用成本作为附加观察，不用它们掩盖错误正式写入。

## 4. 证据专项

检查每个正式引用的segment允许集合、码点范围、quote逐字相等、固定正文摘要、映射与原件摘要、原件可读取及权限。覆盖非BMP字符、全半角、重复句、表格、跨段引用、新旧版本同句不同位置和缺失附件。规范化过程造成的信息损失必须显式记录。

机械定位成功还要人工判断“引文是否支持结论”；真实原文可能只表达预计，模型却写为已实施。此类语义误用不能由字符串匹配判定为通过，必须阻断错误建议或在评测中计错。

## 5. 放行边界

硬约束：无效ID/越权引用/错误版本/失败伪装成功不能进入正式区，观察到一次即阻断该版本放行。语义阈值与自动通过政策尚待批准，初始切片采用显式复核；有人工兜底不等于模型质量免验收。

没有批准量化M方法时，只评测文字评价、空值与程序拒绝非法评分；确定性计算分支记录未覆盖条件。结果写入[待执行报告](../%E6%9E%B6%E6%9E%84%E9%AA%8C%E6%94%B6%E6%8A%A5%E5%91%8A/L0%E6%9C%80%E5%B0%8F%E9%97%AD%E7%8E%AF%E9%AA%8C%E6%94%B6%E6%8A%A5%E5%91%8A_%E5%BE%85%E6%89%A7%E8%A1%8C.md)，保留失败案例及模型原始结构化响应，不要求供应方内部推理过程。
