# L0 故障注入与恢复验证设计

> V0.1 · 2026-10-24 · 故障窗口和预期效果设计，未执行故障注入。

## 1. 通用验收方法

每次记录故障前已提交快照、注入位置、失败状态、恢复动作及恢复后快照。比较当前候选与独立候选的业务差量、回执和修订。恢复不以人工直接改数据库状态“通过”；必须经设计的业务恢复命令。

## 2. 故障窗口矩阵

| 编号 | 注入窗口 | 故障后的正确状态 | 恢复与禁止效果 |
| --- | --- | --- | --- |
| F-01 | 接收事务提交后、工作流启动前 | 命令已接收、启动意图待投递 | 中继恢复确定身份，不丢命令、不另造业务身份 |
| F-02 | 对象写入后、资料版本提交前 | 暂存对象，资料未保存完成 | 校验复用或安全重取；不得向F02交付临时版本 |
| F-03 | 资料保存成功、F02回执丢失 | 资料已保存、交付待确认 | 原消息重投取回原processing_ref |
| F-04 | AI-01超时/截断/结构错误 | 抽取待恢复，candidate_count未知 | 完整重试后接纳一次；禁止NO_EVENT |
| F-05 | AI-02召回或模型失败 | 当前候选待恢复 | 原输入恢复，禁止默认NEW |
| F-06 | AI-03字典读取或模型失败 | 当前候选未通过关系检查 | 禁止伪装合法空关系继续提交 |
| F-07 | AI-04历史读取或模型失败 | 增量未确定 | 禁止默认DUPLICATE或凭空创建进展 |
| F-08 | AI-05模型失败 | 当前候选待恢复 | 禁止以空M/draft掩盖失败；正式对象无新增 |
| F-09 | 正式事务各写入阶段崩溃 | 全部回滚或全部已提交 | 先查commit_key，无半聚合/缺Outbox |
| F-10 | 事务成功、客户端回应丢失 | 已有提交回执与正式修订 | 回原结果，不再AI分析、不新增修订 |
| F-11 | 下游接收成功、发送方漏回执 | 接收端Inbox有效，发送端待确认 | 同message_id重投，接收效果一次 |
| F-12 | 事件并发修订/复核改身份 | 原上下文或审批失效 | 重准备受影响步骤，不强写旧建议 |
| F-13 | 取消或新代次生效后迟到响应 | 迟到建议被替代 | 提交事务拒绝旧代次；已先提交的事实保留 |
| F-14 | 已提交证据对象缺失 | 查询明确不可用，相关新提交暂停 | 恢复原对象并校验，禁止生成替代原文 |
| F-15 | 工作流历史丢失/Worker版本变化 | 业务回执仍可读 | 按业务记录恢复；旧任务包不静默升级 |
| F-16 | 两候选一成功一失败 | 资料partial，成功项不回滚 | 仅恢复失败项，最终完成且无重复效果 |

## 3. 模型故障安全的观察边界

AI-01失败不产生固定候选集合；AI-02～05失败时对应候选在Step 6之前停止。各节点失败都检查Event、EventInformation、EventTarget、三元关系、EventUpdate、EventRating、EventRevision与事件变化Outbox的差量。既有正常候选已提交对象保留，不能要求全库为空。

超时后供应方可能仍返回甚至已完成计算，因此只能承诺业务效果幂等，不能承诺模型恰好调用一次。迟到结果需通过输入摘要、方法包及代次检查；过期响应可归档不可提交。

## 4. 恢复顺序与证据

恢复依赖服务 → 核对固定输入与对象可读性 → 查业务提交/接收回执 → 识别未完成候选或交付 → 发授权恢复命令 → 重检代次/版本 → 验证一次业务效果。若输入或身份改变，创建明确新上下文或授权重算，而非伪装同次技术重试。

每个窗口记录实际对象差量、状态轨迹、操作身份、恢复点、模型尝试、原文引用及消息回执。与[契约验证](../%E5%A5%91%E7%BA%A6%E4%B8%8E%E9%9B%86%E6%88%90%E6%B5%8B%E8%AF%95/L0%E5%A5%91%E7%BA%A6%E4%B8%8E%E9%9B%86%E6%88%90%E9%AA%8C%E8%AF%81%E8%AE%BE%E8%AE%A1.md)共同支持[五项主验收](../L0%E6%9C%80%E5%B0%8F%E4%B8%9A%E5%8A%A1%E9%97%AD%E7%8E%AF%E9%AA%8C%E8%AF%81%E6%96%B9%E6%A1%88.md)，结果登记[报告](../%E6%9E%B6%E6%9E%84%E9%AA%8C%E6%94%B6%E6%8A%A5%E5%91%8A/L0%E6%9C%80%E5%B0%8F%E9%97%AD%E7%8E%AF%E9%AA%8C%E6%94%B6%E6%8A%A5%E5%91%8A_%E5%BE%85%E6%89%A7%E8%A1%8C.md)。
