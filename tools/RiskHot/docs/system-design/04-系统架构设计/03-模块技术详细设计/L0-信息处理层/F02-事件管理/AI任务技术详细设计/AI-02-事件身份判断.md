## 2. 输入与输出

| 方向 | 内容 |
| --- | --- |
| 输入 | Step 2 的 Event 建模建议及关联 Fact、原文证据；程序真实召回的 Event 当前字段及已关联 Fact；固定检索快照、条件、范围、完成状态、覆盖满足与截断标记；规则版本、完整 output_schema 及证据归属表。具体逻辑字段见提示词第 2 节，须由程序适配。 |
| 输出 | 仅 decision、matched_event_id、comparisons、reason、evidence_refs、unresolved_issues。decision=NEW / REUSE / UNRESOLVED；matched_event_id 仅 REUSE 非空且来自输入。comparisons 每项仅 event_id、identity_match（true/false/null）、reason；evidence_refs 为非空完整原文定位对象数组，每项为 material_id、material_version、material_digest、segment_id、start_cp、end_cp、quote；版本是正整数值，身份和摘要为非空字符串，逐项原样引用允许证据。 |
| 运行信封 | 运行/Fact 关联、任务包、输入摘要、有效代次、预算窗口、真实尝试和证据工件由程序记录 |
| 不再使用 | EventRevision、expected_revision、event_update_id；保留资料/定义/方法版本 |

## 3. 校验与交接

程序冻结检索依据及内容摘要、核对允许 ID 和有效身份复核；有效归组建议交 Step 4，Step 7 才创建正式 Event 或写入 fact.event_id 当前归属；按 F02 数据模型 V1.10 同步归属说明与完整性校验，此存储调整尚待工程实施。未批准自动通过政策时须取得有效人工身份复核，模型不输出 requires_review 或免审指令。旧上下文变化须重新比较与复核。

1. 逐项比较主体、具体行动、发生时间、范围、政策/行动标识及已有 Fact。相同主题、相同标题或相同类型不能证明同一事件。
2. 同一行动的宣布、推进、完成可以延续 Event；另一次独立决定或操作另建 Event。
3. NEW/REUSE 均要求检索完成、覆盖满足本次规则且未截断。PARTIAL/FAILED、截断或覆盖不足由程序拦截并恢复；正常空召回仍须候选身份有效且经过核定，不自动创建 Event。结构可读但错误送入模型的检索不完整输入，只允许逐项 null 的防御性 UNRESOLVED，不能用于正式身份核定。
4. comparisons 与输入事件一一对应且顺序一致。REUSE 恰好一项 true、其他全 false；NEW 全 false 或合法空召回；存在 null 或多个 true 时为 UNRESOLVED。NEW 不分配正式 ID，一个 Fact 最多归属一个 Event。
5. 原文有多个独立事件而候选未正确切分时指出问题并回 Step 1，全部比较为 null；实例属性组织错误回 Step 2，不能挂到多个 Event 掩盖切分错误。
6. AI-04 发现身份冲突时返回本步；不能为了保留已做分析而坚持错误归组。
7. 本任务不合并/拆分已有 Event，不批准正式保存，不生成或要求事件修订号。

8. 通过输入 evidence_catalog 逐项校验 material 身份、版本值、内容摘要、分段、码点区间、引文和 Fact/事件归属；候选与各已有事件可以使用不同资料，不能要求所有证据共享候选的资料三字段。调用前、建议接纳及正式保存前复核各资料依据；版本或摘要变化时重建输入并重验比较/复核，不能只换快照标记沿用旧批准。历史 Fact 保留必要引文，但不承诺历史全文可回放；必要证据无法核验先恢复或复核，不混用新正文与旧区间。比较理由引用输出 evidence_refs 的数组下标；确定的 true/false 须具双方身份依据，不能借用其他召回事件的证据。null 可以引用已知一侧并说明缺口；候选有效证据不可读则由程序先恢复输入。

业务关联采用独立关系表。本任务仅提出身份建议，不提出当前字段更新或关系写入方案；不得直接写库、生成审批或绕过校验。

## 4. 执行与恢复

IO Worker 准备固定输入，模型 Worker 执行受预算限制的调用，IO Worker 校验并接纳；Workflow 负责推进。模型等待和人工等待期间不持数据库锁。

响应格式、证据和允许引用先严格校验，语义歧义再交复核。输入或归属变化导致旧建议失效；恢复不得替换输入摘要或清零预算。尝试、原响应、校验、复核和拒绝原因保留审计。

## 5. 验证与发布边界

契约测试覆盖正常结果、合法空值、伪造引用、截断/超时、权限变化、同一操作重试及过期批准。业务样本验证须覆盖本任务处理要求，不能用结构校验代替语义正确性。
