# AI-04 事件增量判定技术详细设计

> V0.2 · 2026-10-24 · 对应[L0 §6.1.4](../../../../../02-%E4%B8%9A%E5%8A%A1%E6%9E%B6%E6%9E%84%E4%B8%8E%E9%A2%86%E5%9F%9F%E8%AE%BE%E8%AE%A1/RiskHot_L0_%E4%BF%A1%E6%81%AF%E5%A4%84%E7%90%86%E5%B1%82_%E4%B8%9A%E5%8A%A1%E6%9E%B6%E6%9E%84%E4%B8%8E%E9%A2%86%E5%9F%9F%E8%AE%BE%E8%AE%A1V1.0.md)与[F02 Step 4](../../../../../03-%E7%B3%BB%E7%BB%9F%E5%8A%9F%E8%83%BD%E6%9E%B6%E6%9E%84/F02%20%E4%BA%8B%E4%BB%B6%E7%AE%A1%E7%90%86%E6%A8%A1%E5%9D%97%E5%8A%9F%E8%83%BD%E8%AE%BE%E8%AE%A1%20V1.0.md)。模型给出增量建议，程序决定实际变化身份与写入动作。

## 1. 程序准备

输入已确认EventContextRef、当前资料固定版本及原文、相关关系建议；对既有事件提供expected_revision、历史EventUpdate、资料版本、来源关系与证据。新事件明确历史为空的原因是“已确认新建”，不把历史查询失败当空历史。

历史超过上下文预算时程序选择可解释范围并记录检索清单；影响判定的关键历史缺失则待处理。已知修订、时间和状态必须显式呈现，不能让模型猜测。

## 2. 输出建议与程序动作

| 分类 | 建议应包含 | 程序处理 |
| --- | --- | --- |
| NEW_EVENT | 首条事实、状态与证据 | 身份决定须为新建；准备初始更新 |
| EVENT_PROGRESS | 进展差异、前后状态、适用时间 | 比较实际变化，准备必要更新 |
| MATERIAL_ADDITION | 新增实质内容及历史差异 | 核定变化身份，避免多来源重复更新 |
| SOURCE_ADDITION | 新资料/版本与来源角色、无实质变化理由 | 只准备来源与证据，不生成EventUpdate |
| DUPLICATE | 已有变化/来源对应引用、重复理由 | 无业务变化处理回执；不重评、不通知 |
| CORRECTION | 新旧差异、被纠正记录/资料、证据 | 追加纠正关系与更新，保留历史 |
| UNRESOLVED | 冲突与缺失依据 | 待复核，不进入正式提交 |

一个候选可包含同一事件的多项独立变化；建议结构保留changes数组，各项分别带差异、适用时间、证据和被替代引用。程序逐项核定business_change_key，不将候选级分类当成“只能有一条EventUpdate”。候选的适用变化项在Step 6同事务提交。

程序要求模型引用允许的历史ID；模型不得分配event_update_id、business_change_key或记录时间。处理规则修复不冒充来源CORRECTION，应记录授权修复原因与旧结果关联。

## 3. 实际变化去重

程序结合身份、语义变化、作用对象/范围、适用时间及历史证据确认变化单元，再分配或复用business_change_key。相同变化的两篇报道应复用变化身份；同一篇资料的两项独立变化不能因类型相同被合并。语义比较有歧义则复核，不把文本哈希当事实身份。

既有事件修订号在提交时再检查；另一候选已先写入时需更新历史、重查变化和评价依据。确认无新变化可转无变化回执，不能强制写一条“重试更新”。

## 4. 交接与异常

确认新事件或有效更新后，程序判断Step 5是否初评/复评；来源增加和重复直达Step 6。若发现独立新决定或身份冲突，返回Step 2，旧关系/评级建议失效。状态前后不合法、未来时间/未知时间被混填、纠正对象不属于当前事件均转复核。

模型失败或历史读取失败不能输出默认DUPLICATE。保存有效的增量建议、比较快照、差异证据和下一步决定；正式历史只在Step 6写入。

## 5. 验证

覆盖七类增量、同变化多来源、同资料多变化、来源增加不建更新、纯重复无通知、纠正保留旧记录、并发修订及历史故障。期望数据库效果见[F02模块设计](../%E6%A8%A1%E5%9D%97%E6%8A%80%E6%9C%AF%E8%AF%A6%E7%BB%86%E8%AE%BE%E8%AE%A1.md)，故障注入见[恢复方案](../../../../05-%E6%9E%B6%E6%9E%84%E6%B2%BB%E7%90%86%E4%B8%8E%E9%AA%8C%E8%AF%81/%E6%9E%B6%E6%9E%84%E9%AA%8C%E8%AF%81/%E6%95%85%E9%9A%9C%E6%81%A2%E5%A4%8D%E9%AA%8C%E8%AF%81/L0%E6%95%85%E9%9A%9C%E6%B3%A8%E5%85%A5%E4%B8%8E%E6%81%A2%E5%A4%8D%E9%AA%8C%E8%AF%81%E8%AE%BE%E8%AE%A1.md)。
