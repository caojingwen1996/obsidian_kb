# Codex 订阅执行、后台调度与安静提醒设计

> 2026-10-24 · 用户已明确选择此前展示的本地 Codex 订阅方案并要求实施、自动调度、异常提醒及一次真实闭环。

## 目标与继承边界

承接[[tools/RiskHot/docs/superpowers/specs/2026-10-24-source-to-candidates-design|来源候选设计]]与[[tools/RiskHot/docs/superpowers/specs/2026-10-24-all-sources-design|全部来源设计]]，保留固定资料版本、AI-01 EXTRACTION_ONLY、集合校验、原文证据、幂等、角色隔离、Temporal 与持久预算。真实闭环须包含实际来源、订阅模型响应、候选校验及持久查询；不代表正式事件或整个 L0 已完成。

## 方案与构建者选择

用户已选择本机 Codex 命令执行，沿用 ChatGPT 登录。现有 HTTP API 模式保留；应用直接集成 Sign in with ChatGPT 需要新增 OAuth 生命周期，本轮不采用。调用仅传固定资料和任务规则；在独立临时工作目录运行，忽略用户配置，关闭 shell、MCP、网页搜索、插件及子代理，不传数据库、模型 API 密钥或业务身份密码。只读、非交互、结构输出，限时、限制输出大小，检查进程成功、turn.completed 与唯一最终消息；保留响应工件。登录失效、额度不足、进程异常与无效结果明确分流。

本轮默认模型由构建者选 gpt-6.1-sol，需真实调用验证；单次最多 150 秒，总预算仍 3 次/10 分钟，模型进程串行。通过 CODEX_EXECUTABLE 显式配置命令路径；订阅模式固定 endpoint=codex://local，不把订阅登录凭据转换为 API 密钥。

## 调度与恢复

构建者默认：已启用且连接器 ready 的来源每小时检查最新 1 条；后台每 30 秒推进，最多 2 条在途采集/抽取。计划、应运行时间、幂等键、操作引用和运行结果保存在 PostgreSQL；同一计划时刻只生成一份命令，重启恢复未提交命令，不补跑休眠期间每个小时。来源停用后不再提交或恢复。

已有 MODEL_NOT_CONFIGURED 且尚未冻结输入的处理可自动续接；其他已冻结配置不被更换。技术失败在有限策略内恢复，结构/证据错误保持复核。订阅额度不足或登录失效暂停新的模型工作并提醒；后台定期检查登录，额度不足至少退避 6 小时。预算耗尽后原有人工恢复仍有效；新增显式的常驻恢复授权仅用于订阅临时网络/额度故障，每个 processing 每 24 小时最多开 1 个恢复窗口，累计记录不清零，复核/权限/来源错误不自动恢复。自动恢复由专用调度身份完成并写审计。

## 提醒与运行

异常记录按稳定问题键去重；持续相同异常不重复通知，恢复后关闭，重新发生可再次提醒。正常开始/完成/无新内容均不发通知。使用 macOS 本机系统通知，不发送邮件或第三方消息；通知交付失败留记录并有限重试。API 与命令提供计划、最近运行、未解除异常和通知交付状态。既有未接通的 14 条来源仍按已知状态展示，用户已接受的缺地址不造成循环提醒。

本机 LaunchAgent 承载现有 supervisor，登录后启动、异常退出重启，日志私有；电脑休眠/离线时不能执行，唤醒后按持久计划续接。安装和卸载命令可复现，只管理当前工作树专属服务。数据库/Temporal/身份服务沿用现有独立 Compose 环境。

## 验收

- 受控进程测试证明订阅身份检查、环境隔离、成功/额度/登录/截断/超时分流；既有证据和全量测试通过。
- 真实 PostgreSQL 测试证明同一时刻不重复、并发调度互斥、暂停来源、重启续接、安静成功、异常只提醒一次与恢复后复发。
- 真实央行公告从计划触发，经真实抓取、固定版本、订阅抽取、校验到候选入库；重复运行复用版本与候选，逐条检查引文和时间。
- 实际启动常驻服务，检查计划和通知交付能力；仅声明实际取得证据的范围。
