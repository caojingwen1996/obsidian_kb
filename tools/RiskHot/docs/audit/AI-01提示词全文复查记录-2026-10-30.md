# AI-01 提示词全文复查记录（2026-10-30）

> 记录迁自[[tools/RiskHot/docs/system-design/03-系统功能架构/AI任务与提示词/AI-01 候选事件提取|AI-01 候选事件提取提示词]]原第 4.1 节。以下为 2026-10-30 的文档复查结果，不代表模型或运行验收通过。


依据为[[tools/RiskHot/docs/system-design/03-系统功能架构/F02 事件管理模块功能设计 V1.0#4.2.4 核心处理规则|F02 抽取规则]]、[[tools/RiskHot/docs/system-design/03-系统功能架构/F02 事件管理模块功能设计 V1.0#4.4.4 核心处理规则|Target 确定规则]]及[[tools/RiskHot/docs/system-design/04-系统架构设计/01-数据模型与存储设计/F02事件管理模块数据模型与存储设计|F02 数据模型]]。本轮修正文档内业务语义，未修改其他 AI 任务或运行实现；结构校验不代替模型评测。

**已修正的语义问题**：Object 与 Target 线索的作用对象口径；多对象和身份/类型/范围待定的保留；持续跟踪价值不能成为准入条件；主文当前动作与引用背景、可核查官方表态与预测内容的区别；否定、例外及冲突信息的保留；统计发布日、相对时间及季度/范围时间口径；标题不单独替代正文证据；全资料覆盖与整批接纳边界；AI-02 只提供身份建议。

**三字段命名已统一**：subject 为行为主体文字，action 为具体行动文字，object 为作用对象文字；输出示例、字段约束与规则正文采用相同命名，action 不再依赖分类字典。

**material 命名已统一**：资料身份、版本值和内容摘要在输入、输出顶层、证据及所有示例中分别使用 material_id、material_version、material_digest；无独立资料版本 ID。

**仍待对齐的机器契约**：以下差异是发布阻断项，不能以提示词字段优先于已确认业务规则，也不能自动改写现行接口。

| 差异 | 已确认要求与待完成事项 |
| --- | --- |
| material 契约运行适配 | 本文输入、输出顶层及每项证据已统一 material_id、material_version、material_digest。程序分别从已保存 material 的 id、version、content_digest 提供这些值；版本是正整数值，摘要按公共内容契约提供。配套 Schema、任务包及读入/接纳校验仍须实现并验证，不重新建立独立资料版本实体。 |
| 三字段统一后的存储适配 | 本草案已统一 subject/action/object，subject 与 action 均为事实文字，可按同义字段映射到 Fact；object 为作用对象文字。Fact 当前没有独立 object 列，其内容及 target_clues 仍须在运行结果、description 和证据中完整保留。分类、关键事实数值及辅助时间字段的存储映射仍待适配，不因提示词字段统一自动新增数据库列。 |
| 覆盖说明与缺口载体 | F02 要求单一/多项/不明范围、覆盖及缺口说明；本草案不输出独立覆盖字段或 warnings。程序的分段覆盖检查不能代替模型的语义范围判断，须在配套任务契约明确判断结果的记录与校验载体，再验证完整覆盖；不能宣称当前包装已经满足。 |
| 版本与发布 | 本文件仍为未发布 V0.3 草案；须使提示词、机器 Schema、字典、字段映射与任务包配套版本化，并完成契约测试和实际样本评测。本文 JSON 包装不得直接当成已批准的新接口。 |

**语义验收清单（文档逐项对照，未调用模型）**：

| 场景 | 预期结果 |
| --- | --- |
| 企业获授合同，明确两家受影响供应商，其中一家只有简称、类型字典缺项 | 抽取实际合同事件；逐项保留两家对象称谓及证据，未知字段留空说明，不因非宏观或无正式身份丢弃。 |
| 调整某项费率，但原文未说明受影响对象 | 费率变化进入事实/数值，Target 线索可空；不凭常识补造企业或市场，也不因无 Target 丢弃事件。 |
| 主文回应旧公告，与纯转述旧公告对照 | 前者提取回应，旧公告作背景；后者可提取原行动，不制造转发事件或套用转载日期。 |
| 可核查官方发言含未来判断，与普通作者预测对照 | 前者可提取实际表态并保留其预测性质；后者不把被预测行动当已发生，也不机械包装成发表事件。 |
| 数据原始发布日早于报道日，另有“下季度实施”安排 | 使用有依据的数据实际发布日；季度/预计实施时间不填实际 event_time，保留描述和原表达。 |
| 同一行动金额在正文与附件中冲突，另有脚注例外 | 保留双方陈述及证据和例外，不选择其一、不丢弃冲突；无法判明的语义交复核。 |
| 标题称全面生效，正文仅说明试点或预告 | 按正文限定抽取；标题即使列入有效分段也不能独立支撑全面生效。 |
| 必要附件缺失或完整响应中一项证据无效 | 待恢复/修正，本次集合暂不接纳；不返回正常零候选或删掉坏条目冒充完整成功。 |
