## 已成立的实现

- FULL_EVENT 与原 EXTRACTION_ONLY 分开，候选集合及启动意图同事务固定；零候选不会制造事件。
- NEW 提交在集合锁内验证 epoch，REUSE 检查预期修订；提交冲突持久退回归组，保留旧记录。两个旧快照 NEW 不能直接各自新增事件，这一核心门槛成立。
- 最终提交读取不可变 CommitProposal，校验步骤摘要及两阶段审批；事件、更新、评级、修订、回执和消息处于一个事务，跨事件证据连接表有复合外键。
- M 保留 null/draft，缺定义没有降格为空字典。交付实际读取固定文件并持久写 Inbox；原 message_id 重投能返回同一回执。
- 已有测试覆盖正常闭环、事务回滚、旧切片兼容、预算及模型无正式写权限。真实验收报告明确仍未通过，没有以测试种子冒充真实业务审批。
