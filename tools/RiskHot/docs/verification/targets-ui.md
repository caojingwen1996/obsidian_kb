# 观测对象页面与导航验证

> 2026-11-05 · 实际页面已更新。新增浏览/查询/详情与人工新建编辑，正式库保持真实空目录。

## 输入与结果

依据用户提供的侧栏截图和三项要求：模块加图标、“全部”改“全部动态”、参考事件列表设计观测对象页面；用户随后确认“同时加入新建和编辑”。继承[[tools/RiskHot/docs/system-design/06产品UI原型设计/DESIGN|统一视觉规范]]，详细范围见[[tools/RiskHot/docs/system-design/06产品UI原型设计/观测对象浏览与维护页面设计|页面设计]]和[[tools/RiskHot/docs/superpowers/plans/2026-11-05-观测对象页面与导航|实施计划]]。

- 四页统一四个功能入口与线性SVG，内容/配置分组不变，移动端全部入口可达。
- `/targets` 提供名称/别名搜索、一级分类与状态组合筛选、20条分页；详情保留完整范围、别名、地区、版本及关联动态。
- 新建/编辑使用独立表单，复用 `read` 与 `event_review` 权限、操作回执及审计。有效修改递增定义版本，历史Event快照不变。完全同名/地区/范围重复建档会拒绝，同名不同范围仍可创建，不自动合并身份。
- 关联数量与明细均按全部来源检查权限，混合来源只要一处无权读取就不展示该事件。
- 本机API已重启加载新路由，页面及实际接口返回200；当前正式Target为0，具备维护权限，可直接新建。没有向正式库导入演示对象。

入口：[观测对象](http://localhost:18081/targets)。本次未修改采集、模型执行、任务队列及其他业务设计。

## Impeccable质量检查

检查结论：视觉继承成立，正文以对象范围与关联事件为主，未添加装饰性指标或模拟统计。按可验证范围评为18/20：无障碍3、性能3、配色4、响应式4、实现一致性4；没有确认的P0/P1问题。

- 正文对白色背景对比度12.99，次级文字5.97，主按钮文字7.73，导航文字6.85，均超过正文4.5要求。
- 实测标题20px/正文14px，手机输入16px，手机导航触达高度至少44px；沿用已有绿色/暖灰色标记与焦点样式。
- 表单采用原生label/input/select/button，错误带alert并获得焦点；SVG图标为装饰性隐藏。空/加载/错误/权限/保存中/未知结果状态分别呈现。
- 机械检测器返回一项 `pipeline.html` 字号警告：工具无法将 `/m1`、`/pipeline` 运行路由解析到文件，回落为默认16px，导致字号判断失真。实际CSS与浏览器渲染有独立层级，故记录为误报；没有修改路由或复制样式迎合工具。原始结果及评估保存在 `design-audit.json`。
- 本轮没有大规模目录负载基准，也未在实体手机或读屏器上实测；响应式验证使用独立Chromium模拟视口。
