## 工程接入后的实际差异

以下差异记录实际实现，不回写成全局视觉规则，也不把原型能力描述直接复制成工程验收结论。

| 方面 | 实际实现及证据 | 文档处理 |
| --- | --- | --- |
| 导航与刷新 | 导航使用实际 `/m4`、`/targets`、`/events`、`/m1`、`/pipeline` 路由；“刷新状态”重新读取服务。无原型角色或场景切换菜单。 | 原型的离线菜单、内存刷新边界不再适用。 |
| 配置历史 | 定义组件补齐名称、上级目录标识、排序、配置状态，并同时用于当前定义及各历史快照；版本历史按版本、说明、时间和操作者展开。 | 当前定义截图可见新增字段；历史字段完整性另由浏览器结果中的对应检查证明，不能只凭默认页截图判断历史通过。 |
| 映射核对 | 已核定记录及撤销窗口展示采用的 Target 名称、身份标识、范围、辖区，使用采用快照；核定窗口对照当前配置与候选事件对象。 | 延续“先核对身份与范围”的方向；本组十二张截图不包含映射窗口，其证据来自代码抽样及已有浏览器检查。 |
| 添加观察 | 选择器新增独立目录区域；桌面目录宽 190px，右侧列表与范围预览并排；900px 以下目录移至内容上方，720px 以下预览与列表纵排。 | 是已确认构图的局部扩展。目录仅用于查找，结果中的目录复选框禁用并显示原因。 |
| 选择数量 | 标题下明确“一次最多选择100项”；跨页选择计数保留，第101项被拒绝并提示。过期选择需核对最新定义后显式重选。 | 属于真实提交约束及反馈，不增加新的视觉样式。 |
| 模态尺寸 | 普通模态实际宽 640px，宽选择器 1040px；手机最大宽为视口减 20px，最大高为动态视口减 20px，圆角 12px。 | 普通模态及边距与原型记录的 620px 等值不同，按实际样式记录，不覆盖原型历史事实。 |

## 可访问性与真实局限

代码可确认：有跳到主要内容入口、显式字段标签、隐藏装饰 SVG、状态文字、可见焦点、原生 dialog、错误警报及忙碌状态；配置资料页签实现左右方向键、Home、End；减少动态效果偏好关闭现有按钮和树箭头过渡。

本次没有执行屏幕阅读器、跨浏览器、全部键盘路径、缩放或高对比模式的完整审计，不能宣布 WCAG 合规。原型中的“手机选择后聚焦详情”和“关闭后完整焦点恢复”等描述不能自动作为工程事实：本次只核对了跳转入口与资料页签的显式焦点代码，动态重绘后的完整焦点连续性仍需专项验证。

既有局部漂移继续保留：移动端导航底部说明仍占据空间，目录状态有11px小字，上级目录显示原始标识并换行；目录展开符使用文本字符。这些是本轮实物事实，不将小字、原始标识展示或字符图标确立为未来设计规范。原型局部 DESIGN 已记录的上级导航与留白条款漂移，本次也未扩大修订。

本文件仅完成页面与规范的交接核对；全量工程回归、真实运行库迁移、部署、完整权限和辅助技术验收分别以对应执行报告为准。
