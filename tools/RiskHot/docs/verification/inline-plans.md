# 信源列表行内计划操作验证

> 历史验证：2026-10-29早期实现曾在目录及计划列表同时提供控件。按用户最新要求，目录已移除全部任务内容，行内控件仅保留在任务计划页；现行边界及验证见[[tools/RiskHot/docs/verification/source-catalog-boundary|目录与任务边界验证]]。

## 实现

- “任务计划”列展示已启用／已暂停及对应的启用计划／暂停计划按钮，和操作列中的启用信源／停用信源明确区分。
- “执行周期”列提供数值、分钟／小时／天和保存周期；显示已保存周期，范围仍为1分钟至1天。输入不会自动提交。
- 启用／暂停沿用已保存周期，不提交尚未保存的输入；自己的成功切换会更新草稿的并发依据。多个标签分组中的同一信源共享周期草稿。
- 复用PATCH /api/v1/l0/schedules/:key和expected_updated_at。并发冲突不覆盖其他修改，行内提供重新读取；结果未知保留原幂等命令，阻止其他写操作覆盖，原键重放后同步列表。
- 只读账号展示周期和状态，无写入控件；未读取计划时不伪造默认状态。未改后台调度规则、数据库或实际计划值。

修改文件：[[tools/RiskHot/src/web/current-app.js|目录与计划交互]]、[[tools/RiskHot/src/web/styles.css|行内控件布局]]、[[tools/RiskHot/src/tests/ingestion-migration.e2e.ts|浏览器用例]]。
