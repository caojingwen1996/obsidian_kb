## 运行与限制

专项命令为 `npm run test:pipeline:f02`，使用已配置的 `SOURCE_BROWSER_EXECUTABLE` 和 `PLAYWRIGHT_MODULE`。默认启动临时只读 Web 服务；设置 `PIPELINE_VERIFY_ORIGIN=http://127.0.0.1:18081` 核对实际服务。浏览器限定独立 Chrome for Testing/Chromium，临时数据目录在 finally 中随浏览器关闭后清理。

本次页面反映已审核业务设计，不代表八步业务执行链路、金融意义规则、AI任务契约和数据库迁移已完成。上游提示词和来源文档的具体发布状态继续按各自正文管理。
