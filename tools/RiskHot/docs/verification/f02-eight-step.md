## 4. 工程裁定与成本

1. 原工作区main及已有未提交资料保留；代码在独立worktree分支实施。应用到原运行目录需要正常的分支集成和发布步骤。
2. S01 task_runs新增input_payload，保存小型不可变命令/引用；否则队列清理后F01输入只能依赖旧Relay。禁止正文和凭据，摘要变化拒绝；成本为一项持久运行字段。
3. 新包输入按o200k_base计算24000 token并限制96000字节，js-tiktoken 1.0.21固定；旧包保留原字节规则。原因是完整AI-01提示词本身31KB，旧24000字节限制会拒绝合法中文任务。该编码是工程预算口径，不等同所有供应模型的计费口径。
4. 首批只推进NEW与text-draft-v1；REUSE明确等待B批，不伪装NEW；用途缺规则显式等待，不由工程代发布。成本是首批不覆盖全部124项业务验收。
5. 实施发生共享文件依赖，因此本轮统一整合验证后提交；未按任务分别部署或切换半套服务。
