## 分类依据与口径

依据[[tools/RiskHot/src/data/source-catalog.js|信源登记范围]]、[[tools/RiskHot/src/data/source-connections.json|当前接入范围]]和[[wiki_bbxm/concepts/冰冰小美-indicator-金融信息（todo整理)|金融信息三大属性定义]]进行人工语义分类。本次未重新核验外部网站，分类是基于已登记范围的研究用途判断，不代表当前每次抓取均包含对应数据，也不代表连接器已经可用。

- 钱的数量：货币、信用、融资、现金及可用资金规模；不同资金池不直接相加。
- 钱的价格：利率、收益率、融资成本和利率预期。统计局的通胀与增长信息仅作间接背景，物价指数不是融资价格。
- 钱的流向：资金提供者、接收者、用途、配置及跨境行为；政策或意愿与已发生流量分别判断。
- 专用利率入口按具体序列分类。例如H.15、FRED当前DPRIME仅为价格；不因平台数据广泛而全部打标。
- 综合媒体的三类标签代表检索范围；博主标签代表已有材料覆盖的研究主题，不能使观点变成一手证据。

博主补充依据：[[wiki_bbxm/timelines/冰冰小美-利率与流动性判断演化|冰冰小美利率与流动性时间线]]和[[wiki_laomujiang/timelines/买股票的老木匠-利率与流动性判断演化|老木匠利率与流动性时间线]]，只用于识别主题覆盖，不采信其中行情数字或政策转述为独立核实事实。美股C姐、墅姐的现有档案不足以确定属性，因此暂不赋值。
