# 专题研究实际目录缺分类修复

> 2026-10-29 · 三个一级分组已恢复固定显示；正式分类数据仍缺失，本次没有将演示值写入实际档案。

## 问题与核实

用户截图表明，虽然“专题研究”按钮已恢复，实际页面仍是40条平铺列表。此前浏览器用例人为提供了分类，只验证非空分支，没有覆盖实际库字段全空的情况，故先前恢复声明不完整。

1. 实际m1.sources的40条metadata均没有dims、levels、priority、frequency字段。
2. 重建前备份同样40条、四字段覆盖均为0。未发现分类字段因本次重建丢失的证据；本机信源原字段保持核对结果。
3. 旧原型通过source-demo.js提供9条演示分类，实际目录不读取该文件。它不是已确认的正式分类来源，不能自动当作运行档案导入。
4. 旧tree逻辑将连续缺失的层级全部压平，因而“专题研究”与全部列表外观相同；分类代码也未统一翻译为中文。

## 修复

- 专题研究固定保留“钱的数量、钱的价格、钱的流向”，空组显示0并提供空状态。
- 未维护金融属性的来源单独放入“待分类信源”，显示数量及编辑档案指引，不能被压平成普通研究列表。
- 有实际分类时继续按观察层级、关注优先级展开。代码QUANTITY/PRICE/FLOW、MACRO/MESO/MICRO、CORE/HIGH/NORMAL均显示中文；代码和中文别名合并去重。
- 其他明确维护的金融属性仍可显示，不静默丢失已有标签；不推测或回填正式分类。
- 档案编辑增加金融属性、观察层级和优先级的填写示例，仍允许未确认内容留空。
