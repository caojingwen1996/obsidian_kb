# 冰冰小美-concept-亏钱效应

## 一句话定义

一种市场状态，市场正在变得“买什么都容易亏”，而且这种亏损会从局部扩散，形成卖出—下跌—恐慌—继续卖出的负循环。

## 核心内涵

### WHY：在体系中的意义

在情绪交易总篇里把亏钱效应定为判断情绪位置的唯一尺度：

**「不管如何定义冰点，高潮点，都是以亏钱效应为节点。恐慌的极致，贪婪的极致，能够看到的都是市场亏损。故而，情绪位置首先要确认亏钱效应。」**

```
亏钱效应在情绪节点中的角色：

冰点确认 → 整个市场没有人挣钱 → 亏钱效应达到极致 → 恐慌＞贪婪
转势确认 → 亏钱效应开始修复 → 转势板出现 → 信心提振
高潮确认 → 做空的个股很少 → 亏钱效应消失 → 贪婪＞恐慌
退潮确认 → 亏钱效应重新出现 → 情绪标倒塌 → 亏钱扩散
```


### WHAT：观察亏钱效应的四个维度

亏钱效应的三种形态：A杀、趋势坏、闪崩

### 1. 结果：参与者是否真实亏钱

这是必选维度，重点观察：

- 昨日强势股次日是否普遍负溢价；
- 涨停、冲高、追涨后是否容易被套；
- 低吸后是否没有反弹，甚至继续创新低；
- 高开是否经常低走；
- 买入后是否很难在T+1安全退出。

### 2. 持续性：亏损是否重复发生

单只股票一次大跌，只是亏损事件；只有重复出现，才构成亏钱效应：

- 同一模式连续失败；
- 同一板块连续两日以上负反馈；
- 当日冲高回落，次日继续低开；
- 反弹后很快跌回起点；
- 昨天亏损的人今天继续承受亏损。

### 3. 扩散性：亏损是否向外传导

|   |   |   |
|---|---|---|
|**亏钱范围**|下跌个股数量/比例|400上涨/4000下跌=大面积亏钱效应，接近冰点|

观察传导路径：

```
高位股失败
→ 中位股、跟风股补跌
→ 板块接力意愿下降
→ 资金切换其他题材
→ 新题材也冲高回落
→ 全市场风险偏好下降
```

轮动越快、套利越多、冲高回落越频繁，说明流动性被分散，持续挣钱效应消失，亏钱效应容易增强。
### 4. 带动性：表面强势能否形成挣钱效应

真正的情绪标需要：

- 带动同题材上涨；
- 提高市场接力意愿；
- 产生次日持续溢价；
- 提振板块或指数信心。

如果只是单股逆势涨停，没有跟风、没有扩散、没有次日溢价，就更可能是孤立报团或吸引接盘，而不是亏钱效应转弱。冰冰小美在恒为科技案例中特别区分了“人气关注”和“市场认可”。[恒为科技亏钱效应案例](https://xueqiu.com/7143769715/325953558)
